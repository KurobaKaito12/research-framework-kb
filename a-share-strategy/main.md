# A股权益投资策略研判框架

本skill封装的是一套**自上而下**的A股策略研判方法论，源自策略研究框架（2025版）。核心理念是：用一套可证伪、可迭代的指标体系，把"A股怎么看"这个模糊问题拆成大势、风格、行业三层可操作的研判。

## 何时启用本skill

只要用户的问题涉及A股市场判断、风格选择、行业比较，就应当启用。常见触发场景：

- "现在A股怎么看 / 大盘还能涨吗 / 是不是见底了"
- "应该买大盘还是小盘 / 红利股还是成长股"
- "哪些行业景气度好 / 哪些行业值得配置"
- "怎么看XX行业 / XX板块还能不能买"
- "市场什么时候反转 / 怎么判断牛熊切换"
- 涉及 ERP、库存周期、产能周期、剩余流动性、M1-M2剪刀差、补库、出清、景气投资、性价比等任何策略概念

## 核心心法（先记住三句话）

> **大势**：长期看周期，中期看基本面，短期看资金面。
> **风格**：大小盘看流动性、看美元；价值成长看贴现率、看ERP。
> **行业**：需求侧找补库，供给侧找出清，中观找高频，最后看性价比。

## 工作流程

### 第一步：识别问题落在哪一层

| 用户问的是 | 主导层级 | 该读哪个reference |
|---|---|---|
| 大盘走势 / 牛熊 / 估值 / 底部信号 | 大势 | `ref-01-trend.md` |
| 大小盘 / 价值成长 / 红利白马 / 风格切换 | 风格 | `ref-02-style.md` |
| 行业选择 / 板块轮动 / 景气投资 / 配置建议 | 行业 | `ref-03-industry.md` |
| 综合性问题（"现在该怎么投"） | 三层都要 | 全读，按决策树串联 |

**关键**：不要绕过reference凭印象作答。这套框架的价值在于**每个判断都有具体指标和阈值**，凭印象会丢失精度。读完对应reference再回答。

### 第二步：按框架拆解

**回答"大势"类问题时**，三个子维度都要覆盖：
- 方向（信用周期、美元周期、极值信号）
- 空间（DDM锚定的合理估值）
- 节奏（日历效应、ERP箱体）

**回答"风格"类问题时**，明确落到四象限的哪一格：
- 大盘价值（红利）/ 大盘成长（白马）/ 中小盘价值（顺周期）/ 小盘成长（主题）

**回答"行业"类问题时**，按决策树走：
1. 当前大势是否趋势下行？是 → 防御（红利/大盘价值）
2. 若非下行，是否有突出的风格特征？
3. 哪些行业基本面有积极边际变化？（补库/出清/景气）
4. 哪些行业不拥挤？（性价比筛选）

### 第三步：标注证据等级和盲点

每个结论后面，明确：
- **支持指标**：依据的具体指标和当前读数
- **反向风险**：什么情况下结论会被推翻
- **指标盲区**：哪些指标在当前宏观范式下可能失效

### 第四步：避免几个常见陷阱

1. **不要把模糊的方向预测包装成精确的点位预测**。
2. **不要孤立看单个指标**。信号集群才有意义——多个一起亮才是大底信号。
3. **不要忽略量化方法的边界**。
4. **景气投资本身可能是Smart Beta**。

## 关于数据

本skill**不负责取数**。当框架需要某个指标时，按优先级处理：
1. 用户已经提供了数据 → 直接套框架做判断
2. 用户未提供 → 明确告知需要的指标名+数据源
3. 如果环境有取数能力，可以建议调用
