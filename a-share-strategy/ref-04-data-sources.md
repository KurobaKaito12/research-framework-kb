# 关键指标的数据源与口径

本文件列出框架中所有关键指标的常用数据源、计算口径、更新频率。当框架需要某个指标但用户未提供时，可据此告诉用户去哪里取数。

注意：本skill不负责取数。但如果环境中存在取数能力（例如 tushare 数据源、联网搜索、akshare 资讯等），可建议用户调用。

## 三、行业比较用指标

### 3.1 微观财报指标（季度）

财报数据来源：Wind、iFind、tushare、东方财富 Choice

| 指标 | 计算方式 | 用途 |
|---|---|---|
| 存货同比 | 当期存货 / 去年同期 - 1 | 库存周期 |
| 营收同比 | 当期收入 / 去年同期 - 1 | 库存周期 |
| 存货周转率 | 营业成本 / 平均存货 | 补库意愿 |
| 偿债现金流 | 现金流量表"偿还债务支付的现金" | 补库约束 |
| 补库现金流 | 现金流量表"购买商品、接受劳务支付的现金" | 补库迹象 |
| 固定资产周转率 | 营业收入 / 平均固定资产净值 | 产能利用率代理 |
| 资本开支 | 现金流量表"购建固定资产、无形资产和其他长期资产支付的现金" | 产能扩张 |
| 资本开支/营收 | — | 产能周期位置 |
| 资本开支/折旧摊销 | — | 供给出清（< 1 为出清信号） |
| 收入vs固定资产增速剪刀差 | 营业收入同比 - 固定资产同比 | 产能周期底部信号（接近交汇=底部，走阔=周转率上行） |
| 合同负债+预收账款 | 资产负债表 | 军工/航空装备前瞻 |
| 每股收入 SPS | 营业收入 / 总股本 | 产能出清筛选辅助 |

**重要口径说明**：
- 默认基于中证800成分股做行业聚合，避免小盘股噪音
- 同比变化用 z-score 标准化更利于跨行业比较
- 一季报数据 4月底披露完毕，年报数据 4月底披露完毕，半年报 8月底，三季报 10月底

### 3.2 中观高频指标

按行业类别分别看：

**周期类（来源：Wind、Bloomberg、海关、产业在线）**
- 石油石化：EIA/IEA全球原油供需平衡
- 煤炭：CCTD港口库存、电厂可用天数
- 有色：LME库存、TC加工费、CFTC净多头
- 钢铁：Mysteel铁水产量、库存
- 玻璃/水泥：国家统计局房屋竣工面积

**制造类（来源：日本经产省、海关、Wind）**
- 自动化设备：日本机器人工业协会订单数据
- 通用设备：日本机床工业协会订单
- 光伏/风电：招标量（公开招标平台、Wind汇总）
- 军工：上市公司合同负债（财报）

**TMT类（来源：行业协会、Bloomberg）**
- PCB：北美PCB B/B ratio（IPC公布）
- 半导体：费城半导体指数（PHLX）
- 计算机：用电量（中电联）
- 游戏：版号审批（国家新闻出版署）

**消费类（来源：产业在线、农业农村部）**
- 白电：产业在线排产数据
- 养殖：农业农村部能繁母猪存栏
- 医疗：全球医药投融资（CB Insights、Crunchbase）

## 五、数据获取的优先级建议

当框架需要指标但用户未提供时，按以下优先级处理：

1. **本环境已连接的取数skill**：例如 `tushare-data` 可以取 A股财务和行情，`akshare-fin-news` 可以取宏观新闻
2. **联网搜索**：抓取最新公开数据（例如央行月度金融数据公布后的新闻、上市公司季报披露汇总）
3. **告知用户自取**：明确给出"需要XX指标的YY口径，可以从Wind/iFind/tushare 拉到"，然后让用户提供

**示例话术**：
> "判断当前信用周期，关键看 M1-M2剪刀差最新读数和近3个月趋势。这个数据央行每月10-15日左右公布，Wind代码 M0001383（M1同比）、M0001385（M2同比）。你可以提供这两个数据，或者告诉我最新一期的剪刀差读数。"

## 六、数据时效与披露节奏

| 数据类型 | 披露节奏 |
|---|---|
| M1/M2 | 月度，次月10-15日 |
| PPI/CPI | 月度，次月9-10日 |
| 工业增加值 | 月度，次月15日左右 |
| GDP | 季度 |
| A股财报 | 一季报4月底、半年报8月底、三季报10月底、年报4月底 |
| 北向资金 | 实时（沪深港通） |
| 融资数据 | 日度（T+1） |
| 产业资本增减持 | 实时（按公告） |

研判时注意数据"已知期"和"目标期"的距离——例如用Q1财报判断Q2行情，财报4月底披露，Q2行情 6 月才结束，时效是合适的。
