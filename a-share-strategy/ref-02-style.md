# 风格研判

风格研判回答的是：当下应该超配哪类风格的资产。框架把A股风格切成两个维度、四个象限。

---

## 一、风格的二元划分和四象限

**二元划分**：

- **市值风格**：大盘 vs 中小盘
- **久期风格**：成长（长久期）vs 价值（短久期）

**四象限组合**：

| | 短久期（价值） | 长久期（成长） |
|---|---|---|
| **大盘** | 大盘价值（红利股） | 大盘成长（白马股） |
| **中小盘** | 中小盘价值（顺周期） | 小盘成长（主题股） |

**各象限的代表指数和行业**：

| 风格 | 代表指数 | 代表行业 |
|---|---|---|
| 大盘价值（红利） | 300价值、中证红利、恒生高股息 | 银行、石油石化、公用事业、建筑 |
| 大盘成长（白马） | 300成长、创业板指、创业板50、恒生科技 | 电新、医药、电子、港股互联网 |
| 中小盘价值（顺周期） | 顺周期指数 | 有色、钢铁、化工、建材、机械 |
| 小盘成长（主题） | 中证1000、中证2000、国证2000、北证50 | 传媒、通信、计算机 |

判断当前应配哪个象限，需要分别看市值维度和久期维度的驱动变量。

## 二、市值风格：大盘 vs 小盘

两个核心驱动变量：

### 2.1 国内剩余流动性

**定义**：剩余流动性 = M2 - 名义GDP增速 ≈ M2 - (工业增加值 + PPI) 【工业增加值、PPI均使用累计同比】

**含义**：宏观流动性在金融市场和实体经济之间的分配相对强度

- 剩余流动性**上行** → 流动性转向"脱实入虚" → 小盘股相对占优
- 剩余流动性**下行** → 流动性转向"脱虚向实"，回到实体 → 大盘股相对占优

**底层逻辑**：小盘股估值对流动性更敏感（缺少基本面锚），大盘股更需要基本面/实体经济支持。

### 2.2 美元指数与外资流向

外资（尤其是配置盘）偏好A股核心资产，集中在大盘股。

- 美元**走弱** + 外资**净流入** → 大盘股相对强
- 美元**走强** + 外资**净流出** → 大盘股相对弱（小盘相对占优）

**定义**：外资采用EPFR的净流入流出数据，或者采用中国五年期CDS利差

### 2.3 市值风格判断的组合矩阵

| 剩余流动性 | 美元/外资 | 市值风格倾向 |
|---|---|---|
| 上行 | 美元弱、外资入 | 矛盾——看哪个更主导，通常美元主导大盘 |
| 上行 | 美元强、外资出 | **小盘强趋势** |
| 下行 | 美元弱、外资入 | **大盘强趋势** |
| 下行 | 美元强、外资出 | 矛盾——通常大盘也偏弱 |

### 2.4 龙头分层的额外观察

在大盘内部，也有分层（这是提出的一个补充视角）：

- 二线龙头（中证500非金融）
- 一线龙头（沪深300非金融）
- 产业巨头（A50非金融）

ROE 穿越周期的能力**逐级上升**：A50非金融的ROE在地产深度调整期仍维持13%~14%，500非金融ROE则大幅下行。这意味着在弱复苏环境下，越是巨头ROE韧性越强，配置上有"向头部集中"的倾向。

### 2.5 边际资金的迭代

A股主要机构投资者：公募、私募、外资、险资（合计持股占比45%+）。

**当前趋势**：从资本市场政策导向看，险资、养老金等长线资金（"耐心资本"）正成为主要增量。长线资金偏好高股息、高ROE的大盘股，这进一步强化大盘价值的配置逻辑。

判断风格时，也要看**边际资金是谁**——如果增量是险资，红利/大盘价值天然受益。

## 三、久期风格：价值 vs 成长

在大盘股内部，价值（红利）和成长（白马）的相对表现，由两个变量决定。

### 3.1 贴现率（特别是美债利率）

成长股 = 长久期 + 高ROE，现金流分布在远端，对贴现率敏感度高。

- 贴现率**下行**（尤其美债利率下行）→ 估值抬升更大 → **大盘成长强于大盘价值**
- 贴现率**上行** → 远端现金流被打折更狠 → **大盘价值强于大盘成长**

### 3.2 风险溢价（ERP）

价值股（尤其高股息品种）具备防御属性，在ERP快速上行时表现突出。

- ERP **快速上行**（恐慌情绪扩散）→ 大盘价值（红利）防御占优
- ERP **下行**（风险偏好回升）→ 大盘成长进攻占优

### 3.3 久期风格判断的组合矩阵

| 美债/贴现率 | ERP | 久期风格倾向 |
|---|---|---|
| 下行 | 下行 | **大盘成长强趋势**（戴维斯双击） |
| 下行 | 上行 | 矛盾——通常防御先行，红利受益 |
| 上行 | 上行 | **大盘价值/红利强趋势** |
| 上行 | 下行 | 矛盾——成长承压，价值偏稳 |

## 四、四象限综合判断的决策流程

给定当前宏观环境，判断超配哪个象限：

```
Step 1: 大势是否趋势下行？
 是 → 红利/大盘价值（防御）
 否 → 进入 Step 2

Step 2: 看市值维度
 剩余流动性 + 美元/外资 → 大盘 or 小盘？

Step 3: 看久期维度
 贴现率 + ERP → 价值 or 成长？

Step 4: 组合得到象限
 大盘 × 成长 → 白马
 大盘 × 价值 → 红利
 小盘 × 成长 → 主题
 小盘 × 价值 → 顺周期（中小盘）
```

## 五、量化在风格判断中的边界

原框架明确：量化不擅长风格轮动（样本量小、价值/成长定义模糊、维度不正交）。

但可以做两件事：

**市值择时模型**：用增长、流动性指标判断趋势，用高动量、高成交、高波动、趋势趋同等拥挤度指标判断拐点（沪深300 / 中证2000 轮动）。

**红利择时模型**：用红利因子自身走势、银行间市场成交量、期限利差三个指标的趋势打分（中证红利 / 中证全指 轮动）。

**使用态度**：作为定性判断的交叉验证，不作为单独决策依据。

## 应用要点

回答风格类问题时，按以下顺序自检：

1. **剩余流动性方向**：M2 与名义GDP差值的当前位置和趋势
2. **美元和外资**：DXY位置、北向资金近期流向
3. **贴现率水平**：10Y美债当前位置、中美利差
4. **ERP状态**：当前ERP相对历史中枢的偏离，方向是上行还是下行
5. **边际资金主导**：当前哪类机构是增量买盘
6. **拥挤度交叉验证**：拥挤指标是否提示风格反转

最后落到四象限的某一格（或两格的均衡），说明依据。**不要给"大盘小盘都要配"这种万金油结论**——框架的价值就在于强迫做选择。
