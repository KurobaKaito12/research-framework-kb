# 场景化速查清单

本文件按常见提问场景，把对应的检查清单和回答模板整理好。研判时直接套用，避免遗漏关键维度。

## 场景一：用户问"现在A股怎么看 / 大盘还能涨吗"

**这是综合性大势问题，按下面四步走：**

### Step 1 · 信用周期定位

- [ ] M1-M2剪刀差当前读数？方向？
- [ ] 对应未来6个月PPI和盈利的指引是什么？
- [ ] M1的三元驱动（政府债+R007+地产销售）当前状态？

### Step 2 · 美元周期定位

- [ ] DXY当前位置（绝对水平和年内位置）
- [ ] 北向资金近1月、近3月净流向
- [ ] 美债10Y利率水平

### Step 3 · 极值信号扫描

12个底部信号清单（用户没数据时让Ta提供）：

**估值类**
- [ ] 全A ERP是否 > 5年均值+1σ
- [ ] 全A vs 中债性价比是否 > 10%
- [ ] 全A vs 美债性价比是否 > 3%

**结构类**
- [ ] 破净个股占比是否 > 54%
- [ ] 高股息(>3%)个股占比是否 > 60%
- [ ] 地板线个股占比异常

**资金/情绪类**
- [ ] 换手率最大回撤5日均 < -1σ
- [ ] 新成立偏股基金份额20日均 < 8.5亿
- [ ] 上交所新增开户数同比3月均 < -1σ
- [ ] 融资活跃度20日均 < 8%
- [ ] 估值分化系数是否极低
- [ ] 产业资本近1月净增持额 > 0

**判读**：
- ≥80% 触发 → 历史大底
- 50%-67% → 阶段小底
- <50% → 信号不足

### Step 4 · 节奏定位

- [ ] 当前在哪个日历窗口？历史胜率多少？
- [ ] 当前ERP在滚动1年箱体的什么位置？
- [ ] 今年是强复苏年还是弱复苏年？（决定箱体下沿能否突破）

### 输出模板

```
【方向】基于信用周期（M1-M2当前XX，趋势YY）和美元周期（DXY位置ZZ），
判断ERP方向倾向于上行/下行/震荡。

【空间】基于库存+产能周期组合（XX阶段+YY阶段），
判断今年盈利属于强/弱复苏年。DDM锚定的合理估值区间为XX。

【节奏】当前处于XX日历窗口（历史胜率约YY%），
ERP在箱体的ZZ位置。短期节奏判断：偏多/偏空/震荡。

【信号】底部信号体系当前触发XX/12个，属于AA状态。

【结论】综合三层判断，当前大势倾向于...
【缺数】判断更精确还需要：[列出缺失的指标]
```

## 场景二：用户问"该买大盘还是小盘 / 价值还是成长"

**这是风格类问题，落到四象限。**

### 市值维度（大盘 vs 小盘）

- [ ] 剩余流动性 = M2 - (工业增加值 + PPI) 当前方向？
 - 上行 → 小盘倾向
 - 下行 → 大盘倾向
- [ ] 美元/外资流向？
 - 美元弱+外资入 → 大盘倾向
 - 美元强+外资出 → 大盘弱（小盘相对占优）
- [ ] 边际资金主导是谁？
 - 险资/养老金主导 → 大盘价值受益
 - 公募回暖 → 大盘成长可能受益
 - 散户/融资主导 → 小盘活跃

### 久期维度（价值 vs 成长）

- [ ] 美债10Y方向？贴现率上行还是下行？
 - 下行 → 成长占优（戴维斯双击潜在）
 - 上行 → 价值占优
- [ ] ERP方向？
 - 上行（恐慌） → 红利防御
 - 下行（风偏回升） → 成长进攻

### 组合到四象限

| 市值 | 久期 | 结论 |
|---|---|---|
| 大盘 | 成长 | 白马（电新、医药、电子、港股互联网） |
| 大盘 | 价值 | 红利（银行、石油石化、公用、建筑） |
| 中小盘 | 价值 | 顺周期（有色、钢铁、化工、建材、机械） |
| 中小盘 | 成长 | 主题（传媒、通信、计算机） |

### 输出模板

```
【市值维度】剩余流动性XX + 美元/外资YY → 倾向大盘/小盘
【久期维度】贴现率XX + ERP YY → 倾向价值/成长
【边际资金】当前主导是XX → 强化AA风格
【最终落点】XX象限：具体方向是BB
【风险】如果ZZ变量反转，结论会向...切换
```

## 场景三：用户问"XX行业还能不能买 / XX行业怎么看"

**这是单一行业问题，按四维评估。**

### 维度1 · 需求侧（补库三要件）

基于最新季报：

- [ ] 存货周转率：是否拐头上行？
- [ ] 偿债现金流：是否拐头下行？
- [ ] 补库现金流：是否拐头上行？

**判读**：
- 三要件齐备 → 主动补库高概率启动
- 部分具备 → 关注下一份季报
- 都不具备 → 需求侧无积极信号

### 维度2 · 供给侧（出清判断）

- [ ] 固定资产周转率位置和方向？
- [ ] 资本开支增速？
- [ ] 资本开支/营收 z-score？是否跌破 -1σ？
- [ ] 资本开支/折旧摊销？是否 < 1？

**判读**：
- 主动扩产早期：周转率↑、capex↑、capex/营收未到中枢 → 进攻
- 基本出清：周转率初现拐点、capex↓、capex/营收近 -1σ → 防守反击
- 准出清：周转率下行放缓、capex加速↓ → 左侧布局

### 维度3 · 中观景气（高频交叉验证）

查"03-industry.md"找该行业的前瞻指标，确认：

- [ ] 该行业的核心前瞻指标当前位置？
- [ ] 与微观财报判断是否同向？
- [ ] 是否有催化（政策、产业事件、订单等）？

### 维度4 · 性价比（低估值 × 低筹码）

- [ ] PE/PB历史分位数（5年/10年）
- [ ] 公募超配/低配状态
- [ ] 北向资金近期流向
- [ ] 成交额占比、换手率分位

**判读**：低估值 + 低筹码 + 低拥挤 = 性价比好

【综合判断】
进攻型 / 防御型 / 等待型 / 规避型

## 场景五：用户问"市场什么时候见底 / 是不是底了"

**这是底部信号问题，专注极值信号体系。**

### 12 指标逐项确认

需要用户提供或拉取以下数据：

```
估值类（3项）:
□ 全A ERP > 5年均值+1σ?
□ 全A vs 中债性价比 > 10%?
□ 全A vs 美债性价比 > 3%?

结构类（3项）:
□ 破净个股占比 > 54%?
□ 高股息(>3%)占比 > 60%?
□ 地板线个股占比异常?

资金情绪类（6项）:
□ 换手率最大回撤5日均 < -1σ?
□ 估值分化系数极低?
□ 新发偏股基金份额20日均 < 8.5亿?
□ 新增开户数同比3月均 < -1σ?
□ 融资活跃度20日均 < 8%?
□ 产业资本近1月净增持 > 0?
```

### 判读规则

- ≥10/12 (≥83%) → 历史大底特征（如2024-02-05, 2008-11-04, 2005-07-18）
- 8-9/12 (67%-83%) → 大底信号较强
- 6-7/12 (50%-67%) → 阶段小底
- <6/12 → 信号不足，可能还在筑底

### 关键提醒

**单一指标无意义**，必须看集群效应。不要因为一两个指标到了就喊底。

## 场景六：用户问"哪些行业产能在出清 / 供给侧拐点判断"

**这是供给侧专题问题，找产能周期底部到反转的行业。**

### 出清识别的核心指标组合

候选行业按以下指标综合判断：

- [ ] **固定资产周转率** z-score：< -0.5（位于历史低位）
- [ ] **资本开支增速** z-score：< -0.5，且最新季度较前期企稳或下降
- [ ] **资本开支/折旧摊销** z-score：< -0.5，且最新季度较前期下降，是否已跌破 1
- [ ] **资本开支/营收**：是否跌破历史均值 -1σ
- [ ] **收入vs固定资产增速剪刀差**：是否接近交汇（底部信号）或开始走阔（周转率上行启动）
- [ ] **每股收入 SPS** 年内变动：> 0（需求侧没有同步恶化）

### 出清三类标的的对应判断

按 `03-industry.md` 的分类，把行业归入：

- **主动扩产早期**：周转率↑、capex↑、capex/营收未到中枢 → 进攻型
- **基本出清**：周转率初现拐点、capex↓、capex/营收近 -1σ → 防守反击
- **准出清**：周转率下行放缓、capex 加速↓ → 左侧布局

### 输出要点

- **政策催化**：是否有产业政策/反内卷加持？可持续性如何？
- **需求端是否同步改善**：供给改善+需求平稳 = 最佳；供给改善但需求继续走弱 = 价格弹性有限
- **估值和筹码位置**：出清行业通常筹码已经较散，性价比可能好
- **历史参照**：与 16 年化工/钢铁/白酒、15 年工程机械、13 年面板等出清案例对照

## 通用回答原则（每个场景都适用）

### DO

1. **明确缺什么数据**：如果用户没给关键指标，直接列出"需要XX/YY/ZZ来支撑判断"
2. **给情景而非点位**：盈利强复苏 vs 弱复苏不同情景下结论可能不同
3. **标注反向风险**：什么情况下结论会被推翻
4. **强调信号集群**：单一指标是噪音，要看组合
5. **区分战略与战术**：跨周期看好 ≠ 短期可以追

### DON'T

1. ❌ 不要给"什么都好"的万金油答案
2. ❌ 不要凭印象套结论而不引用具体指标
3. ❌ 不要把模糊预测包装成精确点位
4. ❌ 不要忽略量化方法的边界（择时、风格轮动、行业轮动量化都有局限）
5. ❌ 不要在缺数据时强行判断，要明确告知缺失

### 范式失效警示

当前需要警惕的几个范式失效点：

- **M1M2指标**：2023年起信用派生效率下降，单看 M1M2 可能失效，需要交叉验证
- **景气投资**：2022Q4 后阶段性失效，单纯追景气在弱成长环境下不一定有效
- **库存周期与产能周期当前组合**：产能下行+库存上行 = 弱复苏（类似13-14年、23年至今）
