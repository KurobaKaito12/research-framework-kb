# 正股基本面研究框架

"以债为名，以股为终"——正股上涨驱动转债上涨是最根本的盈利模式。

## 一、好赛道：行业分析
- 生命周期定位（导入→成长→成熟→衰退）
- 行业吸引力：市场空间、增速、政策、竞争格局、周期属性
- 行业轮动：龙头→绩优→事件驱动→剩余低市值

## 二、好模式：商业模式分析
- 盈利模式：toC品牌/toB项目/平台生态/周转型/高毛利
- 竞争壁垒（波特五力简化）

## 三、好公司：公司质量分析
- 财务质量：ROE>12%、经营现金流/净利润>0.8、负债率<60%
- 治理质量：质押率<50%、无异常关联交易
- 管理层能力：战略眼光、执行力、资本配置

## 四、好价格：估值分析
- DDM/PE模型：业绩增长+利率下行+风险溢价下降→股价上涨
- 两年EPS每年30%增长→涨幅69%→基本可推动转股
- 估值分位：<20%可能低估，>80%高估风险

## 五、转债投资者特殊视角
- 波动率越高，期权价值越大
- A股转债核心是正股驱动，不是波动率交易
- 行研回答好不好，转债还要考虑短期上涨、转股诉求、估值合理性
