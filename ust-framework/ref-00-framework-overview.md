## 二、为什么需要五碗面？

Clarida四因素在理论上完美，但实操中存在盲区：

| Clarida能解释的 | Clarida不好解释的 | 五碗面补充 |
|----------------|-------------------|-----------|
| 利率为什么从4%跌到3.5% | 为什么偏偏是今天跌了20bp？ | 情绪面：CTA翻转/持仓拥挤 |
| 期限溢价上升了50bp | 为什么上升的是这个时点？ | 资金面：准备金触及阈值/流动性事件 |
| 通胀预期上行驱动利率抬升 | Fed会怎么反应？ | 政策面：反应函数+独立性情景 |
| r*趋势性上行 | 谁来买这么多债？ | 供求面：basis trade/PD库存/外资 |

**核心洞见**：Clarida解释**方向和幅度**，五碗面解释**节奏和触发**。
