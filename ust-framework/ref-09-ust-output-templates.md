## 〇 输出哲学（18 条使用原则）

> **来源**：从 SKILL.md §综合判断 抽出。**前 13 条沿用原 13 条原则 + 新增 14-18 来自黄金 ref-08 吸收为通用原则**。**加粗**为美债特异应用。

1. **核心研究框架是纪律**：每次分析必须按该主题的核心维度逐项检查（**美债特异**：5 碗面 + Clarida）
2. **定量归因是锚**：先用 N 因素归因做定量拆解，再 N 维框架做定性校准（**美债特异**：Clarida 4 因素定量 + 5 碗面定性）
3. **边际思维**：关注各因素的边际变化方向而非绝对水平
4. **权重动态**：核心维度权重随环境变化（**美债特异**：5 碗面权重在拐点时上调资金面/供求面）
5. **交叉验证**：公开源数据与市场观察互验（**多源**：FRED / jin10 / web / 同花顺 EDB）
6. **先框架后数据**：先用模型定位，再采数据验证
7. **赔率意识**：不仅判断方向，更要看仓位与预期差
8. **明确不确定**：不确定因素标注概率而非笃定结论
9. **结论先行**：输出先给结论（方向 + 核心驱动），再展开论证——**读者 30 秒内应能抓住核心判断**
10. **叙事驱动**：核心研究框架是分析纪律，但最终输出围绕**一根核心叙事线**组织，**每个核心维度回答"如何支撑/挑战核心叙事"**，而非平行罗列
11. **反面论证**：每个核心判断必须回答"什么情况下我们会错"——**对话式说服力 > 并列式情景表**
12. **跨资产联动**：研究判断不是孤立的，必须写明对其他资产的含义（**美债特异**：但**只给方向不给点位**）
13. **时间轴叙事**：用未来事件时间轴替代静态"节奏与触发"，读者应能看到"哪个月可能转向"
14. **不写元话语**：正文只写分析师对客户说的话。"调用的 ref 清单 / 数据时效一致性 / 跨期追踪 / 检索纪律"是写给模型自己的执行指令，不进正文
15. **可能方向 + 边际排序**：第二层（叙事提炼）先列 3-5 种可能方向（带概率），再按边际影响力从大到小排列驱动因素——不要按固定模板写
16. **反面清单**：见 `ref-10-ust-writing-standards.md` §一——发现以下任何一条，重写
17. **信息收集与标注**：提炼前先做多渠道搜索、输出主题标签（`#主题-子主题-指标` 格式 3-5 个）、区分事实与传言（✅ Fact / 📊 Market view / ⚠️ Rumor / 💭 Analyst）
18. **强制三层流程**：T1/T2/T3 都走"底层逻辑研究 → 叙事提炼 → 文本形成"——**所有文字在第三层**，前两层是过程产物/脚手架

## 一、输出模式 1: T3 核心观点快报（100-250 字）

### 1.1 适用场景

用户问"一句话 / 1 段 / 日报 / IM 快速应答"——给一个**短、准、有判断**的核心观点。

### 1.2 关键原则

> **"T3 不是'快模式'——是'5 碗面速览压缩版'。跳过速览 = 跳过质量门。"**
> **"字数越短，对数据新鲜度和叙事覆盖面的要求反而越高"**（T1/T2 还能展开，T3 一行就暴露缺陷）

### 1.3 强制三层结构（**不可跳过**）

```
┌─ 第一层：底层逻辑研究（5 碗面各 1 句 checklist）——**【脚手架】过程产物，不进文字稿**
│   ① 基本面：10Y/30Y/2Y 水平、Clarida 拆解、YTD 极值
│   ② 政策面：Fed 立场、降息预期、独立性
│   ③ 在岸：SOFR-EFFR、basis trade、CFTC 持仓
│   ④ 离岸：Xccy Basis、央行互换、全球因子
│   ⑤ 供求：净发行/QRA/拍卖/需求端
│   ⑥ 情绪：MOVE/VIX/CFTC 极端度
│   形式：每碗一句话
│
├─ 第二层：叙事提炼（主导+边际+矛盾 各 1 句）——**【脚手架】过程产物，不进文字稿**
│   - 主导驱动 = 哪个碗决定当前叙事主轴
│   - 边际变化 = 哪个信号在恶化/改善
│   - 矛盾点 = 哪个信号与主导叙事冲突
│
└─ 第三层：文本形成（**所有文字在此层，100% 占位**）——**对外呈现的只有这一层**
 单段三层次：**现状（≤ 25%）**→ 预判（40%）→ 含义/操作（35%）
 开头标注"【数据截至 XX 日】"
 100-250字，单段连贯

### 1.3.1 T3 现状描述强制规则

**禁止只有点位信息**——现状部分必须**以叙事形式描述过去两周或一个月的市场变化**，让读者在 30 秒内抓住"这段时间利率怎么走的"。

**写作模板**（直接套用）：
- ✅ "过去两周，10Y 在 X.XX%-X.XX% 区间震荡，期间一度从 X.XX% 上行至 X.XX%（或从 X.XX% 下行至 X.XX%），主要受 ___ 驱动"
- ✅ "近一个月，10Y 从 X.XX% 累计上行/下行约 XXbp，30Y 同步 ___，2Y ___，曲线 ___ 形变"
- ✅ "5 月以来 10Y 围绕 X.XX% 中枢震荡，未形成趋势；2Y 受 ___ 影响下行 XXbp，曲线温和陡峭化"

**期限选择**：
- **必含 10Y**（主语）
- **点其他期限**——只挑**变化大**的（变动 ≥ 同期限 2 倍或对叙事有边际贡献的）
- **不要**面面俱到列 2Y/5Y/10Y/30Y 所有点位的当前值

**措辞铁律**：
- ❌ **不带内部数据源标签**：`(5/19 FRED DGS10)` `(T10YIE / T5YIFR 6/3)` `(5 碗面加权 ★★★★★)`
- ❌ **不带日期戳补注**：`(截至 6/3)` `(5/12 数据)` 等括号补注
- ❌ **不带技术/工具标签**：`FRED`、`BLS` 等数据工具名
- ✅ **用叙事内化时间窗口**：`"过去两周"` `"近一个月"` `"5 月以来"` `"6/2 之后"`
- ✅ **只说数字和方向**——`<起点bp> → <终点bp>`，不附数据源脚注
- ✅ **数据脚注放文末一行**（如 `数据：FRED`）即可，不嵌在叙事中

### 1.4 输出格式

```markdown
# [主题] 核心观点（YYYY-MM-DD）

> **数据截至**：YYYY-MM-DD

【数据截至 XX 日】[1 段连贯文字，100-250 字]
[现状（≤25%，两周/月变化叙事，以10Y为主）→ 预判（40%）→ 含义/操作（35%）]
[主导驱动 + 评级 + 关键时点 + 风险（1 句）]
```

**现状部分示例**（参照 §1.3.1）：
- ✅ 「过去两周10Y在4.45-4.55%区间震荡，从4.50%一度上行至4.58%后回落，30Y跟随10Y在4.65%附近窄幅整理，2Y受降息预期升温下行约8bp，曲线温和陡峭化。」
- ✅ 「近一个月10Y从4.30%累计上行约25bp至4.55%，主要受___驱动；30Y同步走阔但幅度更大，2Y几乎未动，曲线陡峭化约20bp。」
- ❌ 「10Y报4.55%（5/19 FRED DGS10），30Y报4.65%（T10YIE / T5YIFR 6/3），2Y报4.20%。」（违规：只有点位 + 内部标签 + 缺叙事）

### 1.5 T3 自检项（**输出前必走**）

- [ ] **第一层（脚手架）**：是否完成了 5 碗面速览（每碗至少 1 个信号，无则写"无异常"）？——**不进文字稿**
- [ ] **第二层（脚手架）**：是否完成了主导/边际/矛盾三件套？——**不进文字稿**
- [ ] **第三层**：开头是否有"【数据截至 XX 日】"？
- [ ] **第三层**：主导驱动是否在 100 字内出现？
- [ ] **第三层**：是否每碗都有至少 1 个信号**内化**到文本中（不是平行罗列）？
- [ ] **第三层**：是否先给结论（30 秒内能抓住核心）？
- [ ] **第三层**：**文字稿中是否出现"## 第一层""## 第二层""底层逻辑研究""叙事提炼"等分层标记或脚手架标题**？读者只能看到单段三层次正文

**§1.3.1 现状描述自检**：
- [ ] **现状是否含两周/一月变化叙事**——不是只有当前点位，而是描述了"从 X 上行至 Y""在 Z 附近震荡""累计变动 XXbp"等过程？
- [ ] **现状是否以 10Y 为主语**——10Y 是否是首句/主语？其他期限只点"变化大的"？
- [ ] **现状是否避免面面俱到**——没有把 2Y/5Y/10Y/30Y 当前点位全列出来？
- [ ] **现状是否避免了内部标签**——文中没有 `(5/19 FRED DGS10)` `(T10YIE / T5YIFR 6/3)` `(5 碗面加权 ★★★★★)` `(截至 6/3)` 等数据源/日期戳/技术标签括号补注？
- [ ] **现状时间窗口是否内化为叙事**——用 "过去两周""近一个月""5 月以来"等表达，而非单独标注日期？
- [ ] **现状字数是否 ≤ 25%**？

**通用自检**：
- [ ] **5 碗面检查表**是否可追溯到具体 query 结果（不是缓存复用）？
- [ ] 主文本中**是否出现 BofA / WSJ / CNBC / CNN / Bloomberg / Forbes 等机构名/媒体名**？（官方源 Fed/Treasury.gov/BLS/BEA/FRED 允许）

### 1.6 反例（违规模式）

| 违规 | 后果 |
|------|------|
| ❌ 只看了 1 碗就写 T3 | 叙事片面，"供给海啸"等无中生有 |
| ❌ 直接基于常识/经验写 T3 | 数据无支撑，无法交叉验证 |
| ❌ 跳过速览直接压缩 | 违反分析纪律，5 碗盲区全暴露 |
| ❌ 用过期数据未标注 | 读者无法判断新鲜度，整段被打折 |
| ❌ 6 个信号全部塞进 250 字 | 变成目录梗概，无观点 |
| ❌ T3 文本里全是数据没有判断 | 失去"快报"价值，不如直接给数据表 |
| ❌ 用表格 + checkbox 形式 | 核心观点要"一句话定性"，表格太重 |
| ❌ 列举 5+ 个风险 | 核心观点只点最关键的 1 个 |

**§1.3.1 现状描述违规**：
| 违规 | 后果 |
|------|------|
| ❌ **现状只堆点位无变化叙事**：「10Y 报 4.55%，30Y 报 4.65%，2Y 报 4.20%」——只有当前值，没有"过去两周怎么走" | 读者抓不到节奏，违反 §1.3.1 强制规则 |
| ❌ **现状带内部数据源/日期戳**：「10Y 4.55%（5/19 FRED DGS10）」「30Y 4.65%（T10YIE / T5YIFR 6/3）」 | 内部工具暴露给读者，违反"不暴露内部工具"铁律 |
| ❌ **现状带技术/碗面标签**：「(5 碗面加权 ★★★★★)」「(基本面 / 政策面 / 资金面综合)」 | 分析师内部框架泄漏到对外文本 |
| ❌ **现状面面俱到列所有期限**：把 2Y/5Y/10Y/30Y 当前点位全部点出 | 变成数据表，违反"以 10Y 为主+变化大的"原则 |
| ❌ **现状缺时间窗口**：「10Y 上行至 4.55%」——读者不知道是过去 1 周还是 3 个月 | 时间错位被读者默认，叙事失效 |
| ❌ **T3 文字稿中夹带"## 第一层""## 第二层"等分层标题** | 脚手架外露 |

## 二、输出模式 2: T2 异动点评（1000-2500 字）

### 2.1 适用场景

用户问"XX 数据 / 财报 / 政策 / 拍卖 / 异动 / 跨资产联动"——对一个**具体事件**做点评。

### 2.2 关键原则

> **"T2 不是 T3 的'加长版'——是'5 碗面深度速览 + 六段式文本展开'"**
> **"字数从 250 扩展到 1000-2500 后，第二层思维密度需同步加强（多维交叉 + 反面论证 + 跨资产验证）"**
> **"T2 普通式不外露'区间+催化'等内部标签——催化事件清单与 1-2 周方向判断直接融入短期展望段，不单设附加段"**
> **"T1/T2/T3 对外呈现的只有第三层文字稿——第一层（底层逻辑研究 / 5 碗面速览）与第二层（叙事提炼 / 主导+多维交叉+反面论证）是过程产物/脚手架，**不得以"## 第一层""## 第二层"等标题出现在文字稿中**；文字稿中间不能出现任何分层标记、分层提示、过渡性脚手架"**

### 2.3 强制三层结构（**不可跳过**）

```
┌─ 第一层：底层逻辑研究（5 碗面各 1-2 段关键信号点）——**【脚手架】过程产物，不进文字稿**
│   ① 基本面：10Y/30Y/2Y 水平+变动、Clarida 拆解、YTD 极值
│   ② 政策面：Fed 立场、降息预期、近期讲话、独立性事件
│   ③ 在岸：SOFR-EFFR、basis trade、CFTC 持仓
│   ④ 离岸：Xccy Basis、央行互换、全球因子
│   ⑤ 供求：QRA 规模、拍卖、净发行、需求端类别
│   ⑥ 情绪：MOVE、VIX、CFTC 极端度
│   形式：每碗 1 段（100-200 字），比 T3 详尽但不展开论证
│
├─ 第二层：叙事提炼（主导+多维交叉+反面论证）——**【脚手架】过程产物，不进文字稿**
│   - 主导驱动 = 哪个/哪几个碗决定当前叙事主轴（2-3 句）
│   - 多维交叉 = 跨资产验证（股/汇/商/信用/TIPS 联动）——**美债特异：只给方向不给点位**
│   - 反面论证 = "什么情况下我们会错"（3 条反向证据，对话式）
│   - 危机式附加：阈值表（5 类阈值 + 历史案例 + 双区间）
│   - 普通式附加：1-2 周方向判断 + 3-5 关键事件清单（**并入短期展望，不单设附加段**）
│
└─ 第三层：文本形成（**所有文字在此层，100% 占位**）——**对外呈现的只有这一层**
 六段式（1000-2500字）：
 1. 事件速览（200-300字）
 2. 直接原因（250-400字）
 3. 深层原因（300-500字）——反面论证融入
 4. 跨资产验证（300-500字）——**独立成段，只给方向**
 5. 短期展望（300-500字）——**普通式催化事件清单融入此段**
 6. 中长期展望（300-500字）——反面论证融入
 + 危机式：阈值分析表（独立段，200-300字）
（普通式无独立附加段——催化清单并入短期展望）
```

### 2.4 T2 内部二元区分

| 类型 | 触发场景 | 第三层附加 |
|------|----------|-----------|
| **危机式** | MOVE 飙升、跨资产共振、Fed 危机、流动性冻结 | 阈值表（5 类+历史案例+双区间）作为独立段，回答"是否变危机" |
| **普通式** | 单日 10-20bp 异动、有清晰催化但未到危机 | 1-2 周方向 + 3-5 关键事件清单**并入短期展望段**（不单设附加段、不外露"区间+催化"标签） |

### 2.5 T2 vs T3 对照

| 维度 | T3 | T2 |
|------|----|----|
| 字数 | 100-250 | 1000-2500 |
| 第一层 | 6 碗各 1 句信号 | 6 碗各 1-2 段关键信号点 |
| 第二层 | 主导+边际+矛盾（各 1 句） | 主导+多维交叉+反面论证 |
| 第三层 | 单段文本 | 六段式文本展开 |
| 危机式附加 | / | T2.4 阈值表（独立段） |
| 普通式附加 | / | 并入短期展望（不外露） |
| 自检项 | 6 项 | 8 项 |

### 2.7 T2 自检项（**8 项，输出前必走**）

- [ ] **第一层（脚手架）**：是否完成了 5 碗面深度速览（每碗 1-2 段，无则写"无异常"）？——**不进文字稿**
- [ ] **第二层（脚手架）**：是否完成了三件套（主导/多维交叉/反面论证）？——**不进文字稿**
- [ ] **第二层（脚手架）**：是否明确标注了危机式还是普通式（影响第三层结构）？——**不进文字稿**
- [ ] **第三层**：六段必须齐全（不可漏掉跨资产验证或中长期展望）？
- [ ] **第三层**：开头是否有"【数据截至 XX 日】"？
