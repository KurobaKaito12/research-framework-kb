### 切换规则（强制）

1. **首选源滞后 > 3 天** → **必须**切换其他公开源或 web 兜底（FRED 官方实时，优先）
2. **快变量**（油价、地缘、Fed 讲话、CPI 数据日、关税法律）→ **永远用 web 兜底当天**，不能只查单一来源
3. **季频事件**（FOMC 决议、QRA、点阵图）→ 事件当日必 web 同步最新
4. **多源交叉**：FRED 拿到数据后，建议与 jin10 或另一公开源同一日数据做一次 diff（差异 > 5bp 视为异常，提示数据源或字段口径问题）
5. **同花顺 EDB** 优先于 web 兜底用在国内宏观交叉（更稳）

### 工具调用顺序（推荐）

```
1. FRED 查 DGS2/DGS10/DGS30 等核心序列     # 确认最新日期（freshness check）
2. FRED 查 T10Y2Y / T10YIE / DFII10        # 利差与通胀预期基线
3. jin10 日历 / 快讯                        # 当周/当日事件
4. web 搜索重大事件                          # 兜底
5. （按需）同花顺 EDB 国内宏观交叉
```

**识别宏观交易类型**：
- **宽松交易**：除美元外股债商汇均涨（美元跌）
- **紧缩交易**：除美元外股债商汇均跌（美元涨）
- **Risk-on**：风险资产涨，避险资产跌
- **Risk-off**：风险资产跌，避险资产涨
- **滞胀交易**：商品+通胀预期涨，股+债跌
- **衰退交易**：债涨（利率跌），股+商品跌

#### 2.5.3 输出层日期标注（强制）

**T2/T3 输出开头必须明确写"【数据截至 XX 日】"**——标注本身就是质量门。读者看到日期就能判断数据新鲜度，过期数据读者会主动打折。

#### 2.5.4 反例（违规模式）

- ❌ 拉完数据直接写 T3，输出中无日期标注
- ❌ 主源滞后 22 天仍直接使用，未做 web 兜底
- ❌ 只补了美债收益率，没补油价/地缘等快变量
- ❌ 用 YTD 高点代表"当前"，忽略了过去 22 天的重大事件
- ❌ **4 个核心指标（美债收益率水平/期限利差/BEI/远期实际）滞后 > 1 天仍直接使用**——尤其是 THREEFY5 在 FRED 上 5/29 后无新数据，必须 web 拉 NY Fed GSW daily fitted 或 H.15 完整曲线 bootstrap

## 三、数据源速查

全部数据源均为公开源（FRED / 官网 / jin10 / 同花顺 EDB / Web），无需任何内部数据权限。逐类映射详见 §一。

### 3.1 公开源入口速览

- **FRED**（fred.stlouisfed.org）：美债收益率（DGS 系列）、利差（T10Y2Y）、盈亏平衡（T10YIE/T5YIFR）、实际利率（DFII 系列）、OAS（BAML 系列）、VIXCLS
- **Fed / NY Fed / Treasury / CFTC / BIS 官网**：H.4.1、SOMA、TIC、QRA、CoT 报告、央行统计
- **CME FedWatch**：市场隐含降息概率
- **jin10 / 同花顺 EDB**：实时行情、国内宏观交叉
- **亚特兰大联储 GDPNow**：实时 GDP 跟踪

### 3.2 FRED 使用提示

- 序列页可直接看最新观测日期，作为 freshness check
- 支持按日期区间下载（CSV），适合批量取数
- 部分序列有发布延迟（如 THREEFY5），延迟序列按 §2.5.2 的 web 兜底规则处理
