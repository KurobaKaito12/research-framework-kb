## 一、技术分析：美债适配版

> 通用技术分析框架适配至美债市场。核心差异：美债是**收益率曲线**而非单一价格；24小时交易、无涨跌停、机构主导、流动性分层。

### 1.1 美债 vs 股票技术分析关键差异

| 维度 | 股票 | 美债 |
|------|------|------|
| **分析对象** | 股价（涨=好） | 收益率（涨=债跌） |
| **市场结构** | T+1、涨跌停、散户参与 | 24h、无涨跌停、机构主导 |
| **核心标的** | 个股 | 曲线（2Y/5Y/10Y/30Y）+ 利差 |
| **成交量** | 高频可用、含义清晰 | 场外为主、数据滞后→用持仓替代 |
| **支撑阻力** | 价格整数关口、均线 | 利率整数关口（4.0%/4.5%/5.0%）、历史前高/低 |
| **指标适用性** | 全部适用 | 趋势类>超买超卖类；量价类需改造 |
| **筹码** | 有意义 | 无意义→用持仓数据替代 |
| **板块轮动** | 行业/概念 | 曲线段轮动（2s5s/5s30s）+ 跨资产 |

### 1.2 趋势分析

**趋势定义（利率视角）**：
- **利率下行趋势**（债券牛市）：收益率低点越来越低、高点越来越低
- **利率上行趋势**（债券熊市）：收益率低点越来越高、高点越来越高
- **区间震荡**：收益率在支撑与阻力之间横向波动

**支撑与阻力**：

| 类型 | 识别方法 | 例子 |
|------|---------|------|
| **整数关口** | 心理锚定 | 4.0%、4.5%、5.0% |
| **历史前高/前低** | 前期转折点 | 2023年10月10Y 5.0%高点 |
| **均线** | MA20/50/200 | 10Y 200日均线 |
| **前次拍卖定价** | 一级市场锚 | 最近3次10Y拍卖加权均价 |
| **FOMC决议日水平** | 政策锚 | 最近2次FOMC后10Y收盘 |
| **期权行权价** | Gamma墙 | 大量open interest的利率水平 |

**均线系统**：

| 均线 | 含义 | 信号 |
|------|------|------|
| MA20 | 月线 | 短期趋势方向 |
| MA50 | 季线 | 中期趋势方向 |
| MA200 | 年线 | 长期趋势方向 |

金叉=利率下行信号（债券看多）；死叉=利率上行信号。均线在美债上比股票更可靠（趋势性强、假突破少）。

**斐波那契回撤**：利率大幅波动后，38.2%/50%/61.8%回撤位提供目标测算。例：10Y从3.10%涨至5.00%（+190bp），38.2%回撤=4.28%，50%=4.05%，61.8%=3.83%。

### 1.3 价格形态

**反转形态**：

| 形态 | 含义 | 美债要点 |
|------|------|---------|
| 双顶 | 利率见顶 | 两个高点接近+颈线突破确认 |
| 双底 | 利率见底 | 两个低点接近+颈线突破确认 |
| 头肩顶/底 | 经典反转 | 颈线破位=趋势反转 |
| 圆弧顶/底 | 缓慢转向 | 美债中常见（宏观缓慢切换） |

**目标测算**：形态高度等量投射

**持续形态**：旗形/三角旗=趋势中继；对称三角形=收敛→方向选择；矩形=区间震荡→等待突破

**缺口**：美债24h交易缺口少，但CPI/NFP数据缺口T+1~T+3回补率约60%→逆向交易窗口

### 1.4 技术指标

**MACD**（美债最可靠指标之一）：

| 信号 | 含义 | 可靠性 |
|------|------|--------|
| 金叉 | 利率下行 | ★★★★ |
| 死叉 | 利率上行 | ★★★★ |
| 零轴上方金叉 | 强下行趋势中继 | ★★★★★ |
| 顶背离 | 利率见顶预警 | ★★★★ |
| 底背离 | 利率见底预警 | ★★★★ |

参数：日线(12,26,9)；周线(12,26,9)或(5,34,5)

**RSI**：>70超买、<30超卖，但强趋势中可长期超买/超卖→需配合MACD。**背离是最有价值信号**。

**KDJ**：美债波动率regime切换频繁→KDJ钝化严重→**不建议主要使用**

**布林带**——美债波动率分析首选：

| 信号 | 含义 |
|------|------|
| 触及上轨 | 短期超买/波动率扩张 |
| 触及下轨 | 短期超卖/波动率扩张 |
| **Squeeze（收窄）** | **最重要信号**：波动率极低→即将方向选择→配合五碗面判方向 |
| 扩张 | 波动率释放→趋势加速 |

参数：20日+2σ（标准）；13日+1.5σ（更敏感）

**持仓类指标**（替代成交量）：

| 指标 | 来源 | 用法 |
|------|------|------|
| CFTC杠杆基金净持仓 | `CFTC CoT 报告（官网公开，周度）` | 极端值=反转信号 |
| CFTC资管机构净持仓 | `CFTC CoT 报告（官网公开，周度）` | 趋势方向确认 |

| 10Y掉期利差 | `FRED / Web（10Y 掉期利差）` | 流动性压力信号 |

**ADX**（趋势强度）：<20无趋势→做区间；20-40趋势形成→顺势建仓；>60极强→警惕衰竭

## 二、曲线技术分析与交易

> 股票没有"曲线"概念，这是美债技术分析最大的差异化价值。

### 2.1 曲线段技术信号

| 曲线段 | 技术分析对象 | 常用指标 |
|--------|------------|---------|
| 2s10s | 期限利差水平 | MA50/200、布林带、RSI |
| 5s30s | 长端利差 | MACD、趋势线 |
| 10Y TIPS vs 10Y | BEI水平 | 历史分位、布林带 |
| 10Y UST vs 10Y Bund | 跨国利差 | 均值回归、布林带 |

### 2.2 曲线形态四象限

| 利率方向 | 2s10s走扩 | 2s10s收窄 |
|---------|----------|----------|
| **10Y上行** | Bear Steepen（增长乐观/通胀担忧） | Bear Flatten（Fed偏鹰/衰退前兆） |
| **10Y下行** | Bull Steepen（Fed转向/衰退确认） | Bull Flatten（避险+增长悲观） |

### 2.3 曲线交易场景

| 场景 | 2y | 10y | 2s10s | 触发 |
|------|-----|------|-------|------|
| Bull Steepening | -100bp | -10bp | +90bp | Fed加速降息/增长走弱 |
| Bear Steepening | 持平 | +30bp | +30bp | 供给冲击/通胀溢价rebuild |
| Twist Steepening | -50bp | +20bp | +70bp | Fed鸽派+财政扩张 |
| Bull Flattening | -20bp | -60bp | -40bp | 衰退恐慌→避险买长端 |

**Belly核心**：2s10s方向97%由belly驱动→做曲线=交易belly。Belly对鸽派Fed最敏感+对增长放缓对冲效果最好。

**5s30s陡峭化**：陡峭化=更低降息终端+持续供给担忧+通胀偏高；平坦化=Fed不够鸽+发行削减+关税推翻。30Y上限：养老金/LDI需求+5%心理关口。

**不对称性与对冲**：Steepener尾部（牛陡路径仍开）；财政限制长端领涨；日历价差对冲时序错配。

### 2.4 BEI曲线技术

- BEI布林带squeeze → 通胀预期即将方向选择 → 配合油价/关税判断
- TIPS vs 互换 → 实际利率的相对价值
- 5y5y vs 5y曲线 → 通胀曲线形态交易

## 三、Carry & Rolldown

### 3.1 核心公式

- **Carry** = 持有收益 - 融资成本
- **Rolldown** = 随时间沿曲线下滑的资本利得

### 3.2 Carry环境三条件

| 条件 | 验证指标 | Carry友好 |
|------|---------|----------|
| 低波动率 | 1y10y swaption vol < 历史中位数，VIX较低 | ✓ |
| 稳定融资 | SOFR-EFFR利差稳定，SRF使用率低 | ✓ |
| 高名义GDP | 名义GDP增速 > 10y UST收益率 | ✓ |

### 3.3 决策框架

| 情况 | 含义 | 策略 |
|------|------|------|
| 正Carry + 正Rolldown | 有时间优势 | 等待验证即可 |
| 正Carry + 负Rolldown | 部分时间优势 | 需方向判断 |
| 负Carry + 负Rolldown | 无时间优势 | 需高确信度 |

**5Y段通常carry+rolldown最优**——正carry+曲线陡峭→rolldown约+15bp/季度

EM Carry：扩张regime CEEMEA和Latam > AxJ；风险：能源价格飙升→carry unwind

## 十、美债技术分析的限制

1. **宏观驱动>技术驱动**：FOMC/CPI/NPF可以在1小时内打破所有技术形态——永远先看五碗面
2. **流动性分层**：2Y/10Y流动性好→技术信号可靠；20Y/30Y差→信号弱
3. **数据缺口**：成交量数据质量差→量价分析受限→用持仓数据替代
4. **政策锚定**：Fed利率锚定短端→2Y技术信号独立性弱
5. **非价格敏感参与者**：Fed/养老金/央行可以打破技术规律
6. **过度优化风险**：美债数据历史长→容易过度拟合→强调样本外验证
