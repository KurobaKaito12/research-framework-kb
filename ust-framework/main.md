# 美债利率走势研判框架

## 分析架构：五碗面 + Clarida

**五碗面管"看什么"，Clarida管"怎么看"。**

五碗面是**分析纪律**——确保每次研判都完整覆盖五大维度，不遗漏。
Clarida四因素是**归因工具**——精确量化每个驱动力的贡献。

```
五碗面（分析纪律层） Clarida（理论归因层）
───────────────── ─────────────────
① 基本面 ←→ 四因素全量归因 利率变动 = 实际短端利率贡献
② 政策面 ←→ 预期实际短端利率 + 通胀预期贡献
③ 资金面·在岸 ←→ 短端 + 期限溢价 + 实际期限溢价贡献
④ 资金面·离岸 ←→ 期限溢价(离岸) + 通胀风险溢价贡献
⑤ 供求面 ←→ 实际期限溢价
⑥ 情绪面 ←→ 所有因子短期偏离
```

> **详细映射关系见 `ref-00-framework-overview.md`**

**实操顺序**：先Clarida定量归因（方向+幅度），再五碗面逐碗校准（节奏+触发+遗漏检查）。

**美债五碗面权重**（vs 中债对比）：

| 碗 | 美债权重 | 中债权重 | 差异原因 |
|---|---------|---------|---------|
| 基本面 | ★★★★★ | ★★★ | 美债定价效率极高，宏观数据是第一驱动力 |
| 政策面 | ★★★★ | ★★★★★ | Fed透明但独立性风险是新变量；中国央行不透明权重最高 |
| 资金面 | ★★☆ | ★★★★★ | 平时不缺钱，但拐点致命（2019.9/2020.3） |
| 供求面 | ★★★★ | ★★★ | 美国"供给海啸"，中国"资产荒"——方向相反 |
| 情绪面 | ★★★ | ★★★ | 美国有更量化的持仓数据（CFTC/CTA/PD） |

## 第一碗：基本面（★★★★★）

**Clarida四因素归因是基本面的精确拆解工具。**

### 1.1 Clarida定量归因

**双视角拆解**（用可观测市场数据）：

**政策视角**：10y名义利率 = 2y短端利率 + 10y-2y期限利差
- 短端利率 → 美联储政策立场
- 期限利差 → 增长前景与政策预期

**基本面视角**：10y名义利率 = 10y实际利率(TIPS) + 10y盈亏平衡通胀(BEI)
- 实际利率 → 增长预期+真实资金成本
- BEI → 通胀预期+通胀风险溢价

**核心操作**：计算利率变动，按两个视角分别拆解贡献，判断上行/下行主要由哪部分驱动。

| 归因维度 | 公开数据源 |
|---------|----------|
| 2y收益率 | `FRED DGS2 / DGS10 / DGS30` + `CME FedWatch（官网公开）` |
| 10y-2y利差 | `FRED T10Y2Y / T10Y3M` + `纽约联储 ACM（官网公开，月度）` |
| 10y TIPS | `FRED DFII10 / DFII5`（备选：Fed H.15）|
| 10y BEI | `FRED T10YIE / T5YIFR` + `FRED T10YIE + 油价（Web）` |
| 30y-10y利差 | `FRED DGS30 − DGS10`（30y-10y 利差自行作差，变动大时补充） |

### 1.2 增长定位

| 维度 | 公开数据源 |
|------|----------|
| GDP Nowcast + 衰退概率 | `亚特兰大联储 GDPNow（官网公开）` |
| 消费(PCE+薪资) + 就业 | `FRED / BLS·BEA 官网（就业·通胀）` |
| 投资与库存 | `FRED（投资·库存）` |
| 经济意外指数 | `Web（花旗经济意外指数）` |
| 宏观象限 | `自行计算（按框架方法）`（增长-通胀/库存/信贷/盈利-流动性） |

### 1.3 通胀定位

| 维度 | 公开数据源 |
|------|----------|
| 核心PCE/CPI | `FRED / BLS·BEA 官网（就业·通胀）` |
| 5Y5Y BE + 密歇根预期 | `FRED T10YIE / T5YIFR` |
| 通胀与油价 | `FRED T10YIE + 油价（Web）` |
| 薪资增速 | `FRED / BLS·BEA 官网（时薪同比）` |

**BE动态4模式**：
- **Bear Widening**：利率↑+BE↑（正常熊市）
- **Bull Tightening**：利率↓+BE↓（正常牛市）
- **Bear Tightening**：利率↑+BE↓（增长担忧）
- **Bull Widening**：利率↓+BE↑（滞胀信号⚠️）

### 1.4 r*定位

多模型交叉验证：HLW(下行趋势) vs Lubik-Matthes(上行趋势) vs DSGE(上行趋势) vs FOMC SEP(3.00%) vs 市场隐含(3.5-4.0%)

**模型分歧本身就是风险信号**：r*不确定时，市场定价的期限溢价应更高。

> 深度方法论：`ref-01-fundamentals.md`

### 1.5 期限溢价定位

| 模型 | 来源 | 频率 | 特点 |
|------|------|------|------|
| ACM | 纽约联储 | 月度 | FOMC影响力大 |
| CR模型TYP | 三藩联储 | **日度** | 更高频，日常跟踪首选 |
| Kim-Wright | Fed | 不定期 | 补充验证 |

**期限溢价结构判断**：实际期限溢价 vs 通胀期限溢价——如果只有实际期限溢价↑→问题在供需；如果BEI通胀期限溢价也↑→通胀脱锚风险。

### 1.6 基本面小结输出

```
10y利率变动 = 实际短端利率贡献 + 通胀预期贡献 + 实际期限溢价贡献 + 通胀风险溢价贡献
主要驱动 = ______（最强贡献因子）
方向 = 利率上行/下行/区间震荡
幅度判断 = 基于Clarida归因的公允价值区间
```

## 第三碗：资金面·在岸（★★☆ → 拐点时★★★★★）

**美债资金面平时不显，但拐点致命——准备金枯竭、basis trade崩溃可在数小时内重塑曲线。**

> **在岸详见 `ref-03-liquidity.md`，离岸+全球详见 `ref-04-liquidity-offshore.md`**
>
> **L1狭义流动性（货币市场）**：钱够不够用？银行间/回购能否正常运转？
> **L2广义流动性（信用扩张/收缩）**：信用能不能创造？银行愿不愿放贷？
> **L3金融市场流动性（各资产市场）**：资产能不能正常交易？买卖价差/市场深度如何？
>
> **L1是L2的基础，L2是L3的背景——但传导不是自动的，每一层都可以独立出问题。**

### 3.1 在岸流动性温度计

| 指标 | 含义 | 公开数据源 |
|------|------|----------|
| SOFR-EFFR利差 | 银行间松紧 | `FRED SOFR / EFFR（自行作差）` |
| SOFR-OIS利差 | 银行间压力 | `FRED / Web（SOFR-OIS）` |
| RRP余额 | 剩余资金缓冲 | `同花顺 EDB / Web` |
| SRF使用率 | 流动性应急需求 | Fed H.4 / Web |
| 美债流动性指数 | 交易深度 | `FRED VIXCLS + MOVE（官网公开）` |
| MOVE/VIX | 波动率regime | `FRED VIXCLS + MOVE（官网公开）` |

### 3.2 准备金状态

| 状态 | 利率排列 | 传导特征 | 典型时期 |
|------|---------|---------|----------|
| 稀缺 | SOFR > EFFR ≥ IORB > ON RRP | 商业银行是回购资金提供者 | 2019年钱荒 |
| 充足 | IORB > SOFR ≈ EFFR > ON RRP | 地板系统有效运作 | 2020年后 |
| 冗余 | IORB > EFFR > ON RRP ≥ SOFR | 所有利率压至ON RRP下沿 | 2022年中 |

**关键阈值**：准备金/GDP < 8% → 流动性风险非线性上升

### 3.3 Basis Trade脆弱性

对冲基金basis trade规模≈$1T+，是长端重要需求来源，但杠杆端脆弱：
- 资金面紧→repo成本↑→basis trade去杠杆→长端流动性真空
- 跟踪：CFTC杠杆基金持仓 + `CFTC CoT（官网公开）`

### 3.4 资金面·在岸小结输出

```
流动性状态 = 正常/趋紧/危机
影响范围诊断 = L1狭义___ / L2广义___ / L3金融市场___
准备金充裕度 = 充裕/接近阈值/稀缺
广义信用状态 = 扩张/平稳/收缩（SLOUS+C&I贷款+信用利差）
Basis trade稳定性 = 稳定/脆弱/正在去杠杆
资金面对利率的影响 = 目前__（微弱/正在放大期限溢价__bp）
```

## 第五碗：供求面（★★★★）

**美国方向与中债相反：不是"资产荒"，而是"供给海啸"。赤字/GDP 6-7%在低失业率下是历史异常。**

|------|----------|
| 国库券净发行 | `Treasury.gov（官网公开）` |
| 中长期国债发行 | `Treasury.gov（官网公开，国债月度发行额）` |
| 净DV01变化 | = coupon↓ + bill↑ → 私人久期风险净减少 |
| WAM趋势 | 缩短→利差曲线steepening |
| 季度再融资指引 | Web搜索（2/5/8/11月） |

## 第六碗：情绪面（★★★）

### 6.3 赔率-胜率矩阵
