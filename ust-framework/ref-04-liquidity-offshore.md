## 空间维度总览

在影响范围层级（L1→L2→L3）之外，还有空间维度——美元是全球货币，流动性跨越在岸与离岸：

```

│ 空间第三层：全球美元循环                                │

└─────────────────────────────────────────────────────┘
```

# 空间第二层：在岸-离岸传导

> 主要对应 **L1 狭义流动性的离岸映射**，Swap Spread同时反映 **L3 金融市场流动性**

## 一、Eurodollar市场 [L1]

离岸银行（主要是欧洲、日本）吸收美元存款→发放美元贷款→创造离岸美元信用。不在Fed管辖范围内，但规模巨大，是美元全球循环的核心引擎。

## 二、FX Swap市场 [L1]

**FX Swap是离岸获取美元的主要管道**。OTC cross-currency swap 日均成交额约 $1640 亿，是离岸美元流动性的主要管道。

**机制**：非美银行/企业需要美元→用本币做抵押通过FX Swap借入美元→到期换回。当离岸美元紧张时，FX Swap隐含的美元利率上升→基差走阔。

## 三、离岸→在岸传导路径 [L1+L3]

```
离岸美元紧张
    ↓
Xccy Basis走阔（欧元/日元基差扩大）
    ↓
非美投资者美元融资成本↑ → 对美债需求↓
    ↓
Swap Spread承压（外国央行卖出UST换美元）
    ↓
期限溢价↑
```

**关键洞察**：cross-currency basis有九大驱动因素（货币政策分化、对冲需求、监管约束、信用风险等）。**对美债分析而言，最重要的是理解basis走阔→海外UST需求减弱这条链。**

## 四、Cross-Currency Basis（货币互换基差）[L1]

**最重要的离岸美元压力指标。** 基差越负 = 离岸美元越紧缺。

| 基差 | 正常范围 | 压力信号 | 极端信号 | 公开数据源 |
|------|---------|---------|---------|----------|
| 欧元基差 | 0~+5bp | <0（转负） | <-20bp | `BIS / FRED / Web（货币互换基差）` |
| 日元基差 | -15~-25bp | <-30bp | <-50bp | `BIS / FRED / Web（货币互换基差）` |

**历史参考**：2020.3 日元-100bp/欧元-40bp；2022.9 日元-60bp；2025.4 日元-27bp后回稳

**离岸基差高频跟踪方法**：每周报告日元/欧元3个月互换基差变化，作为离岸美元流动性的核心监测。

## 五、Swap Spread（掉期利差）[L1+L3]

**在岸-离岸传导的核心枢纽。** Swap Spread = 互换利率 - UST收益率。负值越深 = 市场更偏好持有UST现券，但也可能反映做市商资产负债表约束。

| 期限 | 正常范围 | 信号 | 公开数据源 |
|------|---------|------|----------|
| 2Y | -10~-20bp | 大幅走阔→流动性压力 | `FRED / Web（互换利差）` |
| 10Y | -30~-45bp | 收窄→供给压力大；走阔→避险强 | `FRED / Web（互换利差）` |
| 30Y | -60~-80bp | 收窄→长端供给/久期压力 | `FRED / Web（互换利差）` |

**与美债联动**：Spread收窄→市场消化UST供给吃力→期限溢价上行压力；Spread走阔→避险需求强→长端利率下行

## 六、FRA-OIS利差 [L1]

**银行体系信用压力的前瞻指标。** FRA反映银行对未来融资成本预期，OIS反映无风险利率预期，二者之差即银行信用风险溢价。

| 指标 | 正常范围 | 预警 | 数据源 |
|------|---------|------|--------|
| 3M FRA-OIS | <30bp | >50bp | Bloomberg / Web |
| 6M FRA-OIS | <40bp | >60bp | Bloomberg / Web |

## 七、表外美元支付义务 [L1+L3]

> **核心发现**：FX Swap/Forwards 创造了规模巨大的表外美元支付义务，这些债务**不体现在任何资产负债表上**，却是离岸美元流动性压力的深层来源。**来源**：Borio, McCauley & McGuire (2022) "Dollar debt in FX swaps and forwards: huge, missing and growing"

### 7.1 核心数据

| 主体 | 表外美元债务规模 | 与表内美元债务比较 | 关键含义 |
|------|----------------|------------------|----------|
| 非美非银行主体 | **~$26万亿** | 表内的2倍 | 企业/基金的美元敞口远超可见数据 |
| 非美银行 | **~$39万亿** | 超过资本10倍 | 银行体系的美元错配被严重低估 |
| 全球合计 | **$80万亿+** | 超过T-bills+repo+CP之和 | 短期美元支付义务规模惊人 |

### 7.2 为什么"缺失"？

FX Swap在会计上被分类为**外汇交易**而非**借款**→不计入债务统计→不受债务限额约束→监管者难以看到全貌。2008和2020年央行出手救助时，**甚至不清楚谁欠了多少**。

### 7.3 与Xccy Basis的深层关系

Xccy Basis走阔不仅是"融资成本上升"——它是**$80万亿+表外头寸的压力释放**：

```
离岸美元紧张 → FX Swap市场需借入更多美元（滚动$80T+头寸）
    ↓
CIP偏离扩大 → 基差走阔 → 表外头寸隐含融资成本飙升
    ↓
被迫平仓 → 抛售美元资产/本币贬值 → 央行被迫干预
```

**对美债的实操含义**：
1. **基差走阔的冲击被低估**：几个bp的基差变化，背后是万亿级表外头寸的压力——"冰山一角"
2. **Q末窗口装饰加剧压力**：非美银行为满足SLR/杠杆率，Q末减少repo借出→转向FX Swap→基差季节性走阔（Kloks et al 2024 "Hunting for Dollars"）
3. **央行的信息劣势**：Swap Lines 救助时，Fed 无法精确知道谁欠了多少

### 7.4 跟踪方法

| 指标 | 含义 | 数据源 |
|------|------|--------|
| FX Swap 存量（半年度） | 表外美元债务总量 | Triennial Survey + OTC Derivatives Statistics |
| Xccy Basis（欧元/日元3M） | 表外压力的实时价格信号 | `BIS / FRED / Web（货币互换基差）` |
| 非美银行美元资产负债缺口 | 银行体系美元错配 | LBS/CBS（季） |
| Q末基差季节性走阔 | 窗口装饰效应 | 日度基差数据 |

# 空间第三层：全球美元循环

> 同时涉及 **L2 广义流动性（全球信用周期）** 和 **L3 金融市场流动性（跨境资本流动）**

## 八、美元潮汐机制 [L2+L3]

### 8.1 "美元—美债"循环

```
美国进口 → 贸易逆差 → 出口国获得美元
    ↓
出口国将美元回流美国 → 购买美债/美股 → 金融账户顺差
    ↓
低利率 + 强消费 → 继续推动进口 → 新一轮循环
```

**循环的脆弱性**：当美元资产吸引力下降（财政担忧/去美元化/地缘风险），回流减弱→美债需求端承压→利率上行→进一步削弱吸引力→负反馈。

### 8.2 套息交易与杠杆

**日元套息**是离岸美元体系最大的杠杆来源之一。低利率借日元→换成美元→买UST/美股。当日元快速升值或美元流动性紧张→unwind→UST抛售+美元走弱。

**跟踪**：CFTC日元净空头、FX Swap基差、日美利差变化。

### 8.3 Real Money再平衡

**BFC汇谈（2025.5）**："过去几年亚系资金普遍存在美元套息头寸裸露的问题。2025年跨境资金有再平衡的趋势——流出美国流向非美。"

**跟踪**：跨境资金流数据、EPFR跨境资金流、TIC数据。

## 九、离岸美元供给：Fed的全球后门 [L1]

### 9.1 中央银行流动性互换（Swap Lines）

**Fed向海外央行提供美元的最后渠道。** 正常时期用量极低，危机时激增。

| 时期 | 互换余额 | 含义 |
|------|---------|------|
| 平时 | $0-200亿 | 离岸美元充裕 |
| 2020年3月 | >$4000亿 | 离岸美元冻结→Fed充当全球最后贷款人 |
| 2026年5月 | ~$206亿 | 温和压力（美伊冲突相关） |

**解读规则**：互换余额快速增加 = 离岸美元严重短缺 = 全球美元流动性危机信号。

### 9.2 FIMA回购工具

Fed于2020年3月设立，允许外国央行将持有的UST抵押给Fed换取美元，而无需在市场上抛售UST。**防止"央行抛美债→美债崩"的关键安全阀。**

### 9.3 SRF（常备回购便利）

对内的紧急流动性后门。允许一级交易商以UST/MBS为抵押从Fed借入隔夜现金。频繁使用 = 在岸流动性紧张。

## 十、离岸美元压力对美债的传导路径 [L1+L2+L3]

### 10.1 三条冲击路径

```
路径1：离岸紧张 → Xccy Basis走阔 → 海外投资者融资成本↑ → UST需求↓ → 期限溢价↑
路径2：离岸紧张 → EM资金外流 → 央行消耗储备 → 抛售UST → 长端供给压力↑
路径3：离岸紧张 → 央行激活互换线/FIMA → Fed被动扩表 → 短期缓解但道德风险
```

### 10.2 历史案例映射

| 事件 | 离岸压力 | 传导路径 | 美债影响 |
|------|---------|---------|---------|
| 2020.3 COVID | 日元基差-100bp | 三条全触发 | 10Y先升至1.2%后Fed介入跌至0.5% |
| 2022.9 UK养老金 | 日元基差-60bp | 路径1+2 | 10Y触及4.25%后回落 |
| 2019.9 Repo危机 | SOFR飙升（在岸主导） | 路径1局部 | 10Y短期上行10bp后Fed介入回落 |
| 2025.4 Liberation Day | 日元基差-27bp | 路径1为主 | "Sell America"股债汇三杀 |

## 十一、全球美元信用周期（GLI框架）[L2+L3]

> Global Liquidity Indicators（GLI）是全球流动性的官方度量——跟踪非银行外币信用（银行跨境贷款+国际债券），按美元/欧元/日元分列。用GLI定位当前信用周期阶段，是判断资金面大方向的"卫星图"。

**来源**：Hardy & von Peter (2023) "Global liquidity: a new phase?"，BIS Quarterly Review December 2023。结合最新统计更新。

### 11.1 全球流动性三阶段

| 阶段 | 时期 | 驱动 | 美元信用特征 | 对美债的含义 |
|------|------|------|------------|------------|
| **Phase 1**<br>银行驱动扩张 | 2003-2009 | 银行杠杆宽松、监管弱 | 银行跨境贷款狂飙，年增速>10%，峰值24%（2007） | 信用泛滥→房产泡沫→利率上行→GFC |
| **Phase 2**<br>债券替代+EMDE扩张 | 2009-2021 | 银行受监管约束退出，低利率推动search for yield | 美元信用向EMDE倾斜，债券融资取代银行贷款 | 压低期限溢价（EMDE央行买UST），但积累错配 |
| **Phase 3**<br>紧缩与分化 | 2022至今 | 全球通胀→同步加息→美元走强 | 美元信用收缩（尤其是EMDE），银行信贷回升 | 信用收缩→利率下行趋势，但期限溢价上行 |

### 11.2 当前定位（2025Q4数据）

**全球跨境银行信贷统计（2025年12月末）**：
- 全球跨境银行信贷：$37万亿+（全年增11%，2008年来最快）
- **美元信用同比+8.5%**（2014年来最快）← 似乎与Phase 3"收缩"矛盾？
- 欧元信用同比+11%，超过美元；日元信用同比-4.9%

**解读**：Phase 3并非单调收缩——2024-2025年出现"信用再扩张"，但结构不同：
- **银行信贷回归**：对NBFI的跨境银行贷款年增速14%→银行重新成为引擎（vs Phase 2的债券驱动）
- **对EMDE美元信用增速6.2%**，远低于欧元信用的12%→美元信用扩张更集中于AE
- **债券融资vs银行贷款**：银行贷款增速重新超过债券→结构回摆向Phase 1模式

**对美债的含义**：
1. **信用再扩张→利率下行空间受限**：全球美元信用8.5%增速→不支撑大幅降息→10Y下行有底
2. **NBFI信用膨胀是脆弱性积累**：对影子银行跨境贷款增速14%→如果逆转→冲击传导至UST市场
3. **EMDE美元信用增速低于AE**→新兴市场不是当前信用扩张主角→"去美元化"在信用端尚未显现

### 11.3 GLI实操

| 步骤 | 做什么 | 数据源 |
|------|--------|--------|
| 1. 定位阶段 | GLI增速扩张还是收缩？银行vs债券谁在驱动？ | Global Liquidity Indicators 季度发布（bis.org/statistics/gli.htm） |
| 2. 信用结构 | 美元/欧元/日元增速对比；AE vs EMDE分布 | 全球跨境银行信贷统计 Graph 5系列 |

| 4. 脆弱性评估 | NBFI信用增速是否异常→未来逆转风险 | IBS 统计 Graph 1系列 |

## 十二、宏观因子与去美元化 [L2+L3]

全球宏观六因子框架（增长/通胀/流动性/法币信用/风险偏好/AI科技），其中**流动性因子**直接对应本碗。

### 12.1 流动性因子与美债

**公开源数据**：
- `自行构建（原方法论自产因子，可跳过）` → 周度六因子水平
- `自行构建（原方法论自产因子，可跳过）` → 拆分为：大类资产共振 + 全球利率 + 大类资产波动 + 美元指数

**实操**：
1. 看流动性因子方向（扩张/收缩）→ 判断资金面大方向
2. 看因子拆解→ 识别驱动是利率、波动还是美元
3. 看流动性-增长相关性 → 转负=滞胀交易；转正=复苏交易
4. 看流动性-通胀相关性 → 转负=紧缩交易

### 12.2 "去美元化"与美债

**策略（2026.4）**："去美元化"是长期变量；三个层级进展不同：去美元资产（脉冲式）< 去美元储备（中期推进）< 去美元结算（早期）。

**对美债的含义**：储备多元化（央行购金替代部分UST）→边际需求减弱→期限溢价长期上行压力。但非美"不可回避的核心配置"属性未根本动摇→短期冲击有限。

### 12.3 法币信用因子

**公开源数据**：`自行构建（原方法论自产因子，可跳过）`中的法币信用因子

**含义**：法币信用因子下行 = 市场对美元信用/美国财政可持续性的担忧↑ → 黄金相对UST受益 → 30Y期限溢价上行压力
