# 基本面分析体系

## 指标跟踪体系

## PMI分析框架

- **荣枯线（50）**：区分扩张/收缩
- **供需缺口**：新订单-生产指数 → 判断需求和供给相对强弱
- **价格分项**：出厂价格、购进价格 → 领先PPI
- **12MMA平滑**：过滤季节性噪音

## "货币-信用"四象限

| 货币\信用 | 宽信用 | 紧信用 |
|-----------|--------|--------|
| **宽货币** | 最差（熊市，经济过热预期）| 次好（牛市，经济弱但流动性充裕）|
| **紧货币** | 次差（信用强，货币收） | 最好（有心无力，债市最佳）|

**"有心无力"对债最好**：实体想扩张但货币偏紧，或货币想宽但信用无法扩张

## 社融指标的局限性（近年失效原因）

1. 新经济天然信贷需求低，传统金融指标代表性下降
2. 金融数据更多反映供给端驱动而非实体需求
3. 社融统计口径扩大（纳入国债等），综合性增强
4. 应对策略：看结构（票据、企业债vs政府债）、看量价分离、高频交叉印证

## 当前宏观理解框架（新旧动能转换）

```
旧经济（地产+城投+重资产）→ 出清中，融资需求持续走弱
新经济（高端制造+科技+绿色）→ 崛起中，但信贷类融资需求天然偏低
结果 → 实体扩表动力不足 → 金融扩表（广义基金/理财膨胀）→ 资产荒
```
