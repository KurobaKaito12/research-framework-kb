# 债券回报来源与盈利模式

## 债券持有期回报公式

持有期回报 = （票息回报 + 下滑回报（骑乘）+ 资本利得）×（1 + 杠杆率）- 资金利率 × 持有时间

**四种赚钱方式：**

| 策略 | 对应判断 | 风险点 |
|------|----------|--------|
| 久期（资本利得） | 利率方向判断 | 利率反向波动 |
| 票息（息差/下沉） | 信用甄别能力 | 信用违约 |
| 波段操作 | 择时能力 | 频繁交易摩擦成本 |
| 杠杆 | 资金面稳定性判断 | 资金面突然收紧 |

## 机构类型与盈利模式

- **银行（配置盘为主）**：偏好利率债，承接一级市场供给，受额度/监管指标约束
- **银行理财**：短期化、净值化，委外驱动，规模扩张是配债主力
- **保险/年金**：拉久期、绝对收益导向，偏好超长利率债，资产负债匹配
- **公募基金/债基**：相对排名压力，资产荒下拉久期+波段操作
- **券商自营**：灵活，可做交易，国债期货参与较多
- **外资**：受中美利差、汇率、锁汇成本影响

## 债市发展阶段变迁

1. **快打慢时代**（2008前）：银行/保险配置盘主导
2. **卖方时代**（2008-2013）：承销商主导，一级半市场
3. **负债能力时代**（2013-2019）：同业创新、理财崛起、杠杆模式
4. **多资产时代**（2019后）：打破刚兑、固收+兴起、信用分化
5. **工具化时代**（2022后）：策略荒+资产荒→ETF/指数化，利率化特征明显
