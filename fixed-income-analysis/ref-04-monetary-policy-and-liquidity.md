# 货币政策与资金面分析

## 货币政策四大目标（相机抉择）

1. **经济增长与充分就业**：GDP、PMI、调查失业率、新增就业、投资、消费、出口
2. **物价稳定**：CPI（核心CPI）、PPI、GDP平减指数、物价预期指数
3. **金融稳定**：宏观杠杆率、债市杠杆、房价/股价、银行息差
4. **国际收支平衡**：人民币汇率、中美利差、跨境资本流动

**三大约束（制约降息的关键）：**
- 汇率（人民币贬值压力、中美利差收窄风险）
- 银行息差（商业银行净息差已降至1.5%以下警戒线）
- 防空转（打击资金套利、股债过度炒作）

## 货币政策框架演变

```
2015年前：存贷款基准利率为锚（价格型调控萌芽）
2015-2018：MLF → LPR报价改革探索期
2019：MLF正式挂钩LPR，双支柱框架确立
2022：MLF → LPR → 存款利率（打通负债端传导）
2024：弱化MLF，强化7天逆回购为主要政策利率
 收窄利率走廊，推出临时隔夜正/逆回购
2025：MLF正式退出政策利率定位，完善利率走廊
```

## 从宏观状态推断降息概率

**支持降息的信号组合：**
- PMI三个月均值持续低于50
- 社融同比持续下行
- CPI/PPI持续负增长或低通胀
- 房价同比持续负增长
- 银行息差有空间（>1.6%）
- 中美利差收窄幅度可控/汇率稳定
- 实际利率偏高（名义利率-CPI > 2%）

**制约降息的信号：**
- 汇率贬值压力加大
- 银行息差过低（<1.5%）
- 通胀预期回升
- 资产价格过热

```

 ↓
短端利率（1年国债/存单）
 ↓
LPR报价（1年/5年）
 ↓
贷款利率 & 存款利率
 ↓
实体融资成本
```

**债市传导：**
```
OMO降息 → 资金中枢下移 → 短端利率下行 → 曲线陡峭（牛陡）
 → 市场预期长端利率也下行 → 长端跟随下行（牛平）
```

## 资金面分析框架（四维度）

### 量（流动性总量）
- 央行OMO净投放/净回笼
- 降准释放资金量
- 财政资金收支（税期效应：月中、季末压力大）
- 政府债发行缴款（大规模发行压资金）

### 价（资金价格）
- DR001/DR007（银行间，核心锚）
- R001/R007（含非银，关注分层程度）
- GC001（交易所）
- 与7天OMO的偏离程度

### 结构（资金分层）
- 大行 vs 中小行 vs 非银利率分层
- 货币基金融出量变化（大行+货基双中心格局）
- 存单利率（银行主动负债成本）

### 波动（季节性规律）
- 月末/季末：MPA考核压力，资金面普遍收紧
- 税期（每月15-25日前后）：缴税压缩流动性
- 春节前：取现需求大，央行通常加大投放
- 政府债发行高峰期：缴款压资金
