# 债市供求关系分析

## 供给端分析框架

### 利率债供给预测

```
国债净供给 ≈ 中央财政赤字
新增地方一般债 ≈ 地方财政赤字限额
新增地方专项债 ≈ 全年专项债限额
政金债 ≈ 政策性银行信贷计划
```

### 关注供给节奏
- 是否前置发行（年初集中发行→资金面承压但后期偏松）
- 特别国债/特殊再融资债是否超预期
- 地方债发行是否滞后（→机构欠配→抢利率债）
- 月度供给量与季节性对比

### 信用债供给
- 产业债：与企业盈利/融资需求挂钩
- 城投债：化债政策约束，整体收缩
- 银行资本债（二永债）：补充资本金需求持续
- 科创债（2025年扩容，重点关注）

## 需求端分析框架

### 银行自营
- **大行**：承接利率债一级供给主力，放贷优先，季末OCI浮盈兑现
- **城商行**：偏好信用债+中等久期，负债成本偏高
- **农商行**：可投信贷资产少，企业债/存单配置多，受严监管约束

**配置决策影响因素：**
- 信贷额度（信贷多→买债少，信贷少→买债多）
- MPA考核（广义信贷增速约束）
- 资本充足率（影响风险资产扩张能力）
- 息差压力（债券收益率是否覆盖负债成本）
- 会计分类：FVTPL（交易）/ FVOCI（配置）/ AC（持有到期）

### 银行理财
- **规模**：约32万亿（2026年2月），是债市最大买方之一
- **资产配置**：债券43.9% + 现金存款23.3% + 存单13.5%（2025年）
- **行为特征**：
 - 净值化后稳定性下降，赎回风险需关注
 - 短期化明显（偏好1-3年品种）
 - 委外是公募基金重要资金来源
- **反馈机制**：行情好→理财业绩好→规模扩张→继续配债→正向循环
- **风险点**：债市调整→净值下跌→赎回潮→被动抛债→踩踏

### 保险资金
- **规模**：约30万亿+
- **特征**：拉久期（偏好10年以上，甚至30年/50年）、绝对收益导向
- **配置逻辑**：收益率需覆盖负债成本（保险产品预定利率）
- **近年变化**：IFRS9实施→资产负债久期匹配压力，久期缺口约6年
- **关注利差损风险**：长期低利率→资产收益率持续下滑

### 公募基金/债基
- **规模**：持续扩张，债券ETF突破5000亿（2025年7月）
- **行为特征**：
 - 相对排名压力→趋势追涨
 - 资产荒→拉久期为主要策略
 - 工具化倾向明显（利率债ETF、信用债ETF、科创债ETF）
- **债券ETF影响**：成分券被动买入→利差压缩→非成分券与成分券估值分化

### 外资机构
- **规模**：约4-5万亿，占比约2-3%
- **驱动因素**：中美利差（锁汇后）、汇率预期、地缘风险
- **近年回流原因**：外汇掉期带来的套利机会
- **持仓结构**：以国债为主（约六成），存单占比也较高
- **市场影响**：非常小，不主导债券定价

## 金融资产创造与资产荒逻辑

```
实体融资需求弱（旧经济出清，新经济信贷需求低）
 ↓
社融增速下行，银行"被动"扩表（大行放贷、小行买债）
 ↓
广义基金规模膨胀（手工补息叫停→存款搬家→理财/债基扩张）
 ↓
债券需求持续扩张，资产供给相对不足
 ↓
资产荒 → 利率持续下行，利差持续压缩
```

**资产荒的破局因素：**
- 经济实质性复苏，融资需求回升
- 债券供给大幅扩张（财政加力）
- 监管收紧非银扩张
- 股市赚钱效应显著，资金从债转股
