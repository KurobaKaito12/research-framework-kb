## 核心框架：债市"五碗面"

五碗面用于把任何债市问题拆解为同一套可比较的信息集：

```
基本面（①）→ 中期趋势的根本
政策面（②）→ 货币/财政/监管政策
供求面（③）→ 机构行为与供需结构
资金面（④）→ 短期利率锚
情绪/估值/技术面（⑤）→ 短期波动与拥挤度
```

**标准分析步骤：**
1. 判断当前经济所处周期位置（基本面）
2. 评估货币政策取向与资金面松紧（政策面+资金面）
3. 分析债券供求结构（供求面）
4. 评估市场情绪与估值分位（情绪面）
5. 综合得出利率中枢判断与策略建议

## 快速分析模板

当遇到具体债市问题时，按以下六步顺序思考：

**Step 1：当前处于哪个大周期阶段？**
→ 利率上行/下行趋势中？新旧动能转换？大国博弈影响？

**Step 2：五碗面各自指向什么？**
→ 基本面：增长/通胀/融资需求
→ 政策面：货币/财政/监管取向
→ 资金面：DR007水平/央行态度
→ 供求面：供给节奏/机构行为/资产荒程度
→ 情绪面：久期/仓位/估值分位

**Step 3：主要矛盾是什么？**
→ 哪个因素当前权重最高？是否存在预期差？

**Step 4：赔率与胜率如何？**
→ 当前位置输赢比是多少？市场仓位如何？

**Step 5：策略选择**
→ 久期方向、品种选择、杠杆水平、止损纪律

**Step 6：风险情景**
→ 什么情况会证明判断错误？如何止损？
