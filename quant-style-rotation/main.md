# A股风格因子择时与轮动

> 来源：金工研究《基于趋势和拐点的市值因子择时模型》（2025-05-25）、《红利因子择时与2025Q1行业ETF投资建议·ETF智投系列之三》（2025-01-07），林晓明/徐特/何康等。

## 0. 核心框架

风格因子择时 = **趋势模型（右侧）+ 拐点模型（左侧）** 的融合：

| 模型 | 信号侧 | 数据 | 作用 |
|------|--------|------|------|
| 趋势模型 | 偏右侧 | 宏观指标趋势 + 因子自身趋势 | 顺势开仓/清仓 |
| 拐点模型 | 偏左侧 | 量价拥挤度 | 提前预警强势风格反转（"一票否决"） |

**关键判断**：因子走势越温和（如红利），单靠趋势模型就够；因子越易爆发突破/破位（如市值），趋势模型难从右侧跟上，**必须引入拐点模型**左侧提示反转。

## 1. 第一步：定义风格因子（择时对象）

风格因子 = **多头组日收益率均值 − 空头组日收益率均值**，累乘得净值。定义要兼顾 BARRA（便于指增产品暴露管理）和宽基指数成分（便于 ETF 轮动）。

**市值因子**（沪深300 ↔ 中证2000）：
1. 剔除上市不满 63 交易日的股票 → A
2. 剔除 A 中过去 63 日均成交额后 10% → B
3. 剔除 ST/*ST/停牌/北交所 → C
4. C 按过去 63 日均总市值十分组；第10组（小市值）日对数收益均值 − 第1组（大市值）日对数收益均值 = 市值因子日收益率

**红利因子**（中证红利样本空间）：
1. 中证全指成分，剔除上市不足63日、ST/*ST
2. 留过去 250 日均总市值与均成交额均在前 80% 的个股
3. 留过去三年连续分红、且过去一年股利支付率 ∈(0,1) 的个股
4. 按过去三年平均现金股息率十分组；第1组（高股息）− 第10组（低股息）= 红利因子日收益率

## 2. 趋势模型：多组双均线系统

为应对噪声、降低参数敏感性，用 **45 组双均线**：短均线窗长 ∈{1,5,10,15,20}，长均线窗长 ∈{5,10,15,20,30,40,60,90,120,180,250}（长 > 短），共 11+10+9+8+7=45 组。

**打分规则**：每个交易日，对"利好多头风格"的指标统计 45 组"金叉"比例，对"利空"的指标统计"死叉"比例。比例 ≥X 记 +1，≤1−X 记 −1，否则记 0（维持前期仓位，降换手）。**X 是关键参数，需偏离 0.50** 避免震荡市频繁交易。

**指标得分汇总 → 开/清仓**：总分 ≥1 开仓因子；≤−1 清仓；=0 维持。

### 市值因子的宏观趋势指标
先验逻辑：**景气利空小市值、宽松利好小市值**。单指标须在训练集（及剔除2024年初两个月的训练集）双区间内、在6个X取值下满足：信号次数≥2、≥5个X回归年化收益优于基准、≥5个X最大回撤更低、≥5个X最长新高天数显著下降、且满足先验逻辑方向。同维度指标**共享X**降过拟合。

- **经济增长维度（5指标，最优 X=0.65）**：铜金比、波罗的海干散货指数(BDI)、PTA平均产业链负荷率、建材综合指数、秦皇岛港煤炭吞吐量。（均按日历日升采样、ffill、做指数/移动平均预处理）
- **流动性维度（4指标，最优 X=0.60）**：R007、Shibor三个月、1年期国债到期收益率、10年期国债到期收益率。

### 红利因子的宏观趋势指标
先验逻辑：红利受益于"资产荒"。
- **银行间市场成交量**（Wind M0041739）：放大 → 资金空转找不到出路 → **利好**红利（金叉计分）。
- **期限利差**（10年−1年国债，S0059749−S0059744）：走阔 → 借短买长有利可图 → **利空**红利（死叉计分）。
- 加上红利因子自身净值趋势，三者得分 ∈[−3,+3]；首次 ≥+1 开仓、回落至 ≤−1 清仓。

**开仓阈值 X 较鲁棒**：红利场景 X∈{0.60~0.75} 均优于 0.55；市值场景趋势模型最优 X≈0.60。

## 3. 拐点模型：拥挤度 + 门限测试（市值因子核心创新）

逻辑："击鼓传花"式上涨 → 量价拥挤 → 找不到接棒者 → 踩踏式反转。用量价观察交易是否拥挤。

### 十类拥挤度指标
基于小/大市值组成分股量价构建，每类含多参数/多视角子指标（**因子视角** vs **个股视角**，差异源于滚动窗口内成分股变化）：
1. **动量之差**（小−大，T∈{5,10,20,30,40,50,60}）
2. **成交额之比**（小/大）
3. **换手率之比**（成交额/流通市值）
4. 波动率之比
5. **真实波幅之比**（隔夜与日内波动较大者，归一化）
6. **涨跌比之差**（(涨家数−跌家数)/总数）
7. 强势股占比之差（站上T日均线占比）
8. **配对相关性之差**（相关矩阵非对角元均值，刻画走势趋同）
9. **第一主成分贡献率之差**（最大特征值/特征值之和）
10. **风险对冲系数之差**（等权组合波动率/个股波动率之和）

### 门限测试（检验子指标是否具反转特征）
用量价指标 w 年滚动分位数定义门限值（w∈{3,4,5}，未来收益窗 t∈{5,10,15,20}）。良好拥挤度指标应满足：门限越接近100%（小市值越拥挤）→ 市值因子未来跌幅越大；越接近0%（大市值越拥挤）→ 未来涨幅越大。即未来 t 日收益率均值**随门限值升高显著下降**（用均值而非中位数以纳入极端踩踏）。

通过门限测试需同时满足（对小、大市值反转均有效，降过拟合）：
1. 门限1%~10%段，未来收益均值95%置信下显著下降趋势
2. 门限1%~5%段，每个门限的未来收益均值 >0.01%
3. 门限90%~99%段，95%置信下显著下降趋势
4. 门限95%~99%段，每个门限未来收益均值 <−0.01%
5. 低门限段收益均值 > 高门限段收益均值
6. 不同 (w,t) 组合中只要有一个满足即可

市值因子上 8 类指标有子指标通过（共38个，仅波动率之比、强势股占比之差未通过）。

### 拥挤度得分合成（三层逐级取极端一半求均值）
1. 单子指标：不同 w 中，小市值取门限值最高的一半求均值、大市值取最低一半求均值
2. 一类指标：不同参数T/视角的子指标同样取极端一半求均值
3. 跨类别：得到**小市值拥挤度得分**（越近100%越拥挤）、**大市值拥挤度得分**（越近0%越拥挤）

拥挤度与未来1日收益相关性不高（7.3%/4.6%），但**反转前会偏左侧达到极端值**，可提前约20日预警（如2023-10-24起小市值拥挤>95%，2024-01-10反转）。

## 4. 趋势 + 拐点融合 → 风格轮动

- **趋势得分**：增长维度 + 流动性维度（各∈{+1,−1,0}），和 ∈[−2,+2]，两维共享 X。
- **拐点得分（一票否决，±2）**：近20交易日内若有2日小市值拥挤度 >阈值C → 记 −2；若有2日大市值拥挤度 <1−C → 记 +2；同时拥挤以**先出现者为准**。信号延续20日（左侧、未来20日门限测试表现好）。
- **总得分 = 趋势 + 拐点**：≥1 开仓因子；≤−1 清仓；=0 维持。
- **最优方案**：趋势(开仓阈值X=0.60) + 拐点(高拥挤阈值C=95%)。相较市值因子基准，年化/回归年化 +13pct 上下，最大回撤降约32pct，最长新高天数降约1100日，开仓仅17次（低频）。
- **应用于轮动**：沪深300代表大市值、中证2000代表小市值，用最优信号轮动 → 年化21.02%，跑赢等权基准13.74%（截至2025-04-30）。

## 5. 评价指标（择时专用）

除年化收益、最大回撤外，引入两个抗运气指标：
- **回归年化收益**：对 ln(nav_t)−ln(nav_0)=kt 回归，取 k×250。降低单次大波段/黑天鹅的极端运气干扰。
- **最长新高天数**：买在阶段高点后最多需多少交易日回本，衡量"小幅回撤但久不盈利"的糟糕体验。

## 6. 过拟合防范（贯穿全流程）

- 同维度指标共享参数 X；
- 单指标须在"含/不含2024年初两个月"双区间稳健；
- 子指标须对大、小市值反转**双向有效**，而非分别挑选；
- 用多组双均线/多参数取极端一半求均值，避免依赖单一参数；
- 优先低换手（"以不变应万变"）。

## 7. 应用本 skill 时

1. 先明确择时对象（市值/红利/其他风格）并按规则构建因子净值。
2. 跑趋势模型（45组双均线 + 维度指标打分），给右侧顺势观点。
3. 若因子易爆发（如市值），叠加拐点模型（拥挤度+门限），给左侧反转预警。
4. 融合总分给开仓/清仓/维持结论，必要时映射到对应宽基ETF轮动。
5. **方法迁移须谨慎**：红利等温和风格拐点模型构建难度大；缺数据时说明所需输入，不要编造拥挤度/信号。
