# 公募基金评价归因筛选

> 来源：金工研究基金研究系列（2020-2023），林晓明/黄晓彬/张泽/刘依苇等。
> 本 skill 仅提供方法论，不涉及证券投资基金评价业务，不构成对任何基金产品的推荐或投资建议。产出分析时请声明数据来源（Wind / 研究团队 等）。

## 0. 全流程框架（系列核心）

基金评价及筛选四步走：

1. **确定类别与风格** → 2. **多维定量评价**（业绩 / 持续性 / 选股择时能力 / 可投资性） → 3. **绩效归因**（拆解收益来源） → 4. **定量+定性综合评价**

底层认知（系列二）：**基金特征 ↔ 基金绩效密不可分**——基金特征（经理、持续性、标签）决定绩效，绩效反映特征。**收益来源 = 资产配置 + 行业轮动 + 基金筛选** 三环节，每环节每年都贡献可观收益（历年最优/最差大类资产收益差均值71pct、行业86pct、头尾权益基金57pct）。

**关键事实**：A股公募权益基金**业绩持续性弱、持续时长短**，历年靠前/靠后基金之后收益无显著差别，**简单动量/反转策略选不出绩优基金** → 必须依托系统性框架。

## 1. 第一步：类别与风格

- **一级分类**：以证监会分类为准；二级可用晨星分类（事前法律文件 + 事后实际）。
- **股票基金风格**：
 - 持仓法（晨星风格箱：规模 × 价值成长）
 - 净值法（威廉·夏普风格分析：净值对风格指数收益率回归，可高频跟踪）
 - **风格漂移**：对比招募说明书检验；用 **SDS 指标**定量评价风格稳定程度。
- **债券基金风格**：久期配置 + 信用配置，同样可用持仓法或净值法估计。

## 2. 第二步：多维定量评价

### 2.1 业绩指标
- 基础：收益率、波动率、最大回撤
- 风险调整：**夏普比率、特雷纳指数、信息比率**
- 其他：**Calmar 比率、MRAR、M² 测度**

### 2.2 业绩持续性
- **横截面分析法**、**交叉积比率法（CPR）**、**Hurst 指数法**。
- CPR：统计季度/半年度/年度周期的 ln(CPR) 分布判断持续性。结论：国内权益基金持续性弱。

### 2.3 选股择时能力（系列一专题）
均起源于 CAPM / Jensen 单因素模型（Jensen 只评选股 alpha、无法评择时）：

| 模型 | 原理 | 择时判据 |
|------|------|----------|
| **Jensen 单因素** | 单因素回归，α 衡量选股 | 无择时 |
| **T-M（Treynor-Mazuy）** | 引入市场收益**二次项**，使 β 随市场收益连续变动 | β₂（二次项系数）>0 为正向择时 |
| **H-M（Henriksson-Merton）** | 假设 β **二分**（上涨/下跌市场不同） | 上涨市 β₂ 与下跌市 β₁ 之差 >0 为正向择时 |
| **C-L** | 与 H-M 类似，**分开**衡量不同市场环境的 β | β₂ − β₁ > 0 为正向择时 |

实证规律：牛市选股择时能力都较强；熊市正向选股不明显、择时弱；震荡上涨市选股较强、择时不稳；灵活配置型基金择时能力强于其他类别。

### 2.4 投资可行性
基金交易渠道、FOF 可投资范围、规模、申赎状态、流动性、机构认可度。

## 3. 第三步：绩效归因

### 3.1 股票基金
- **Brinson 模型**（基于持仓，系列三专题）：将超额收益分解为三部分——
 - **配置收益（类别/行业配置）**：超低配某行业带来的收益
 - **选择收益（个券选择）**：行业内选股带来的收益
 - **交互作用**：配置与选择的交叉项

 本质对比"基金权重×基准收益"与"基准权重×基准收益"等组合，逐行业拆解。
- **Barra 模型**（基于持仓）：从风格因子角度拆解收益暴露。
- **Fama 模型**（基于净值）：对基金收益做多因子回归。
- **DEA 模型**（基于净值）：构建 DEPI 指标横向比较同类基金。

### 3.2 债券基金
- **Campisi 模型**（基于重仓券持仓）：较成熟。
- **基于净值**：从**利率风险因子、信用风险因子、可转债风险因子**三角度分解收益率。

## 4. 第四步：定量 + 定性综合评价

定量有局限（基金公司文化、经理职业素养难量化），需结合定性：
- 对**基金公司、基金经理、基金费率、基金业绩**设计评分点 + 权重，加权得综合得分。
- 制定**基金调研评价问卷**，后续跟踪调研检验评价结果与实际运作的匹配度。

## 5. 主动权益基金标签体系（系列五）

主动权益基金灵活度高、差异大、与经理策略高度相关，需**四维度三层级**标签体系：

| 维度 | 标签内容 |
|------|----------|
| **基金业绩** | 收益（绝对+超额）、风险（波动/回撤）、风险调整（夏普/卡玛）、持续性（Hurst） |
| **持仓特征** | 行业集中度与轮动性、是否行业主题、持股风格与风格集中度/**漂移度**、资产/个股**换手率**、重仓股**抱团度与拥挤度** |
| **基金经理能力** | **选股**（动态行业配置 AA + C-L 的 α）、**择时**（C-L 中收益溢价对市场溢价的暴露）、**行业配置**（行业间配置 + 左右侧能力） |
| **可投资性** | 规模、申赎状态、机构认可度 |

**实证发现**：
- 绩优基金各有特色，各指标因子相关性整体较低。
- 随机森林：**大小盘/成长价值风格因子 + 持仓集中度 + 变动性**对业绩及持续性解释力最高；选股能力、机构持有比例有一定择基效果。
- 合成后：风格因子、投资集中程度、持仓波动性对**卡玛比率与业绩持续性**有高区分度。
- **高持股风格漂移度 + 高行业轮动性** 两标签与绩优基金重合度较高。

## 6. 应用本 skill 时

1. 先**定类别与风格**（证监会分类 + 持仓/净值法），检查风格漂移（SDS）。
2. 同类同风格内用业绩指标 + 持续性（交叉积比率/Hurst）筛选，警惕"业绩持续性弱"——不要用简单动量/反转选基。
3. 评经理能力用 **T-M/H-M/C-L** 区分选股与择时，注意结论受牛熊环境影响。
4. 归因拆解收益来源：股票用 **Brinson（配置/选择/交互）**，债券用 **Campisi**，必要时叠加 Barra/Fama。
5. 主动权益用**四维标签体系**全面画像，重点看风格因子、集中度、波动性、漂移度/轮动性。
6. 定量须配定性（公司/经理/费率）综合打分。
7. 缺数据时明确所需持仓/净值/申赎字段，**不要编造业绩、归因或能力检验结果**；表述上避免对具体产品作推荐。
