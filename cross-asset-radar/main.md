# 大类资产隐含预期雷达（cross-asset-radar）

## 核心理念

> 资产价格是预期的贴现机器。一组资产的相对表现 + 相关性结构，是市场对未来的"投票结果"。
> 本框架不做配置决策，只回答两件事：
> ① 市场当前在 price in 什么（全球主线 + 中国主线）；② 这对各类资产意味着什么。
> 最有价值的产出是**背离扫描**——当资产间隐含预期互相矛盾，背离点就是机会或风险预警。

## 与相邻 skill 的分工

| Skill | 回答的问题 |
| --------------------------- | ------------------------------------------------------------- |
| asset-allocation | 配置方法论框架（模型/理论/相关性原理） |

| **cross-asset-radar（本）** | **市场在想什么 + 对各类资产意味着什么（预期解码，不给权重）** |

### 第 1 步：风险偏好温度计（市场画像 2.1）

横向比对一篮子 risk-on/off 代理，给 0~100 读数 + 方向 + 一句定调：

| 维度 | 指标 | risk-on 信号 |
| ------------- | ------------------------- | ------------------ |
| 波动率 | VIX | 低且下行 |
| 信用 | HY 利差 | 收窄 |
| 避险货币 | USDJPY↑、美元指数走弱 | 日元走弱、美元不抢 |
| 避险/工业金属 | 金银比↓、铜金比↑ | 偏工业属性 |
| 极端风偏 | BTC | 走强 |
| 中国情绪 | AH 溢价收窄、A股/港股放量 | 内外资风偏回升 |

读数规则：多数指标指向 risk-on 给 >60；分歧明显给 40~60 并点明分歧源；多数 risk-off 给 <40。

### 第 2 步：相关性结构 → regime 识别（市场画像 2.2）

用近 20/60 日相关性符号判断市场状态（**全球在前**）：

- 股债**负**相关 = 增长驱动（正常跷跷板）
- 股债**正**相关同跌 = 通胀/政策驱动（2022式）或流动性危机
- 金股同涨 = 流动性宽松驱动
- 油金同涨 = 滞胀担忧
- 美元与美股同向走强 = 美国资产 exceptionalism 资金虹吸
- 铜-美股同向 = 全球增长共识；背离 = 增长预期分歧

**中国专项判读：**

- A股与黑色系背离（A股/螺纹钢比值 + 相关性）= A股未定价真实地产基建需求走弱（黑色系在定价）；A股在定价什么需要独立证据验证（可能为政策预期、流动性驱动、风格轮动等），不可从背离直接推断
- AH 溢价走阔 = 内外资风险偏好分化、外资定价权下降
- 中美 10Y 利差走阔（中债收益率 vs 美债10Y）= 货币政策分化、人民币贬值与外资流出压力

### 第 3 步：背离扫描（市场画像 2.3，核心交付物）

> 当资产间隐含预期互相矛盾，背离点就是机会或风险预警。逐对检查，每条给四要素。

**四要素（每条背离必填）：**

1. **隐含什么**——这对资产各自在 price in 什么，矛盾在哪
2. **成因甄别**——是「全局预期分歧」（多个资产对同一宏观变量看法不一）还是「单市场独有触发剂」（某市场被自身因素驱动，与全局无关）。这是背离扫描的灵魂，决定了背离是真信号还是假信号
3. **历史谁通常对**——经验上哪类资产对宏观拐点更敏感（债券>股票、信用>权益、铜>股指等）
4. **启示**——对应资产的操作含义（不给权重，给方向与关注点）

**背离推断铁律——只否定，不肯定：**
从背离本身只能得出**否定判断**：强势资产定价的**不是**弱势资产所代表的那个变量。不能从背离直接推断强势资产**在**定价什么——后者需要独立证据。

- 正确：「A股强于螺纹 → A股未定价真实地产基建需求走弱」
- 错误：「A股强于螺纹 → 股市在抢跑政策预期」
- 正确做法：否定之后，另寻独立证据（政策文件、资金流向、估值、调研等）支撑正面判断，并在报告中分开陈述"排除项"与"推断项"。

**全球候选对（在前）：**

| 背离对 | 隐含矛盾 |
| ---------------------------- | -------------------------------------------------- |
| 美股涨 vs 铜跌 | 美股未定价需求走弱（铜在定价），正面驱动待独立验证 |
| 信用利差扩 vs 美股创新高 | 信用市场警示违约风险 vs 权益未定价该风险 |
| 美债定价降息 vs 周期股/铜强 | 债市看衰 vs 风险资产未定价衰退，正面驱动待独立验证 |
| 金涨 vs 实际利率涨（DFII10） | 黄金常与实际利率反向，同涨=避险/央行购金/去美元化 |
| VIX 低 vs 信用利差扩 | 期权市场淡定 vs 信用市场紧张 |
| 美元强 vs 美股强 | 美国 exceptionalism 资金虹吸 or 避险美元 |
| 油涨 vs 美债盈亏平衡通胀不动 | 油价上行未传导到通胀预期=供给冲击 vs 需求拉动 |

**中国候选对（在后）：**

| 背离对 | 隐含矛盾 |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| A股强 vs 黑色系弱 | A股未定价真实地产基建需求走弱，正面驱动待独立验证（可能：政策预期/流动性/风格轮动） |
| A股 vs 美股背离 | 内外增长预期分歧、风险偏好传导断裂 |
| 港股 vs A股背离（AH 溢价异动） | 内外资分歧、外资定价权变化 |
| 中债定价宽松 vs A股走强 | 债市定价基本面疲弱 vs A股未定价该疲弱，正面驱动待独立验证 |
| 中美利差走阔 vs 人民币未贬 | 利差压力 vs 汇率韧性，关注央行干预/结汇 |

## 报告模板（市场隐含预期诊断快照）

> 五段。全球在前、中国在后。定性为主、轻数据，每个关键数字带来源。

### 标题（强制）

报告必须以标题开头，格式：

```
【跨资产雷达 YYYY-M-D】
```

日期取数据快照的最新交易日（非当天日期）。月、日不补零。例如6月16日收盘数据，标题写「【跨资产雷达 2026-6-16】」。

### ① 核心主线（最先回答）

一句话点明当前市场最主导的交易主线。**默认全球 + 中国各一句**；除非两者演绎的是同一主题（如全球流动性宽松同时驱动两边），才合成一句。

### ② 市场画像

- **2.1 风险偏好温度计**：0~100 读数 + 较上次方向 + risk-on/off 定调，列 3~5 个支撑指标
- **2.2 市场 regime**：当前相关性状态 + 主导驱动（增长/通胀/政策/流动性），全球在前、中国在后，与相关性符号一致
- **2.3 背离扫描**：2~4 个矛盾点，全球候选对在前、中国在后，每条四要素（隐含/成因甄别/历史谁对/启示）

### ③ 市场在 price in 什么

- **全球维度（在前）**：全球主线、海外经济（增长/通胀/政策）、美国 exceptionalism，各一句 + 支撑指标
- **中国维度（在后）**：增长、通胀、产业逻辑、政策四条隐含判断各一句 + 支撑指标

### ④ 市场启示

- **中国资产**：A股 / 港股 / 中债 / 人民币的具体含义
- **全球资产**：美股 / 美债 / 黄金 / 铜油的方向与关注点
- **潜在预期差提醒（单列）**：市场当前共识与可能被忽视的预期差，机会视角

### ⑤ 风险点（反向验证，独立成段）

解读若错最可能错在哪。与预期差提醒区分：**预期差 = 机会**（市场没看到的），**风险点 = 自我质疑**（我可能看错的）。

## 自检清单（发送前必过）

1. **标题**是否存在，格式是否为「【跨资产雷达 YYYY-M-D】」（月日不补零）？日期是否取数据快照最新交易日？
2. **核心主线**是否明确、一句话能说清，且全球+中国各有落点？
3. **风险偏好温度计**读数是否有 3~5 个指标支撑，不是凭空给分？
4. **regime** 判断是否与相关性符号一致，没有自相矛盾？
5. **背离**每条是否溯源到具体资产，且区分了「全局分歧」vs「单市场独有触发剂」？背离推断是否遵循「只否定不肯定」——正面推断有独立证据支撑？
6. **全球维度是否覆盖**——「price in 什么」是否真的写了全球主线/海外经济/美国 exceptionalism，没有只盯中国？
7. **预期差提醒是否单列**——是否在市场启示里单独成块，且与风险点区分清楚？
8. 每个关键数字是否**带来源**（接口名+日期）？美元指数是否括号注明「广义口径，非 DXY」？数据缺失处是否标注「暂缺」而非臆造？
9. 报告末尾**不附数据来源说明**（继强总要求，来源已在正文中随数字标注，无需集中罗列）。用了 Wind 取数也无需附加声明。
10. **文字校验（强制最后一步）**：发送前通读全文，检查：(a) 错别字；(b) 语句残缺或奇怪的表述；(c) 中英文标点混用。发现任何一处必须修正后才能发送。

## 不做什么

- 不做配置权重决策，本框架只解码预期 + 扫背离
- 不做 DCC-GARCH 等复杂建模（近 20/60 日相关性符号已足够定性）
- 不做自动定时跟踪（按需快照交付）
- 不臆造缺失数据——金银比/铜金比缺金价时标「暂缺」，不编数字
