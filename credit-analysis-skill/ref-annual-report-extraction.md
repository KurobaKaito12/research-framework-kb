# 年报数据提取指南（通用）

## 数据优先级

| 优先级 | 来源 | 说明 |
|-------|------|------|
| 1 | 最新年度审计报告 | 年末/全年数据 |
| 2 | 次年审计报告期初数/上期金额 | 获取历史年度数据 |
| 3 | 评级报告 | 仅用于补充 |
| 严禁 | 评级报告季末/1-9月数据 | 不可替代年报年末数据 |

## 提取方法

- 严禁依赖自动PDF提取脚本（A股年报cmap字体重映射问题）
- 使用Agent基于read_file工具的逐页阅读方式
- 提取：财务报表章节定位→逐表提取→有息债务专项提取→经营数据提取

## 常见提取错误（必须避免）

| 错误 | 正确做法 | 校验方法 |
|------|---------|---------|
| 资产总计误读为流动资产合计 | 确认读取"资产总计" | 核对报表最下方大字 |
| 负债总额误读为流动负债合计 | 确认"负债合计" | 核对报表最下方大字 |
| 合同负债误读为资产 | 合同负债属负债类 | 查看左右位置 |
| 有息债务漏项 | 完整包含四项 | 逐项核对公式 |
| 有息债务混入无息科目 | 仅包含带息融资科目 | 检查每个科目 |

## 数据校验清单（强制）

1. 资产总计 = 负债合计 + 所有者权益合计
2. 资产总计 ≠ 流动资产合计（通常大20%以上）
3. 有息债务 = 短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券 ≥ 0
4. 利润表勾稽：营业收入 - 营业成本 ≈ 毛利润
5. 现金流量表勾稽：净增加额 ≈ 经营+投资+筹资+汇率变动

## 提取原则

1. 财务数据必须使用审计报告数据
2. 历史数据从次年审计报告获取
3. 经营数据如年报未披露可从评级报告补充，须标注来源
4. 年报未披露的数据不编造
5. 同一指标口径全文一致
