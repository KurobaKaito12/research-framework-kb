# 通用财务指标体系与计算公式

## 一、规模与地位指标
总资产、总负债、所有者权益、营业收入、营业成本、行业排名/市占率

## 二、盈利能力指标

| 指标 | 计算公式 |
|------|---------|
| 毛利率 | (营业收入-营业成本)/营业收入 |
| 净利率 | 净利润/营业收入 |
| ROE | 归母净利润/平均归母所有者权益 |
| ROA | 净利润/平均总资产 |
| EBIT | 利润总额+利息费用-利息收入 |
| EBIT利润率 | EBIT/营业收入 |

## 三、营运能力指标
- 应收账款周转天数 = 365/(营业收入/平均应收账款余额)
- 存货周转天数 = 365/(营业成本/平均存货余额)
- 总资产周转率 = 营业收入/平均总资产

## 四、资产质量指标
应收账款/总资产、存货/总资产、受限资产/总资产、固定资产成新率

## 五、资本结构指标
资产负债率、有息负债率、权益乘数、长期资本负债率

## 六、有息债务计算

```
有息债务 = 短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券
短期债务 = 短期借款 + 一年内到期的非流动负债
长期债务 = 有息债务 - 短期债务
```

补充科目：租赁负债、长期应付款（视行业判断是否带息）

## 七、偿债能力指标

| 指标 | 计算公式 |
|------|---------|
| 现金短债比 | 货币资金/短期债务 |
| 流动比率 | 流动资产/流动负债 |
| 速动比率 | (流动资产-存货)/流动负债 |
| 利息保障倍数 | EBIT/利息费用 |
| EBITDA利息覆盖倍数 | EBITDA/利息费用 |
| 经营现金流/有息债务 | 经营现金流净额/平均有息债务 |

## 八、现金流指标
经营/投资/筹资现金流净额、自由现金流、经营现金流/净利润、销售回款率

## 九、期间费用指标
期间费用率、销售/管理/财务/研发费用率

## 十、推算值标注规范
必须包含：指标名称、计算结果、分子分母数值、计算公式、数据来源
