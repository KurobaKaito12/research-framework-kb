# 数据优先级与来源规则

## 一、数据优先级总原则

| 优先级 | 数据来源 | 使用规则 |
|-------|---------|---------|
| P0 | 最新年度审计年报 | 最高优先级 |
| P1 | 历史年度审计年报 | 通过次年审计报告获取 |
| P2 | 评级报告 | 仅补充年报未披露数据 |
| P3 | 同花顺iFinD | 宏观经济/行业数据最高优先级来源（如有） |
| P4 | Wind/网络搜索 | 次选来源 |

## 二、各类数据来源规则

### 财务数据：必须使用年报审计数据，严禁用评级报告替代
### 经营数据：如年报未披露可使用评级报告补充，须标注来源
### 宏观/行业数据：同花顺iFinD（如有）为最高优先级来源，公开数据次之

## 三、数据使用红线

1. 严禁使用评级报告非年末数据替代年报数据
2. 严禁编造数据
3. 严禁无数据支撑的横向比较

## 四、数据标注规范

- 表格下方必须标注数据来源
- 推算数据必须标注推算逻辑
- 网络搜索数据标注搜索日期
