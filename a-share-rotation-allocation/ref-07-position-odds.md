# 仓位管理与概率赔率

仓位管理的本质：通过仓位控制改变赔率。

## 一、概率-赔率-换手率三角

```
概率（胜率）× 赔率（盈亏比）× 换手率（操作频率）
```

| 类型 | 概率 | 赔率 | 换手率 |
|------|------|------|--------|
| 价值投资者 | 高 | 低 | 低 |
| 趋势交易者 | 中 | 中高 | 中 |
| 超短线玩家 | ~50% | 靠仓位放大 | 极高 |

### 趋势投资的经验值
- **40%的概率 + 3倍以上赔率** 可能是比较好的组合
- 止损线应基于预期涨幅用赔率反算

## 二、仓位管理改变赔率

**交易者永远不应追求盈利最大化，而应追求赔率最大化。**

### 分步加仓法
1. 初始小仓位建仓（试错）
2. 浮盈确认后加仓
3. 单票最大回撤达到阈值则全部止损
4. 绝不在亏损时补仓

## 三、情绪周期驱动的仓位

| 市场周期 | 仓位 | 操作方式 |
|----------|------|---------|
| 上升期/高潮期 | 全仓或接近全仓 | 集中持有2-3只 |
| 混沌期 | 半仓左右 | 试错为主 |
| 退潮期 | 三成以下 | 宁可错过 |

## 四、不同市场环境的仓位策略

| 市场环境 | 建议仓位 | 配置方向 |
|----------|---------|---------|
| 牛市初期 | 70-90% | 成长+弹性 |
| 牛市中期 | 80-100% | 景气方向 |
| 牛市末期 | 50-70% | 逐步向防御转移 |
| 熊市初期 | 20-40% | 高股息+防御 |
| 熊市末期 | 40-60% | 逆向加仓 |
| 震荡市 | 40-60% | 做结构不做仓位 |

## 五、风控纪律

1. **永远不要all-in**
2. **单票仓位上限**：不超过30%
3. **止损必须执行**
4. **不在亏损时补仓**
5. **定期复盘**
