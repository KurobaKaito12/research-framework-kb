# 情绪周期与短线节奏

情绪周期决定短期操作节奏，是仓位和择时的核心变量。

## 一、情绪周期五阶段

| 阶段 | 表现 | 操作策略 |
|------|------|---------|
| **冰点** | 连板生态极弱 | 管住手，等待试错信号 |
| **拐点** | 有标的突围 | 小仓位试错 |
| **发酵** | 连板梯队形成 | 正常出击，关注龙头 |
| **高潮** | 批量涨停 | 大仓位参与 |
| **衰退** | 龙头疲力 | 减仓 |

### 三大区域
| 区域 | 仓位建议 |
|------|---------|
| 筑底期（冰点+拐点） | 三成以下 |
| 上涨期（发酵+高潮） | 大仓位 |
| 退潮期（衰退） | 三成以下 |

## 二、情绪标杆判定

- 情绪标杆 = 市场连板高度或断板反包高度的最高标的
- 连板高度持续递增 = 正向周期，递减 = 逆向周期

## 三、情绪周期的量化观测

| 指标 | 冰点信号 | 高潮信号 |
|------|---------|---------|
| 连板高度 | 2-3板 | 7板以上 |
| 涨停数量 | <30只 | >100只 |
| 连板晋级率 | <30% | >60% |
