# A股量化行业轮动

## 0. 总框架

行业轮动 = **截面**比较不同行业的投资机会。行业弹性大于宽基，捕获主线即显著跑赢。框架三大维度：

| 维度 | 内容 | 时效 | 2024后状态 |
|------|------|------|-----------|
| **基本面（景气投资）** | 宏观/中观/微观三视角判断 g/Δg | 月频 | **2024年几乎"全军覆没"** |
| **交易面** | 技术分析（DBCD）、残差动量、拥挤度、资金流 | 月/周频 | 残差动量、拥挤度经受考验 |
| **机器学习** | 遗传规划动态挖因子 | 周频 | 技术面遗传规划表现好 |

收益拆解视角：行业收益 = 市场/风格 Beta（景气投资捕捉）+ 残差（残差动量捕捉行业专属信息，二者近乎不相关，可等权融合成月频模型）。

**标的颗粒度（敏感变量）**：以中信一级为主、合理拆分部分二级。拆分依据：①一级行业市值庞大；②下属二级逻辑分化且各自明确；③二级有≥10年基础数据可建模；④二级有对应 ETF 可落地。过粗则逻辑混杂不显著，过细则新主题样本不足。

## 1. 基本面：行业景气投资（核心）

目标：判断行业盈利能力 g（>0）及其边际变化 Δg（>0），右侧投资 g>0/Δg>0、规避 g<0/Δg<0。"上帝视角"（已知真实ROE/ΔROE做多前五名）长期跑赢，难点在无上帝视角下如何预测 g/Δg。用**宏观、中观、微观三视角共4个因子**互补（"偏科生"组成"全科生"）。

### 1.1 宏观景气度：戴维斯双击因子
建立**动态**宏观-行业映射（避免静态投资时钟"刻舟求剑"）。将传导拆两段，重点建模第一段（宏观→行业分子端/分母端，比对股价更直接）：
- 分子端代理 = 各行业 ROE_TTM 季度差分（Δg）；分母端代理 = 实时 PB 对数季度差分（ΔPB）。
- 5年滚动窗口（终点为最近已发布财报）内，**多元线性稳健回归**建立"宏观因子变化→Δg/ΔPB"映射；代入最新宏观因子预测考察截面各行业 Δg/ΔPB。
- 用分段函数由 Δg、ΔPB 预测值构建**戴维斯双击因子**（突出双击机会、双杀风险）。宏观因子用自上而下 Factor Mimicking 构建的国内宏观预期指数。

### 1.2 中观景气度：产业链 Nowcasting
为每个行业建中观基本面数据库（上游供需、下游供需、行业内竞争，几十到几百指标）。因结构不规则、跨行业不可比，**以财务指标为"媒介"**：先用中观指标预测财务（净利TTM同比、营收TTM同比、ROE_TTM环比），再做行业间比较。
- 5年滚动窗口内**逐行业精选5-10个中观指标**（与真实财务的相关性+领先滞后性，用时差相关系数 + DTW 双重评价）。
- 用 **Nowcasting 模型**（亚特兰大联储实时预测GDP法；研究团队提出 Simple-Nowcasting 提效）在财报真空期实时更新预测。
- 基于 g/Δg 逻辑构建5个因子，**rank等权**合成中观景气度。构建前对预测值序列做 zscore（小样本用"减中位数除以四分位距"），消除行业长期中枢差异。
- 程序定期筛指标优于人工：客观、及时、可回测、无幸存者偏差（仅用≤截面信息）。

### 1.3 微观景气度：成分股自下而上
- **微观财务因子**：用真实财报 + 分析师一致预期，精选指标（如合成预期净利/营收/EBIT 的 CAGR 同比变化、净利调高家数占比、买入评级家数占比同比等）。注意：该因子已成机构标配，2021年9月后逐渐拥挤、NDCG长期<75%。
- **微观北向因子**（北向行为最贴合景气投资）：用北向持股市值比例（行业陆股通成分北向持仓市值 / 该行业陆股通成分总流通市值）。
 - **加仓持续性**：取最近60个沪深港通交易日持股比例序列对时间索引拟合趋势项做 t 检验，t 越正加仓越持续（t 无量纲，消除外资行业偏好）。
 - **加仓幅度** = 最新持股比例 / 最近60日均值。
 - 两者截面 rank 按 **2:1** 加总 = 北向因子。

### 1.4 综合景气度
4因子加权求和（**中观50% + 微观财务15% + 微观北向15% + 宏观20%**，约束中观>微观>宏观）。取综合得分前五名等权配置、月度调仓。2016-04~2023-08 多头年化超额 14.34%。注意：因子截面**非单调、小样本**，合成增益有限（小样本学习是方向）。100组随机权重检验：>95%概率取得>10%年化超额。

## 2. 交易面

### 2.1 残差动量（剥离风格后的核心驱动）
剔除市场因子和风格因子影响，残差捕捉产业政策、技术进步等非结构化驱动。改进版引入**波动率反转**：对日波动率最高月份的残差做反转处理。2017-01~2026-02 改进残差动量年化超额 12.90%（已被某FOF产品借鉴）。2024Q3~2025Q2 曾大幅回撤后快速修复、2026初创新高。

### 2.2 行业拥挤度（高位风险前瞻预警）
逻辑同风格拥挤：击鼓传花上涨→量价背离→踩踏。用**门限测试**精选 **4个量价指标**，单指标**滚动分位数达95%阈值**触发拥挤信号；**3或4个指标同时触发 = 行业高拥挤**。2026初成功预警国防军工、工业金属、贵金属（拥挤度3/4分略领先阶段高点）。规避高拥挤行业对长期业绩正贡献。

### 2.3 技术分析（DBCD）
效仿 Alpha101 思路，目前仅 **DBCD（异同离差乖离率）** 在周频行业轮动有效且参数鲁棒（用斐波那契参数 13,55,8）。DBCD = 乖离率一阶导，持续扩大表明强趋势→做多。但超额波动大、2024表现不佳。

## 3. 机器学习：多目标遗传规划

应对：①市场主线弱、轮动加快，**月频模型2022Q3后下台阶**（年化超额17%→7%、换手+40%），需周频；②MACD/KDJ等传统技术指标周频几乎全失效；③用选股因子合成行业因子"听天由命"。故**直接基于行业指数量价用遗传规划挖因子**。

- **多目标适应度**：单目标（仅|IC|或NDCG@k）面临种群拥挤、因子同质化。引入 **|IC|（单调性）+ |IC|胜率 + NDCG@k（多头组表现）** 三维评价，子代选择用 **NSGA-II** 算法形成对抗，保持种群多样性（种群规模 >> 进化次数；初始种群分小种群各自进化）。
- **工程**：算子用 PyTorch 实现便于 GPU 加速；每3个月重训练，每次设多个随机种子多轮挖掘，**贪心策略**合成综合因子。
- **技术面遗传规划**（28个量价输入变量）样本外好：2022-10~2026-02 年化超额 **25.39%**。
- **基本面遗传规划**仅依赖结构化信息，仍无法深刻理解行业基本面，表现一般 → 指向 LLM 整合非结构化信息。

## 4. 因子评价：NDCG（优于IC）

行业轮动是**截面非单调、小样本**任务，投资者只关注最好的一组行业，高IC ≠ 能选出最好组。**NDCG** 给排名靠前样本更高关注度：
- 因子序列转预测排名 i（值大排前），收益序列转真实得分 r（分组靠前得分高，如第一组得5分，组内不细分）。
- $DCG_i = \dfrac{2^r-1}{\log_2(i+1)}$，$DCG=\sum_i DCG_i$；NDCG = DCG / IDCG（理想排序），越接近1越有效。
- **行业分六组时 NDCG=75% 为良好水平**。

## 5. 景气投资失效原因与应对

| 失效原因 | 表现 | 应对 |
|----------|------|------|
| **因子阶段性失效** | 2021/9后4因子NDCG之和破300%频率骤降（拥挤）；微观财务因子NDCG长期<75% | 按 t-1 期 NDCG 微调权重：$w_{new,i}=\dfrac{w_{fix,i}\cdot NDCG_i}{\sum_j w_{fix,j}\cdot NDCG_j}$；失效是阶段性的，被遗忘后或重新有效 |
| **高景气被透支** | 股价涨太贵（估值）/太快（拥挤） | 引入估值（PB分位）+拥挤度（门限测试量价）做**日频交易风险监控** |
| **市场主线较弱** | 主线弱不利景气投资、轮动加快 | 多策略配置或分域建模；转周频 |

**2024教训**：行业逻辑**时序不稳定**（如汽车科技属性增强使"乘用车销量"解释力下降）+ **截面不可比**（不同行业核心定价指标不同：资本开支/股东回报/盈利增长/盈利质量）→ 基本面因子全军覆没，连机器学习挖基本面因子也无稳定超额。

## 6. 落地：行业主题 ETF

每月末为每个行业指数推荐一只ETF替代，综合考虑：ETF与行业指数**相关性**、ETF相对指数**alpha**、ETF**流动性**。ETF含分红机制且选了正alpha，落地表现可略优于价格型行业指数（2018-12~2023-08 ETF组合年化31.45%、最大回撤-27.37%、日跟踪误差0.45%）。

## 7. 下半场（破局方向）

1. **风格择时辅助行业轮动**（如红利/价值成长择时叠加，国证价值100-成长100轮动）。
2. **行业轮动与 CTA 信号结合**。
3. **大语言模型**整合非结构化信息，破解基本面行业轮动困局。

## 8. 应用本 skill 时

1. 先明确轮动标的颗粒度（中信一级/拆分二级）与频率（月频景气 / 周频技术）。
2. 基本面给观点时分**宏观（戴维斯双击）/中观（Nowcasting g·Δg）/微观（财务+北向）**陈述，再综合（中观权重最高）。
3. 务必叠加**交易风险监控**：估值分位 + 拥挤度（4量价指标，3-4个达95%分位=高拥挤，规避）。
4. 用 **NDCG** 而非 IC 评价因子；当前若有因子失效迹象，按 NDCG 微调权重。
5. 主线弱/轮动快时转周频（残差动量、技术面遗传规划、DBCD），并说明月频可能失效。
6. 缺数据时明确所需输入，**不要编造景气因子值、拥挤度分位或北向资金数据**。

## 风险提示

各视角模型均据历史规律总结，规律可能失效（景气趋势不可持续时判断偏差、基本面行业逻辑时序不稳）；模型有其适用市场条件，无法保证任何环境下取得超额；遗传规划在滚动窗口挖掘的规律可能在下次重训练前失效；涉及的具体行业/基金不代表任何投资意见。
