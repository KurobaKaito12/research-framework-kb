# 医药行业分析框架
> 覆盖创新药、CXO、医疗器械、中药、医疗服务、疫苗、血制品、连锁药房八大子行业。医药行业最大的特殊之处：估值锚不是PE而是管线，风险不是周期而是审批，竞争壁垒不是规模而是专利。

---

## 〇、总论：医药研究的三个"不同于"

医药行业是A股大消费中研究框架最复杂、子行业差异最大的板块。医药研究方法论提出了三个核心"不同于"：

**（1）不同于传统消费：估值锚是管线，不是品牌。** 消费品看品牌壁垒和定价权，创新药看管线深度和成功率。一家创新药公司的市值，大部分来自尚未上市的在研产品——这意味着DCF比PE更有解释力，风险调整净现值（rNPV）是标准工具。

**（2）不同于传统制造：竞争壁垒是专利，不是规模。** 制造业扩产能建壁垒，医药靠专利悬崖建壁垒。专利到期（Patent Cliff）是医药投资最大的风险事件——仿制药一旦获批，原研药价格可能在6个月内跌去80%。

**（3）不同于其他行业：政策是最大变量。** 医保谈判（每年一次）、集采（不定期，影响幅度极大）、FDA/EMA审评、DRG/DIP支付改革——医药行业的政策密度和影响力在A股所有行业中排名第一。

### 0.1 医药估值方法论总纲

| 企业类型 | 首选方法 | 辅助方法 | 核心锚 |
|:---|:---|:---|:---|
| 创新药（未盈利） | rNPV（管线DCF） | PS 5-10x | 管线成功率+销售峰值 |
| 创新药（已盈利） | PE 25-40x | rNPV交叉验证 | 核心品种增速+License-out |
| CXO | PE 18-30x | 订单/营收比 | 全球医药投融资景气度 |
| 医疗器械 | PE 25-40x | PEG | 集采降幅+创新管线 |
| 中药OTC | PE 20-35x | 股息率 | 提价能力+独家品种 |
| 医疗服务 | PE + 单院/单床估值 | PS | 单院爬坡+DRG/DIP |
| 疫苗 | rNPV + PE | 批签发量 | 管线+政府采购 |
| 血制品 | PE + 吨浆市值 | PB | 浆站数+采浆量 |

## 一、创新药

### 1.1 核心分析框架：管线概率加权估值（eNPV/rNPV）

创新药公司的市值，本质上是其全部在研管线的预期价值之和。标准工具是**风险调整净现值法**：

```
rNPV = SUM(每个管线产品的预期峰值销售额 × 成功率 × 折现因子)

其中：
- 峰值销售额 = 目标适应症市场规模 × 预计市占率峰值 × 年治疗费用
- 成功率：由所处临床阶段决定
- 折现因子：WACC通常取10-15%，同时折现时间和风险
```

**中国创新药研发整体成功率**（各阶段→上市，基于行业统计）：
- Phase I → 上市：约7%
- Phase II → 上市：约15%
- Phase III → 上市：约50%
- NDA → 上市：约80%

**要点**：成功率是最大的估值杀手——Phase II到Phase III之间的"死亡谷"，是创新药投资最大风险点。估值时不能用"最优情景"的峰值销售，而必须概率调整。

### 1.2 创新药驱动因素

2026年中国创新药全球竞争力持续提升，海外授权（License-out）常态化成为收入新支柱。

**核心关注点**：
- 核心管线临床进度（II/III期数据读出是最强催化）
- License-out交易（首付款+里程碑+销售分成，单笔金额反映MNC对管线的真实估值）
- 医保谈判结果（降价幅度 vs 以价换量预期）
- 海外注册（FDA/EMA审评，决定全球市场天花板）
- 热门靶点赛道：PD-1/ADC/GLP-1/双抗/CAR-T——需判断是"赛道红利"还是"拥挤陷阱"

**关键风险**：单管线失败（临床数据不达预期）可能导致股价单日腰斩；专利挑战（仿制药企或者MNC提起专利无效）；医保谈判结果不达预期（降幅过大侵蚀利润）。

### 1.3 估值方法

- **已盈利（恒瑞）**：PE 25-40x，辅以rNPV交叉验证——如果rNPV显著高于PE隐含市值，说明管线价值未被充分定价
- **未盈利（百济神州）**：rNPV为主，PS 5-10x为辅
- **License-out催化**：单笔授权金额 + 管线NPV重估——重大License-out公告后通常触发15-30%估值上修
- **海外对标**：美股大型制药PE 15-20x，A股溢价来自国产替代+成长性

## 二、CXO（医药外包）

### 2.1 分析框架——"全球医药研发投入 × 订单转化率 × 地缘政治"

CXO本质是"卖铲人"——需求来自全球Pharma的研发外包。分析框架不同于创新药，更类似于服务型制造业：在手订单决定未来2-3年收入能见度，新签订单增速决定成长斜率，产能利用率和人均产值决定利润率。

**产业链分工**：
- **CRO**（合同研发组织）：药明康德、泰格医药、康龙化成。核心是"人"——研究员数量、人均产值、临床试验管理效率
- **CDMO**（合同定制研发生产）：药明生物、凯莱英、博腾股份。核心是"产能"——反应釜体积、产能利用率、技术工艺壁垒
- **CSO**（合同销售组织）：康哲药业。核心是"渠道"——终端覆盖率和品种代理权

### 2.2 核心关注点

- **新签订单**（先于收入1-2季度）
- **在手订单/营收比**（>3 = 高能见度）
- **地缘政治**（《生物安全法案》动态——这是2024-2026年CXO板块最大的系统性风险源）
- **产能利用率**（>85% = 可涨价，<70% = 价格战）
- **前五大客户集中度**（集中度过高意味着单一客户风险）
- **口服GLP-1供应链**是新增长点——非肽类小分子工艺更简单、产能扩张更快

**估值方法**：PE 18-30x（已较2021年峰值的60-80x大幅回归）。与创新药不同，CXO的收入和利润能见度高得多，PE估值更有锚定意义。辅助指标：EV/EBITDA 10-18x。

## 三、医疗器械

### 3.1 分析框架——"集采化解 + 创新驱动 + 国际化"

医疗器械行业拐点已来。核心判断：长期投资机会来自创新+出海+并购。

**集采影响的三阶段演变**：
- 2020-2023：价格冲击期——冠脉支架从万元级降至千元级
- 2024-2025：规则优化期——从"唯低价论"转向"质价双优"，续约价格温和回升
- 2026+：格局出清期——国产龙头凭借成本优势和产品力扩大份额

**估值特征**：板块PE处于历史中位附近，但PB处于历史极低分位——这一"PE vs PB背离"是典型的底部信号。龙头估值处于历史低位区间。

### 3.2 核心关注点

- 集采降幅（平均降幅已从70%+收敛至40-50%）
- 创新医疗器械注册证（PFA/RDN/TAVR/手术机器人等新方向）
- 海外收入占比（龙头海外占比持续突破50%，是估值切换的核心变量）
- 脑机接口/AI医疗等新方向（属于远期期权）
- 并购整合（迈瑞并购海肽、微创分拆等案例）

**估值方法**：PE 25-40x（成长期），龙头当前12-21x处于低位。海外对标：美敦力PE 18-22x、史赛克PE 20-25x、直觉外科PE 45-55x。

**医疗器械特色KPI**：
| KPI | 含义 | 健康区间 |
|:---|:---|:---|
| 集采降幅 | 中标价/原价 | <50% = 温和，>70% = 压力 |
| 创新器械注册证数 | NMPA年度获批 | 逐年增长 |
| 海外收入占比 | 全球化程度 | >30% = 有分散化价值 |
| 存量装机 | 已安装设备数 | 越大越稳（试剂复购绑定） |

## 四、中药

### 4.1 分析框架——"独家品种 + 提价能力 + OTC品牌"

中药本质是类消费品——尤其是品牌中药OTC（片仔癀、云南白药、东阿阿胶），具备消费品提价属性，分析框架更接近消费品而非制药。

**两个子类**：
- **品牌中药OTC**：核心是品牌壁垒+定价权。片仔癀、云南白药的核心产品具有独家品种地位，消费者价格敏感度极低（片仔癀历史上多次提价均未影响销量）。
- **处方中药**：受医保控费和集采影响，类似于仿制药。核心看独家品种能否维持价格。

### 4.2 核心关注点

- 独家品种提价节奏（最核心的业绩驱动）
- 原材料（天然麝香/牛黄/三七等）成本——决定了毛利率方向
- OTC vs 处方渠道比例（OTC占比高意味着政策免疫）
- 品牌延伸（从药品向日化/保健品拓展）

**估值方法**：PE 20-35x，片仔癀历史中枢约35-40x。对于品牌壁垒极高的OTC龙头，PE中枢可以持续高于行业平均。海外对标：强生健康消费品PE 18-22x。

## 五、医疗服务

### 5.1 核心分析框架：单院/单床爬坡模型

医疗服务（医院/连锁诊所）的本质是"服务型连锁"——每个网点经历开业→爬坡→成熟三个阶段。核心估值模型是逐个网点的爬坡曲线叠加：

```
医疗服务价值 = SUM(成熟院区利润 × PE + 爬坡院区收入 × 爬坡系数 + 新建院区投入成本)
```

行业研究显示：民营医院的投资回报周期通常为3-5年（第一年亏损、第二年盈亏平衡、第三年微利、第五年成熟）。

### 5.2 DRG/DIP支付改革的影响

DRG/DIP是医保支付方式的重大改革——从"按项目付费"变为"按病种打包付费"。影响：
- 对医院：控费压力加大，倒逼成本管控和效率提升
- 对药企：高价创新药如果效果显著（缩短住院天数），反而受益于DRG
- 对器械：高性价比国产器械替代进口的机会

**核心关注点**：单院/单床收入及同比、床位数扩张计划、医保依赖度（医保收入占营收比例）、DRG/DIP覆盖范围、医疗事故/监管处罚风险。

### 5.3 估值方法

- **连锁医院/诊所**：成熟院区用PE（20-30x），成长院区用PS+爬坡系数
- **单院模式**：PE 25-40x，由单院盈利增速决定
- **辅助**：EV/床位数、EV/门诊量
- **海外对标**：HCA Healthcare PE 13-16x、Tenet Healthcare PE 12-15x

## 六、疫苗

### 6.1 分析框架——"管线 + 批签发 + 政府采购"

疫苗行业具有"类药品+类消费品"的双重属性：研发端类似于创新药（需要临床试验和NMPA审批），销售端类似于消费品（品牌和渠道）。

- **管线期**：用rNPV法，按各期临床成功率折现（I期70%、II期40%、III期85%）倒推合理市值
- **上市后**：批签发量是唯一权威的月度数据；政府采购占比和价格稳定度是关键

### 6.2 核心关注点

- 批签发量（中检院月度公告）——反映终端需求
- 招投标政府采购价格变化——对价格敏感的品种波动大
- 二类苗（自费）vs 一类苗（政府定价，利润低）结构
- 出海进度（WHO预认证 → 出口新兴市场）
- 新型疫苗管线（mRNA/带状疱疹/HPV升级版/RSV）

**估值方法**：PE 25-35x（成长期），DCF（对管线波动大的公司）。海外对标：赛诺菲PE 15-18x、默沙东PE 16-20x。

## 七、血制品

### 7.1 分析框架——"浆站 → 采浆 → 吨浆 → 品种"

血制品是A股医药中最具资源品特征的子行业——供给端受浆站审批严格限制（天然垄断），需求端稳定增长且价格刚性。

```
浆站数量 × 单站采浆量 → 总采浆量（吨） → 吨浆收入和利润 → 整体利润
```

核心逻辑：采浆量的增长率决定了收入的增长率，品种丰富度（白蛋白/静丙/凝血因子等）决定了吨浆利润率。

### 7.2 核心关注点

- 浆站数量及年新增批文数（最稀缺的增长资源）
- 采浆量（吨/年）
- 吨浆收入/吨浆利润（反映品种丰富度和工艺效率）
- 新产品（凝血因子类、静丙升级版）上市进度

**估值方法**：PE 25-35x + 吨浆市值（每吨采浆量对应的市值，可比公司横向对标）。海外对标：CSL PE 24-30x、基立福PE 18-22x。

## 八、连锁药房与医药流通

### 8.1 连锁药房

**分析框架——"门店扩张 + 处方外流"**：

连锁药房的增长逻辑来自两个维度：外延（门店数增长）+ 内生（同店增速，由处方外流+品类结构调整驱动）。行业集中度低（CR5约20%，对标美国CR3>70%），并购整合逻辑清晰。

**核心关注点**：净增门店数、日均坪效、医保资质门店占比、处方药销售占比、自有品牌（毛利率高于代理品种10-15pct）。

**估值方法**：PE 18-25x。海外对标：CVS PE 12-15x、Walgreens PE 8-12x。

### 8.2 医药流通

类公用事业属性——收入体量大但利润率薄（净利率1-2%）。核心看点是集中度提升+数字化转型。两会提案中"推进医疗数字化改革"有望推动行业效率改善。

**估值方法**：PE 10-15x，辅以股息率。

## 九、通用分析工具与实战心法

### 9.1 医药行业政策周期

医药股投资最大的风险是政策风险。政策周期通常分四个阶段：

| 阶段 | 特征 | 影响 | 应对 |
|:---|:---|:---|:---|
| 政策酝酿期 | 征求意见稿出台 | 板块波动加剧 | 减仓规避不确定性 |
| 政策落地期 | 正式文件发布 | 利空出尽或利好兑现 | 关注方案比预期好/差 |
| 执行阵痛期 | 企业收入/利润承压 | 业绩miss、估值下杀 | 等待出清信号 |
| 适应恢复期 | 企业调整策略 | 龙头份额提升 | 买入龙头 |

2026年医药政策关键词：医保谈判温和化、集采规则优化、创新药支持（FDA/EMA互认试点）、商保扩容。

### 9.2 医药估值切换信号

| 信号 | 含义 | 操作 |
|:---|:---|:---|
| PE持续下行+Pipeline估值依然高 | 市场在杀盈利而非杀管线 | 关注买入时机 |
| 核心产品进入医保 | 以价换量，收入跳升 | 重估管线NPV |
| 临床III期数据读出+阳性 | 最大不确定性消除 | 估值从PS切到PE |
| License-out大单 | MNC背书管线价值 | 上调目标价15-30% |
| 集采续约价格回升 | 政策压力缓解 | 板块重估 |

### 9.3 四条实战心法

**1. 管线是医药公司的核心资产，但不是唯一资产。** rNPV模型的核心缺陷在于过度简化——它假设所有管线独立折现，忽略了平台价值（同一技术平台可以持续产生新品种）和商业化能力差异。估值时先算rNPV作为定量锚，再叠加定性判断——公司的研发效率是否高于同行？商业化团队是否被验证过？

**2. 医保谈判是"价格杀手"，但杀出来的往往是龙头。** 历史上恒瑞、百济、信达都是在医保压力下跑出来的——降价筛选的不是"谁的药最便宜"，而是"谁的研发效率最高、销售团队最强"。过度恐慌医保降价，往往错过最好的买点。

**3. 医疗器械看"装机量+复购"，不只看卖设备。** 医疗器械最好的商业模式不是设备销售，而是"设备+耗材/试剂"的复购闭环——体外诊断(IVD)、骨科植入、牙科修复都是这一模式。设备装机量是行业先行指标，耗材收入才是利润来源。

**4. 中药是A股医药中最"反共识"的板块。** A股研究圈层对中药存在系统性偏见（"不科学""缺乏临床数据"），但这恰恰创造了定价无效的α空间。片仔癀、云南白药的品牌壁垒和提价能力，放在消费品的框架里理解比放在医药的框架里更准确。
