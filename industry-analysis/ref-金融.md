# 金融行业分析框架
> 覆盖银行、保险、证券、多元金融四大板块。金融行业最大的特殊性：企业经营的"商品"是风险本身——银行赚信用风险价差，保险赚精算风险差价，券商赚市场风险居间收益。高杠杆放大一切，1%的资产质量变化能引发10%+的净资产波动。金融股的估值锚不是PE，而是PB和ROE。

---

## 〇、总论：大金融的底层逻辑

### 0.1 "ROE-PB"定价模型——金融股估值的第一性原理

这是全球金融股估值的核心框架，由银行业研究团队在1990年代系统化。推导过程：

```
PB = (ROE - g) / (COE - g)
```

其中ROE=净资产收益率，g=永续增长率，COE=股权资本成本。

**核心含义**：当ROE > COE时，PB应该 > 1（创造价值）；当ROE < COE时，PB应该 < 1（毁灭价值）。A股银行当前PB普遍在0.5-0.7x，意味着市场定价隐含的假设是银行ROE将长期低于股权资本成本——要么息差继续压缩，要么坏账大面积爆发。判断这个隐含预期是否合理，就是银行投资的核心博弈。

**实用对照**：ROE 12% + COE 10% + g 3% → PB≈1.2x；ROE 8% + COE 10% + g 2% → PB≈0.5x。银行破净（PB<1）的根本原因是市场认为ROE不可持续地低于COE。

### 0.2 利率环境决定金融股大方向

金融企业的核心驱动力可以简化为三个利率变量：
- **长端利率**（10年国债收益率）：决定保险再投资收益率、银行资产端定价
- **短端利率**（DR007）：决定银行负债成本、券商资金成本
- **信用利差**：决定银行坏账、信用债投资、城投风险

利率下行周期→金融股承压（息差压缩+投资收益下降）；利率企稳回升→金融股估值修复。

### 0.3 A股大金融的特殊定价因素

相比海外金融股，A股存在四个独特变量：
- **社会功能定位**：银行承担支持实体经济责任，贷款利率受政策指导，利润空间被有意压缩
- **地产风险敞口**：银行资产端与地产链相关（按揭+开发贷+城投），地产出清进度直接影响资产质量预期
- **国有体制**：六大行+主要股份行为国有控股，分红率、资本补充、战略方向受政策驱动
- **资本市场景气度**：券商/保险的业绩与A股市场量价高度同步

### 0.4 大金融估值方法总纲

| 子行业 | 核心估值法 | 辅助方法 | 关键指标 |
|:---|:---|:---|:---|
| 银行 | PB + 股息率 | DDM、隐含不良率反推 | ROE、净息差、不良率 |
| 保险-寿险 | P/EV（内含价值倍数） | P/NBV | EV、NBV、投资收益率 |
| 保险-财险 | PE + COR | PB | 综合成本率、承保利润 |
| 券商 | PB + ROE | PE（周期性修正） | 自营收入、经纪份额、杠杆率 |
| 信托/AMC | PB（折价） | NAV | AUM、不良资产处置收益 |
| 金融科技 | PS / PE | 用户数×ARPU | MAU、贷款余额、take rate |

## 一、银行

银行是A股大金融中市值最大、研究最深、方法论最成熟的板块。

### 1.1 四类银行分类

A股银行按体制分为四类，每类的经营逻辑和研究侧重截然不同：

| 类型 | 核心特征 | 研究重点 |
|:---|:---|:---|
| 国有大行 | 规模巨大、息差最低、资产质量稳健、高分红 | 息差筑底、分红率、国际化 |
| 股份行 | 分化最剧烈、零售vs对公路线分化 | 零售转型、财富管理、资产质量 |
| 城商行 | 区域经济绑定、对公驱动、成长性强 | 区域经济、对公需求、扩张节奏 |
| 农商行 | 下沉市场、小微贷款、高息差 | 小微不良、区域风险、息差韧性 |

### 1.2 量-价-质三维分析框架

银行业分析围绕三个维度展开，不可偏废：

| 维度 | 核心问题 | 关键指标 | 判断逻辑 |
|:---|:---|:---|:---|
| 量（规模） | 增长动力在哪 | 总资产增速、贷款增速、存款增速、信贷结构（对公/零售/按揭/小微占比） | 增速高于M2=抢占份额；结构优于同业=定价权强 |
| 价（利差） | 赚钱能力如何 | NIM（净息差）、生息资产收益率、计息负债成本率、存款β | NIM趋势比绝对水平重要；存款β低=负债端护城河 |
| 质（资产质量） | 会不会爆雷 | 不良率、关注类占比、拨备覆盖率、信用成本率、逾期率 | 关注类是领先指标（提前2-3季度）；拨备是利润蓄水池 |

**核心原则**：量-价-质不可割裂。高增长+低不良=优质；高增长+高不良=危险；低增长+高拨备=防守型。

**综合利润公式**：
```
净利润 = (净息差 × 生息资产规模) + 非息收入 - 业务管理费 - 拨备计提 - 税
```

### 1.3 NIM拆解（银行核心定价工具）

```
NIM = 生息资产收益率 - 计息负债成本率
 = Σ(各期限资产利率 × 占比) - Σ(各期限负债利率 × 占比)
```

**NIM分析三要素**：
1. **存贷利差**：贷款利率-存款利率，直接反映定价权
2. **期限结构传导**：收益率曲线形态变化对各期限利差的影响
3. **存款β**：市场利率变化传导到存款成本的比例。β<0.3=强定价权（国有大行），β>0.6=存款成本随行就市（小行）

**核心变量**：LPR走势、存量房贷重定价节奏、存款利率自律上限调整。大行息差改善逻辑在于资产端定价已极低（下行空间收敛），而负债端存款成本仍有下降空间。

### 1.4 资产质量前瞻信号

金融风险的核心规律是"不暴露≠不存在，暴露了=来不及"。以下指标比不良率更早：

| 信号 | 领先周期 | 判断规则 |
|:---|:---|:---|
| 关注类贷款占比 | 2-3季度 | 连续2季环比上升>10% = 预警 |
| 逾期90天+/不良比率 | 1-2季度 | 比率上升 = 不良认定趋严或资产恶化 |
| 展期/借新还旧占比 | 3-4季度 | 占新增贷款比上升 = 隐藏不良信号 |
| 特定行业集中度（房地产/LGFV） | 中长期 | HHI>0.25 = 尾部风险 |

**拨备覆盖率的使用**：高拨备（>200%）=利润缓冲垫厚，可以通过释放拨备平滑利润；低拨备（<150%）=利润脆弱，不良上升直接冲击利润表。

### 1.5 隐含不良率反推法

当前银行PB水平隐含了市场对资产质量的悲观预期。反推方法：假设当前净息差和信贷成本水平，计算PB=X时市场隐含的不良率是多少。如果该隐含不良率远高于实际水平和合理情景，则PB可能被低估。这是银行投资的核心博弈——判断隐含预期是否合理。

### 1.6 银行估值方法论

| 方法 | 适用条件 | 核心逻辑 |
|:---|:---|:---|
| PB-ROE | 主流方法，适用于所有银行 | P/B = f(可持续ROE, COE, g)。ROE>COE则PB>1 |
| DDM（股息贴现） | 分红稳定的大行 | 基于可分配利润（CET1缓冲后）估算可持续股息 |
| PE（调整后） | 盈利稳定、非经常项目小的银行 | 必须剔除处置收益/公允价值波动/一次性拨备 |

**不同银行的估值锚**：
- 国有大行：PB band + 股息率 + DDM验证。核心锚是股息率与10年期国债的利差
- 股份行龙头（招行等）：PB + PE。零售/财富管理溢价，PB可高于行业均值
- 优质城商行：PB + PE + 成长性溢价。区域经济禀赋+对公驱动
- 农商行：PB为主。小微高息差vs区域集中度风险

### 1.7 银行特色KPI速查

| KPI | 公式 | 健康区间 | 预警阈值 |
|:---|:---|:---|:---|
| NIM | 净利息收入/生息资产 | 1.5-2.5%（因行而异） | <1.3%或连续3季下降 |
| 不良率 | 不良/贷款总额 | <1.5% | >2%或环比升幅>20bp |
| 拨备覆盖率 | 拨备/不良 | >180% | <150% |
| 关注类占比 | 关注类/贷款总额 | <2% | 连续上升>10% |
| CET1比率 | CET1/RWA | >10% | <8.5% |
| ROE | 净利润/净资产 | >10% | <8% |
| 成本收入比 | 营业费用/营业收入 | <40% | >50% |

## 二、保险

### 2.1 寿险核心框架——EV/NBV双轮驱动

保险公司利润确认横跨10-30年，会计利润几乎无法反映真实经营状况。因此使用内含价值（EV）和新业务价值（NBV）两个保险特有指标。

```
EV（内含价值）= ANW（调整后净资产）+ VIF（有效业务价值）
PEV = 市值 / EV

ROEV = (预期EV回报 + NBV + 经营经验偏差 + 假设调整) / 期初EV
```

**EV增长驱动拆解**：
- 预期EV回报：既有业务的"自然释放"，随VIF摊销而实现
- NBV：新增业务的贡献，是增长的核心引擎
- 经验偏差：死亡率/退保率/费用率实际vs假设的差异
- 假设调整：精算假设变更对EV的一次性影响（常为负面）

### 2.2 NBV分析（增量引擎）

```
NBV = 新单保费 × NBV Margin（新业务价值率）
```

**NBV margin的三重驱动**：
1. **产品结构**：保障型>储蓄型>投连型。年金/定期寿险margin高于万能/分红
2. **渠道效率**：个险margin高但成本也高，银保margin低但起量快
3. **精算假设**：RDR（风险贴现率）越低、投资收益率假设越高，NBV越大——需警惕激进假设

**NBV分析的敏感性至关重要**：投资收益假设下降50bp，VIF可能下降20-30%，NBV可能下降50-70%。这是保险股最大的"预期差"来源。

### 2.3 渠道分析框架

| 渠道 | 收入贡献 | 成本特征 | 关键指标 |
|:---|:---|:---|:---|
| 个险（代理人） | NBV占比最高 | 首年费用率40-70% | 代理人数量、人均NBV、人均新单APE、13月续保率 |
| 银保 | 保费规模大，NBV margin低 | 手续费率较高 | 合作银行数量、单点产能、银保NBV占比 |
| 经代/其他 | 占比小 | 首年佣金较高 | 渠道多样性 |

**渠道质量黄金指标**：人均NBV（=NBV/代理人数量），反映代理人队伍的"含金量"。行业头部约10万元/人/年，低于5万=低效渠道。

### 2.4 利差损分析（保险最大风险）

```
利差损风险 = 资产端投资收益率 < 负债端预定利率
```

**监测指标**：
- **久期缺口**：资产久期-负债久期。缺口越大，利率下行对EV冲击越大
- **净投资收益率趋势**：持续下行威胁EV可持续性
- **利率敏感性DV01**：利率下降50bp→EV/NBV影响幅度（从公司披露中提取）
- **预定利率调整**：监管下调预定利率→负债成本降低→利差损风险收窄

### 2.5 财险：COR分析框架

```
COR（综合成本率）= 赔付率 + 费用率
```

COR<100%意味着承保盈利。不同险种的COR特征：
- 车险：份额最大、竞争激烈，COR通常97-99%
- 非车险（健康/意外）：高增长、波动大，COR 95-105%
- 农险/信用保证险：政策性+波动极大，高度分化

### 2.6 保险估值方法论

| 方法 | 适用 | 核心逻辑 |
|:---|:---|:---|
| PEV | 寿险主流 | 市值/EV。PEV<1=破净（类似银行PB<1），历史区间0.5-1.5x |
| NBV倍数 | 成长型 | 市值/NBV。类似PE，反映市场对NBV增长的预期 |
| PE + PB | 财险 | PE 8-12x + PB 1.0-1.5x，COR是核心驱动 |
| DDM | 分红型 | 基于可分配盈余估算股息流 |

**PEV核心驱动**：NBV增速高+NBV margin稳定→PEV扩张；利差损担忧→PEV压缩。PEV<0.5通常对应极度悲观（利差损+低增长）。

### 2.7 保险特色KPI速查

| KPI | 公式 | 健康区间 |
|:---|:---|:---|
| EV | ANW+VIF | 增速>8%为健康 |
| PEV | 市值/EV | >1=溢价，<0.7=深度折价 |
| NBV | 新业务未来利润现值 | 增速>10%为成长 |
| NBV margin | NBV/APE | >30%为优，<15%偏低 |
| 代理人数量 | — | 企稳回升=先行信号 |
| 人均NBV | NBV/代理人数量 | >8万为优 |
| 净投资收益率 | 投资收益/投资资产 | >4%为健康 |
| 久期缺口 | 资产久期-负债久期 | 越小越好 |
| COR | 赔付率+费用率 | <100%=承保盈利 |

## 三、证券

### 3.1 轻资产vs重资产二元分析

证券业分析首先需要区分业务属性：

| 属性 | 业务类型 | 收入来源 | 资本占用 | ROE特征 |
|:---|:---|:---|:---|:---|
| 轻资产 | 经纪、投行（承销/并购）、资管 | 手续费/佣金/管理费 | 低（表外为主） | 高周转、ROE稳定 |
| 重资产 | 自营交易、股权投资、融资融券、做市 | 投资收益/利差/点差 | 高（表内资本） | 高波动、顺周期 |

**判定标准**：交易性金融资产/总资产>30%→重资产倾向。行业趋势是轻资产→重资产迁移（自营盘扩大、科创板跟投、做市业务扩张）。

### 3.2 五大业务线拆解

| 业务线 | 核心驱动 | 收入特征 |
|:---|:---|:---|
| 经纪 | 股基成交额 × 佣金率 + 代销金融产品收入 | 最传统也最"看天吃饭"，财富管理转型是核心叙事 |
| 自营投资 | 股债市场+衍生品策略+OCI账户配置 | 收入占比最大、业绩分化最大——头部券商从方向性博弈转向多元策略 |
| 资管 | AUM × 管理费率 | 从通道业务向主动管理转型 |
| 投行 | IPO/再融资/债承 | 政策节奏驱动，IPO收缩时投行收入骤降 |
| 信用 | 两融余额 + 质押规模 | 市场活跃度的同步指标 |

### 3.3 四类券商分类

| 类型 | 特征 | 研究重点 |
|:---|:---|:---|
| 综合龙头 | 全业务线强、市占率高、国际化 | 自营策略、市占率、ROE |
| 财富管理型 | 高净值客户、代销能力强 | AUM增长、代销结构 |
| 互联网券商 | 流量优势、低成本获客 | MAU、基金代销、毛利率 |
| 弹性标的 | 自营弹性大、市值中小 | 自营收入波动 |

### 3.4 ROE杜邦分解（券商版）

```
ROE = 净利率 × 总资产周转率 × 权益乘数
```

| 杜邦因子 | 轻资产驱动 | 重资产驱动 |
|:---|:---|:---|
| 净利率 | 经纪费率↑、承销费率↑、资管费率↑ | 自营收益率↑、利差↑ |
| 资产周转率 | 经纪量↑、IPO节奏↑、AUM↑ | 自营换手率↑（但增加波动） |
| 权益乘数 | 低杠杆（3-5x） | 高杠杆（5-8x） |

**核心矛盾**：重资产扩张提升净利率和ROE，但同时增加波动和尾部风险。优质券商的特征是轻资产收入占比高+自营收益率稳定（而非单纯高）。

### 3.5 周期判断指标体系

证券业是典型的市场β行业——景气判断需要区分领先/同步/滞后：

| 类型 | 指标 | 频率 | 领先周期 | 信号含义 |
|:---|:---|:---|:---|:---|
| 领先 | 新开户数 | 周/月 | 1-2季度 | 散户入场=交易量先行 |
| 领先 | 日均成交额 | 日/周 | 1-2季度 | 交易活跃=经纪收入先行 |
| 领先 | 融资融券余额 | 日/周 | 1-2季度 | 杠杆上升=风险偏好先行 |
| 同步 | IPO/再融资发行规模 | 月/季 | 同步 | 投行收入同步 |
| 同步 | 资管AUM变动 | 季 | 同步 | 管理费收入同步 |
| 滞后 | 行业ROE | 季 | 滞后1-2季 | 业绩确认滞后于市场 |
| 滞后 | 券商股股价 | 日 | 领先于业绩 | 股价通常提前1-3月见顶/底 |

**信号组合规则**：3项领先指标中至少2项同时反转（如新开户↓+成交额↓）→行业周期拐点预警。

### 3.6 券商估值方法论

| 方法 | 适用 | 注意 |
|:---|:---|:---|
| PB | 重资产占比高的券商（核心方法） | PB-ROE匹配：ROE>10%应有PB>1x。券商PB与上证指数相关系数>0.80 |
| PE | 轻资产占比高的券商 | 必须剔除自营公允价值波动（用调整后净利） |
| 分部估值（SOTP） | 综合型大券商 | 轻资产业务用PE、重资产业务用PB、资管用P/AUM |

**PB是券商的核心估值锚**——因为券商盈利高度波动，PE在牛市顶部极低（3-5x），在熊市底部极高甚至亏损。PB相对稳定：熊市底部0.8-1.0x，震荡市1.0-1.5x，牛市中期1.5-2.5x，牛市顶部2.5-4.0x。

**互联网券商**（东方财富等）：因平台属性，用PE 25-40x + MAU/基金代销规模，不同于传统券商PB框架。

### 3.7 证券特色KPI速查

| KPI | 公式 | 健康区间 |
|:---|:---|:---|
| ROE | 净利润/净资产 | >8%为优，<5%偏低 |
| 经纪市占率 | 公司股基成交额/全市场 | >3%（大型） |
| 经纪佣金率 | 经纪收入/成交额 | 行业趋势下行（万分之2-2.5），差异化靠增值服务 |
| 投行承销市占率 | 承销规模/全市场 | >5%（头部） |
| 资管AUM | — | 增速>10%为优 |
| 自营收益率 | 自营收益/交易性金融资产 | 3-8%为正常区间，>10%警惕高波动 |
| 交易性金融资产占比 | 交易性金融资产/总资产 | >35%=重资产倾向 |
| 融资融券余额 | — | 市场情绪的同步指标 |

## 四、多元金融与金融科技

### 4.1 信托

行业正经历"痛苦转型"——从过去的通道业务+非标融资，转向标品信托+家族信托+资产服务信托。核心看主动管理能力（AUM结构、主动管理占比）和风险项目化解进度。A股纯信托标的极少，PB 0.8-1.2x。

### 4.2 AMC（不良资产管理）

AMC的核心业务是收购银行不良贷款包，通过"时间换空间"实现回收。在地产出清期，AMC面临双重压力——收购的地产不良资产减值+新不良资产定价困难。因资产质量不透明，市场给予大幅PB折价。

### 4.3 期货

期货公司收入=经纪佣金+利息收入（客户保证金）+风险管理（做市/基差贸易）。行业竞争格局分散，佣金战激烈。PE 15-25x，龙头享溢价。

### 4.4 金融科技

分两类：
- **助贷/消金平台**：核心是贷款余额 × take rate × 风控能力。PE通常5-10x（因监管风险折价）
- **金融IT**（恒生电子、同花顺、宇信科技）：核心是金融机构IT支出 × 市占率。PE 25-40x（成长+SaaS属性）。东方财富/同花顺PE 30-50x（互联网流量属性）

## 五、金融行业通用分析工具

### 5.1 监管周期定位

金融行业受监管周期影响不亚于商业周期：

| 子行业 | 监管关键变量 |
|:---|:---|
| 银行 | 信贷额度松紧、拨备覆盖率监管下限、LPR改革、TLAC达标压力 |
| 保险 | 偿二代资本要求、预定利率上限调整、报行合一 |
| 证券 | 注册制节奏、两融保证金比例、做市商资格 |

**分析原则**：监管收紧→压缩杠杆/ROE→估值收缩；监管放松→释放弹性→估值扩张。政策信号优先关注央行（货政报告）、金监总局（监管指标调整）、证监会（发行节奏）。

### 5.2 宏观映射关系

| 宏观变量 | 银行 | 保险 | 证券 |
|:---|:---|:---|:---|
| 利率↑ | NIM↑（短期利好） | 存量债券浮亏，EV↓（利空） | 自营债券浮亏（利空） |
| 利率↓ | NIM↓（利空） | 负债折现率↓→VIF↑（利好） | 交易量可能活跃（利好经纪） |
| GDP↑ | 贷款需求↑、不良↓ | 保费增长↑ | 投行IPO↑、成交↑ |
| 信用利差↑ | 不良压力↑ | — | 债承↓、自营信用风险↑ |

**注意银行的"利率双面性"**：利率上升短期利好NIM，但若持续上升导致企业偿债压力加大，最终不良上升，中长期反转为利空。

### 5.3 金融行业互通关系

- **银保联动**：银保渠道是保险的重要销售网络，银行理财vs保险产品存在竞合关系
- **银证联动**：银行理财资金是券商资管的重要资金来源，三方存管是经纪业务基础
- **证保联动**：保险资金是资本市场重要长期投资者，券商是保险资金管理的外包方

### 5.4 金融股日历效应

- 1月：开门红数据（保险NBV前瞻）、信贷"早投放早收益"
- 3月：两会（监管政策方向）+ 年报季
- 4月：一季报（保险NBV/券商自营验证）
- 7-8月：中报（银行息差拐点验证）+ 政策窗口
- 10月：三季报 + 四季度政策预期
- 12月：估值切换（下一年PE/PB）

## 六、实战心法

**1. "PB<1不一定便宜，PB>2不一定贵"——关键看ROE。** 金融股的PB估值必须与ROE联合使用。ROE/PB>15%的金融股值得深入研究——这意味着每块钱净资产每年创造15分钱以上的收益。一家PB 0.3x但ROE仅3%的银行，远比PB 1.2x但ROE 15%的银行更"贵"。

**2. 银行股的真正风险不是息差，是"尾部信用事件"。** 息差下降是慢变量，可以通过成本管理对冲；但大客户/行业集中暴雷是快变量，可以在一个季度内吞噬数年利润。银行研究的核心不是预测息差能否回升5bp，而是排除尾部信用风险的概率。

**3. 券商是A股最纯粹的"β工具"——不要在底部卖、不要在顶部追。** 券商PB与上证指数的相关系数超过0.80。最简单的策略就是在PB<1x时关注、PB>2x时谨慎。核心能力不是选个股，而是判断市场方向。

**4. 保险是"利率周期+资本市场"的双因子博弈。** 保险股的难点在于负债端（NBV）和资产端（投资收益）经常反向运动——利率下行→保单好卖但投资收益下降→NBV增但EV可能缩。只有利率上行+资本市场牛市"双击"时，保险才有大行情。

**5. 区分"真便宜"和"价值陷阱"。** 看到PB<0.5x的银行，先问自己：ROE是否仍>10%、不良率是否持续下降、拨备覆盖率是否>200%、股息率是否>5%。四个条件都满足=真便宜；ROE持续下降+关注类/逾期贷款快速上升=价值陷阱。

**6. 大金融最大的结构性机会：从"低估值陷阱"到"红利核心资产"。** 在长期利率走低、理财收益率下行的环境下，银行和保险的高股息率正成为机构投资者（保险资金、养老金、社保基金）的"刚需配置"。这是可能持续多年的结构性资产配置范式转换，而非短期交易机会。
