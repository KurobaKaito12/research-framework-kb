# 制造行业分析框架
> 覆盖新能源汽车、光伏、风电、储能、工程机械、船舶海工、人形机器人、工业机器人、国防军工、高端装备十大板块。制造业最大的特点：竞争优势最终归结为成本曲线和规模效应，技术优势必须转化为成本优势才有持续性。

---

## 〇、总论：大制造的底层研究范式

### 0.1 什么是"大制造"

"大制造"横跨机械设备、汽车、电力设备、国防军工四个一级行业，延伸至部分电子（功率半导体）、基础化工（新材料）的交叉地带。共同点是：以物理世界的"制造-交付"为核心，产品有形、产能可量化、周期性明显。与 TMT 的"信息-算力"范式不同，大制造的分析逻辑根植于实体产能与需求的动态平衡。

### 0.2 五个底层研究特征

**（1）周期性是第一属性。** 几乎所有子行业都呈现周期波动，但驱动力不同——工程机械受固定资产投资驱动（朱格拉 8-10 年 + 库存 3-4 年），新能源受渗透率 S 曲线驱动（技术扩散周期），军工受五年规划驱动（政策周期）。识别"我们在哪个周期的哪个位置"是所有分析的起点。

**（2）产能是供给侧的核心变量。** 制造业扩产需要建厂、买设备、招工人，周期 18-36 个月，决策一旦做出短期不可逆。产能利用率是判断景气拐点的最敏感指标——当利用率从 75% 回升到 85% 以上时，价格和利润率通常开始改善。

**（3）成本结构决定竞争壁垒类型。** 三条路径：规模效应路径（产能越大→单位固定成本越低，典型如动力电池、光伏）；技术壁垒路径（工艺诀窍 + 认证周期 → 高切换成本，典型如航空发动机、半导体设备）；客户绑定路径（进入大客户供应链后形成协同开发关系，典型如汽车零部件 Tier 1）。

**（4）出海是 A 股大制造最大的结构性 α。** 2024-2026 年，中国制造业最强的叙事不是内需，而是全球化能力差异。工程机械出口占比从 2020 年的约 25% 升至近年 50%+，新能源汽车出口持续高增，船舶在手订单占全球 50% 以上。海外收入占比的变化是重估公司估值中枢的核心变量。

**（5）政策既是催化剂，也是风险源。** 补贴推动渗透率跳升（新能源车购置税减免）、也可能制造产能过剩（光伏）；出口管制可以创造国产替代机遇（半导体设备），也可能限制增长空间（对华关税）。研究任何子行业，政策清单必须是第一张工作底稿。

### 0.3 大制造估值方法论总纲

与 TMT 不同，大制造的估值更重视资产负债表和现金流，因为重资产属性使得 PB、EV/EBITDA 比 PS 更有锚定意义。

| 企业类型 | 首选方法 | 辅助方法 | 核心锚 |
|:---|:---|:---|:---|
| 成长制造（渗透率 < 30%） | PEG、远期 PE | PS、DCF | 渗透率曲线 |
| 周期制造（格局稳定） | PB band、EV/EBITDA | 历史 PE 分位 | 产能利用率 |
| 平台型龙头 | DCF + SOTP | PE + 出海溢价 | ROIC 和自由现金流 |
| 早期/亏损（人形机器人） | PS、EV/Sales、市值/TAM | 对标海外可比 | 量产时间表 |
| 军工（计划经济特征） | PE + 订单周期 | PB | 五年规划交付节奏 |

## 一、机械设备

### 1.1 核心分析框架：三层递进分析

机械行业分析从宏观到微观层层落地：

```
宏观（制造业投资增速）→ 中观（上市公司 CAPEX 和订单）→ 微观（企业竞争优势）
```

| 分析层次 | 核心问题 | 关键指标 |
|:---|:---|:---|
| **宏观** | 制造业整体景气方向 | 制造业固定资产投资增速、PMI、工业机器人产量 |
| **中观** | 细分赛道的资本开支周期 | 上市公司 CAPEX/营收比、在建工程增速、订单/出货比 |
| **微观** | 企业靠什么赢 | 市占率趋势、毛利率 vs 同行、新产品占比、大客户突破 |

### 1.2 两种竞争类型

| 竞争类型 | 特征 | 代表行业 | 分析重点 |
|:---|:---|:---|:---|
| **资本要素型** | 规模决定成本，产能决定份额 | 水泥、钢铁、化工 | 产能规模、成本曲线、区位优势 |
| **技术服务型** | 技术/服务差异化，客户粘性 | 机械、汽车零部件、家电 | 新产品占比、下游客户质量、研发强度 |

机械行业属于技术服务型——核心竞争力不是产能规模，而是产品技术含量 + 客户关系深度 + 售后响应速度。

### 1.3 机械行业二阶导框架

**z = d²x/dt²——机械需求是终端需求的二阶导数。** 这是机械行业方法论最核心的数学直觉。终端需求（x）的增速放缓时，机械需求（z）已经负增长；终端需求小幅反弹时，机械需求大幅反弹。这解释了为什么机械股的业绩波动和股价弹性远大于下游行业。

**二阶导的三层含义**：
- **下行段**：终端需求增速放缓（dx/dt > 0 但减速）→ 二阶导为负 → 机械企业接单骤减、产能利用率崩塌 → 股价往往先于基本面见底
- **拐点段**：终端需求增速企稳回升（dx/dt 从负转正）→ 二阶导从负转正 → 机械企业新签订单突然加速 → 这是机械股弹性最大的阶段
- **上行段**：终端需求持续加速（dx/dt > 0 且加速）→ 二阶导为正 → 量价齐升、利润率扩张 → 股价主升浪

**经济复苏周期中的机械股表现**：过去多轮复苏周期验证了二阶导框架的解释力——高增长期机械弹性最大、弱复苏期机械跑输、结构复苏期精选赛道、全面复苏期全面超配。

### 1.4 工程机械：完整分析模板

**行业定位**：A 股研究方法论最成熟的周期板块之一。销量增速是景气判断的核心高频指标，出口占比提升是结构性趋势。

**分析框架——"内需周期 + 出海结构性"双轮模型**：

**第一层：内需周期判断**
- 更新周期：挖掘机平均寿命 8-10 年，上一轮高峰 2016-2021 年，2025-2028 年进入更新替换高峰
- 新增需求：基建投资（专项债）、房地产（底部企稳）、矿山（矿产开发）
- 领先指标：PMI 新订单、挖掘机开工小时数（小松数据）、水泥/钢材产量

**第二层：出海结构性增长**
- 中国品牌全球份额从 2019 年的 7% 升至 2025 年的超 20%
- 出口区域：东南亚/中东/非洲为主（"一带一路"），欧美高端市场正在突破
- 海外收入毛利率高于国内 5-10 个百分点 → 海外占比提升是利润率改善的核心驱动

**第三层：产品结构升级**
- 大挖/矿挖占比提升 → 单台 ASP 上升
- 电动工程机械渗透率刚起步，趋势确定
- 高空作业平台（AWP）是高成长子品类

**需求侧三个驱动力**：

| 需求来源 | 占比 | 先行指标 | 特征 |
|:---|:---|:---|:---|
| 更新需求（存量替换） | ~50-60% | 保有量增速 + 设备使用年限 | 提供「底仓」需求 |
| 增量需求（新投资） | ~25-30% | 房地产开发投资、基建投资 | 提供「弹性」 |
| 出口 | 占比持续提升（已从 ~10-20% 升至 50%+） | 海外市占率、一带一路项目 | 结构性的增量 |

**短期判断指标**：开机小时数（小松挖掘机 / 国内品牌）反映下游施工活跃度；经销商库存深度反映渠道健康程度；二手机价格反映终端真实需求。

**人力资源成本的结构性影响**：制造业员工薪酬/营收比例持续上升，永久性挤压利润率，自动化需求长期上行，工业机器人/自动化装备受益。

**估值——"底部买 PB，顶部卖 PE"**：

| 周期位置 | 主要方法 | 参考区间 |
|:---|:---|:---|
| 底部（亏损/微利） | PB | 三一 PB 底部约 1.2x |
| 复苏初期 | 远期 PE | 8-12x |
| 景气高峰 | PE | 6-10x，此时需警惕高利润不可持续 |
| 下行期 | PB 回撤 | 等待下一周期 |

**出海溢价修正**：传统周期股 PE 8-12x，但因出海带来成长性，龙头 PE 中枢抬升至 12-18x。对标卡特彼勒 PE 15-18x、小松 PE 12-15x。恒立液压因液压件"卖铲人"+ 泵阀国产替代逻辑，PE 20-30x，高于主机厂。

### 1.5 核心零部件国产化分析框架

```
国产替代成功率 = 技术差距缩小 × 下游大客户推动 × 成本优势显著

典型路径：维修市场（低端）→ 二线客户 → 一线客户 → 全球配套
```

**关键进展指标**：是否进入下游大客户的供应链（定点/认证/小批量）？产品性能和寿命测试是否达标？价格 vs 海外竞品是否有 20-30% 以上优势？

### 1.6 机械设备特色 KPI 速查

| KPI | 含义 | 健康区间 |
|:---|:---|:---|
| 订单/出货比（Book-to-Bill） | 新增订单/已交付 | > 1.0 = 积压增加，景气上行 |
| 在手订单/营收比 | 订单覆盖月数 | > 12 月 = 高能见度 |
| CAPEX/营收比 | 资本投入强度 | 成熟期 < 5%，扩张期 5-15% |
| 新产品收入占比 | 产品迭代能力 | > 20% = 研发有效转化 |
| 人均创收 | 营收/员工数 | 逐年提升 = 效率改善 |
| 毛利率 | 产品竞争力和定价权 | > 25%（技术服务型） |
| 出口收入占比 | 海外竞争力 | > 20% = 有分散化价值 |

## 二、新能源汽车产业链

这是 A 股大制造中市值最大、研究最成熟的板块。产业链极长，从上游锂矿到下游整车，中间横跨电池、电驱、热管理、轻量化、智能驾驶等十余个环节。

### 2.1 整车（新能源车企）

**分析框架——"销量 × ASP × 单车利润"三因子模型**（全球车企覆盖的标准框架）：

- **销量**：月度交强险/批发数据是最高频指标。中国新能源车渗透率已从 2020 年的 5% 升至 2025 年的接近 50%，2026 年进一步突破。
- **ASP（平均售价）**：反映产品结构升级或价格战程度。
- **单车利润**：BOM 成本（电池占 30-40%）、制造费用、销售费用的函数。

**核心关注点**：月度销量排名变化（格局是否在重塑？）；新车型周期（上市前 3 个月是股价最强催化期）；出海进度（关税壁垒 vs 产能出海）；智能化差异（城市 NOA 渗透率成为差异化核心）；毛利率趋势（价格战下是否还能维持 20% 以上毛利？）。

**估值**：传统整车 PE 8-15x（含燃油车包袱折价）；新能源龙头 PE 20-30x + SOTP（整车+电池+半导体+出海）；造车新势力未盈利阶段用 PS 0.5-2x + 市值/年销量（单车市值法），盈利后切 PE；华为系用 EV/销量 + 智选车生态估值。

#### 2.1.1 汽车七段供应链利润分布

汽车产业链按价值分布可分为七段，不同环节的利润率和估值逻辑差异显著：

| 产业链环节 | 核心价值 | 利润驱动 | 估值锚 |
|:---|:---|:---|:---|
| **整车制造** | 品牌溢价最高 | 品牌力+产品力+规模效应 | PE/PEG |
| **三电系统**（电池/电机/电控） | 成本占比最高（BOM 约 37-39%） | 技术迭代+规模降本 | PE + SOTP |
| **电子电气架构**（智驾芯片/传感器/域控） | 增长最快的成本项 | 渗透率提升+国产替代 | PS→PE 切换 |
| **底盘系统** | 传统壁垒 | 轻量化+智能化升级 | PE |
| **车身** | 标准化程度高 | 材料创新（铝压铸一体化） | PE |
| **内外饰** | 差异化空间 | 消费属性+设计驱动 | PE |
| **通用件** | 成本竞争 | 规模+良率 | PE/PB |

**关键判断**：三电+电子电气合计占 BOM 约 57-59%，且是成本降幅最快的部分。"电比油贵→油电平价→电比油低"是电动车渗透率 S 曲线的核心驱动力。

#### 2.1.2 "六边形战士"竞争分析框架

车企竞争力可从六个维度进行结构化评估，各维度评分决定企业的攻守能力：

| 维度 | 核心评估内容 | 关键跟踪指标 |
|:---|:---|:---|
| **品牌** | 用户心智和调性定位 | NPS、品牌溢价率、复购率 |
| **产品** | 续航/智能化/空间/设计 | 车型月销量、产品矩阵完整度、换代节奏 |
| **价格** | 定价策略和性价比 | ASP 走势、各价位段市占率 |
| **渠道** | 门店密度和直营/经销模式 | 门店数、单店销量、渠道下沉度 |
| **供应链** | 垂直整合和成本控制 | 自研自供比例、BOM 成本 vs 同行 |
| **服务** | 充电网络/售后/金融保险 | 充电站密度、售后满意度、金融服务渗透率 |

**使用规则**：六维度独立评分后做雷达图，满分企业在行业中享有估值溢价。单一维度极致（如比亚迪供应链）或全方位均衡（如理想产品+渠道）都可以是竞争优势的来源，关键是找到护城河的最强维度。

### 2.2 动力电池

**分析框架——"装机量 × Wh 单价 × 毛利率"模型**：全球动力电池装机量持续高增，龙头市占率稳定在 35-40%，CR2 合计超 50%。

**核心关注点**：装机量与市占率变化（SNE Research 月度数据是核心跟踪指标）；技术路线切换（磷酸铁锂 vs 三元 vs 钠离子 vs 固态）；Wh 成本下降曲线（龙头已降至 0.3 元/Wh 以下）；储能第二曲线（龙头储能出货持续高增）；海外产能布局（匈牙利、印尼、北美 IRA 影响）；产能利用率（龙头满产、二三线分化严重）。

**估值**：宁德时代 PE 20-30x（A 股历史中枢约 25x）+ 储能业务 SOTP + 海外扩产期权；二线电池 PE 15-25x + 大客户绑定溢价；产能利用率 < 60% 的二三线用 PB 1-2x 等待出清。

### 2.3 锂电材料（正极/负极/隔膜/电解液）

**分析框架——"量价利"周期模型**：量跟随下游电池装机量增长；价受原材料成本和供需决定，经历过大起大落的价格周期；利的核心是毛利率。

**电池 BOM 成本结构**（从上游到下游逐层拆解）：

| 成本项 | 占 BOM 比例 | 核心定价变量 | 分析重点 |
|:---|:---|:---|:---|
| **正极材料** | 最高（LFP 约三成，NCM 约六成） | 锂/钴/镍价格、前驱体工艺 | 成本占比最高，技术路线（LFP vs NCM vs 钠电）决定成本天花板 |
| **铜箔** | LFP 第二成本项 | 铜价、极薄化趋势 | 复合箔材"三明治"结构（PET/PP 基材+金属镀层）是安全性和减重的关键方向 |
| **负极材料** | 中等 | 石墨价格、硅基负极渗透率 | 人造石墨主流，硅基负极为能量密度提升的下一代方向 |
| **隔膜** | 中等 | 产能利用率、涂覆比例 | 壁垒最高、毛利率最优的材料环节 |
| **电解液** | 中低 | 六氟磷酸锂价格、添加剂配方 | 同质化程度高，规模+成本决定竞争力 |

**技术迭代路径**：液态锂离子 → 半固态 → 全固态。固态电池若量产，隔膜和液态电解液环节面临技术替代风险，这是锂电材料最大的长期结构性变量。

**核心关注点**：产能利用率与开工率（行业严重过剩阶段是布局信号）；出海建厂进度；头部客户份额变化；新技术路线对材料体系的影响。

**估值**：典型周期股，PB band（1.5-4x）+ 周期底部用重置成本法。景气上行切 PE 15-25x。恩捷股份历史 PE 中枢约 30x（龙头溢价），但周期底部可跌至 15x 以下。

**关键风险**：固态电池如 2028 年量产，隔膜和液态电解液环节面临技术替代风险。

### 2.4 智能驾驶产业链

**分析框架——"渗透率 × 单车价值量"双驱动**：这是高阶智驾从"选配"变"标配"的过程。城市 NOA 渗透率已突破 10%，正处于加速爬坡期。

| 环节 | 核心变量 | 2026 市场空间 |
|:---|:---|:---|
| 激光雷达 | 出货量 × ASP（下探至千元级） | ~679 亿 |
| 域控制器 | 搭载率 × 单价（3,000-8,000 元） | 500 亿+ |
| 线控制动 | EHB/EMB 渗透率 | 200 亿+ |
| 高精地图/定位 | 城市 NOA 开通城市数 | 100 亿+ |

**核心关注点**：城市 NOA 月度开通率；激光雷达价格下探节奏（千元级 → 15 万元级车型标配）；L3 法规进展；Robotaxi 进度；纯视觉 vs 融合路线之争。

**估值**：激光雷达从 PS 8-15x 切换到 PE 40-60x（成长期）；域控 PE 30-50x，PEG 1-1.5 合理；线控底盘 PE 25-40x。

### 2.5 汽车零部件（传统 + 电动化）

**分析框架——"客户结构 × 单车配套额 × 国产替代率"**：国内 Tier 1 的核心逻辑已从"配套自主品牌"升级为"全球平替"——拓普切入特斯拉、三花进入奔驰/宝马热管理体系、福耀全球市占率 35%。

**核心关注点**：特斯拉/比亚迪等大客户份额；新能源单车价值量提升（热管理从燃油车 2,000 元 → 电动车 5,000-8,000 元）；出海建厂（墨西哥/东欧）；铝压铸一体化等新工艺。

**估值**：PE 15-25x（传统零部件），有新能源/海外客户溢价的可给 PE 25-35x。平台型公司享受估值溢价。对标海外：麦格纳 PE 8-12x（成熟），法雷奥 PE 10-15x。

## 三、光伏

### 3.1 分析框架——"反内卷出清周期 + 技术迭代"

光伏是 A 股大制造中周期性最强、内卷最惨烈的板块。2023-2025 年经历了史无前例的产能过剩和价格崩塌。

```
光伏行业景气度 = 全球装机需求 × 产能供给 × 技术路线迭代 × 贸易壁垒
```

**当前产业状态**：组件价格已从历史底部回升，部分厂商涨幅显著；硅料价格企稳但仍低于收储目标；反内卷政策密集落地（工信部介入、市场监管总局通报价格违法）；头部企业开工率回升，行业集中度持续提升；BC 电池、高功率组件等差异化产品成为新竞争焦点。

**产业链四环节拆解**：

| 环节 | 当前格局 | 核心矛盾 |
|:---|:---|:---|
| 硅料 | CR5 > 80%，收储去产能 | 库存历史峰值，减产力度待观察 |
| 硅片 | N 型替代 P 型 | 产能严重过剩，价格战持续 |
| 电池片 | PERC → TOPCon → BC/HJT | 技术路线之争未定 |
| 组件 | 一体化 vs 专业化 | 价格修复但距盈利仍有距离 |

**核心跟踪**：组件价格（央国企集采价格是最关键高频指标，盈利需组件价涨至 1 元/W）；产能出清进度（硅料收储平台实际执行力度、二三线退出节奏）；技术路线（TOPCon vs BC vs HJT）；装机量（中国和全球年度新增装机持续创历史新高）；白银价格（银浆成本占组件 BOM 的 8-10%，银价暴涨直接推高成本底线）；储能配套（光储一体化是新增量）。

### 3.2 估值方法

当前光伏股处于"困境反转"估值阶段：PB band（隆基历史 PB 底部约 1.5x，通威约 1.2x）；产能价值法（每 GW 产能对应市值，硅料约 8-12 亿/万吨，组件约 2-3 亿/GW）；困境反转 PE（假设行业回归正常盈利，用远期正常化利润 × PE 12-18x 倒推当前合理市值）；反内卷受益龙头溢价（出清后格局改善的龙头享受格局溢价）。

**定价锚迁移**：从 PEG（成长）→ PE/股息率（成熟）→ 当前切换至 PB + 困境反转 PE。

## 四、风电

### 4.1 分析框架——"陆风盈利修复 + 海风成长加速 + 出海打开天花板"

**关键趋势**：全球风电新增装机持续创纪录，中国占 2/3 以上；海风装机增速远高于陆风（CAGR 25-30%）；陆风招标价格从 2024 年低点回升 50%+；"十五五"规划海上风电累计并网目标明确。

**核心跟踪**：风机招标量价（招标量先于装机 1-2 年，价格决定毛利率）；海风装机节奏（审批、核准、开工、并网各阶段跟踪）；出口市场（中国风机出口均价约 1,800 元/kW，高于国内 20%，欧洲海风是最大增量）；大型化放缓（陆风已到 8-10MW，海风到 16-20MW，大型化红利接近尾声）；反内卷效果（价格回升 → 2026-2027 年交付订单毛利率改善 → 业绩兑现期）。

### 4.2 估值

风机整机 PE 12-20x（对标维斯塔斯 PE 15-20x），困境反转阶段用远期 PE；零部件 PE 15-25x，海上风电零部件因壁垒更高可给溢价；东方电缆（海缆龙头）PE 20-30x，海风建设直接受益。

## 六、人形机器人

### 6.1 产业阶段判断

用 Gartner Hype Cycle 定位：当前处于"期望膨胀期"向"泡沫破裂低谷"过渡的边界。全球产量从万台级起步，年增速极高（翻倍以上）。整机价格从百万级下探至 20 万元区间，消费级下探至数万元。

**分析框架——"本体厂商进度 × 零部件国产化 × 下游场景验证"三维跟踪**：

产业链分六层：

| 层级 | 核心组件 | 价值量占比 | 国产化率 |
|:---|:---|:---|:---|
| 感知层 | 视觉/力觉/触觉传感器 | 10% | 60% |
| 决策层 | AI 芯片 + 大模型 | 15% | 30% |
| 执行层-关节 | 减速器（谐波/RV/行星） | 20% | 谐波 70%/RV 40% |
| 执行层-电机 | 伺服电机 + 驱动器 | 15% | 50% |
| 执行层-丝杠 | 滚柱丝杠/行星滚柱 | 10% | < 20% |
| 结构/总成 | 灵巧手、机身、线束 | 30% | 80% |

### 6.2 核心关注点

特斯拉 Optimus 量产时间表（这是全球产业节奏的锚）；BOM 成本拆解与降本路径（20 万 → 15 万 → 10 万是扩量关键，减速器+电机+丝杠占 BOM 约 45%）；滚柱丝杠国产化（技术壁垒最高、国产化率最低 < 20% 的环节，国内北特科技、贝斯特、恒立液压正加速突破）；下游场景真实需求（当前主要是工厂搬运/危险作业，消费级仍是概念）；软件能力（具身智能——端到端大模型 + 世界模型，仍在早期）。

### 6.3 估值方法（A 股最难估值的板块）

**方法一：市值映射法。** 假设 2030 年全球年销量 100 万台，ASP 15 万元/台 → TAM 1,500 亿。某零部件企业市占率 20% → 收入 300 亿，净利率 15% → 净利润 45 亿。给 30x PE → 合理市值 1,350 亿，按 5 年折现（12% WACC）→ 当前约 765 亿。

**方法二：对标特斯拉产业链映射法。** Optimus 量产后对标特斯拉汽车零部件供应链格局，按类似市值/收入比倒推 A 股零部件公司的机器人业务期权价值。

**方法三：传统业务 PE + 机器人期权。** 例如绿的谐波 = 传统工业机器人减速器 PE 30x + 人形机器人业务 PS 10-20x（根据在手订单/意向合作折算）。

**关键警示**：人形机器人在 A 股已被充分主题化，很多标的的股价已隐含 2028-2030 年的乐观预期。区分"真有订单和产能的公司"和"PPT 概念股"的核心标准：是否进入特斯拉/智元/宇树/优必选的供应链，是否有在手订单和实际出货。

## 七、工业机器人及自动化

**分析框架——"密度提升 × 国产替代"双驱动**：中国工业机器人密度已超过德国（约 400 台/万人），但仍低于韩国（超 1,000 台/万人）。国产品牌份额从 2019 年的约 30% 升至近年约 45%，核心逻辑是在焊接、喷涂等中高端应用领域逐步替代发那科/ABB/库卡/安川四大家族。

## 八、海工装备与船舶

### 8.1 分析框架——"造船超级周期 + 海工结构性景气"

当前处于 2003 年以来第二轮造船超级周期的中段。克拉克森新造船价格指数处于近 20 年高位。

**关键趋势**：龙头船企在手订单排期至 3 年以上，营收和毛利率持续上行；FPSO 市场未来五年全球规模突破千亿美元，中国船厂承接约 35% 全球订单；海上风电安装船、LNG 运输船等高附加值船型占比持续提升。

**核心跟踪**：克拉克森新造船价格指数（全球造船景气温度计）；在手订单/交付排期（决定未来 2-3 年收入确定性）；毛利率趋势（高价订单逐步交付推动毛利率持续上行）；船型结构（LNG 船、集装箱船、FPSO 等高附加值占比）；南北船合并协同效应（管理费率下降、产能优化）；海上风电装机节奏（十五五规划海风累计并网 1 亿千瓦）。

### 8.2 估值

中国船舶 PE 10-15x（对标韩国现代重工 PE 8-12x），因在手订单确定性极高，也可用 EV/在手订单金额或市值/年化营收；海工（海油工程、中集海工）EV/EBITDA 6-10x + 在手订单/市值倍数；船舶零部件 PE 15-20x。

## 九、国防军工

### 9.1 分析框架——"五年规划节奏 + 国产替代 + 新兴领域"

军工是 A 股中最不透明的板块——产量、价格、订单大多涉密，传统的"量价利"模型难以直接套用。取而代之的是"计划-排产-交付-结算"四阶段追踪模型。

**三条主线**：
- **传统军贸周期**："十五五"规划交付节奏（2026-2030），重点关注航空装备、导弹弹药的批产交付
- **国产替代**：航空发动机（两机专项）、军用芯片、惯导系统
- **新兴领域**：商业航天（2025 年市场万亿前夜）、低空经济（eVTOL，2025 年市场规模 1.5 万亿）、卫星互联网

### 9.2 资产注入与备考估值

军工行业最大的特色是资产证券化率低，上市公司往往只是集团的小部分资产，真正的投资故事是"集团资产注入"。

```
军工企业最终价值 = 已上市资产价值 + 拟注入资产评估价值 × 注入概率
```

备考 PE 步骤：① 识别拟注入资产（从集团承诺/国企改革计划中提取）；② 估算注入资产的营收/利润（集团公开数据或对标已上市）；③ 模拟合并 → 备考净利润；④ 备考 PE = 当前市值 / 备考净利润。备考 PE 通常在 20-50x，视注入确定性和成长性调整。

**十二大军工集团**：核工业（中核/中核建）、航天（航天科技/航天科工）、航空（航空工业/中国航发）、船舶（中国船舶/中国船舶重工）、兵器（中国兵器/中国兵器装备）、电子（中国电子/中国电科）。

**四条投资主线**：资产注入（集团资产证券化）、型号驱动（新型号定型/批产 → 业绩爆发）、军贸/出海（武器出口 → 第二增长曲线）、军民融合（军用技术 → 民用市场）。

### 9.3 估值

传统主机厂 PE 35-50x（看似极贵，但对标洛克希德·马丁 PE 16-20x、雷神 PE 18-22x，A 股溢价来自国产替代稀缺性 + 军费增长确定性）；航空发动机 PE 60-80x 甚至更高（"两机专项"国产替代是国家安全级别的确定性，产能瓶颈导致远期利润弹性极大）；军工电子 PE 30-45x（国产替代 + 民品扩展双逻辑）；商业航天/低空经济早期主题阶段，PS + 市值/TAM，缺乏盈利锚。

**核心跟踪**：军费预算增速（每年 3 月两会公布）；大额订单公告；预付款/合同负债（最有效的领先指标——大客户预付 → 排产 → 交付 → 确认收入）；商业航天发射频次；低空经济政策落地（eVTOL 适航取证、空域管理改革）；军工院所改革/资产注入。

### 9.4 军工特色 KPI

| KPI | 含义 | 注意 |
|:---|:---|:---|
| 军品收入占比 | 主业纯度 | 纯军品 = 政策受益确定性强 |
| 资产证券化率 | 已上市资产/集团总资产 | < 30% = 有大量注入空间 |
| 备考 PE | 注入后模拟 PE | 20-50x 正常区间 |
| 军费关联度 | 收入增速 vs 国防预算增速 | > 军费增速 = 结构受益 |
| 预付账款/合同负债 | 军工客户的预付款 | 大幅增加 = 订单放量信号 |
| 存货-在产品 | 在产未交付的军品 | 大幅增加 = 生产加速 |

## 十、高端装备（机床 / 激光 / 检测）

### 10.1 机床

**分析框架——"国产替代率 × 下游资本开支"**：中国是全球最大的机床消费市场（约占 30%），但高端五轴数控机床国产化率仍不足 10%。核心矛盾：下游需求（航空航天/汽车/模具）稳定增长，但高端供给受制于数控系统（发那科/西门子）、主轴、丝杠等核心功能部件。

光纤激光器国产化率 > 90%，已从国产替代切换到出海 + 新应用（新能源切割/焊接）。估值：PE 20-30x，锐科激光周期属性更强，用 PB 2-4x + PE。

### 10.3 检测设备

类消费属性（检测需求持续稳定增长），商业模式优秀（轻资产、高现金流）。估值：PE 25-35x，华测检测对标欧陆/SGS 给 PE 25-30x。

## 十一、通用分析工具与实战心法

### 11.1 成本优势分析框架

```
单位成本 = 固定成本/产量 + 变动成本/单位

成本优势来源：
1. 规模效应（固定成本摊薄）—— 产量越大，单位固定成本越低
2. 学习曲线（累计产量翻倍，成本下降 15-25%）—— 先发者有累计经验优势
3. 工艺/良率（变动成本降低）—— 技术 know-how 难以复制
4. 原材料/能源套利（区位优势）—— 靠近原料产地或低价能源
```

### 11.2 产能周期与盈利拐点

| 阶段 | CAPEX 信号 | 产能变化 | 价格/利润信号 | 投资含义 |
|:---|:---|:---|:---|:---|
| 扩张期 | CAPEX/营收比 > 10% | 在建产能激增 | 价格承压、利润率下降 | 回避（供给释放前夜） |
| 消化期 | CAPEX 增速放缓 | 产能逐步释放 | 价格筑底 | 观察（等待出清信号） |
| 出清期 | CAPEX 转负 | 尾部企业退出 | 价格企稳、龙头盈利改善 | 买入（底部确认） |
| 紧缺期 | CAPEX 开始恢复 | 供给不足 | 量价齐升 | 买入/持有 |

**信号组合**：龙头 CAPEX 扩张 + 尾部 CAPEX 停投 = 格局改善信号；全行业 CAPEX 同步收缩 = 真正的出清信号。

### 11.3 制造业通用估值方法

| 生命周期 | 首选估值法 | 核心逻辑 |
|:---|:---|:---|
| 成长期（渗透率 5-30%） | PEG | 增速是核心，PEG < 1 = 低估 |
| 成熟期（渗透率 30-70%） | PE + EV/EBITDA | 盈利稳定，看估值分位数 |
| 出清/反转期 | PB + 正常化 PE | 利润底部，看资产和正常化利润 |
| 出口/全球化期 | 分部估值（SOTP） | 国内+海外两部分各自估值 |

### 11.4 四条实战心法

**1. "利润率拐点"比"收入增速"重要十倍。** 大制造公司的股价最大涨幅，几乎都发生在毛利率从底部回升的阶段——而不是收入增速最快的阶段。原因是制造业有强经营杠杆：毛利率从 10% 升到 15%，净利润可能翻 3 倍。买在利润率底部、卖在利润率顶部，是制造股超额收益的最大来源。

**2. 产能利用率比产能规模更重要。** 大制造的魅力不在"我有多少产能"，而在"我的产能在以什么利用率运转"。产能利用率 < 60% → 固定资产折旧成为沉重负担；产能利用率 > 85% → 每一分新增收入都在直接贡献利润。跟踪产能利用率的变化方向，是判断制造股拐点的最有效手段。

**3. 海外收入占比是估值中枢的"隐形开关"。** A 股的工程机械、船舶、汽车零部件龙头，海外收入占比从 10% 升至 50%+ 的过程中，PE 中枢普遍上移 3-5x。因为海外收入 = 分散内需风险 + 更高毛利率 + 更稳定的现金流——这三个特征正是估值溢价的核心驱动力。

**4. 政策驱动型行业，做"出清后的赢家"不做"补贴期的跟风者"。** 光伏、锂电、风电的教训反复验证了一点：政策补贴期是产能泡沫的温床，真正的投资机会在补贴退坡、尾部出清之后。不要在"政策蜜月期"买入，要在"行业最绝望时"布局龙头。
