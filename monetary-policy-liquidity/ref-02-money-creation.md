# 货币创造原理

### 2.1 基础货币与广义货币

二级银行体系：央行发行基础货币 → 商业银行派生广义货币

货币创造机制：
- 贷款创造存款（资产决定负债），非"先有存款后有贷款"
- 法定存款准备金制度约束银行无限扩张
- M2 = 基础货币 × 货币乘数
- 银行之间通过同业拆借、债券买卖交换基础货币，不改变基础货币总量
- 降准改变超储水平，不影响基础货币总量
- 企业、居民、非银之间直接融资出现货币转移，不改变货币总量

### 常见误解纠正
- 误解1：先有存款才能放贷 → 正确：贷款与存款同时产生，资产决定负债
- 误解2：央行超发货币导致房价上涨 → 正确：房地产大周期才是本质，M2增速是映射；楼市上行→居民贷款买房→银行扩表→M2加速，楼市是"印钞机"，楼市下行是"碎钞机"
- 误解3：银行间流动性宽松等于股市流动性宽松 → 正确：央行OMO操作对象集中在银行，对股市无直接影响，需区分流动性层次

### 2.2 M0/M1/M2口径（2025年最新版）

- M0 = 流通中的现金（银行体系以外）
- M1 = M0 + 非金融企业活期存款 + 机关团体活期存款 + 个人活期存款（2025年新增）+ 非银行支付机构客户备付金（2025年新增）
- M2 = M1 + 准货币（非金融企业定期存款 + 居民定期存款 + 其他存款）
- 货币乘数 = M2 / 基础货币

### M1-M2剪刀差含义
- M2增速 > M1增速 → 企业盈利下滑，投资意愿降低，经济下行压力大
- M2增速 < M1增速 → 企业交易活跃，经济景气上升（非绝对规律，需结合成因）
- M1-M2剪刀差领先PPI同比约6个月，进而领先企业盈利拐点约6个月

### M2口径历次调整逻辑
- 2001年：纳入证券公司客户保证金
- 2002年：纳入境内外资合资机构存款
- 2011年：纳入住房公积金中心存款和非存款类金融机构存款
- 2018年：用货币市场基金替换货币市场基金存款（含存单）
- 2025年：将个人活期存款和非银支付机构客户备付金纳入M1
- 核心认知：指标不是一成不变，不能僵化理解

### 2.3 M2与社融的关系

#### M2派生渠道（银行资产端扩张驱动）
- 银行：贷款投放、购买企业债券、非标/资管投放、购买黄金/楼宇等实物资产
- 财政：政府在央行存款减少 → 银行超储增加（财政支出投放货币）
- 外占：外汇占款增加时被动派生（2014年后系统性减少，已非主要渠道）

#### M2 vs 社融宏观含义
- M2代表广义资金供给（存款创造结果，资金供给端）
- 社融代表实体融资需求（资金需求端）
- M2增速 > 社融增速 → 实体流动性宽松，典型如2020年、2022年"融资需求不足式宽松"
- M2增速 < 社融增速 → 信贷需求旺盛，经济扩张期
- 近两年M2-社融对债市指示意义显著减弱，需结合背后成因分析，不能机械套用
