### 狭义流动性（银行间）

| 法则 | 判断标准 | 数据来源 |

| DR007 偏离度 | 持续高于OMO+30BP → 偏紧；持续低于OMO → 偏松 | `加权平均利率:银行间质押式回购` |

| 银行负债压力 | 1Y AAA存单利率 > MLF利率 → 负债压力大 | `中债商业银行同业存单到期收益率(AAA):1年` |
| 分层改善效果 | 降准 > MLF > 逆回购 | — |
| 季节性扰动 | 月末/缴税/春节偏紧；季初/年末支出偏松 | — |

### 广义流动性（实体）

| 法则 | 判断标准 | 数据来源 |
|------|---------|---------|
| M2-社融增速差 | 正值 → 流动性宽裕；负值 → 实体需求强 | `货币供应量(M2):同比` + `社会融资规模:同比` |
| M2-M1剪刀差 | 持续高位 → 企业资金定期化，预期偏弱 | `M2同比` - `M1同比` |
| 货币-信用四象限 | 双宽(债承压)/宽货紧信(债牛)/紧货宽信(债熊)/双紧(最危险) | M2+社融组合判断 |
| 票据利率信号 | 月底大跌=冲量=需求差；月底大涨=额度不足=需求强 | `国股银票转贴现利率:6个月` |
| 信贷结构信号 | 企业中长贷多 → 实体信心强；票据冲量 → 需求偏弱 | `金融机构:新增人民币贷款:分类` |
