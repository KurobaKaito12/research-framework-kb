# 实体流动性分析框架（广义流动性）

### 5.1 量的维度：社融与M2

#### 跟踪指标体系
- 社融新增量/同比增速（总量信号）
- M2、M1同比增速及剪刀差
- M2-社融增速差（正值：流动性宽松；负值：实体需求强）
- 社融/名义GDP比值趋势
- "广义货币（M2）和社会融资规模增速与经济增长和价格水平预期目标相匹配"

#### 社融对债市领先性弱化原因（近年来）
- 原因一：新旧动能切换，新经济融资需求天然偏低，信贷类指标指示意义弱化
- 原因二：金融数据经常由供给因素驱动而非需求主导（银行冲量、票据充量）
- 原因三：防空转等监管导致信贷数据失真
- 原因四：国债等纳入社融统计后，财政节奏对社融数据影响加大，指标更复杂
- 应对策略：关注结构与价格；大趋势与利率依然同频；结合财政力量和高频数据交叉印证

### 5.2 价的维度：广谱利率体系

| 利率指标 | 含义 | 跟踪频率 | 关注要点 |
|---------|------|---------|---------|
| 一般贷款加权平均利率 | 企业综合融资成本 | 季度披露 | 最全面；趋势性变化反映货币政策传导效果 |
| 个人住房贷款利率 | 居民杠杆成本，地产景气信号 | 季度/月度 | 存量房贷利率调整影响居民消费能力 |
| 票据贴现利率（6个月） | 实时反映信贷需求冷热 | 日度 | 月底走势极重要：月底大跌=银行冲量=需求差；月底大涨=额度不足=需求强 |
| 信托平均收益率 | 非标融资成本，城投地产信号 | 周度 | 监管收紧时快速上行 |
| 企业债发行利率 | 直接融资成本 | 日度 | 利率低时发行增加，有季节性特征 |
| 同业存单利率 | 银行负债成本，传导至贷款 | 日度 | 重要的货币市场价格信号 |

### 5.3 结构的维度：社融内部拆解

#### 居民端分析
- 短期贷款：消费信贷景气程度
- 中长期贷款 ≈ 按揭贷款：地产景气核心跟踪指标，与新房销售数据交叉验证

#### 企业端分析
- 短期贷款：经营性流动资金需求
- 中长期贷款：长期资本开支信号，制造业+基建+化债综合反映
- 票据融资：月底低迷=银行冲量（需求差），月底抬升=额度不足（需求强），是最实时的信贷需求温度计
- 企业债：利率低时发行增加，受融资条件和监管政策影响大

#### 非标分析
- 信托贷款/委托贷款：城投、地产主要融资渠道，受监管影响大，趋势性收缩
- 未贴现银行承兑汇票：中小企业重要融资渠道，与股市资金联系相对更紧密

#### 政府债券
- 纳入社融后，财政节奏对社融数据影响显著加大
- 发行节奏快 → 资金面承压（缴款+挤出效应）
- 关注专项债发行进度和使用效率

### 5.4 票据的特殊作用

#### 票据作为信贷需求温度计
- 贴现利率低+贴现量大 → 贷款需求差，银行用票据冲量
- 贴现利率高+贴现量小 → 贷款需求强，额度不足，卖票腾额度
- 2022年票据-贷款的反向关系尤为典型明显

#### 票据作为中小企业融资渠道
- 对中小企业来说，票据融资成本低于贷款
- 票据背书：高资质主体信用向远端传导
- 跟踪指标：国股银票转贴现利率（6个月）与贷款需求指数（BCI）对比

### 5.5 货币-信用周期分析框架（流动性投资时钟：六种情形）

货币与信用的松紧组合决定流动性环境的大方向，是资产配置的核心宏观变量。传统四象限框架将"紧信用"简单归为一类，但实际中信用收缩可分为"融资需求不足（被动）"和"主动信贷管控"两种截然不同的情形，对资产的含义差异显著。因此将框架升级为六种流动性情形。

#### 5.5.1 六种情形资产表现矩阵

| 组合 | 宏观特征 | 利率债 | 信用债 | 股票 | 商品 | 现金 | 典型时期 |
|------|---------|--------|--------|------|------|------|---------|
| 宽货币+融资需求不足 | 融资需求不足式宽松 | ★★★★ | ★★★ | ★★ | ★ | ★★★ | 2022年/2024-2025年 |
| 宽货币+紧信用(主动) | 信贷管控型紧缩 | ★★ | ★ | ★ | ★★ | ★★★★ | 2011年（地产调控+表外监管） |
| 紧货币+融资需求不足 | 货币收紧+需求不足 | ★ | ★★ | ★★ | ★★ | ★★★★ | 2014年（紧货币+地产下行） |
| 紧货币+紧信用 | 去杠杆，最危险 | ★★ | ★ | ★ | ★★ | ★★★★★ | 2013年/2017-2018年 |
| 宽货币+宽信用 | 流动性最优，经济扩张 | ★★ | ★★★★ | ★★★ | ★★★★ | ★ | 2009年/2020年上半年 |
| 紧货币+宽信用 | 经济过热，主动收紧 | ★ | ★★ | ★★★ | ★★★★ | ★★★★ | 2010-2011年 |

★ 越多表现越好，同一情形内跨资产比较反映相对收益排序。

#### 5.5.2 六种情形投资指南

**情形一：宽货币+宽信用（经济复苏）**

典型背景：宽松政策见效，信贷需求回暖，经济企稳回升。流动性环境最优。

| 维度 | 操作建议 |
|------|---------|
| 利率债 | **逆风环境**，长端利率有上行压力。降低久期至中性以下。收益率曲线陡峭化，做空长端+做多短端的carry trade |
| 信用债 | **最佳象限**。信用环境改善+资金充裕，利差压缩空间大。可适度下沉资质，中低等级信用债表现最佳。久期维持中等水平 |
| 可转债 | **表现突出**。正股上涨+债底支撑，进攻性凸显。重点偏股型转债和股性较强的品种 |
| 股票 | **整体上涨**，盈利改善+流动性充裕双轮驱动。早周期行业（金融、地产链、可选消费）领涨。大小盘均有表现但小盘弹性更大 |
| 商品 | **全面上涨**。需求回暖+通胀预期升温。工业品、能源涨幅居前。有色受益于全球复苏预期 |
| 现金/短端 | 机会成本最大，资金利率低但信用扩张环境下应降低现金比例 |

**核心策略：超配信用债和股票，低配利率债，关注从债券到股票的轮动拐点。**

**情形二：宽货币+融资需求不足（被动）**

典型背景：经济下行+通胀回落→央行主动宽松，但实体融资需求低迷，信用扩张受阻。

| 维度 | 操作建议 |
|------|---------|
| 利率债 | **最受益象限**。久期策略为主，哑铃型配置（短端受益于资金宽松+长端受益于经济悲观预期），10Y国债收益率有下行空间，曲线牛陡→牛平 |
| 信用债 | **跟随利率债上涨**，但利差压缩幅度取决于信用风险预期。高等级信用债优于低等级，不建议在此象限下沉资质 |
| 可转债 | **中性偏正面**，债底保护+正股低位，适合右侧建仓或低价策略，注意正股下行风险 |
| 股票 | **整体承压**，盈利下行压制估值。防御性板块（公用事业、高股息）相对收益。成长股受益于利率下行但受制于风险偏好。等待信用扩张信号确认后再加仓 |
| 商品 | **需求驱动向下**，除非供给端扰动。工业品价格受制于总需求不足 |
| 现金/短端 | 货基收益随资金利率下行走低，但仍是低风险偏好下的底仓选择 |

**核心策略：拉长久期，买入利率债和高等级信用债，静待信用扩张信号。**

**情形三：宽货币+紧信用（主动管控）**

典型背景：实体融资需求尚可，但央行/监管部门主动收紧信贷投放——地产调控导致的按揭额度受限、表外融资监管、地方平台融资约束等。货币宽松但信用受控，形成"钱多但去路不畅"的格局。

| 维度 | 操作建议 |
|------|---------|
| 利率债 | **中性偏正面**。短端受益于货币宽松，但长端受制于信用收缩影响经济预期，收益率曲线陡峭化（牛陡）。久期策略中等为宜，偏短端 |
| 信用债 | **回避**。主动信用管控直接压制信用扩张，信用事件风险上升。规避受管控行业（地产、城投）的信用债，仅保留高等级短久期 |
| 可转债 | **谨慎**。正股受信用管控压制，但债底有资金面支撑。关注不受管控行业的转债机会 |
| 股票 | **结构分化**。受管控行业板块承压（地产、金融），受益于宽松但不受管控的板块（如充裕流动性追逐的成长主题）有结构性机会 |
| 商品 | **中性偏弱**。管控压制投资需求，但流动性充裕对商品有一定支撑 |
| 现金/短端 | 资金利率低，但避险需求下短端仍有配置价值 |

**核心策略：规避受管控行业敞口，关注流动性充裕驱动的结构性机会，利率债短端优于长端。**

**情形四：紧货币+融资需求不足**

典型背景：央行出于防风险/控杠杆/稳汇率等原因收紧货币，但实体融资需求本身偏弱。货币收紧压制短端，但融资需求不足使长端上行幅度受限，形成"熊平"格局。

| 维度 | 操作建议 |
|------|---------|
| 利率债 | **短端承压、长端相对抗跌**。短端利率受货币收紧直接推升，但长端受制于融资需求不足上行幅度有限，曲线熊平。短久期防御为主，长端可逢高配置 |
| 信用债 | **利差走阔风险**。信用环境偏弱叠加流动性收紧，信用利差趋于走阔。全面降低信用敞口，仅保留高等级 |
| 可转债 | **偏弱**。正股缺乏业绩驱动+估值受利率上行压制，总体降低仓位 |
| 股票 | **整体承压但非系统性杀估值**。货币收紧压制估值，但融资需求不足意味着经济下行空间有限，市场以结构性调整为主。防御板块优于周期 |
| 商品 | **需求+金融双杀**。融资需求不足压制工业品需求，货币收紧抬升资金成本 |
| 现金/短端 | **最佳配置**。短端利率上行后现金类收益提升 |

**核心策略：缩短久期，增配现金，回避信用敞口，等待货币政策转向信号。**

**情形五：紧货币+宽信用（经济过热）**

典型背景：经济偏热，央行主动收紧。但信用扩张惯性仍在，实体融资需求旺盛。

| 维度 | 操作建议 |
|------|---------|
| 利率债 | **最差象限**。熊市格局，长端利率大幅上行。久期降至最低，配置盘可逢利率冲高逐步建仓（逆势，需等待明确的政策拐点信号） |
| 信用债 | **利差走阔风险**。信用环境尚可但流动性收缩首先冲击信用债，尤其是低等级。逐步降低信用敞口，向高等级迁移 |
| 可转债 | **分化明显**。正股尚有支撑但估值受利率上行压制。股性强者抗跌，债性弱者承压。总体应降低仓位 |
| 股票 | **见顶风险**。盈利仍在扩张但估值受利率上行压制，整体回报受限。受益于通胀上行的板块（资源品、能源）仍有机会。金融板块受益于息差扩大 |
| 商品 | **最强象限**。通胀上行+需求仍旺，商品牛市。原油、工业金属领涨。黄金在加息初期承压 |
| 现金/短端 | 最优配置。资金利率大幅上行，短端收益可观。提高现金和货币基金比例 |

**核心策略：超配现金和商品，低配债券，股票转为防御，等待政策转向信号。**

**情形六：紧货币+紧信用（去杠杆）**

典型背景：经济下行叠加融资收缩，流动性环境最差。可能由主动收紧（2013）或被动收缩（2018）触发。

| 维度 | 操作建议 |
|------|---------|
| 利率债 | **"避风港"+流动性冲击矛盾体**。基本面利好利率债（经济下行+信用收缩），但流动性冲击可能导致利率债被抛售（2013）。关键看央行态度——若央行维稳资金面，利率债有配置价值；若央行放任（2013钱荒），则回避 |
| 信用债 | **最危险**。信用收缩+流动性冲击双重打击，违约风险上升。全面降低信用敞口，只保留高等级短久期。避免民企债和低等级城投 |
| 可转债 | **全面回避**。正股下跌+信用风险+流动性不足，三重压力。等待信用和流动性拐点信号出现后再考虑 |
| 股票 | **大幅承压**。估值和盈利双杀，系统性风险。防御类板块（高股息、公用事业）相对抗跌，但仓位应大幅降低 |
| 商品 | **需求下行主导**，多数品种下跌。美元走强时黄金也承压。避险属性下黄金相对抗跌 |
| 现金 | **最佳配置**。"现金为王"象限，保持充足流动性，等待右侧信号 |

**核心策略：现金为王，维持短久期，不接飞刀。等待紧货币政策转向信号再入场。**

#### 5.5.3 六种情形转换路径与先行信号

六种情形按以下路径自然轮动（货币政策方向主导切换），政策干预和外部冲击可导致跳跃式转换。

**顺时钟转换路径：**

```
融资需求不足 → 宽信用 → 紧货币 → 紧信用/融资需求不足
```

各情形之间的具体转换方向：

| 转换方向 | 关键信号 | 时间差 |
|---------|---------|--------|
| 宽货+融资需求不足 → 宽货+宽信 | 深层判断：旧经济（地产投资/销售）是否企稳，新经济capex能否转化为银行信贷需求。表层确认：社融同比企稳回升、企业中长贷放量、PMI重回50以上（前者是根因，后者是验证信号） | 1-2个季度 |
| 宽货+宽信 → 紧货+宽信 | CPI突破3%、央行公开市场操作开始净回笼、政策利率上调 | 2-3个月 |
| 紧货+宽信 → 紧货+紧信（主动） | PMI回落至50以下、社融增速见顶回落、信用利差走阔 | 1-2个季度 |
| 紧货+宽信 → 宽货+宽信 | 央行降息/降准、政策放宽、信贷管控放松 | 1-3个月 |
| 紧货+紧信（主动）→ 宽货+紧信（主动） | 央行转向宽松，但信贷管控持续 | 1-3个月 |
| 宽货+紧信（主动）→ 宽货+融资需求不足 | 信贷管控放松但实体融资需求自发走弱 | 1-2个季度 |
| 紧货+融资需求不足 → 宽货+融资需求不足 | 央行转向宽松 | 1-3个月 |
| 宽货+融资需求不足 → 紧货+融资需求不足 | 央行因防风险/稳汇率收紧 | 1-3个月 |

**逆时针/跳跃转换案例：**

- **2024-2025年**：直接从紧货币+紧信用跳跃到宽货币+融资需求不足。跳过宽信用复苏期，因经济未过热、政策主动预防式宽松。历史上相当罕见。
- **2008年**：雷曼倒闭后，从紧货币快速切换到宽货币+融资需求不足（2008Q4），约2个月完成，属于外部冲击触发的跳跃。
- **2020年**：疫情冲击下，紧货币快速切换到宽货币+融资需求不足（2020Q1），约1个季度。

#### 5.5.4 当前周期定位与对策框架

当前各维度定位（需结合最新数据更新）：

| 维度 | 当前状态 | 判断依据 |
|------|---------|---------|
| 货币松紧 | 宽货币（适度宽松） | 7D OMO处于历史低位，央行明确"适度宽松"基调 |
| 信用松紧 | 偏紧（融资需求不足主导） | 社融增速企稳但结构偏弱，企业中长贷占比不高，票据冲量现象隐现。更接近"融资需求不足"而非"主动紧信用" |
| 当前情形 | **宽货币+融资需求不足** | 货币主动宽松+实体融资需求偏弱，资金淤积银行间 |
