# 货币政策与流动性分析实战指引

## 8.1 流动性分析八步排查流程

收到"分析当前资金面/流动性/货币政策"类任务时，按以下步骤系统排查。

### Step 1：确认政策利率状态（30秒）

获取当前政策利率最新值，判断是否近期有调整。

| 核心问题 | 判断依据 |
|---------|---------|
| 7天逆回购当前多少？最近一次调整是什么时候？ | `数据需求(query="逆回购:7日:回购利率(最近3个月)")` |
| 利率走廊上下限多少？ | SLF隔夜(上限) + 临时正回购隔夜(下限) |
| MLF利率多少？是否仍在操作？ | `数据需求(query="中期借贷便利(MLF):操作利率:1年(最近6个月)")` |
| LPR是否调整？1年期和5年期是否同步？ | `数据需求(query="贷款市场报价利率(LPR):1年(最近6个月)")` |

**关键判断**：若最近1个月内政策利率调整过，优先判断调整的触发因素和后续空间。

### Step 2：判断央行操作方向（2分钟）

最近一段时间的央行操作体现了什么意图？

| 观察维度 | 具体指标 | 数据来源 |
|---------|---------|---------|
| OMO净投放/回笼 | 逆回购到期+续作量 | `数据需求(query="逆回购:7日:回购金额(最近1个月)")` |
| MLF续作情况 | MLF操作金额 vs 到期量 | `数据需求(query="中期借贷便利(MLF):操作金额:1年(最近3个月)")` |
| 降准落地 | 准备金率变化 | `数据需求(query="存款准备金率:大型金融机构(最近6个月)")` |
| 结构性工具 | PSL/再贷款投放量 | `数据需求(query="PSL抵押补充贷款:期末余额(最近1年)")` |
| 央行沟通信号 | 货政报告/例会/发布会措辞变化 | iFind新闻 / 联网搜索 |

**关键判断**：央行是"补水"还是"收水"？操作量超出预期还是符合预期？措辞有无边际变化（如"灵活适度"vs"精准有力"vs"适度宽松"）。

### Step 3：评估狭义流动性（银行间，3分钟）

资金面的实际松紧程度。

| 核心指标 | 观测方法 | 判断标准 |
|---------|---------|---------|
| DR007 | 与7天逆回购利率比较 | DR007围绕7D OMO波动 → 正常；持续高于OMO+30BP → 偏紧；持续低于OMO → 偏松 |
| R007 | 与DR007的利差 | R007-DR007 < 30BP → 正常；> 50BP → 非银融资紧张 |
| 资金利率波动率 | 日内/周内振幅 | 振幅加大 → 资金面不稳定，可能有季节性扰动 |
| 超储率 | 季度数据+月末估算 | 超储率 < 1.0% → 偏紧；1.0%-1.5% → 中性；> 1.5% → 偏松 |
| 银行同业存单利率 | 1年期AAA存单 vs MLF利率 | 存单利率 > MLF → 银行负债压力大；< MLF → 负债充裕 |
| IRS利率互换 | 1年期FR007 IRS | IRS上行 → 资金收紧预期；下行 → 宽松预期 |

**取数模板：**
```
数据需求(query="加权平均利率:银行间质押式回购(最近3个月)")
数据需求(query="常备借贷便利(SLF):操作利率:7天(最近1年)")
数据需求(query="中债商业银行同业存单到期收益率(AAA):1年(最近3个月)")
```

**关键判断**：DR007偏离政策利率多少BP？偏离方向持续了多久？是季节性还是趋势性？

### Step 4：评估广义流动性（实体，2分钟）

实体层面的流动性充裕程度和信用扩张意愿。

| 核心指标 | 观测方法 | 判断标准 |
|---------|---------|---------|
| M2同比 | 与名义GDP增速比较 | M2 > 名义GDP+2% → 宽货币 |
| 社融同比 | 增速趋势 | 社融同比上行 → 宽信用；持续下行 → 信用收缩 |
| M1同比 | 企业活期存款 | M1回升 → 企业流动性改善，经营活跃度提升 |
| M2-M1剪刀差 | 定期化vs活期化 | 剪刀差持续高位 → 企业资金定期化，预期偏弱 |
| 信贷结构 | 中长期贷款占比 | 企业中长贷多 → 实体融资需求强；票据冲量 → 需求偏弱 |

**关键判断**：宽货币是否向宽信用传导？是"流动性陷阱"还是"信用扩张"？实体预期在改善还是恶化？

### Step 5：评估资本市场流动性（2分钟）

股市和债市的资金面。

| 核心指标 | 观测方法 |
|---------|---------|
| 股债比价 | 沪深300股息率/10年国债收益率，判断资金在股债间的迁移 |
| 理财规模 | 理财规模是否扩张 → 资管产品配置力量增强 |
| 两融余额 | 两融余额趋势 → 杠杆资金风险偏好 |
| 北上资金 | 北上净流入/流出 → 外资对中国市场的态度 |
| 债券市场杠杆 | 银行间回购成交量/债券托管量 → 杠杆率是否过高 |

### Step 6：考虑财政-货币协同与政府债供给（1分钟）

| 核心问题 | 分析框架 |
|---------|---------|
| 政府债供给压力大吗？ | 计算未来1-2个月政府债净融资量，与历史同期比较 |
| 财政存款变化方向？ | 财政支出加快 → 释放流动性；财政存款累积 → 回收流动性 |
| 央行是否配合？ | 政府债供给大时，央行是否降准/加大OMO投放对冲 |

### Step 7：考虑外部约束（1分钟）

| 约束条件 | 影响方向 |
|---------|---------|
| 中美利差（10年国债） | 利差倒挂越深 → 降息空间越受制约 |
| 人民币汇率 | 贬值压力大 → 央行宽松空间受限 |
| 跨境资本流动 | 资本外流压力 → 央行偏好稳健操作 |

### Step 8：综合判断与展望（2分钟）

将前七步结论整合输出。先判断任务类型：

**即时点评**（如数据公布后快评）：按场景选用以下四种模板之一。

**Template A — 四点式快评**（适用于短平快点评）
1. 现状
2. 边际变化
3. 潜在影响
4. 展望

**Template B — 递进式六段**（适用于月度流动性数据、降准降息落地等央行操作点评）
1. 先看总量
2. 再看脉络（月度/历史比较）
3. 不是……（排除误读）
4. 而是……（正面定性）
5. 潜在影响
6. 展望

**Template C — 事件快评**（适用于政治局会议、货政报告、讲话等政策事件点评）
1. 发生了什么
2. 内容拆解
3. 含义解析
4. 市场影响

**Template D — 深度快评**（适用于重磅政策/数据，需给出独立判断）
1. 时机选择（为什么是现在）
2. 主要内容（具体做了什么）
3. 超预期的点（预期差在哪）
4. 我们的理解（独立判断）
5. 启示（投资含义）

**展望/评估**（如季度展望、中期评估）：调用 §8.4 五部分模板完整输出。

**历史回顾**（如"过去一年的脉络""货币政策的演变"）：按时间线分段。先识别关键转向节点并排序，每个阶段提炼"阶段特征+核心驱动+标志事件"，最后用一条主线穿透全文。

### 资金面分析输出质量自检清单

完成Step 1-7的数据排查和Step 8的初步判断后，在输出最终分析前，逐项自查以下五条。任一条未满足则必须补充后再输出。

**1. 叙事主线：供给vs需求框架，不是并列罗列**

不能写成"第一、第二、第三"的并列结构。必须以"供给多/少 + 需求强/弱 = 资金面松/紧/平衡"的主线贯穿。先定性再展开，每一段都服务于这条主线的论证。

> 错误示范：央行投放了X、财政释放了Y、外汇流入Z → 所以资金松（三点并列，无穿透）
> 正确示范：供给端三条水管都在放水，但需求端钱没去处 → 资金淤积银行间 → 融资需求不足式宽松

**2. 定性标签：必须给当前资金面一个判断性定义**

用一句话定性当前状态，标签要刺穿现象直达本质。禁止只描述"DR007低于OMO"而不给出定性判断。

常用定性标签：
- **融资需求不足式宽松**：实体融资需求弱 → 资金淤积金融体系（常见于信用收缩期）
- **主动宽松**：央行主动降准/降息/放量投放导致的宽松（成本低、信号明确）
- **中性平衡**：DR007围绕OMO波动，供需基本匹配
- **结构性收紧**：总量尚可但分层加剧（R007-DR007利差走阔）
- **季节性扰动**：缴税/跨季/春节等可预期的短期波动

> **术语规范**：禁止使用"衰退式宽松"一词。一律替换为"融资需求不足式宽松"。实质驱动是实体融资需求弱导致资金淤积，而非经济衰退，两种定性有本质差异。

**3. 供给端全面检查：不漏"小水管"**

逐项排查五因素模型中的每一项，不能因为某个变量"通常不重要"就跳过。外汇占款虽已不是2014年前的主变量，但在汇率大幅波动或资本流动异常时期，边际增量可能超出预期。

- 央行操作：OMO量 + MLF续作 + 结构性工具 + 买断式逆回购（"重价不重量"但要看工具切换方向）
- 财政存款：政府债发行 + 财政支出节奏（结合季节性规律判断）
- 外汇占款：即使不是主变量，也要思考一句"有无边际影响"
- 现金走款：季节性扰动（春节/长假）

**4. 主动vs被动辨析：说清楚宽松的根因**

必须在分析中点明当前宽松是"央行主动为之"还是"实体需求弱导致的被动结果"。同一利率水平下，两种成因的可持续性和政策含义截然不同。

- 主动宽松 → 央行可随时调整力度，持续性取决于政策目标
- 被动宽松（融资需求不足式宽松）→ 根子在实体，宽货币到宽信用传导不畅，央行想收也收不紧，需等实体需求回升

**5. 可持续性判断：近端变数 + 远端变数**

给出时间维度上的判断，不能只有静态描述。至少覆盖：
- 近端（1-2个月）：边际变数是什么？（税期/政府债供给/跨季）
- 远端（3-6个月）：什么会打破当前格局？（信贷需求回升/政策转向/外部冲击）

### 深度分析质量三重检查（通用）

适用于所有非即时点评类的分析输出——展望评估、历史回顾、股市流动性分析等。输出前逐项自检，缺任何一重则必须补充。

**第一重：事实完整。** 有没有遗漏关键节点、数据、驱动因素？历史回顾不能跳阶段，展望评估不能漏约束条件，流动性分析不能跳过某个资金维度。通过标志：读者找不到明显的信息缺口。

**第二重：归纳到位。** 散点信息是否被提炼为阶段特征或模式判断？每个事实都有"所以呢"的归因。通过标志：每一个自然段都有判断句，而非只有数据描述。

**第三重：洞察升维。** 全文有没有一条贯穿的主线结论？它应该是一个体现了整体判断的句子，不是表层的"偏松/偏紧"定性，而是穿透到根因——比如"主动宽松只用了一个月，剩下全是被动宽松的静默期"。通过标志：读者能用一个句子复述你的核心判断。

> 三重检查逐层递进。第一重防止遗漏，第二重防止堆砌，第三重防止平庸。如果第三重通不过，说明分析只有"正确"但没有"穿透"，需要重新提炼主线。

## 8.3 分析框架应用场景

### 场景A：央行降息/降准点评

调用链路：
1. `ref-03-cenbank-policy.md` 第3.2节 → 判断本次用的什么工具，在工具图谱中是什么定位
2. `ref-03-cenbank-policy.md` 第3.4节 → 回顾降息信号是否充分，超预期还是符合预期
3. `ref-04-narrow-liquidity.md` → 分析对银行间流动性的影响（超储变化、资金利率预期）
4. `ref-07-integrated-analysis.md` → 判断传导至实体和资本市场的路径

核心输出：降息/降准的政策意图、传导路径、后续空间判断。

### 场景B：流动性与资金面分析

调用链路：
1. 8.1节八步排查流程 → 按步骤走完Step 1-7
2. `ref-04-narrow-liquidity.md` → 深挖狭义流动性（为主）
3. `ref-07-integrated-analysis.md` → 确认流动性层次判断
4. 8.2节取数指引 → 获取所需数据

核心输出：当前流动性状态 + 边际变化 + 未来1个月展望。

### 场景C：债市资金面与杠杆分析

调用链路：
1. `ref-04-narrow-liquidity.md` → 资金利率与杠杆判断
2. `ref-06-capital-market-liquidity.md` → 债市资金与机构行为
3. 8.2节 → 取回购成交量、IRS、存单利率等数据

核心输出：资金面是否支持债券加杠杆、杠杆率是否已处于高位。

### 场景D：股市流动性判断

调用链路：
1. `ref-06-capital-market-liquidity.md` → 核心框架

## 8.4 货币政策展望/评估输出模板

撰写货币政策展望或评估报告时，严格按以下五部分结构输出。每部分必须包含对应内容，禁止跳过或合并。

---

### Part 1：央行四大目标评估 + 核心矛盾

逐一评估四大目标当前状态，判断 ref-03 §3.1 中目标优先级归属。

**（1）经济增长与充分就业**
- 最新 GDP 增速 vs 当年目标：达标/高于/低于？偏离幅度？
- PMI、工业增加值、调查失业率趋势
- **增长结构判断（关键）**：
 - 经济动能来源：内需主导还是外需拉动？货币政策对内需更敏感——内需内生性回暖时货币趋紧概率上升，外需驱动时容忍度更高
 - 地产投资/销售是否企稳：地产链条若出现持续性好转，是货币政策可能边际收紧的最重要先行信号
 - 基建与制造业投资的边际变化：判断财政发力节奏和制造业周期位置
 - 结论不仅是"达标与否"，而是判断增长是"量的达标"还是"质的改善"——后者才可能触发政策转向
- 结论：是否触发"下行期"条件？（GDP 低于目标 0.5%+，或三项中两项：PMI 连续三月 < 50、社融偏弱、CPI/PPI 为负）

**（2）物价稳定**
- CPI 同比趋势及核心驱动（猪肉/能源/服务）
- PPI 同比：收窄还是扩大？
- 通胀性质判断：需求端通胀 / 供给端通胀 / 通缩缓解 / 无压力
- **通胀成因分辨（关键）**：同等通胀读数下，成因不同则政策含义截然相反
 - 供给因素（猪瘟、地缘冲突、供应链中断、OPEC 减产等）引发的 PPI 或 CPI 上行 → 货币政策容忍度较高，不会因此收紧，因为供给冲击不可持续且紧缩会抑制需求端修复
 - 需求端尤其是内需引发的价格信号上涨（如消费回暖推动核心 CPI 上行、地产复苏带动 PPI 回升）→ 货币政策容易趋紧，此时降息概率下降甚至存在加息风险
- 结论：必须同时标注"方向+成因"，不能只有方向判断。例如："CPI 回升至 1.0%，但核心驱动是猪肉供给扰动，非内需复苏，对货币政策不构成制约"

**（3）金融稳定**
按以下五个子维度系统评估，每个标注含义方向和当前状态：

- **银行净息差**（越低越宽松，正相关；越高加息制约越小，对称视角）：NIM 低于 1.50% 警戒线意味着银行利润空间极度逼仄，此时央行有动机维持宽松流动性（降低银行负债成本），但总量降息空间也受此制约——因为再降息会进一步压缩 NIM。NIM 越低 → 需维持宽松但更依赖结构性工具而非总量降息。反之，NIM 回升至 >1.80% 且银行利润修复时，降息制约解除，加息空间随之打开
- **金融加杠杆行为**（越高越紧缩，反向指标）：跟踪债市杠杆率（回购成交量/债券托管量）、资金空转迹象。杠杆高位时央行操作更审慎，防止"资产荒"演变为金融风险
- **房地产价格**（越高越紧缩，反向指标）：70 城房价环比持续正增长、地产销售/投资显著回暖时，货币政策收紧概率上升。房价持续疲软则构成宽松理由
- **股市表现**（仅严重持续下跌才触发宽松）：一般性调整不构成货币政策考量。但若出现流动性危机（如连续暴跌、恐慌性抛售、股权质押爆仓风险），央行会通过降准/降息/流动性工具维稳
- **地方债务化解进度**（压力越大越宽松，正向）：化债进度越紧迫、地方政府融资平台风险越高，货币政策越需要维持低利率环境配合，构成宽松理由

**（4）国际收支与汇率**
- 中美利差（10Y/短端）：倒挂幅度变化
- 人民币汇率：贬值/升值方向，是否突破关键点位
- 跨境资本流动：北向资金、外汇储备变化
- 结论：汇率是否构成硬约束？

**（5）其他考量与约束因素**

央行实际操作中，除四大目标外还受到以下因素的显著影响（随经济环境变化重要性有差异）：

- **五篇大文章**（科技/绿色/普惠/养老/数字金融）：央行结构性货币政策工具的投放方向，影响再贷款额度分配和PSL投向。若某领域被列为"重点"，对应结构性工具可能扩容
- **维护银行净息差与银行体系健康**：避免银行体系风险积累是央行的隐性约束。存款利率自律机制是否推动新一轮存款利率下调，直接影响银行负债成本和降息空间。中小银行风险化解进展也制约政策节奏
- **维护金融市场稳定**：近年权重上升——4月政治局会议提出"增强货币政策前瞻性灵活性针对性"并与"维护金融市场稳定"关联；央行通过国债买卖调控长端利率、通过SFISF和回购再贷款支持资本市场，均体现此目标。债市波动率、股市运行状态会影响央行操作时点和工具选择
- **金融强国建设与框架转型**：利率走廊收窄、MLF退出政策利率角色、货币供应量统计改革、向价格型调控转型等长期进程，约束了短期内工具选择的灵活度。例如转型期央行可能更倾向于使用成熟工具（OMO、降准）而非正在改革中的工具（MLF）
- **财政-货币协同**：政府债券发行节奏、特别国债发行、地方化债进度的流动性影响，需要货币政策配合对冲。财政发力阶段降准的概率上升
- **央行年度重点工作**：年初工作会议、金融工作会议等确定的当年优先事项（如2026年潘功胜行长提出的"促进经济稳定增长、物价合理回升"作为货币政策重要考量）
- **畅通货币政策传导机制**：资金淤积在银行间还是有效流向实体？Q1例会新增"规范信贷市场经营行为，降低融资中间费用"，说明央行关注点从总量宽松部分转向疏通传导、减少金融摩擦。传导效率偏低时，总量宽松效果打折扣，央行可能更依赖结构性工具
- **居民资产配置行为变化**：居民存款向理财、基金、股票搬家时，存款利率的边际传导效率下降——即使降息，居民存款成本下降的受益群体缩小，而风险资产价格已受益于流动性充裕。利率越接近1%，存款搬家效应越强，央行降息意愿越低（降息边际成本上升、边际效用递减）。此因素在2025年后权重上升：M2增速回落而股市活跃，居民存款增速与M2增速的偏离度可作为量化跟踪指标

**▶ 核心矛盾总结（1-2 句话）**
将四大目标评估与上述因素综合，提炼当前货币政策面临的最核心平衡：哪一个约束是最紧的？哪个目标在边际上变化最大？整体取向偏松/偏中/偏紧？

### Part 2：政策工具选择

基于 Part 1 的约束条件检查，判断政策工具的选择方向、力度和时点。

**约束条件检查清单**

| 约束条件 | 当前状态 | 对宽松的制约程度 | 边际变化 |
|---------|---------|-----------------|---------|
| 银行 NIM | — | 高/中/低 | 收紧/放松/不变 |
| 汇率/中美利差 | — | 高/中/低 | 收紧/放松/不变 |
| 物价（CPI 超预期） | — | 高/中/低 | 收紧/放松/不变 |
| 防空转/金融风险 | — | 高/中/低 | 收紧/放松/不变 |
| 政府债供给对冲需求 | — | 高/中/低 | 收紧/放松/不变 |

**降息判断——七因子决策模型**

央行降息决策由以下七个因子综合决定，逐一检查后代入决策规则：

| 因子 | 宽松方向 | 判断标准 |
|------|---------|---------|
| ① 经济增速严重低于目标 | 正向（越低越需降息） | GDP 低于年度目标 0.5pp 以上 |
| ② 社融增速持续疲软 | 正向 | 社融同比连续 3 个月下行，或低于名义 GDP+2% |
| ③ 通胀持续低迷 | 正向 | CPI 同比持续低于 1% 且 PPI 为负 |
| ④ 房价持续疲软 | 正向 | 70 城房价环比持续为负，地产销售面积同比负增长 |
| ⑤ 银行息差处于合理水平 | 反向（过低制约） | NIM 低于 1.50% 构成降息制约；高于 1.80% 无制约 |
| ⑥ 汇率无贬值压力 | 正向（无制约则空间打开） | 中美利差不持续扩大，人民币无单边贬值预期 |
| ⑦ 实际利率已充分修复 | 反向（越低越无需降息） | 名义政策利率-CPI同比 < 0.5% → 实际利率已偏低，降息紧迫性下降 |

**决策规则：**
- ①-④ 中满足 3-4 项 + ⑤-⑦ 无明显制约 → 降息概率很高（>70%），进入降息窗口
- ①-④ 中仅满足 2 项 + ⑤-⑦ 中任一存在制约 → 央行倾向于观望，依赖结构性工具
- ①-④ 中仅满足 0-1 项 → 降息概率很低，无需讨论降息时点
- 特殊情形：若央行通过公开讲话/货政报告释放明确的"预热"信号（如"强化降息预期管理"），且约束因素同步解除 → 即使①-④仅满足 2 项也可能触发降息

**降息有效性评估（补充判断）**

七因子模型判断的是"能不能降"，还需补充"降了有没有用"——同样影响央行决策：

| 条件 | 有利降息有效 | 不利降息有效 |
|------|------------|------------|
| 借款人意愿 | 企业有资本开支意愿，居民有加杠杆意愿 | 企业持币观望，居民提前还贷 |
| 政府加杠杆 | 政府债发行加速，财政-货币协同 | 政府债发行偏慢，财政扩张意愿不足 |
| 银行投放意愿 | 银行风险偏好正常，资本充足率充裕 | 银行惜贷，风险偏好极低 |
| 传导渠道 | 信贷需求旺盛，票据利率正常 | 票据冲量，资金淤积银行间 |

- 若"有利"条件≥3项，降息有效性高，央行更愿意降（概率上调）
- 若"不利"条件≥3项，降息有效性低，央行倾向于观望（即使概率模型显示可降）

**加息判断——六因子决策模型**

对称于降息模型，加息决策由以下六个因子综合决定。核心区别：通胀、增长、房价在加息场景下高度共线（历史上加息周期通常三者同步），因此设计为六因子而非七因子。

| 因子 | 方向 | 判断标准 |
|------|------|---------|
| ① 通胀严重超目标 | 正向（越高越需加息） | CPI>3%且持续，且为需求端驱动；或CPI+PPI均>OMO+1%（实际利率深度为负）|
| ② 经济明显过热 | 正向 | GDP持续高于目标1pp以上，PMI>53持续3个月 |
| ③ 房价持续明显上行 | 正向 | 70城房价同比>5%（一线>10%），环比持续>0.5% |
| ④ 信贷持续高增 | 正向 | 社融增速持续高于名义GDP+3pp，或M2>12%持续半年以上 |
| ⑤ 实际利率为负 | 正向（越低越需加息） | OMO利率-CPI<0，或存款利率-CPI<0（居民实际存款负利率） |
| ⑥ 外部环境无制约 | 反向（有制约则无法加） | Fed不在降息周期；中美利差未深度倒挂；人民币无序升值压力不大 |

**加息类型区分**（关键逻辑）：
- **基准利率（存贷款）加息**：历史上仅在全面过热期使用，需①-⑤中满足4-5项。2004/2006-07/2010-11年属此类
- **OMO/MLF利率上调**：可以在非过热期"轻踩刹车"，①-⑤中满足2-3项即可触发。2017-18年属此类——CPI仅~2%，但金融去杠杆+跟随Fed驱动OMO上调
- **LPR不对称上调**：仅上调1年期LPR但不调5年期，定向收紧企业信贷，是较精细的收紧手段

**决策规则：**
- ①-⑤中满足4-5项 + ⑥无明显制约 → 基准利率加息概率很高（>70%），进入加息窗口
- ①-⑤中仅满足2-3项 + ⑥无明显制约 → OMO利率上调概率较高，基准利率维持不变
- ①-⑤中仅满足0-1项 → 加息概率很低，甚至无需讨论
- 历史对应：2010-11年满足5项 → 基准利率加息5次共125bp；2017年满足2-3项（信贷高增+房价偏热）→ OMO上调4次共25bp但基准利率不动

**历史案例速查：**

| 周期 | 触发因素 | 加息类型 | 力度 |
|------|---------|---------|------|
| 2004 | CPI 5.3%+实际负利率+FAI>30% | 基准利率 | +27bp（一次性） |
| 2006-07 | CPI 1.5→6.5%+GDP 11-14%+房价>10%+股价暴涨 | 基准利率 | +162bp（8次） |
| 2010-11 | CPI 6.5%+M2 27.7%+房价涨30-50%+实际负利率 | 基准利率 | +125bp（5次） |
| 2017-18 | 跟随Fed+去杠杆+房价偏热，CPI仅~2% | OMO/MLF | +25bp（4次，微调） |

**降准判断**
- 必要性：政府债供给高峰是否需要降准对冲？超储是否偏低？
- 窗口期：税期/跨季/政府债集中发行时点哪个最可能？
- 幅度：25BP 还是 50BP？

**结构性政策工具**
- 再贷款/再贴现：已投放多少？后续空间？
- PSL：是否继续投放支持地产/三大工程？
- 买断式逆回购：是否成为常规中长期流动性投放工具？
- 存款利率自律机制：是否继续推动存款利率下行（变相降息）？

### Part 3：市场共识度与预期差

按 ref-10 框架分析市场对货币政策的定价和分歧。

**市场价格反推（ref-10 §10.2）**
- IRS 1Y vs 7D OMO：IRS - OMO = X BP → 市场隐含的升降息预期幅度
- 国债期货（T/TF/TS）：基差、跨期价差反映的多空情绪
- 1Y AAA 存单利率 vs MLF：银行负债压力 + 市场对 MLF 利率的预期
- 10Y 国债收益率趋势与含意定价

**卖方机构共识/分歧统计**
- 搜集 3-5 家头部卖方对同一问题的判断（降息/降准/流动性方向）
- 标注一致 vs 分歧的维度
- 市场定价偏向共识的哪一侧？是否存在被 consensus trade 过度拥挤的方向？

**预期差识别**
| 预期差类型 | 市场定价 | 可能的实际情况 | 预期差方向 |
|-----------|---------|---------------|-----------|
| 方向性 | 市场认为... | 实际可能... | 偏松/偏紧 |
| 幅度 | 市场定价了 X BP | 实际可能 Y BP | 更大/更小 |
| 时点 | 市场预期 Q2 | 实际可能 Q3 | 提前/延后 |
| 传导 | 市场认为传导顺畅 | 实际可能梗阻 | 分歧 |

**交易含义（一句话点明）**
如有明确的预期差：按 ref-10 §10.4.3 五步检查清单给出策略。

**数据层面**
