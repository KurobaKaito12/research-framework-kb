# A股多维量化择时

> 来源：金工研究《再论A股择时：多维度融合》（2025-05-29）、《多维度融合（二）》（2025-09-17）、《多维择时模型的拆解与重构》（2026-05-18），林晓明/韩晳/何康等。

## 0. 核心思想

单指标择时各有局限（噪声多、灵敏性不足、样本内外不一致），需**多维融合**调和信号达到 1+1>2。框架沿三条主线演进：

1. **单指标库**：估值、情绪、资金、技术四大维度，逻辑清晰、分散度高。
2. **分层合成 → 多维框架**（2025 奠基）：离散信号逐层合成，万得全A多空择时夏普约 1、年化约 22%（2010–2025/4）。
3. **拆解重构 → 多维打分**（2026 最新）：26 底层因子 → 12 子维度 → 四路径拆解 → 连续打分映射分档仓位，日频最优夏普 1.72。

## 1. 单指标库与信号规则

择时标的：**万得全A**（框架可拓展至上证50、沪深300、中证500、中证1000、中证2000）。日频调仓，多空模拟（+1做多/−1做空/0中性），费用双边万五。

| 维度 | 指标 | 经济学含义 | 信号策略 |
|------|------|-----------|----------|
| 估值 | **股权风险溢价 ERP** = 1/PE − 10年国债收益率（亦可用股息率口径 erp_div） | ERP 高→股票相对债券吸引力大→宜买 | 正向区间/布林带（高位买、低位卖） |
| 资金 | **融资买入额**（杠杆资金，日频流量，交易所公布） | 与市场高度相关，追随行情紧密 | 布林带（突破上轨买、下轨卖） |
| 资金 | 机构净主动买入额（主力资金） | 机构主动买入行为 | 分位数 |
| 技术 | **布林带**（万得默认参数，不优化） | 经典通道趋势 | 突破上轨做多、下轨做空 |
| 技术 | **个股涨跌成交额占比差**（微观，平滑至月频取同比） | 个股强弱分布 | 正向趋势跟踪（右侧） |
| 技术 | 价格乖离率、换手率乖离率、涨停股占比、ADX、创新高占比、隐波 | 量价/趋势强度 | 布林带/动量 |
| 情绪 | **期权沽购比 PCR**（成交口径 = 认购/认沽成交额） | 散户买入开仓，成交表征**非理性情绪** | **反向**布林带（反指） |
| 情绪 | **期权隐含波动率 IV**（高价值IV/低价值IV 比值，反映偏斜） | 偏斜变动表征情绪 | **反向**布林带（反指） |
| 情绪 | **股指期货会员持仓**（前20大会员持买/持卖） | 专业机构多空力量，**左侧同向**预示 | 正向布林带（顺势）/动量 |
| 情绪 | 期权持仓沽购比（持仓口径） | 市场长期趋势同向 | 同比动量 |

**关键区分**：期权成交类（PCR、IV）捕捉非理性情绪→**逆向操作**，胜率高赔率低、对牛市后半程参与不足；期货会员持仓、量价趋势类→**顺势操作**，胜率低赔率高。两类互补。

## 2. 分层合成框架（2025 奠基）

将离散信号逐层调和：

- **第一层（维度内合成）**：布林带 + 个股涨跌成交额占比差 → **技术**指标；期权PCR + 隐波 + 期货会员持仓 → **情绪**指标。形成 **估值 / 情绪 / 资金 / 技术** 四维度。
- **第二层（左右侧合成）**：
 - **左侧指标 = 估值 + 情绪**：胜率高、赔率低（预判反转）
 - **右侧指标 = 资金 + 技术**：胜率低、赔率高（趋势跟随）
 - 两者互补，左右侧合成夏普约 0.9，超额更稳定。
- **第三层（多维综合）**：左侧 + 右侧再合成。对比不同方案，**按四个维度合成的框架夏普约 1**，降噪同时保留各维信息，胜率赔率均衡、可拓展性好。

**泛化性**：拓展至各宽基均有效；**估值更适配大盘，资金和技术（短期投机）更适配中小盘**。用 PBO 过拟合检验确认多维相对单指标提升稳定。

## 3. 拆解重构：多维打分（2026 最新）

### 3.1 指标体系：26 底层因子 → 12 子维度
26 个底层因子按自身规则发离散信号（±1/0），经**投票**合成 12 个子维度（仍为 ±1/0）：多数等权投票（成员信号均值取 sign）；期权沽购比加权（持仓量PCR 0.5、成交量/成交额PCR倒数各 0.25）。

12 子维度归四大类：
- 估值：**erp**（erp_pe、erp_div）
- 情绪：**期权偏度**、**期权沽购比**、**期货会员持仓**、**期权持仓沽购比**
- 资金：**杠杆资金**（融资买入额）、**主力资金**（机构净主动买入）
- 技术：**价格**、**量能**、**异动**、**趋势强度**、**期权隐波**

### 3.2 四路径收益拆解（厘清适用场景）
将信号转向视作开仓，按持仓方向 × 开仓时市场方向（择时标的5日收益符号）拆为四条子路径：

| 子路径 | 含义 |
|--------|------|
| s1 追高 | 上行趋势做多 |
| s2 抄底 | 下行中逆势做多 |
| s3 追空 | 下行趋势做空 |
| s4 逃顶 | 上行中逆势做空 |

组合路径：趋势 = s1+s3（顺势）；反转 = s2+s4（逆势）；多头 = s1+s2；空头 = s3+s4。

**收益来源极不均衡，据此判定指标擅长场景**：量价/量能擅长**追高**；期权隐波、期权偏度擅长**抄底**；估值（erp）四场景均有正收益、追空较弱；资金类偏右侧入场、左侧离场（追高最佳，抄底/追空差）；异动类擅长抄底。**难度递增：追高 < 抄底 < 逃顶 ≈ 追空**；多数指标纯多头优于纯空头。

### 3.3 三类打分模型
将离散信号升级为**连续打分**（合成时不离散化，直接取信号均值，保留方向+强度），再映射为分档仓位：

| 模型 | 思路 | 最优档/夏普 |
|------|------|------------|
| **A_1 分层** | 子维度→四大类（等权均值∈[−1,1]）→四类等权合成 | 五档，日频夏普 1.48 |
| **A_2 不分层** | 跳过大类聚合，直接对 12 子维度等权均值（避免强信号被稀释） | 七/九档，夏普 1.50，年度正收益概率 100% |
| **B 路径优选** | 每条子路径仅取该路径夏普**前 8** 的子维度参与合成（指标只在擅长场景发力） | 九档，夏普 **1.72**，年正收益 100% |

**打分→仓位映射**（score∈[−1,1]）：阈值0（多空满仓，收益最高波动最大）、阈值0.33、三档 round(score)、五档 round(2·score)/2、七档 round(3·score)/3、九档 round(4·score)/4。档位越多越平滑、降交易磨损。

**各路径入选子维度（B 模型）**：
- s1 追高：量能、杠杆资金、期货会员持仓、期权偏度、期权持仓沽购比、期权隐波、价格、趋势
- s2 抄底：期权偏度、异动、期权沽购比、期权隐波、期货会员持仓、期权持仓沽购比、erp、量能
- s3 追空：期权沽购比、期权隐波、期权偏度、异动、期权持仓沽购比、期货会员持仓、价格、erp
- s4 逃顶：杠杆资金、期权隐波、期权偏度、期权持仓沽购比、erp、趋势、主力资金、期货会员持仓

### 3.4 频率衰减
日频最优夏普 1.7+；周频/半月频降至约 0.9–1.3；月频进一步降至约 0.5–1.2。**择时优势集中在日频**。

## 4. 场景化评价

定义三类场景检验实战能力：
- **短期极端行情**：|单日涨跌|≥3.5% 或 |5日区间最大涨跌|≥10% → A_2/B 预判与反应正确率约 60%，优于 A_1。
- **阶段拐点**：涨跌幅>15% 且持续≥5日 → B 识别率约 61.8%（A_1 47.1%、A_2 52.9%）。
- **阶段趋势**：涨跌幅>20% 且持续≥20日 → B 把握率约 80%（A_2 73.3%、A_1 60%）。

结论：极端行情 A_2≈B；**中期拐点、长期趋势 B（路径优选）更优**，但需关注过拟合风险。

## 5. 评价指标

多空回测看：年化收益、年化波动、夏普、最大回撤、Calmar、**胜率**、**赔率**、持仓天数均值。胜率高/赔率低（情绪反指类）与胜率低/赔率高（趋势类）需配合使用。

## 6. 应用本 skill 时

1. 先表态择时标的（整体A股=万得全A，或具体宽基）与频率（默认日频）。
2. 给方向时**分维度陈述**：估值（ERP分位）、资金（融资买入额趋势）、情绪（PCR/IV是否极端、期货会员持仓方向）、技术（布林带/量价趋势），再给综合判断。
3. 当前若需精细化，按 A_2/B 思路给**连续打分 + 分档仓位**，并指出当前更接近哪条路径（追高/抄底/追空/逃顶）。
4. **区分左侧（估值+情绪，预判反转）与右侧（资金+技术，趋势跟随）**，说明各自胜率/赔率特征。
5. 提示适配性：大盘看重估值，中小盘看重资金/技术。
6. 缺数据时明确指出需要哪些指标输入，**不要编造信号或分位**。
