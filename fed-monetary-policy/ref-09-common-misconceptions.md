# 常见误读清单

| 误读 | 正确理解 |
|------|---------|
| RMP扩表=宽松 | RMP是充足准备金框架下的技术操作，不传递宽松信号 |
| QT=收紧 | QT缩减资产负债表，但在ON RRP仍有余额时主要消耗ON RRP而非准备金 |
| 准备金下降=流动性紧张 | 需区分ON RRP下降（正常消耗）vs 准备金下降（需关注） |
| Fed扩表=利好股市 | RMP影响波动率不影响方向，QE才利好方向 |
| SOFR上升=Fed加息 | SOFR可能因SLR季末效应等非政策因素跳升 |
| 点阵图=Fed承诺 | 点阵图是票委预判，不是承诺，实际路径经常偏离 |
| 曲线倒挂=立即衰退 | 倒挂平均领先12-18个月，重新陡峭化时才是衰退真正临近 |
| 10Y上行=通胀恶化 | 必须拆解：实际利率上行 vs BEI上行 vs 期限溢价上行 |
| 财政赤字扩大→利率必然上行 | 还需看需求端（安全资产需求可能压低利率） |
| Fed独立性不可动摇 | 1951年Accord确立的独立性不是宪法规定的 |
