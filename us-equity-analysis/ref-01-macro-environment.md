# 宏观环境分析

## 1. 四种宏观情景框架

宏观环境是美股估值和盈利的共同驱动。用增长和通胀两个维度定义四种情景：

| 情景 | 增长 | 通胀 | Fed政策 | 美股表现 | 受益风格 |
|------|------|------|---------|---------|---------|
| **软着陆（Goldilocks）** | 温和放缓 | 回落至目标 | 预防式降息 | 正面 | Quality + Growth |
| **过热（Overheating）** | 强劲 | 回升/粘性 | 加息或暂停降息 | 初期正面，后期风险 | Value + Cyclical |
| **衰退（Recession）** | 负增长 | 快速回落 | 大幅降息 | 负面 | Defensive |
| **滞胀（Stagflation）** | 放缓 | 高企 | 两难（无法降息） | 负面 | 实物资产 + 短久期 |

### 1.1 情景判断的关键指标

| 指标 | 软着陆 | 过热 | 衰退 | 滞胀 |
|------|--------|------|------|------|
| GDP增速 | 1-2% | >3% | <0% | 0-1% |
| CPI同比 | 2-3% | >3.5% | <2% | >4% |
| 失业率 | 缓慢上升 | 下降 | 快速上升 | 上升 |
| Fed利率 | 逐步降息 | 维持或加息 | 快速降息 | 维持高位 |
| 10Y Treasury | 3.5-4.5% | >4.5% | <3% | >5% |

### 1.2 2026年基准情景判断

当前（2025年底-2026年初）市场共识：**软着陆为主，但过热和衰退风险并存**

- 基准情景（Goldilocks）概率最高（~55%），但过热概率上升至~25%
- 部分机构认为"无周期"/"金发姑娘"后疫情范式仍在延续
- 部分机构认为财政扩张和资本支出周期推动超趋势增长
- MS：Rolling Recovery，但关税和DOGE政策不确定性是风险

## 2. 美联储政策分析

### 2.1 Fed政策的两个维度

**对估值的影响（P/E）**：
- 降息 → 折现率下降 → P/E扩张
- 加息 → 折现率上升 → P/E压缩

**对盈利的影响（EPS）**：
- 预防式降息（经济仍强）→ 融资成本下降，企业受益
- 被动式降息（经济衰退）→ 需求下降，盈利受损

**关键区分**：
- 预防式降息利好股市（1995、2019）
- 衰退式降息初期利空股市（2001、2008、2020）

### 2.2 中性利率（r*）之争

当前市场核心辩论：中性利率是否结构性上移？

| 观点 | 论据 | 对美股含义 |
|------|------|-----------|
| **r*上移** | 财政扩张、AI投资、劳动力市场结构性紧张 | Fed降息空间受限，利率底部抬高，估值天花板降低 |
| **r*未变** | 长期趋势力量（人口老龄化、债务负担） | 降息可回到更低水平，估值有扩张空间 |

### 2.3 Fed与市场预期的偏差

**路-人-狗框架（参考fed-monetary-policy skill）**：
- **路（基本面）**：经济数据的真实状态
- **人（美联储）**：Fed的政策立场和点阵图
- **狗（市场）**：CME FedWatch等市场定价

**偏差信号**：
- 市场定价降息 > Fed点阵图 → 若Fed鹰派，市场需重新定价（利空）
- 市场定价降息 < Fed点阵图 → 若Fed鸽派，市场惊喜（利好）
- 基本面恶化但Fed不降息 → 政策滞后风险（利空）

## 3. 财政政策

### 3.1 财政扩张的影响

**正面**：
- 直接刺激经济增长（政府支出）
- 减税提升企业盈利（TCJA延续、OBBBA）
- 基础设施投资利好工业、材料、公用事业

**负面**：
- 赤字扩大→发债增加→长端利率上行→估值压缩
- 债务/GDP上升→长期财政可持续性担忧
- 通胀风险（若经济已接近充分就业）

### 3.2 OBBBA（One Big Beautiful Bill Act）

2026年美国财政政策的核心变量：

| 政策领域 | 影响行业 | 方向 |
|---------|---------|------|
| 国防开支增加 | 航空航天、军工 | 利好 |
| 基础设施投资 | 工业、材料、建筑 | 利好 |
| 能源政策 | 传统能源、清洁能源 | 混合 |
| 税收改革 | 整体企业盈利 | 若减税延续则利好 |
| 移民政策 | 劳动力供给敏感行业 | 收紧=劳动力成本上升 |

### 3.3 财政主导风险（Fiscal Dominance）

若财政赤字持续扩大而Fed被迫配合（维持低利率或购买国债）：
- 通胀预期上升
- 美元信用受损
- 长端利率可能失控上行
- 对股市的净影响取决于增长刺激效应 vs 利率压制效应哪个更大

## 4. 关税与贸易政策

### 4.1 关税的影响路径

**直接路径**：
- 进口成本上升 → 企业利润率受压
- 消费者价格上涨 → 实际购买力下降
- 报复性关税 → 美国出口受损

**间接路径**：
- 供应链重组 → 资本开支增加（短期利好工业，长期效率损失）
- 不确定性上升 → 企业推迟投资
- 美元走强 → 跨国企业盈利折算受损

### 4.2 2025年经验

2025年"解放日"关税冲击后的市场反应：
- 短期：市场恐慌，波动率飙升
- 中期：部分关税被推迟或豁免，市场修复
- 长期：贸易政策不确定性成为企业资本开支的制约因素

### 4.3 2026年展望

- 关税政策不确定性较2025年有所下降（已有部分deal达成）
- 但结构性贸易摩擦持续
- 企业加速"近岸外包"和供应链多元化
- 对通胀的影响取决于关税规模和传导效率

## 5. 美元走势

### 5.1 美元与美股的关系

**美元走强**：
- 利好：美国资产吸引力上升，资金流入
- 利空：跨国企业海外收入折算减少，出口竞争力下降

**美元走弱**：
- 利好：跨国企业盈利折算增加，出口竞争力上升
- 利空：可能反映美国相对经济弱势，资金流出

**净影响**：取决于驱动因素
- 美元因增长强劲而强 → 利好美股（资金流入+盈利强）
- 美元因避险而强 → 利空美股（全球风险偏好下降）
- 美元因Fed降息而弱 → 混合影响

### 5.2 美元周期与全球资金

- 美元强势周期 → 新兴市场资金流出 → 美股相对受益
- 美元弱势周期 → 资金寻找非美机会 → 美股相对受损

2025-2026年：美元从高位回落，反映美国例外主义见顶预期
