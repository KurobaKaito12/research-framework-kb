# 盈利与估值拆解

## 1. EPS增长质量分析

### 1.1 EPS增长来源拆解

EPS增长 = 营收增长 + 利润率变化 + 回购贡献 + 一次性项目

**高质量增长**：主要由营收增长驱动
**低质量增长**：主要由回购或一次性收益驱动

| 来源 | 可持续性 | 分析要点 |
|------|---------|---------|
| **营收增长** | 高 | 是 demand-driven 还是 price-driven？ |
| **利润率扩张** | 中 | 是周期性的还是结构性的（如AI效率提升）？ |
| **回购** | 低（对价值） | 贡献EPS但不改变企业内在价值 |
| **一次性收益** | 不可持续 | 需剔除，看core EPS |

### 1.2 科技vs非科技盈利分化

2023-2025年的核心特征：科技板块盈利增速远超非科技板块

| 指标 | 科技板块 | 非科技板块 | 分化信号 |
|------|---------|-----------|---------|
| NTM EPS增速 | ~20-25% | ~8-12% | 差距>10pp=高分化 |
| 利润率趋势 | 扩张 | 稳定或收缩 | 科技利润率优势扩大 |
| EPS修正方向 | 持续上修 | 修正平淡 | 上修比差距>2:1=科技主导 |

**宽基化（Broadening）的关键信号**：非科技板块EPS增速开始追赶科技板块

2026年预期（基于外资行共识）：
- Tech+ EPS增速：~20%（放缓但仍强劲）
- S&P 500 ex-Tech+ EPS增速：~10-15%（加速追赶）
- 差距从2023年的40%+收敛至~6-10%

### 1.3 利润率分析

**EBIT Margin是盈利质量的关键指标**：

- S&P 500整体EBIT Margin共识预期：2026年~20%，2027年~20.2%
- 若margin扩张停滞或收缩 → 盈利增长必须依赖营收增长 → 增长质量下降

**利润率扩张的驱动因素**：
- 定价权（品牌、垄断、技术壁垒）
- 运营效率（AI自动化、供应链优化）
- 规模效应
- 低竞争压力

**利润率承压的信号**：
- 工资增长快于价格增长
- 原材料成本上升
- 竞争加剧（价格战）
- 监管成本增加

### 1.4 EPS修正趋势

**上调/下调家数比（Revisions Ratio）**是最重要的盈利动能指标：

| 比值 | 含义 | 策略含义 |
|------|------|---------|
| >1.5 | 强劲上修动能 | 超配 |
| 1.0-1.5 | 温和上修 | 中性偏超配 |
| 0.8-1.0 | 修正平衡 | 中性 |
| <0.8 | 下修动能 | 低配 |

**行业层面的修正分化**：
- 若上修集中在少数行业 → 市场集中度风险
- 若上修广泛分布于多个行业 → 宽基化确认

## 2. 估值框架

### 2.1 P/E分位数分析

**核心指标**：NTM P/E（Next Twelve Months Price/Earnings）

| 分位数区间 | 含义 | 策略含义 |
|-----------|------|---------|
| <10th | 极度便宜 | 历史罕见买入机会 |
| 10th-25th | 偏便宜 | 积极配置 |
| 25th-75th | 合理区间 | 按基本面配置 |
| 75th-90th | 偏贵 | 谨慎，等待回调 |
| >90th | 极度昂贵 | 减仓或对冲 |

**注意事项**：
- P/E分位数高≠必跌（若盈利增速足够高，高P/E可维持）
- 需结合利率环境：低利率环境下可接受更高P/E
- 需结合PEG ratio综合判断

### 2.2 PEG Ratio

**PEG = P/E ÷ EPS增长率**

| PEG区间 | 含义 |
|---------|------|
| <1.0 | 成长估值合理甚至被低估 |
| 1.0-1.5 | 成长估值合理 |
| 1.5-2.0 | 成长估值偏贵 |
| >2.0 | 成长估值昂贵 |

**应用**：
- 科技板块用PEG比单纯P/E更合适
- PEG<1的科技股在盈利验证后通常有超额收益
- PEG>2的科技股需要持续超预期才能维持估值

### 2.3 股权风险溢价（ERP）

**ERP = 股票预期回报 - 无风险利率**

简化计算：ERP ≈ Earnings Yield（1/PE）- 10Y Treasury Yield

| ERP水平 | 含义 | 策略含义 |
|---------|------|---------|
| >5% | 股票相对债券吸引力高 | 超配股票 |
| 3-5% | 股票吸引力中性 | 按基准配置 |
| <3% | 股票相对债券吸引力低 | 低配股票或增配债券 |

**2025-2026年特征**：ERP处于历史低位（~0-2%），反映股票估值相对债券不便宜

### 2.4 科技vs非科技估值差

**Growth vs Value P/E Premium**：
- 当前（2025年底）科技vs非科技P/E溢价约60-80%
- 溢价收窄信号：轮动从科技向非科技
- 溢价扩大信号：科技继续跑赢

## 3. 利率与估值的关系

### 3.1 DCF视角

股票价格 = 未来现金流折现

- 折现率（r）上升 → 现值下降 → P/E压缩
- 折现率（r）下降 → 现值上升 → P/E扩张

**关键利率**：
- 10Y Treasury收益率：影响长期现金流折现
- 实际利率（TIPS）：影响成长股相对价值
- 信用利差：影响风险溢价

### 3.2 非线性关系

利率与估值的关系不是线性的：

| 利率区间 | 对估值的影响 | 原因 |
|---------|------------|------|
| <2% | 利率小幅变化对估值影响大 | 分母效应敏感 |
| 2-4% | 正常区间，估值对利率敏感度中等 | 经济健康+利率适中 |
| 4-5% | 利率上升开始明显压制估值 | 融资成本上升，替代资产吸引力增加 |
| >5% | 显著压制估值，尤其成长股 | 高折现率+衰退风险 |

### 3.3 实际利率的特殊影响

实际利率 = 名义利率 - 通胀预期

- 实际利率上升 → 成长股受压（未来现金流折现更狠）
- 实际利率下降 → 成长股受益
- 2022年后实际利率大幅上升是科技股估值压缩的主要原因

### 4.2 估值拆解逻辑（内部参考，不输出）

目标价的本质是 预期EPS × 目标P/E。理解这一公式有助于分析驱动因素：
- 若市场在涨但EPS未上修 → 主要由估值扩张（情绪/流动性）驱动
- 若市场在涨且EPS同步上修 → 由基本面改善驱动，更健康
- 若EPS上修但市场未涨 → 估值压缩抵消了盈利增长，需警惕
