## 2. 情绪指标

### 2.1 AAII投资者情绪调查

美国个人投资者协会（AAII）每周调查散户投资者的看涨/看跌比例。

| 牛熊比 | 情绪状态 | 反向信号 |
|--------|---------|---------|
| >2.0 | 极度乐观 | 警示顶部风险 |
| 1.0-2.0 | 温和乐观 | 中性 |
| 0.5-1.0 | 悲观 | 可能接近底部 |
| <0.5 | 极度悲观 | 强烈反向买入信号 |

### 2.2 VIX（波动率指数）

VIX反映S&P 500期权的隐含波动率，是市场的"恐惧指数"。

| VIX水平 | 市场状态 | 策略含义 |
|---------|---------|---------|
| <12 | 极度平静（Complacency） | 风险积聚，不建议追高 |
| 12-18 | 正常区间 | 按趋势操作 |
| 18-25 | 担忧加剧 | 警惕回调，考虑对冲 |
| >25 | 恐慌 | 可能是买入机会（若无系统性风险） |
| >35 | 极度恐慌 | 强烈反向买入信号（如2020年3月） |

**VIX的深层解读**：
- VIX与标普500同步下跌 → 市场自满，风险积聚
- VIX上升但标普500横盘 → 投资者在买保护，警惕事件风险
- VIX飙升+标普500暴跌 → 恐慌抛售，可能是底部

## 3. 情绪与价格的背离信号

### 3.1 负背离（Bearish Divergence）

- **价格新高 + 情绪指标未新高** → 上涨动能减弱
- 例子：标普500创新高，但AAII牛熊比下降、VIX未创新低
- 含义：参与上涨的广度在收窄，顶部风险上升

### 3.2 正背离（Bullish Divergence）

- **价格新低 + 情绪指标未新低** → 下跌动能减弱
- 例子：标普500回调，但VIX未创新高、散户情绪已极度悲观
- 含义：卖压耗尽，反弹或反转可能

### 3.3 VIX与标普500的关系

| 组合 | 含义 |
|------|------|
| 标普涨 + VIX涨 | 投资者在上涨中买保护，警惕事件风险 |
| 标普涨 + VIX跌 | 正常趋势，但VIX过低=自满 |
| 标普跌 + VIX涨 | 正常恐慌，关注VIX峰值 |
| 标普跌 + VIX跌 | 异常，可能预示更大下跌 |

## 4. 拥挤交易风险

### 4.1 识别拥挤交易

| 信号 | 含义 |
|------|------|
| 单一主题/股票占主动基金持仓过高 | 集中风险，调仓时波动大 |
| 某行业ETF资金流入持续领先 | 可能过度拥挤 |
| 空头比例极低 | 缺乏空头回补的向上燃料 |
| 期权市场单边押注 | Call skew极端=拥挤 |

### 4.2 当前拥挤领域（2025年底-2026年初）

**可能拥挤**：
- AI主题（尤其是半导体和云厂商）
- 大型科技股（Mag 7）

**可能欠配**：

- 小盘股（Russell 2000相对S&P 500处于低位）
- 国际市场（相对美股低配）

## 5. 情绪分析的局限性

- **情绪是反向指标，但不是timing工具**：极端情绪可能持续很长时间
- **需要结合估值和基本面**：情绪极端+估值极端=高置信度信号；情绪极端但估值合理=信号较弱
- **结构性变化可能使历史阈值失效**：如ETF普及改变了散户行为模式
