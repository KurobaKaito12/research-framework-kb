# 输出模板与写作规范

## 一、通用写作原则

### 1.1 读者定位

本skill的输出面向**专业机构读者**：基金经理、投资经理、卖方研究员、财富管理机构。他们已经熟悉P/E、EPS、Fed政策等基本概念。

- **不写教科书**，但关键机制可以点透
- **报告呈现判断和证据，不呈现分析流程**
- **没有判断的段落不要写**

### 1.2 核心标准

- **定价机制是内在逻辑，不是外在文字**
- **主要矛盾优先**：抓住一到两条主线写深写透
- **买方视角落点**：每个判断最终回答能否操作、怎么表达、赔率胜率、风险锚
- **少做无增量判断**
- **内部推理和正文输出要分开**

### 1.3 四条最优先消除的硬伤

1. **元话语泄漏**：不写"skill提示""根据框架""此处需以内部数据库复核"等内部备忘
2. **取材旁白泄漏**：不写"文档指出""参考资料显示"，结论一律用分析师口径直接陈述
3. **数据编造**：不编造任何精确数字
4. **正文标注数据来源**：不在正文中用括号标注数据来源，如"(Wind)""(金十数据)""(Bloomberg)"等。数据来源在内部查询记录中留痕即可，正文呈现分析师判断口径

### 1.4 抽象术语转换

**严禁使用空泛抽象术语。** 必须直接说具体逻辑：

| ❌ 禁用 | ✅ 正确写法 |
|--------|-----------|
| "风险偏好回升" | "VIX回落至12以下，AAII牛熊比升至1.5，显示避险情绪消退" |
| "盈利韧性" | "S&P 500 NTM EPS上修家数占比达65%，信息技术板块EPS增速预期上修2个百分点" |
| "估值承压" | "10Y Treasury收益率升至4.5%，S&P 500 NTM P/E从22倍压缩至20倍" |
| "资金面宽松" | "EPFR数据显示美股基金连续4周净流入，合计$15bn" |
| "情绪修复" | "VIX从28回落至18，标普500恐惧贪婪指数从'极度恐惧'回升至'中性'" |
| "宏观环境友好" | "ISM制造业PMI回升至52，CPI同比回落至2.8%，软着陆概率上升" |

## 二、输出类型A：一段话核心观点

**适用**：晨会分享、快问快答、即时沟通

**格式**：一段话（不超过300字），包含：
1. 核心矛盾（当前最关键的一到两个变量）
2. 关键数据（支撑判断的最新数据点）
3. 后续展望（方向判断）
4. 策略倾向（超配/低配/观望，以及最看好的方向）

**范例**：
> 当前美股核心矛盾是AI Capex增速见顶担忧与宽基化盈利改善的博弈。标普500 NTM EPS增速维持在12%，但科技与非科技分化从40pp收窄至10pp，宽基化信号确认。10Y Treasury收益率回落至4.3%，支撑估值稳定。VIX处于18的适中水平，AAII牛熊比1.2，情绪不过热。策略上维持中性偏超配，结构上从纯AI暴露转向均衡配置，超配医疗保健和金融，低配消费可选。关键观察锚：云厂商Q2 Capex指引和AI收入占比。

## 三、输出类型B：市场异动点评

**适用**：美股单日大幅波动、财报季、FOMC决议后反应、重大政策发布

**格式**：按"事件→分析→展望→启示"四段式输出

### 3.1 事件（1段）

- 发生了什么：具体价格变动、时间、触发事件
- 市场反应：相关资产联动（债券、美元、VIX、板块分化）

### 3.2 分析（2-3段）

按"直接触发剂→核心矛盾→放大机制→反向约束"展开：

**直接触发剂**：什么事件直接导致了今天的波动？
**核心矛盾**：这个事件触动了市场的哪根神经？
**放大机制**：为什么波动幅度超出预期？（杠杆、拥挤交易、算法交易）
**反向约束**：什么因素在限制波动进一步升级？

### 3.3 展望（1-2段）

- 驱动持续性：这个因素是暂时冲击还是趋势改变？
- 关键观察锚：接下来看什么数据/事件来验证或证伪？
- 情形分析（可选）：基准/上行/下行情景

### 3.4 启示（1段）

- 策略建议：方向+工具+节奏
- 风险提示：与结论相反的触发因素

**范例结构**：

---

**事件**

3月X日，标普500下跌2.1%收于XXXX点，纳指100下跌2.8%，VIX飙升至25。触发因素是X公司财报不及预期，AI Capex指引下调，引发市场对AI ROI的担忧。半导体板块领跌（SOXX -4.2%），但医疗保健和金融相对抗跌。

**分析**

直接触发剂是X公司Capex指引下调15%，但这只是导火索。核心矛盾是市场一直在担忧的"AI Capex峰值"是否已至。2025年云厂商Capex已达$400bn，2026年增速预期从25%下调至15%，产业链从高增长进入稳增长阶段，估值需要从"growth"向"mature growth"切换。

放大机制在于半导体板块持仓拥挤。CFTC数据显示半导体期货非商业净多头处于历史90%分位，调仓时流动性不足导致价格 overshoot。反向约束在于：①其他云厂商尚未下调指引；②AI应用收入仍在增长；③10Y Treasury收益率下行提供估值支撑。

**展望**

此次调整更可能是估值重置而非趋势逆转。关键观察锚：①下周Y公司和Z公司的财报Capex指引；②4月云厂商AI收入数据；③半导体订单book-to-bill ratio。若指引普遍下调，则调整可能持续；若仅X公司个案，则有望反弹。

基准情景：短期震荡整理，等待AI收入数据验证。上行情景：AI收入超预期，Capex担忧消退。下行情景：多家云厂商下调，AI进入资本周期下行。

**启示**

策略上建议：①减持纯Capex暴露的半导体设备股；②增持有AI收入兑现的软件和应用层；③保持医疗保健和金融作为防御底仓。风险控制：若标普500跌破XXXX点（200日均线），进一步减仓科技。

## 四、输出类型C：中长期展望

**适用**：周度/月度回顾、半年度/年度展望、专题策略

**格式**：按"回顾→驱动因素分析→策略建议"三段式输出

### 4.1 回顾（带时间线）

分阶段回顾，每个阶段给：
- 时间区间
- 关键点位（开盘/收盘/高点/低点，必须有数据支撑）
- 驱动事件
- 遗留矛盾

**范例时间线**：

| 阶段 | 时间 | 标普500 | 驱动事件 | 遗留矛盾 |
|------|------|---------|---------|---------|
| 阶段一：开年震荡 | 1月初-2月中 | 5800→5900 | 降息预期回摆 | 中性利率之争 |
| 阶段二：AI Capex爆发 | 2月中-4月初 | 5900→6200 | 财报季Capex超预期 | ROI何时验证 |
| 阶段三：关税冲击 | 4月初-5月初 | 6200→5600 | 解放日关税 | 贸易政策不确定性 |
| 阶段四：修复反弹 | 5月初-6月初 | 5600→6100 | 关税暂缓+降息预期 | 增长是否真的 resilient |

### 4.2 驱动因素分析（按需展开）

选择当前最关键的2-4个因素展开，每个因素一段：

**宏观环境**：增长、通胀、Fed政策、财政、关税
**盈利驱动**：EPS增长、利润率、修正趋势、科技vs非科技分化
**估值驱动**：P/E水平、利率环境、风险溢价、历史分位
**AI周期**：Capex、ROI、产业链分化、集中度
**资金流**：EPFR、散户、杠杆、情绪

每段结构：判断句（首句）+ 关键数据 + 逻辑链条 + 边际变化

### 4.3 策略建议

**核心判断**：一句话给出方向判断

**情景分析**：

| 情景 | 概率 | S&P 500目标 | 核心假设 | 触发条件 |
|------|------|------------|---------|---------|
| 基准 | 50% | 7300-7600 | 软着陆+盈利双位数增长+估值稳定 | 经济数据维持当前轨道 |
| 乐观 | 25% | 8200-9000 | AI超预期+强劲增长+估值扩张 | AI收入爆发+Fed大幅降息 |
| 悲观 | 25% | 5700-6200 | 衰退+盈利下修+估值压缩 | 失业率飙升+AI Capex崩溃 |

**操作建议**：
- 方向（超配/低配/中性）
- 工具（股票/ETF/期权）
- 观察锚（关键数据或事件）
- 失效条件（什么情况下改变判断）

**风险提示**：覆盖与结论相反的触发因素

## 五、文风反面清单

写报告前逐条对照：

| 问题 | 反面例子 | 正确做法 |
|------|---------|---------|
| 元话语泄漏 | "根据本skill的分析框架" | 直接给出判断 |
| 取材旁白 | "文档指出风险偏好回升" | "VIX回落至18，避险情绪消退" |
| 抽象术语 | "盈利韧性较强" | "S&P 500 NTM EPS增速12%，上修家数占比65%" |
| 数据编造 | "年初以来上涨约15%" | 查实际数据后写"年初至今上涨13.2%（截至X月X日）" |
| 方法论复述 | "分析框架分为三步" | 直接给出当前判断 |
| 正确的废话 | "市场存在上行和下行风险" | 明确指出基准情景和关键触发条件 |
| 章节重复 | 同一观点在多个章节重复 | 每个段落有增量信息 |
| 格式扁平 | 连续大段文字无层次 | 用粗体标签、bullet list、表格拉出结构 |
| 来路不明的精确数字 | "P/E约22.5倍" | 查实际数据后写"NTM P/E 22.3倍（FactSet，X月X日）" |
| 情景平铺 | 三个情景概率相等，无主推 | 明确主推基准情景，给出概率 |
| 结论不可执行 | "可关注科技板块机会" | "超配信息技术，通过XLK或个股表达，止损设于标普500跌破200日均线" |
| 回顾偏科 | 只写上涨阶段，回避下跌 | 完整回顾涨跌各阶段 |
