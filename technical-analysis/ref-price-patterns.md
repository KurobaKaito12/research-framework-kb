# price-patterns.md

> **定位**：本文件系统覆盖价格形态分析的两大类别——反转形态与持续形态，以及缺口理论。重点放在每种形态的严格定义、确认条件、目标测算方法、统计可靠性和常见失败模式上。

---

## 一、形态分析基础

### 1.1 颈线

颈线是连接形态中两个关键反转点（波谷或波峰）的直线。在头肩顶中，颈线连接两肩之间的两个波谷；在双顶中，颈线连接两个波峰之间的波谷[^10]。颈线的穿透是形态完成的**必要确认条件**——Schwager 明确指出，头肩形态"直到颈线被穿透才被视为完成"[^3]。

### 1.2 突破确认

形态的有效性取决于突破的确认。核心确认要素包括：

| 条件 | 说明 |
|------|------|
| 收盘价突破 | 收盘价（而非盘中价）穿越颈线/边界才算有效突破 |
| 突破幅度 | 收盘价穿越颈线至少 1%-3% 的幅度可增强确认 |
| 成交量放大 | 突破时成交量显著放大（≥ 前 5 日均值 120%）是可靠确认信号[^14] |
| 回踩不破 | 突破后价格回踩颈线但不重新跌破，构成二次确认 |

### 1.3 目标测算

最经典的目标测算方法来自头肩形态的**等距原则**：从头部（或双顶的峰部）到颈线的垂直距离，等于颈线突破后预期的最小目标距离[^40]。该方法同样适用于双顶双底、三角形等形态——三角形边界间的最大宽度即为突破后的最小目标幅度。

但 Schwager 对此持保留态度："图表形态作为价格目标的指示器，其可靠性可能远低于作为交易信号的可靠性"[^40]。

## 二、反转形态

### 2.1 头肩顶

**结构**：由五个转折点（A-E）构成三个峰和两个谷[^19]。中间峰（头，C 点）高于两侧峰（肩，A 点和 E 点）[^22]。颈线连接两肩之间的波谷。

**关键确认**：颈线被收盘价有效穿透[^3]。

**前置条件**：有效的头肩形态必须出现在一段"显著的上涨走势之后"。缺乏此前提、仅形状类似头肩的构造可能产生误导[^3]。

**失败形态**：价格穿越颈线后又重返颈线上方，即构成失败的头肩形态。Schwager 在 E-mini S&P 500 和 Nikkei 225 的实例中展示了多个失败的头肩顶形态[^23]。一个重要实战原则：**失败信号比原始信号更可靠**[^42]。

### 2.2 头肩底

结构与头肩顶完全对称，出现在下跌趋势末端。颈线连接两肩之间的波峰。右肩形成时成交量通常递减，突破颈线时需要显著放量。

### 2.3 双顶（M 头）

**结构**：价格两次触及同一阻力位后回落，形态呈"M"形[^32]。颈线为连接两峰之间波谷的直线[^10]。

**特征**：第一次触及阻力位时成交量显著，第二次触及时成交量通常减弱[^14]。价格跌破颈线后确认形态完成。

**三重顶**：同一价位出现三次受阻回落的峰部，结构与双顶相同但重复次数更多，出现频率低于双顶[^22][^32]。

### 2.4 双底（W 底）

结构与双顶完全对称。国泰君安对市场底部的研究将 W 型底部描述为：市场经历 V 型反弹后再度下跌但未突破前期低点，形成第二轮反弹，在图形上构成 W 形[^31]。双底和三重顶/底都属于"相当罕见"的形态[^32]。

### 2.5 圆弧顶/底

**特征**：价格沿弧形路径缓慢转折，没有明确的峰部或谷部。圆弧顶通常出现在长期上涨的末期，多方力量逐步衰竭；圆弧底出现在长期下跌的末期，空方力量逐步枯竭。

中泰证券使用核回归（Nadaraya-Watson 估计）对股价进行平滑处理以降低局部波动影响，从而识别圆弧底的极值点[^4]。核回归将股价分解为趋势项 $m(x_t)$ 和噪声项 $\varepsilon_t$，通过对趋势项的曲率分析来判定圆弧形态[^4]。

**杯柄形态**：可视为圆弧底的变体——先形成一个圆弧形"杯体"，再在右上沿形成一个短暂的回撤"手柄"，突破手柄后确认看涨[^42]。

### 2.6 V 形

**特征**：价格急速反转，几乎没有过渡期。国泰君安将 V 型底部定义为"市场处于大幅下跌触及最低点后，即出现一波幅度较大的反弹或反转"[^31]。V 形的反转通常由突发性消息（利好或利空）触发，事先难以预测，事后才能确认。

## 三、持续形态

### 3.1 三角形

三角形是最常见的持续形态之一，同时也可作为顶部和底部反转形态[^5]。关键在于突破方向而非形态本身[^5]。

**三种基本类型**[^7]：

| 类型 | 结构 | 突破方向 |
|------|------|---------|
| 对称三角形 | 上下边界均向内收敛，斜率近似对称 | 通常延续前期趋势 |
| 上升三角形 | 上边界水平（阻力位），下边界向上倾斜（更高的低点） | 通常向上突破 |
| 下降三角形 | 下边界水平（支撑位），上边界向下倾斜（更低的高点） | 通常向下突破 |

**突破时机**：最可靠的突破发生在三角形水平宽度的 1/2 到 3/4 处。如果价格一路收敛到顶点（apex）仍未突破，则后续突破的可信度很低[^14]。

**突破确认**：突破需伴随成交量放大[^14]。

**作为反转形态**：三角形也可以出现在趋势末端。Schwager 展示了铂金和橙汁期货中下降三角形作为顶部的案例，以及 DAX 和铜期货中三角形作为底部的案例[^5]。主要顶部和底部可能同时符合多种形态定义——例如三角形的顶部或底部也可以被解读为头肩形态，且两者的确认点通常相近[^2]。

### 3.2 旗形

**结构**：在一段急速的价格运动（"旗杆"）之后，价格在一个狭窄的、略微倾斜的通道内做短暂休整，通道方向与旗杆方向相反。突破旗形上/下边界后，价格延续旗杆方向继续运动。

**交易应用**：旗形是顺势交易的理想入场点——错过初始突破的交易者可以在旗形内部建仓[^24]。旗形的上边界（在下降趋势中）可作为止损参考位[^26]。

### 3.3 楔形

**上升楔形**：上下两条边界线均向上倾斜，但上边界更陡。通常出现在上升趋势末端，向上突破的概率较低，向下突破（反转）的概率更高。

**下降楔形**：上下两条边界线均向下倾斜，但下边界更陡。通常出现在下降趋势末端，向下突破的概率较低，向上突破（反转）的概率更高。

### 3.4 矩形

**结构**：价格在两条水平平行线（上边界阻力位、下边界支撑位）之间来回震荡。

**交易规则**：矩形上边界被突破则看涨，下边界被突破则看跌。突破方向是唯一关键——矩形本身不预示突破方向[^50]。矩形区间内可进行高抛低吸的区间交易，但需在突破发生时及时调整仓位方向。

## 四、缺口理论

### 4.1 缺口的定义

缺口是指相邻两个交易日的价格区间之间存在无成交的空白区域——当日最低价高于前日最高价（向上缺口），或当日最高价低于前日最低价（向下缺口）[^49]。

### 4.2 缺口的分类

| 类型 | 出现位置 | 含义 |
|------|---------|------|
| 普通缺口 | 横盘震荡区间内 | 交易稀疏造成，无趋势含义，通常很快被回补 |
| 突破缺口 | 价格突破关键支撑/阻力位时 | 标志趋势的真正启动，通常伴随放量，不易被回补 |
| 中继缺口 | 趋势运行中段 | 标志趋势的加速，有时可用于测量趋势目标（从突破缺口到中继缺口的距离 = 中继缺口到趋势终点的距离） |
| 衰竭缺口 | 趋势末端 | 标志趋势动能的最后一次释放，随后趋势反转，通常很快被回补 |

国泰君安的研究指出，突破缺口、中继缺口、衰竭缺口的分类"由于定义比较模糊，暂不作讨论"[^49]——这也反映了缺口分类在量化研究中的固有困难。

### 4.3 缺口回补

缺口回补是指价格在后续走势中重新进入缺口区域。技术分析中有多种关于缺口回补的经验法则（如"三天内不补则三周内补"、"三天不补则短期内不会补"），但这些法则需要用数据逐一验证[^49]。

**实战要点**：
- 普通缺口和衰竭缺口的回补概率极高。
- 突破缺口如果伴随显著放量且回踩不补，则趋势延续信号可靠。
- 在 A 股中，因涨跌停板制度导致的缺口（一字板跳空）需要特别甄别——如果是情绪驱动的连续涨停跳空，回补概率取决于后续情绪变化而非技术面。

## 五、形态识别的量化困境

形态识别是技术分析中最具争议的领域之一。一个核心难题在于：**形态的定义高度主观**。

有研究者指出，传统形态识别的主要方法是"硬写代码，主观设置一大堆参数寻找相似形态"，但这种做法"泛化能力太差，要么找出来的东西不符预期，要么遗漏掉真正的好形态"[^1]。另一种方法是使用 DTW（动态时间规划）来测量新序列与参考形态序列的相似度，但泛化能力仍然有限[^34]。深度学习方法（CNN、LSTM）在形态识别中也处于早期探索阶段[^34]。

更深层的问题是：**经验丰富的手工交易者和量化从业者之间存在"两岸相隔"的知识鸿沟**。一个真正有预测效力的形态可能同时参考价格序列和成交量、跨多个时间周期，但量化研究者缺少看盘经验，手工交易者缺少量化能力，导致"很难出现成熟手工交易者和量化从业者深度合作的案例"[^34]。

**对 LLM 的启示**：形态识别的模糊性恰恰是 LLM 的优势领域。LLM 可以综合多个维度的信息（价格、成交量、趋势环境、消息面）进行"类人"的形态判断，而不需要严格的量化阈值。但在判断完成后，仍应给出置信度评估，而非二元化的"是/否"结论。

## 工具使用指导

使用 股价表现（ifind-ds-stock-mcp）获取价格形态识别所需的数据。

**扫描反转/持续形态**：
- query: "隆基绿能最近120日的收盘价、最高价、最低价、成交量"
- LLM 根据价格序列识别头肩顶/底、双顶/底、三角形、旗形等形态
- 注意：工具返回的是原始数据，形态识别由 LLM 根据本文件定义完成

**形态突破确认 — 需同时获取成交量**：
- query: "恒瑞医药最近60日的收盘价、最高价、最低价、成交量"
- 关键验证：突破时成交量是否 ≥ 前5日均量的120%（参见第一节 1.2）

**技术形态标签（数据源可直接返回）**：
- query: "比亚迪最近半年是否出现涨跌停、连板、创新高创新低"
- 行情数据源可直接返回定性形态标签，如"连续涨停3日"、"创60日新高"等

**缺口识别**：
- query: "中科曙光最近30日的开盘价、最高价、最低价"
- LLM 判断是否存在跳空缺口（当日最低价 > 前日最高价 或 当日最高价 < 前日最低价）

**典型调用场景**：
```
用户问："宁德时代最近有没有形成双底？"
→ 数据需求："宁德时代最近120日的收盘价、最高价、最低价、成交量"
→ LLM 识别两次触底的价格位置、间隔时间、成交量变化
→ 判断是否满足双底定义（两底价格接近、间隔适当、突破颈线需放量）
```
