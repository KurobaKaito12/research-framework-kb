# indicators.md

> **定位**：本文件是技术分析技能库中篇幅最大、信息密度最高的核心模块。技术指标是将价量数据通过数学公式转化为可量化信号的标准化工具，其核心价值在于"可量化、定义明确、便于执行纪律"[^2][^11]。本文件系统覆盖四大类技术指标——趋势类、超买超卖类、波动率类、成交量类——的数学原理、标准用法、实战验证数据与已知局限。

## 零、技术指标的本质与分类

### 0.1 技术指标的本质

技术指标是根据价、量的历史资料，通过建立数学模型给出计算公式，得到一个体现标的证券在某个方面内在实质的指标值[^11]。技术指标强调**数值的量化表达**，这与形态分析强调"形态特征"的刻画存在根本差异[^11]。

广发证券的一项深刻观察指出："大多数技术分析的指标都是相似的，它们都在描述相同的现象——要么是价格变化的速度，要么是价格变化速度的快慢。一个'价格在均线上做多'的策略，完全可以换成'RSI高于50时做多'，或者是ROC大于0时做多'"[^48]。这一结论对实战有重要启示：**与其折腾不同指标的复杂组合，不如从其他维度（波动率、基本面、仓位管理）着手提高策略表现**[^48]。

### 0.2 技术指标为何可能有效

华创证券指出，技术指标有效背后存在行为金融学逻辑[^12][^26]：
- **均线类指标**：均线具有支撑和阻力作用——越多的人相信均线有支撑，在价格波动到均线附近时就会有大量买入资金流入[^14]。
- **动量类指标**：利用"羊群效应"——价格上涨时人们更贪婪地在高位买入，下跌时恐慌地在低位卖出[^12]。
- **反转类指标**：利用交易时的恐慌效应——判断股价是否超过正常的运行区间[^12]。
- **量价指标**：量价的匹配和背离承载着比单一价格维度更多的信息[^38]。

### 0.3 四大分类体系

光大证券将常用技术指标划分为四大类[^2][^13]：

| 类别 | 核心逻辑 | 代表指标 | 特征 |
|------|---------|---------|------|
| **趋势指标** | 对"均线"的演绎表达，追随趋势方向 | MACD、DMI、TRIX、SAR、MTM | 滞后指标，趋势中有效，震荡中失效 |
| **反趋势指标（超买超卖类）** | 基于"物极必反"的反转效应 | KDJ、RSI、CCI、W&R、MTM | 领先指标，极值区有效，趋势中钝化 |
| **压力支撑指标（通道类）** | 构建通道给出价格变化区间 | BOLL、ENV、KELT、MIKE | 路径型指标，辅助判断支撑阻力 |
| **量价指标** | 在价格序列上叠加成交量信息 | OBV、EMV、WVAD、TAPI | "量价配合"视角的量化表达 |

东北证券将技术指标分为趋势类、动量类、波动类和成交量类四大类，从信息发现、趋势追随和羊群效应三个维度分析了技术分析能获取超额收益的原因[^44]。

### 0.4 四大类指标的实证表现

光大证券对 28 个技术指标在 2002-2015 年全部 A 股上进行了系统回测，核心发现[^2][^6][^8]：

| 类别 | 胜率表现 | 盈亏比表现 | 行业稳定性 |
|------|---------|-----------|-----------|
| 趋势指标 | 胜率盈亏比此消彼长 | 相对平衡 | 行业稳定性好 |
| 反趋势指标 | 整体胜率表现较优 | — | 行业稳定性好 |
| 压力支撑指标 | 表现较为一致 | 盈亏比稳定性弱于趋势与反趋势 | — |
| 量价指标 | 均值表现一致 | 均值表现一致 | 组间分化较大 |

基于凯利公式综合评价，光大证券最终**推荐 8 个指标**：MACD、DDI、DMA、TRIX、B3612、ENV、EMV、TAPI[^8]。

广发证券对 125 个技术指标在沪深 300 指数上的回测（2005-2019）发现：除价格反转类指标外，其他四类（价格动量、成交量、价量、大盘）多空择时长期表现良好，年化收益率中位数分别为 18.6%、16.9%、16.1%、13.5%[^44]。由于国内以趋势市为主，价格反转类指标总体表现不佳[^44]。

## 一、趋势类指标

趋势指标的核心共性是对"均线"的演绎表达，目的是**追随趋势方向**[^13]。它们属于滞后指标——当信号出现时，趋势已经运行了一段距离。

### 1.1 MA（移动平均线）

#### 1.1.1 计算方法

移动平均线是技术指标中"举足轻重"的基础工具[^5]。最简单的形式是对收盘价取过去 N 天的简单移动平均（SMA）。在此基础上，存在多种衍生变体[^5]：

| 类型 | 公式 | 特征 |
|------|------|------|
| 简单移动平均（SMA） | $SMA_N = \frac{1}{N}\sum_{i=1}^{N} C_{t-i+1}$ | 各期权重相等 |
| 加权移动平均（WMA） | 近期价格权重更大 | 降低滞后性 |
| 指数移动平均（EMA） | $EMA_t = \alpha \cdot C_t + (1-\alpha) \cdot EMA_{t-1}$ | $\alpha = 2/(N+1)$，兼顾灵敏度与平滑性 |
| 动态移动平均（DMA） | 如 VIDYA 指标，根据波动率自适应调整平滑系数 | 趋势强时降低滞后性，趋势弱时增加平滑性[^5] |

广发证券指出，围绕均线的一个核心话题是**延迟性与平滑性的权衡**——周期越长越平滑，但信号延迟越严重[^5]。

#### 1.1.2 经典买入/卖出法则

光大证券整理了均线经典的八大法则[^37]：

**买入法则**：
1. 均线从下降逐渐走平且略向上方抬头，价格从均线下方向上突破——**买进信号**[^37]。
2. 价格位于均线之上运行，回档时未跌破均线后又再度上升——**买进时机**[^37]。
3. 价格位于均线之上运行，回档时跌破均线但短期反弹后仍在均线之上，均线继续上升——**买进时机**[^37]。
4. 价格位于均线以下运行，连续数日大跌，离均线愈来愈远——**买进时机**（超跌反弹）[^37]。

**卖出法则**：上述四条的镜像对称[^37]。

#### 1.1.3 多均线系统

**双均线交叉**：短期均线上穿长期均线 = 金叉（买入信号）；下穿 = 死叉（卖出信号）[^14][^39]。这是最经典的趋势跟踪策略之一。广发证券回测显示，双 MA 策略（5日/20日）在沪深300上的累积收益率为 1053.61%，信息比 0.79[^42]。

**BBI（多空指数）**：取 3/6/12/24 日四条均线的平均值。广发证券回测显示 BBI 策略累积收益率达 1279.63%，信息比 0.84[^42]。BBI 通过综合不同周期均线的平滑性和滞后性，是一种多周期融合的思路[^42]。

**均线多头/空头排列**：短期 > 中期 > 长期均线 = 多头排列（强势上涨趋势）；反之 = 空头排列。均线排列的扩散程度反映趋势强度。

**均线粘合**：多条均线纠缠在一起，意味着多空力量均衡，即将选择方向。均线粘合后的发散方向通常预示后续趋势方向。

#### 1.1.4 均线的 A 股实战注意

- **5日/10日均线**：短线交易的核心参考线，适合日内和超短线。
- **20日/30日均线**：波段交易的生命线，20日均线被广泛视为"月线"，是中短期趋势的关键分界。
- **60日/120日/250日均线**：中长期趋势的分水岭。250日均线（年线）在 A 股中有极强的心理支撑/阻力意义。
- **量能配合**：均线突破如果伴随放量，信号更可靠；缩量突破均线可能是假突破。

### 1.2 EXPMA（指数移动平均线）

#### 1.2.1 与 SMA 的区别

EXPMA 使用指数加权移动平均（EMA），给予近期价格更大的权重。相比 SMA，EMA 对价格变化的响应更快，滞后性更低[^5]。

#### 1.2.2 使用方法

- EXPMA 的用法与 MA 类似，但信号更灵敏。
- 短期 EXPMA 上穿长期 EXPMA 为买入信号，下穿为卖出信号。
- 价格在 EXPMA 上方运行且 EXPMA 向上倾斜 = 多头趋势；反之 = 空头趋势。
- EXPMA 的灵敏度优势在快速波动的行情中更明显，但在横盘震荡中可能产生过多的假信号。

### 1.3 MACD（指数平滑异同平均线）

#### 1.3.1 计算公式

MACD 是从双移动平均线发展而来的[^30]：

$$DIFF = EMA(CLOSE, S) - EMA(CLOSE, P)$$
$$DEA = EMA(DIFF, M)$$
$$MACD柱状图 = 2 \times (DIFF - DEA)$$

默认参数：S=12, P=26, M=9。DIFF 是快线，DEA 是慢线，MACD 柱状图反映快慢线的距离变化[^30]。

#### 1.3.2 核心用法

光大证券整理的标准用法[^3]：

1. **零轴判断多空**：DIF、MACD 在 0 以上 = 多头市场；在 0 以下 = 空头市场[^3]。
2. **金叉/死叉**：DIF 向上突破 DEA = 买入信号；DIF 向下跌破 DEA = 卖出信号[^3]。
3. **零轴上方金叉更强**：DIF、MACD 在 0 以上时，DIF 向上突破 DEA = 可作买入；DIF 向下跌破 DEA = 作卖出[^3]。
4. **零轴下方信号需谨慎**：DIF、MACD 在 0 以下时，DIF 向上突破 DEA 可视为"抄底"信号，但需确认趋势后操作[^3]。
5. **背离信号**：股价出现两个或三个近期低点而 MACD 并不配合出现新低 = 买入信号；反之 = 卖出信号[^3]。
6. **双交叉信号**：高档两次向下交叉则很可能大跌；低档两次向上交叉则很可能大涨[^3]。

#### 1.3.3 MACD 的实战进阶

**MACD 柱状图的缩短**：柱状图从峰值开始缩短，代表趋势动能减弱。如果柱状图在零轴上方开始缩短，虽 DIFF 仍高于 DEA，但上涨动力已在衰减。这是 MACD 信号中**最领先**的部分。

**MACD 顶背离与底背离**：
- 顶背离：价格创新高，但 MACD 柱状图的高点低于前高，或 DIFF/DEA 的高点低于前高。代表上涨动能衰竭，是强烈的看跌预警。
- 底背离：价格创新低，但 MACD 的低点高于前低。代表下跌动能衰竭，是潜在的看涨信号。

**MACD 的已知局限**：
- MACD 是滞后指标，在快速反转行情中信号延迟明显[^4]。
- 在横盘震荡中，MACD 的频繁金叉死叉产生大量假信号。
- 零轴下方的金叉可能是"下跌中继"而非真正反转——需要等待 MACD 突破零轴后才确认趋势转变[^3]。

#### 1.3.4 实证数据

光大证券测试显示，MACD 在全 A 股上的信号胜率均值为 0.38（低于 50%，因为 A 股长期上涨导致卖空信号天然不利），盈亏比均值为 1.83，行业稳定性好[^8]。MACD 是光大证券推荐的 8 个指标之一，且通过八均线体系的优化后表现进一步提升[^2][^8]。

广发证券回测显示，MACD 在样本内的最优信号胜率为 52%[^16]。在与其他指标结合时（如 MACD 金叉 + 价格触及布林带下轨），牛市中的胜率可达 68%[web1]。

### 1.4 DMI（趋向指标）

#### 1.4.1 计算原理

DMI 由 Wells Wilder 创造，通过分析价格在涨跌过程中买卖双方力量均衡点的变化，提供趋势判断依据[^27]。核心包含四条线[^1]：

| 线 | 含义 |
|----|------|
| +DI | 上升方向线（多方力量） |
| -DI | 下降方向线（空方力量） |
| ADX | 趋向平均线（趋势强度，不看方向） |
| ADXR | ADX 的平滑版本 |

#### 1.4.2 使用方法[^1]

1. **+DI 与 -DI 交叉**：+DI 在 -DI 上方 = 上升强于下降；+DI 上升并穿过 -DI = 买入信号。若 ADX 止跌回升则涨势更强[^1]。
2. **ADX 判断趋势强度**：ADX 从低位（20 以下）向上升 = 有行情启动。ADX 脱离 20-30 区间向上升都可认为有行情[^1]。
3. **ADX 超过 50 突然转向**：是转势信号——趋势可能即将结束[^1]。
4. **ADX 在 +DI 和 -DI 下方**：退出观望，市场无明确趋势[^1]。
5. **ADX 上下拐点**：通常在 70 以上或 20 以下出现[^1]。

#### 1.4.3 实战价值

DMI 的独特价值在于 **ADX 对趋势强度的独立判断**。其他趋势指标（如 MA、MACD）只告诉你趋势方向，但 DMI 的 ADX 能告诉你"当前趋势是否足够强，值得入场"。ADX > 25 通常被视为趋势明确存在的阈值[^1]。

### 1.5 TRIX（三重指数平滑平均线）

#### 1.5.1 计算方法

$$TRIPLE\_EMA = EMA(EMA(EMA(CLOSE, N), N), N)$$
$$TRIX = \frac{TRIPLE\_EMA - REF(TRIPLE\_EMA, 1)}{REF(TRIPLE\_EMA, 1)}$$

三重指数平滑消除了大部分短期波动和市场噪音，使 TRIX 成为**最适合中长期操作**的趋势指标[^3][^42]。

#### 1.5.2 使用方法[^3]

1. TRIX 向上交叉 MATRIX（TRIX 的移动平均线）= 买进；向下交叉 = 卖出[^3]。
2. **TRIX 与股价背离**：应注意随时可能反转[^3]。
3. **零轴穿越**：TRIX 上穿 0 轴 = 买进信号；跌破 0 轴 = 卖出信号[^3]。
4. **盘整行情中不适用**[^3]。

#### 1.5.3 实证数据

广发证券回测显示，TRIX 策略累积收益率达 1195.50%，信息比 0.92，最大回撤 -28.31%[^42]。TRIX 通过三重移动平均有效过滤了噪音，是表现最稳定的趋势指标之一。光大证券同样将 TRIX 列为推荐的 8 个指标之一[^8]。

### 1.6 DMA（平均差）与 MTM（动力指标）

**DMA**：短期均线与长期均线之差[^3]。
- DMA 向上交叉其平均线 = 买进；反之 = 卖出[^3]。
- DMA 的交叉信号比 MACD、TRIX 略快[^3]。
- DMA 与股价产生背离时的交叉信号可信度较高[^3]。
- DMA、MACD、TRIX 三者构成一组指标群，互相验证[^3]。

**MTM（动力指标）**：$MTM = C_t - C_{t-N}$，度量当前价格与 N 日前价格之差[^17]。
- MTM 从下向上突破 MTMMA = 短期买入信号；从上向下突破 = 短期卖出信号[^1]。
- 本质上衡量的是价格变化的"速度"，而非方向。

### 1.7 SAR（停损转向指标）

#### 1.7.1 设计理念

SAR（抛物线指标/停损指标）是一种**自带止损机制**的趋势跟踪系统。它的设计目标不是预测趋势方向，而是跟踪已确认的趋势并提供动态止损点。

#### 1.7.2 使用方法[^1]

1. **多空判断**：股价在红色圆圈（SAR 点）上方 = 多头市场；在绿色圆圈下方 = 空头市场[^1]。
2. **止损转向**：收盘价跌破 SAR = 多头停损，开始空头交易；收盘价突破 SAR = 空头停损，开始多头交易[^1]。

#### 1.7.3 实战评价

SAR 的优势在于**简单明确、自带止损**——不需要额外设定止损位，SAR 本身就是动态止损点。但在横盘震荡中，SAR 会频繁发出多空翻转信号，导致连续小亏损。因此 SAR 更适合趋势明确的行情，不适合震荡市。

### 1.8 趋势类指标综合实战框架

```
步骤1：判断是否存在趋势
 └─ DMI 的 ADX > 25？如果是，存在趋势。
 └─ 如果 ADX < 20，市场无趋势，趋势类指标信号权重极低。

步骤2：确定趋势方向
 └─ MACD 的 DIFF 与 DEA 在零轴上方还是下方？
 └─ 均线排列状态：多头排列 vs 空头排列？
 └─ 价格与 EXPMA 的关系？

步骤3：寻找入场点
 └─ MACD 金叉（零轴上方更强）[3]
 └─ DMA 向上交叉其均线[3]
 └─ 价格回踩关键均线（20日/60日）获得支撑后反弹
 └─ SAR 翻转为多头[1]

步骤4：监控趋势强度
 └─ ADX 是否在上升？如果 ADX 开始下降，趋势可能减弱。
 └─ MACD 柱状图是否在缩短？动能是否衰减？
 └─ TRIX 是否开始趋近零轴？

步骤5：识别趋势衰竭
 └─ MACD 顶/底背离[3]
 └─ TRIX 与股价背离[3]
 └─ ADX > 50 后突然转向[1]
 └─ 价格创新高但 MACD 未创新高[3]
```

## 二、超买超卖类（反趋势）指标

反趋势指标的构建大多基于过去一段时间的涨跌幅特征或 K 线价格特征，强调一段时间序列内价格的变化状态。使用方式上，反趋势指标侧重于在**极值区间的反转表达**[^1]。

**核心局限**：这类指标属于预测股价后期变化的领先指标[^19]，但在强趋势行情中会出现**钝化**——指标长时间停留在超买/超卖区间而价格继续上涨/下跌。这是反趋势指标最大的陷阱。

### 2.1 RSI（相对强弱指标）

#### 2.1.1 计算方法

$$RSI(N) = 100 \times \frac{SMA(MAX(Close - LastClose, 0), N, 1)}{SMA(ABS(Close - LastClose), N, 1)}$$

RSI 刻画的是一段时间内多空双方的力量对比——上涨幅度代表多方力量，下跌幅度代表空方力量[^11]。默认参数 N 通常取 6、12、24[^17]。

#### 2.1.2 标准用法[^4]

| RSI 区间 | 状态 | 操作建议 |
|----------|------|---------|
| 0 < RSI < 20 | 极弱，超卖 | 买入 |
| 20 < RSI < 50 | 弱势 | 卖出，空仓 |
| 50 < RSI < 80 | 强势 | 买入，持仓 |
| 80 < RSI < 100 | 极强，超买 | 卖出 |

1. **快速 RSI 在 20 以下由下往上交叉慢速 RSI** = 买入信号[^4]。
2. **快速 RSI 在 80 以上由上往下交叉慢速 RSI** = 卖出信号[^4]。

#### 2.1.3 实战进阶

**RSI 背离**：价格创新高但 RSI 未创新高（顶背离），或价格创新低但 RSI 未创新低（底背离）。RSI 背离是所有超买超卖指标中最可靠的信号之一。

**RSI 50 线的多空分界**：RSI 在 50 以上 = 多方占优；在 50 以下 = 空方占优。RSI 从下方突破 50 可视为趋势转强的确认。

**RSI 的"区间漂移"问题**：在强牛市中，RSI 可能长期在 70-90 区间运行；在强熊市中，RSI 可能长期在 10-30 区间运行。此时机械套用 80/20 阈值会产生严重误判。解决方案：根据市场状态动态调整阈值（如牛市中超买阈值调至 85，熊市中超卖阈值调至 15）。

**广发证券的动态区间 RSI（DZCCI 思路的延伸）**：利用 RSI 过去 N 天的移动平均加减常数倍标准差来构造 RSI 变化的上下轨，用 RSI 的移动平均值突破上下轨来产生交易信号。动态区间的方法使指标能根据过去一段时间的行情自动调整阈值[^20]。

### 2.2 KDJ（随机指标）

#### 2.2.1 计算方法

KDJ 由 George Lane 首创，综合了动量、相对强弱和平均线的优点[^23]。

$$RSV = \frac{C_n - L_n}{H_n - L_n} \times 100$$
$$K_t = \frac{M_1-1}{M_1} \cdot K_{t-1} + \frac{1}{M_1} \cdot RSV_t$$
$$D_t = \frac{M_2-1}{M_2} \cdot D_{t-1} + \frac{1}{M_2} \cdot K_t$$
$$J_t = 3K_t - 2D_t$$

默认参数 N=9, M1=3, M2=3[^17]。RSV 度量当前收盘价在过去 N 天最高价和最低价之间的位置[^20]。

#### 2.2.2 标准用法[^4]

1. **K 值高于 80** = 超买区，短期股价容易向下回档；**K 值低于 20** = 超卖区，短期股价容易向上反弹[^4]。
2. **K 在 20 左右从下方交叉 D** = 短期买进信号[^4]。
3. **K 在 80 左右从上方交叉 D** = 短期卖出信号[^4]。
4. **J > 100** = 容易形成短期头部；**J < 0** = 容易形成短期底部[^4]。
5. **KDJ 在 50 左右波动时信号失效**[^4]。
6. **背离**：价格创新高/低而 KD 未创新高/低 = 可能反转[^4]。
7. **连续金叉**：K 在 20 左右由下往上连续两次交叉 D = 股价上涨概率很大[^4]。
8. **连续死叉**：K 在 80 左右由上往下连续两次交叉 D = 股价下跌概率很大[^4]。

#### 2.2.3 实战进阶

**KDJ 钝化**：当 K 值和 D 值持续在 80 以上（或 20 以下）运行时，KDJ 进入钝化状态，此时金叉/死叉信号基本失效。钝化通常发生在强趋势行情中。

**J 值的极端敏感性**：J 值可以超出 0-100 范围。J > 100 时如果开始回落（即使仍 > 80），可能提前预示顶部的到来。J < 0 时如果开始回升，同理。

**KDJ 与 RSI 的差异**：KDJ 的 RSV 分子中使用的是最高价和最低价，而 RSI 只使用收盘价。因此 KDJ 对价格波动的极端值更敏感，但噪音也更大[^23]。

**SLOWKD（慢速随机指标）**：对 KDJ 进行额外平滑处理，减少假信号。SLOWKD 在 20 以下多次反复金叉后重新站在 20 以上 = 筑底阶段完成[^10]。

### 2.3 CCI（顺势指标）

#### 2.3.1 计算方法

$$CCI(N) = \frac{TP - MA}{MD \times 0.015}$$

其中 $TP = (High + Low + Close) / 3$，MA 为 TP 的 N 日均值，MD 为 TP 与 MA 偏差的 N 日均值[^19]。

#### 2.3.2 使用方法[^33]

1. CCI > 0 = 多头市场；CCI < 0 = 空头市场[^33]。
2. CCI 在 ±100 之间 = 常态行情；> +100 = 强势；< -100 = 弱势[^33]。
3. CCI 由下向上突破 +100 = 买进；由 +100 上方向下突破 +100 = 卖出[^33]。
4. CCI 由上向下突破 -100 = 卖出；由 -100 下方向上突破 = 买入[^33]。
5. 弱市中，CCI 可能长期在 +100 以下运行[^33]。

#### 2.3.3 特点

CCI 与 RSI、KDJ 的关键区别在于：CCI 没有固定的上下边界（理论上可以无限延伸），这使得它更适合衡量**极端偏离常态**的情况。0.015 的常数因子使约 70%-80% 的 CCI 值落在 ±100 之间[^19]。

### 2.4 W&R（威廉指标）

#### 2.4.1 计算方法

$$W\&R(N) = \frac{H_n - C_t}{H_n - L_n} \times 100$$

W&R 与 KDJ 中的 RSV 计算逻辑相似（都是度量收盘价在最高最低价之间的位置），但方向相反：W&R = 0 表示收盘价等于最高价（最强），W&R = 100 表示收盘价等于最低价（最弱）。

#### 2.4.2 使用方法[^10]

1. W&R 上升至 20 以上后再跌破 20 = 卖出信号；下降至 80 以下后再突破 80 = 买进信号[^10]。
2. W&R 向上触碰 0% 四次 = 良好卖点；向下触碰 100% 四次 = 良好买点[^10]。
3. **过于敏感**，必须与 RSI 等较为平滑的指标一起使用[^10]。
4. W&R 进入超买超卖区后，应结合 MACD 的信号一同判断[^10]。

### 2.5 MTM（动力指标）

$$MTM(N) = C_t - C_{t-N}$$

MTM 度量当前价格与 N 日前价格的绝对差值[^17]。

**使用方法**[^1]：
- MTM 从下向上突破 MTMMA = 短期买入信号。
- MTM 从上向下突破 MTMMA = 短期卖出信号。

**ROC（变动率指标）**：与 MTM 类似，但计算的是百分比变化而非绝对差值[^4]。

### 2.6 反趋势指标的通用实战原则

1. **强趋势中信号失效**：在明确的上升趋势中，RSI/KDJ 长期处于超买区但不下跌；在下降趋势中长期处于超卖区但不反弹。此时反趋势指标的信号**不可信**。
2. **极值区间的反转信号更有价值**：RSI 降到 15 以下或升到 85 以上时出现的反转信号，比 RSI 在 30-70 区间的交叉信号可靠得多。
3. **背离是最强信号**：价格与指标的背离是所有反趋势指标信号中最可靠的。但背离可能持续很长时间才兑现，不能仅凭背离就立即反向操作。
4. **多指标交叉验证**：W&R 过于敏感，需要与 RSI 等平滑指标配合[^10]；RSI 进入极值区后需结合 MACD 判断[^10]。
5. **参数敏感性**：不同参数下指标表现差异巨大。华创证券对 22 个指标进行了 1000+ 组参数搜索，建议对参数进行优化但需严格避免过拟合[^12]。

## 三、波动率类指标

波动率类指标衡量价格波动的剧烈程度，既可用于辅助判断趋势状态，也可用于止盈止损和仓位管理。

### 3.1 布林带

#### 3.1.1 计算方法

布林带由 John Bollinger 创造，是在移动平均线基础上加减标准差的倍数来构造通道的典型代表[^5]。

$$中轨 = SMA(CLOSE, N)$$
$$上轨 = 中轨 + K \times STD(CLOSE, N)$$
$$下轨 = 中轨 - K \times STD(CLOSE, N)$$

默认参数：N=20, K=2[^5]。

#### 3.1.2 核心用法

**1. 波动率收缩与扩张**：
- 上下轨距离缩小（带宽收窄）= 市场波动率降低，可能处于盘整蓄势阶段。
- 上下轨距离急剧放大（带宽扩张）= 波动率升高，趋势可能正在启动或加速。

**2. 价格触及轨道的含义**：
- 价格触及上轨：代表当前价格相对于近期均值偏高。但**并非自动的卖出信号**——在强趋势中，价格可以沿着上轨持续运行（"轨道骑行"）。
- 价格触及下轨：同理，在下跌趋势中价格可以沿着下轨持续下跌。

**3. 不同市场环境下的策略差异**[^9]：
- **平衡市**：股价在上轨道卖出，在下轨道买入（区间交易策略）。
- **牛市**：突破上轨为买入信号（趋势跟踪策略）。
- **熊市**：跌破下轨为卖出信号（趋势跟踪策略）。

这是布林带使用中最关键的区分：同样的触及上轨信号，在震荡市和趋势市中的操作方向完全相反。

**4. %B 指标**：
$$\%B = \frac{Close - 下轨}{上轨 - 下轨}$$
%B > 1 = 价格在上轨之上；%B < 0 = 价格在下轨之下。%B 将价格在布林带中的位置标准化为 0-1 区间（可以超出），便于量化比较[^18]。

**5. 布林带宽度（Bandwidth）**：
$$BW = \frac{上轨 - 下轨}{中轨}$$
带宽的极低值通常预示着即将出现大幅波动（"暴风雨前的宁静"）。

#### 3.1.3 布林带的实战价值

布林带的最大价值在于**将趋势判断和波动率分析合二为一**：
- 中轨（20日均线）提供趋势方向参考。
- 上下轨提供波动率边界。
- 带宽变化提供趋势启动/衰竭的预警。

一个有效的组合策略：MACD 金叉 + 价格触及布林带下轨 = 强势多头入场信号（MACD 提供趋势方向，布林带下轨提供超卖位置）。掘金量化平台的回测显示该组合在牛市中胜率达 68%[web1]。

### 3.2 ATR（平均真实波幅）

#### 3.2.1 计算方法

$$True Range = MAX(High - Low, |High - PrevClose|, |Low - PrevClose|)$$
$$ATR(N) = SMA(TrueRange, N)$$

默认参数 N=14。ATR 衡量的是特定时间内资产价格的平均波动范围[web3]。

#### 3.2.2 核心应用

**1. 止损设置（最核心用途）**：

ATR 的最大价值在于**为止损提供基于波动率的动态参考**，而非固定的百分比止损。

- 经典海龟法则：**止损 = 建仓价 - 2 × ATR**[^41][web3]。ATR 上升时止损距离自动加大（给予价格更多活动空间），ATR 下降时止损距离自动缩小。
- 追踪止损：**止损 = 最高价 - N × ATR**。随着价格上升，止损位跟随上移但不会下移。

**2. 仓位管理（海龟法则核心）**：

海龟交易系统的仓位管理以 ATR 为核心[web5][web6]：
- **单位头寸 = 账户权益的 1% / (N × ATR × 合约乘数)**
- 每个单位代表一个 ATR 的风险。
- 加仓规则：价格高于初始价格 0.5 ATR 时加仓[^41]。

**3. 波动率状态判断**：
- ATR 上升 = 市场进入高波动期，情绪活跃，风险加大[web4]。
- ATR 下降 = 市场趋稳，交易密度下降[web4]。

**4. 策略适配**：
- ATR 较低时适合突破策略（低波动后通常伴随高波动突破）。
- ATR 较高时适合均值回归策略（高波动后倾向于回归均值）。

#### 3.2.3 ATR 在 A 股中的特殊应用

- A 股涨跌停板制度下，ATR 可以帮助判断"一字板"后的合理止损距离。
- A 股不同板块的 ATR 差异巨大（科创板/创业板 ATR 远高于主板），使用固定百分比止损不合理，ATR 动态止损更适合跨板块操作。

### 3.3 SAR（已在前文趋势类指标中详述）

SAR 也可归为波动率类指标，因为其加速因子会根据价格波动的速度自动调整停损点的位置。波动率越大，SAR 点移动越快；波动率越小，SAR 点移动越慢。

### 3.4 波动率类指标的综合应用

```
步骤1：用布林带判断当前波动率状态
 ├─ 带宽处于历史低位？→ 即将出现大幅波动，准备应对突破。
 ├─ 带宽正在扩张？→ 趋势正在运行中，使用趋势跟踪策略。
 └─ 带宽处于历史高位后开始收缩？→ 趋势可能衰竭。

步骤2：用 ATR 设定止损和仓位
 ├─ 止损 = 入场价 ± 2×ATR
 ├─ 仓位 = 账户可承受风险 / (ATR × 合约乘数)
 └─ 追踪止损 = 持仓期间最高/低价 - 2×ATR

步骤3：结合趋势指标确认方向
 ├─ 布林带中轨方向 = 趋势方向
 ├─ 价格在中轨上方 + 带宽扩张 = 上升趋势加速
 └─ 价格在中轨下方 + 带宽扩张 = 下降趋势加速
```

## 四、成交量类（量价）指标

量价指标在价格序列的特征上叠加了成交量信息，侧重于"量价配合"观点的表达[^9]。广发证券的研究明确指出："量和价的交叉维度是最容易出成绩的，相比于单一的价格维度，量价的匹配和背离承载着更多的信息"[^38]。

### 4.1 OBV（能量潮/On Balance Volume）

#### 4.1.1 计算方法

OBV 由 Joe Granville 创造，通过统计成交量变动的趋势来推测股价趋势[^46]。核心逻辑：

- 当日收盘价 > 前日收盘价：当日 OBV = 前日 OBV + 当日成交量。
- 当日收盘价 < 前日收盘价：当日 OBV = 前日 OBV - 当日成交量。
- 当日收盘价 = 前日收盘价：当日 OBV = 前日 OBV。

OBV 只考虑价格变化的**方向**（涨/跌），不考虑变化的**幅度**[^20]。

#### 4.1.2 使用方法[^7]

1. **OBV 与价格背离**：股价上升创新高但 OBV 未创新高 = 上升能量不足，卖出信号；股价下跌创新低但 OBV 未创新低 = 有能量支撑，买入信号[^7]。
2. **OBV 创新高/新低**：OBV 创新高股价也应创新高，若不能 = 持股者回吐，卖出信号[^7]。
3. **OBV 穿越零轴**：OBV 从负转正 = 买进信号；从正转负 = 卖出信号[^7]。
4. **长期盘整后 OBV 上冲**：OBV 持续一个月以上横向移动后，力度大于 45 度以上上冲 = 买入信号（条件：当日成交量 > 5日均量 100%，5日均量 > 10日均量）[^7]。
5. **WVAD 与 OBV 同时发力**：上涨概率更高[^7]。

#### 4.1.3 实战要点

OBV 的核心价值在于**量价背离的识别**。当价格与 OBV 走势出现分歧时，通常 OBV 方向代表了"聪明钱"的真实意图。但 OBV 有一个重要缺陷：它只考虑了价格变化的方向，未考虑变化幅度——一根涨 0.01 元的 K 线和一根涨 5 元的 K 线对 OBV 的贡献相同（如果都上涨的话）。PVT 指标正是为了弥补这一缺陷而设计的。

### 4.2 VWAP（成交量加权平均价）

#### 4.2.1 计算方法

$$VWAP = \frac{\sum (Price_i \times Volume_i)}{\sum Volume_i}$$

VWAP 用成交量作为权重对价格求加权平均[^20]。

#### 4.2.2 核心特征

VWAP 是**机构交易的核心参考指标**。机构大单交易的目标之一就是使成交均价优于 VWAP——在 VWAP 下方买入、在 VWAP 上方卖出。

- **日内 VWAP**：从当日开盘起累积计算，是日内交易者的基准线。价格在 VWAP 上方 = 买方占优；下方 = 卖方占优。
- **VWMA（成交量加权移动平均线）**：与 SMA 类似但按成交量加权。广发证券的回测中，VWMA 策略累积收益率 1053.61%，信息比 0.79[^42]。

#### 4.2.3 实战应用

- **机构建仓/出货判断**：如果价格在 VWAP 上方运行且成交量放大，说明机构在主动买入。
- **日内支撑阻力**：日内 VWAP 是重要的动态支撑/阻力位。价格回踩 VWAP 获得支撑后反弹 = 多头信号。
- **算法交易基准**：许多机构的交易算法以 VWAP 为执行基准。理解 VWAP 有助于判断机构的交易行为。

### 4.3 EMV（简易波动指标）

#### 4.3.1 计算原理

EMV 的核心逻辑是：**当较少的成交量就能推动价格上涨时，说明市场"轻松"上行；当需要大量成交量才能推动价格时，说明市场"吃力"**[^7]。

#### 4.3.2 使用方法[^7]

1. EMV > 0 = 量跌价增（少量资金就能推升股价），买进[^7]。
2. EMV < 0 = 量跌价跌，卖出[^7]。
3. EMV 趋近于 0 = 大成交量推动，趋势不明[^7]。

#### 4.3.3 实证数据

光大证券将 EMV 列为推荐的 8 个指标之一[^8]。EMV 的独特价值在于它不是简单地将量价相加，而是通过"量能效率"的视角来评估趋势质量——低量上涨比放量上涨更能说明筹码锁定良好、抛压轻。

### 4.4 MFI（资金流量指标）

#### 4.4.1 计算方法

MFI 由 Welles Wilder 将 RSI 修改后演变而来[^46]。RSI 以成交价为计算基础；MFI 结合价和量，"可以说是成交量的 RSI 指标"[^46]。

$$TP = (High + Low + Close) / 3$$
$$MF = TP \times Volume$$

如果当日 TP > 昨日 TP，MF 计为正货币流量（PMF）；否则计为负货币流量（NMF）[^17]。

$$MFI = 100 - \frac{100}{1 + PMF/NMF}$$

默认参数 N=14[^17]。

#### 4.4.2 使用方法

MFI 的用法与 RSI 类似[^29]：
- MFI > 80 = 超买（资金过度流入）；MFI < 20 = 超卖。
- MFI 与价格的背离信号比单纯的超买超卖更有价值。

**MFI 的独特价值**：MFI 结合了价格和成交量两个维度，能够识别"价格上涨但资金在流出"或"价格下跌但资金在流入"的量价背离情况。这种背离往往是趋势反转的早期信号。

#### 4.4.3 实证数据

广发证券回测显示，MFI 策略累积收益率 626.89%，信息比 0.66[^29]。

### 4.5 其他量价指标

**TAPI（现值率）**：TAPI = 成交量 / 加权指数[^7]。TAPI 无固定高低界限，必须结合大势和 K 线使用[^7]。在多头市场中 TAPI 与股价同创新高；TAPI 与股价不同步时 = 多头市场尾声[^7]。

**WVAD（威廉变异离散量）**：WVAD 用收盘价与最高最低价均价的差值对成交量加权，累积计算。WVAD 与 OBV 同时上攻 = 上涨概率更高[^7]。

**CHAIKIN（佳庆指标）**：佳庆指标由负值向上穿越 0 轴 = 买进信号（条件：股价必须在 90 周期均线之上才有效）[^9]。佳庆曲线产生急促凸起 = 行情即将反转[^9]。

**PVT（量价趋势指标）**：与 OBV 类似，但 PVT 考虑了价格不同涨跌幅的影响，而 OBV 只考虑方向[^50]。广发证券回测显示 PVT 策略累积收益率 1619.17%，信息比 0.88[^50]——是所有回测量价指标中表现最好的之一。

## 五、指标的联合使用与优化

### 5.1 多指标投票体系

广发证券提出了因子打分多空择时方法：先用各类别内部的指标信号投票产生一个类别信号，再用 5 个类别信号投票产生最终的多空信号[^44]。该方法的年化收益率达 23.7%，波动率 25.2%[^44]。

**多头仓位管理策略**：以类别信号为多的比例作为仓位——5 个类别信号有 3 个为多，则仓位 6 成。该策略年化收益率 14.2%，波动率仅 14.8%[^44]。

### 5.2 市场状态识别与指标切换

光大证券采用八均线体系对上涨、下跌和震荡三种状态进行划分，发现结合市场状态使用指标可显著改善表现[^2]：
- **趋势类指标**在趋势市中有效，震荡市中失效。
- **反趋势指标**在震荡市中有效，趋势市中钝化。
- **量价指标**在各状态中表现分化较大，需单独评估。

**核心原则**：在震荡市场环境中，当指标存在多种用法时，选取条件更为苛刻的交易信号可以避免交易条件宽松造成的损失[^2]。

### 5.3 指标组合的实战示例

**趋势跟踪组合**：MACD（方向）+ ADX（强度确认）+ ATR（止损/仓位）
- MACD 金叉确认多头方向
- ADX > 25 确认趋势存在
- 入场后以 2×ATR 设定止损，以 0.5×ATR 进行加仓

**超买超卖组合**：RSI（极值识别）+ KDJ（交叉确认）+ MACD（趋势过滤）
- RSI < 20 识别超卖
- KDJ 在 20 以下金叉确认
- MACD 在零轴附近或出现底背离 = 趋势可能反转

**波动率突破组合**：布林带（突破信号）+ ATR（波动率状态）+ OBV（量能确认）
- 布林带带宽处于低位后开始扩张
- 价格突破布林带上/下轨
- OBV 方向与突破方向一致 = 有效突破

## 六、技术指标的常见陷阱

### 6.1 参数过拟合

华创证券对 22 个指标进行了大规模参数搜索，明确警告需要通过买卖点有效性、策略多空收益有效性、样本内外有效性、数据窥探检验等多种方法来避免过拟合[^12]。"技术指标的有效是一种统计上的结果，不是说它未来每次都会有效"[^26]。

### 6.2 单一指标崇拜

没有任何一个技术指标在所有市场环境下都有效。趋势指标在震荡市失效，反趋势指标在趋势市钝化。必须根据市场状态选择合适的指标，或使用多指标投票体系[^44]。

### 6.3 忽视市场微观结构

在 A 股中，涨跌停板、T+1 制度、融资融券、大宗交易等制度特征会影响技术指标的表现。例如：
- 涨停板会导致当日成交量失真（大量挂单无法成交），影响 OBV、MFI 等量价指标。
- T+1 制度下，日内技术指标的信号无法当日兑现。

### 6.4 指标之间的冗余

广发证券的研究指出，大多数技术指标都在描述相同的现象[^48]。MACD 金叉、RSI 突破 50、ROC 大于 0，本质上可能表达的是同一个市场状态。使用大量高度相关的指标进行"多重确认"可能只是对同一信息的反复计算，而非真正的独立验证。
