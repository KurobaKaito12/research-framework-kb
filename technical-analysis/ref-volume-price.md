# volume-price.md

> **定位**：量价关系是技术分析中最核心、信息含量最高的分析维度之一。与单一的价格维度相比，量价的匹配和背离承载着更多的信息。本文件系统覆盖量价关系的九种基本形态、量价背离的深层机制与量化验证、换手率分析的多维应用、资金流向分析的原理与陷阱，以及量价指标的实战使用框架。

---

## 一、量价关系的基本原理

### 1.1 为什么"量"比"价"更重要？

技术分析有三个经典假设：市场行为包容消化一切、价格以趋势方式演变、历史会重演。其中第一个假设的"信息"几乎全部通过**成交量和成交价格**两个维度传递到市场中。价格反映的是交易结果（共识），成交量反映的是交易强度（分歧程度）。

从流动性视角可以给出更深层解释：市场的流动性可以粗糙地分为两部分——**筹码的流动性**（供给）和**资金的流动性**（需求）。在底部，供需都处于全量休眠状态；在顶部，供需都处于全量激活状态。而上升和下降过程中，虽然供需的流动性都会同向变化，但两者**速度上的差异**将决定量价的后续变化方向。这种差异正是量价背离的微观基础。

### 1.2 量与价的关系本质

- **成交量**：多空双方博弈的"激烈程度"。成交量放大 = 分歧加大；成交量缩小 = 共识增强。
- **价格**：多空双方博弈的"结果"。价格上涨 = 多方获胜；价格下跌 = 空方获胜。

将这两个维度组合，就得到了量价关系的基本框架：**方向（涨/跌）× 强度（放量/缩量/平量）= 9 种基本量价形态**。

## 二、九种基本量价形态

### 2.1 九种形态速查表

| 量价关系 | 成因及市场含义 | 出现位置 | 信号可靠性 |
|---------|-------------|---------|-----------|
| **量增价涨** | 投资者情绪高涨，成交量持续放大，股价不断被推升 | 上升通道 | 高（经典多头信号） |
| **量增价平** | 成交量放大而股价不涨：可能为主力对倒、底部震荡吸筹 | 底部/横盘 | 中（需结合位置判断） |
| **量增价跌** | 主力出货，抛盘严重，杀伤力十足 | 下降通道 | 高（空头信号，风险极大） |
| **量缩价涨** | 两种可能：①股价偏高，投资者跟进意愿不强，缺少人气；②筹码集中，主力惜售 | 上升趋势中段/高位 | 中（需区分两种成因） |
| **量缩价平** | 两种可能：①上升通道中缩量横盘洗盘，突破有望大涨；②高位震荡主力出货，跌破箱体暴跌 | 上升通道中段/高位 | 低（信号模糊） |
| **量缩价跌** | 两种形态：①上升通道中的短线洗盘；②下降通道中的中线调整 | 上升通道/下降通道 | 中（取决于位置） |
| **量平价涨** | 横量上涨，市场人气较好，主力控盘能力强 | 上升通道 | 中高 |
| **量平价平** | 滞涨现象，多空不明，不宜操作 | 各种位置 | 极低 |
| **量平价跌** | 一般出现在下降通道，股价加速赶底，成交量温和缩量 | 下降通道 | 中高（赶底信号） |

### 2.2 四种核心形态的深度解读

在实战中，有四种量价形态的信息含量最高，值得深入理解：

**（1）量增价涨——最健康的上涨形态**

量增价涨出现在上升通道中，代表买方力量持续增强，每一波上涨都有增量资金推动。这是趋势确认的核心信号——**没有成交量配合的上涨是"空中楼阁"**。

关键验证条件：
- 量增的幅度应与价涨的幅度大致匹配。如果成交量暴增数倍但价格涨幅有限，说明上方抛压沉重，需要警惕。
- 在上涨趋势的不同阶段，量增价涨的含义略有不同：初期放量上涨是建仓信号，中段放量上涨是趋势加速信号，末期放量上涨可能是"赶顶"信号。

**（2）量缩价跌——下降趋势的"正常状态"**

量缩价跌一般呈现两种形态：上升通道中的短线洗盘和下降通道中的中线调整。区分两者的关键在于**位置**：

- 如果股价在上升趋势中、均线多头排列完好，突然出现量缩价跌的回调，大概率是短线洗盘——获利盘了结导致的暂时性卖压。
- 如果股价已在下降趋势中、均线空头排列，量缩价跌说明空方力量正在"自然衰减"（因为没人愿意接盘），但这并不意味着底部已到——缩量下跌可以持续很长时间。

**（3）量缩价涨——最需要警惕的上涨形态**

量缩价涨存在两种截然不同的成因，是最容易误判的量价形态：

- **良性缩量上涨**：筹码高度集中在主力手中，抛压极轻，少量买盘就能推高股价。常见于主力高度控盘的股票中。
- **危险缩量上涨**：市场人气不足，投资者对当前价位不认同，不敢追高。一旦有风吹草动，股价可能快速回落。

**区分方法**：观察股价所处的位置和前期走势。如果是在长期底部启动后的缩量上涨，且前期有过放量建仓的过程，则倾向于良性；如果是在连续大涨后的高位缩量上涨，则倾向于危险。

**（4）量增价跌——最危险的下跌形态**

量增价跌一般出现在下降通道中，代表主力出货、抛盘严重，"杀伤力十足"。放量下跌意味着每创新低都有大量卖盘涌出，且买盘在积极承接（但被压倒）。这种形态下**不宜抄底**——放量下跌的股票不知道"底在哪里"。

## 三、量价背离

### 3.1 什么是量价背离

量价背离是指价格走势与成交量走势出现方向性不一致的现象。从流动性周期变化的视角来看，"量价协同"与"量价背离"是同一过程的"一体两面"：

- **量价协同**：趋势行情的典型特征。在底部，流动性枯竭，量价保持低迷；在顶部，流动性充沛，量价保持高涨。
- **量价背离**：反转行情的典型特征。在市场完成出清后，流动性出现拐点，量价关系从协同转为背离。

### 3.2 量价背离的流动性机制

从"筹码流动性"和"资金流动性"两个维度可以解释量价背离的形成机制：

**在上升达顶过程中**：资金流动性相较于筹码"先强后弱"。上升过程中供不应求导致量价齐升（协同），但到市场顶部阶段，**资金的边际流动性增量不及筹码的边际流动性增量**，于是价格无力继续上攻。此时价格可能仍在创新高，但成交量已开始萎缩——这就是顶部的量价背离。

**在下降达底过程中**：资金流动性相较于筹码"先弱后强"。下降过程中供大于求导致量价齐跌（协同），但到市场底部阶段，**资金的边际流动性增量强于筹码的边际流动性增量**，于是价格终究托底企稳。此时价格可能仍在创新低，但成交量已开始放大或出现止跌迹象——这就是底部的量价背离。

**核心结论**：趋势行情往往伴随着"量价协同"，反转行情则体现为"量价背离"。这种量价之间相关性的周期变化是使用换手率进行"顶底识别"的结构基础。

### 3.3 量价背离的四种基本形态

将日内量价走势分为四种典型情形：

| 量价形态 | 含义 | 预期股价变动 |
|---------|------|------------|
| 价升量升（量价趋同） | 市场分歧加大，乐观和悲观投资者数量都很多，市场情绪趋于"冷静" | **下跌**（拐点可能到来） |
| 价跌量跌（量价趋同） | 市场对股票后期预期一致，进一步下跌可能性较大 | **下跌** |
| 价升量跌（量价背离） | 市场参与各方对股价后续走势预期较为一致，股票还未达到预期价格 | **上涨** |
| 价跌量升（量价背离） | 买卖双方均有大量挂单，投资者情绪逐步乐观 | **上涨**（企稳反弹可能） |

**核心发现**：当量价出现背离时（无论当前股价处在上升还是下降通道），未来上涨的可能性均较高。

### 3.4 量价相关性的量化度量

#### 3.4.1 日频量价相关性因子

将量价走势在中短期上简化为"量价背离"与"量价同向"两类，可以使用**量价相关性**（过去半个月中，股票复权收盘价与日换手率之间的 Pearson 相关系数）来衡量背离/同向程度。

回测发现，量价相关性在半个月的换仓周期下具有十分好的选股效果并具有显著的 Alpha。**量价背离的股票未来表现更好**——即日内缩量上涨或放量下跌优于放量上涨或缩量下跌。

#### 3.4.2 高频量价相关性因子

使用日内 1 分钟频率的价格和成交量序列计算 Pearson 相关系数，构建高频量价相关性因子，效果进一步提升：月均 Rank IC 显著为负（相关性越低、未来收益越高），月度胜率高，多空对冲收益稳定。

#### 3.4.3 量价相关性因子的多种构建方式

| 因子名称 | 含义 | 计算逻辑 |
|---------|------|---------|
| VP | 量价相关性 | corr(volume, close) |
| VP\_last\_30min | 收盘前半小时的量价相关性 | 取尾盘 30 分钟数据计算 |
| 一阶量价背离 | 量价一阶变化的背离程度 | corr(rank(Δprice), rank(Δvolume)) |
| 量价排序协方差 | 收盘价与成交量排序的协方差 | -cov(rank(close), rank(volume)) |
| 量幅同向因子 | 量幅同向变化程度 | 成交量变化幅度与价格变化幅度的同向变化程度 |

### 3.5 量价背离在技术指标中的体现

量价背离在多个经典技术指标中有具体的表现形式：

**（1）价格与 OBV 的背离**

价格创新高但 OBV 未创新高 = 顶背离（上涨动能不足）；价格创新低但 OBV 未创新低 = 底背离（下方有承接）。这是 OBV 最核心的应用场景。

**（2）价格与 MACD 的背离**

MACD 柱状图的高度代表价格上涨/下跌的"加速度"。价格创新高但 MACD 柱状图变矮 = 上涨动能衰减。参见 [indicators.md](ref-indicators.md) MACD 章节。

**（3）价格与成交量的背离**

在 K 线图中直接观察：一段上涨趋势中，价格连创新高但成交量递减 = 顶背离；一段下跌趋势中，价格连创新低但成交量递增 = 底背离。

## 四、换手率分析

### 4.1 换手率的定义与分类

换手率是一类而非一个指标。常用的换手率类型包括：

| 类型 | 定义 | 特征 |
|------|------|------|
| 股本换手率 | 成交量 / 总股本 | 最基础的换手率，但总股本中包含限售股，会低估实际换手程度 |
| 金额换手率 | 成交额 / 总市值 | 消除了股价绝对水平的影响，便于横向比较 |
| 自由流通股本换手率 | 成交量 / 自由流通股本 | 更准确反映实际可交易筹码的换手程度 |
| 融资换手率 | 融资买入金额 / 总成交额 | 衡量融资盘的参与程度，杠杆资金的活跃度 |
| 异动换手率 | 基于高频分时数据遴选富有信息含量的成交部分 | 数值仅为股本换手率的约 1%，但信息含量更高 |

### 4.2 换手率与市场状态的关系

#### 4.2.1 量价协同：换手率与指数同步变动

自 2014 年以来，沪深 300 指数的"量"的顶底往往也是"价"的顶底，而这种协同关系在换手率层面同样存在。各种换手率（包括股本换手率、金额换手率、自由流通股本换手率、融资换手率、异动换手率）虽然数值大小存在差异，但与指数都存在不同程度的"量价协同"效应。

#### 4.2.2 量价背离：换手率用于"顶底识别"

利用换手率进行顶底识别的核心着力点在于识别**量价背离**。

具体来说：
- **顶部识别**：指数仍在创新高，但换手率已经开始下降（或换手率的上升速度明显放缓）→ 量价背离，顶部可能即将到来。
- **底部识别**：指数仍在创新低，但换手率已经开始上升（或换手率的下降速度明显放缓）→ 量价背离，底部可能正在形成。

#### 4.2.3 改进模型

在基础的长短均线模型（基于换手率的长期和短期均线交叉）上，存在多项改进空间：

**改进一：异动换手率更胜一筹**。异动换手率通过遴选高频分时数据中富有信息含量的成交部分，过滤了噪音交易，在择时信号上比传统换手率更精准。

**改进二：动量修正能有效逃顶**。在换手率模型的基础上叠加动量修正因子，可以有效改善在市场急跌时的信号滞后问题。

**改进三：融资换手率更加精准**。将金额换手率的分子端替换为融资买入金额得到的融资换手率，在识别市场顶部时比传统换手率更加灵敏。

### 4.3 换手率的绝对水平与市场含义

| 换手率水平 | 市场含义 |
|-----------|---------|
| < 1% | 极度低迷，流动性接近枯竭，可能处于长期底部区域 |
| 1%-3% | 正常偏低，市场人气一般 |
| 3%-7% | 正常水平，市场交投活跃 |
| 7%-15% | 高度活跃，短线资金大量参与 |
| > 15% | 极度活跃，可能存在投机过热或重大事件驱动 |
| > 30% | 极端换手，通常意味着筹码在急剧换手，多空博弈白热化 |

### 4.4 净换手率

从 Level-2 逐笔成交数据出发，结合量价信息反推投资者的买卖偏好，可以构建"净换手率"指标：

$$净换手率 = \frac{全天主动买入量 - 全天主动卖出量}{流通股本}$$

净换手率为正时，绝对值大说明投资者积极买入；净换手率为负时，绝对值大说明投资者恐慌出仓。该指标的关键在于它**带方向性**——传统换手率只是绝对值，不带方向性，不便直接看出多空力量对比。

## 五、资金流向分析

### 5.1 资金流向的计算原理

"资金流向"是 A 股投资者最常用的分析工具之一，但其计算方法存在重大缺陷。主流行情软件的资金流向计算逻辑如下：

将每天的交易时间按分钟切分（或按逐笔切分），如果某分钟 K 线股价是上涨的，则该分钟内的**全部成交金额**记为"流入"；如果某分钟 K 线是下跌的，则记为"流出"。

进一步的，按单笔金额大小将成交分为大单（如 >100 万元）、中单、小单。大单中上涨方向的成交记为"主力流入"，下跌方向的记为"主力流出"。

### 5.2 资金流向的已知缺陷

#### 5.2.1 方向归因的荒谬性

资金流向计算的根本问题在于：只要在某一个时间段价格出现上涨，则该时间段的所有成交金额都记为流入。这意味着——如果某投资者以市价卖出 100 万股，这笔交易被主动买入方吃掉导致价格上涨，那么这笔**卖出**交易会被记录为"流入 1000 万"。换言之，**资金流向测算的不是"谁在买卖"，而是"谁推动了价格变化"**。一个卖出的交易，只要对手方是用市价单买入的，就会被记为"流入"。这种归因逻辑在本质上是有误导性的。

#### 5.2.2 主力资金的识别困境

"主力资金"的定义本身就存在模糊性。主流软件通常将单笔金额超过一定阈值（如 50 万或 100 万）的成交归为"大单"，但一个大户的单笔 100 万买入和一个机构的拆单买入（每笔 99 万），在统计上可能被分别归为"大单"和"中单"，但实际上后者才是真正的机构行为。

#### 5.2.3 单日数据的噪音

单日的主力资金净流入/流出数据噪音极大，不具备可靠的预测能力。在对主力资金净流入进行标准化处理后，资金流出的速率更加平滑——这意味着应关注趋势性变化而非单日数据。

### 5.3 资金流向的正确使用方法

尽管存在上述缺陷，资金流向数据如果**正确使用**，仍然可以提供有价值的信息：

**（1）持续性比单日数据更重要**

连续 3-5 天的净流入比某一天的突然暴增更有参考价值。单日的巨额净流入可能只是个别大单的偶然行为，而连续多日的净流入才可能代表持续的资金建仓行为。

**（2）结合股价位置判断**

低位持续净流入可能是建仓信号，高位净流入反而要警惕出货——因为主力可能通过"对倒"手法制造流入假象。

**（3）注意量价配合**

如果股价上涨 + 主力净流入 + 成交量放大 = 多头信号较可靠。如果股价上涨 + 主力净流出（即散户在推高股价）= 需要警惕。

**（4）行业/板块级别的资金流向比个股级别更可靠**

个股级别的资金流向受单笔大单影响极大，噪音很高。但行业/板块级别的资金流向（将行业内所有个股的资金流向加总）可以有效平滑个别噪音，更能反映资金的真实偏好方向。

### 5.4 替代资金流向的分析方法

由于传统资金流向数据存在上述缺陷，更可靠的方法包括：

**（1）Level-2 逐笔数据分析**

使用逐笔成交数据（而非分钟聚合数据），可以更准确地判断每一笔交易的真实买卖方向。Lee-Ready 算法是学术界广泛使用的主动买卖判别方法，划分准确率较高。

**（2）大单推动涨幅因子**

构建"前 30% 的大单推动涨幅"因子：将日内成交量排名前 30% 的时间段对应的收益率进行累积。该因子衡量的是"真正由大资金推动的价格涨幅"，比传统资金流向数据更有意义。

**（3）净换手率（前文已述）**

净换手率指标通过主动买卖量之差来度量多空力量对比，是比传统资金流向更科学的替代方案。

**（4）量价相关性因子**

量价相关性因子从"价格与成交量的协同/背离程度"来间接推断资金行为，避免了传统资金流向数据的方向归因问题。

## 六、量价指标体系

量价指标定义为"在价格序列的特征上叠加了成交量信息，侧重于'量价配合'观点的表达"。核心量价指标包括：

| 指标 | 核心逻辑 | 关键信号 |
|------|---------|---------|
| OBV（能量潮） | 累积量价方向信息 | 量价背离、穿越零轴 |
| EMV（简易波动指标） | 量能效率（少量资金推升 = 筹码锁定好） | EMV > 0 = 量跌价增 |
| TAPI | 成交量 / 加权指数 | 与股价同步/背离 |
| WVAD（威廉变异离散量） | 以收盘价在高低价中点之上的程度对成交量加权 | WVAD 与 OBV 同时上攻 |
| CMF（蔡金资金流） | CLV（Close Location Value）对成交量加权 | 穿越零轴 |
| PVT（量价趋势） | 考虑价格变化幅度的 OBV | 趋势方向判断 |
| MFI（资金流量指标） | "成交量的 RSI" | 超买超卖、量价背离 |
| VR（成交量比率） | 上升日成交量 / 下降日成交量 | VR < 70 低迷、VR > 300 过热 |

## 七、量价分析的综合决策框架

```
步骤1：判断当前市场状态（趋势/震荡）
 ├─ 均线排列 + ADX > 25 = 趋势市
 └─ ADX < 20 = 震荡市

步骤2：观察当前量价形态
 ├─ 趋势市中：
 │ ├─ 上升趋势 + 量增价涨 = 趋势健康，持股
 │ ├─ 上升趋势 + 量缩价涨 = 警惕（区分控盘 vs 缺人气）
 │ ├─ 上升趋势 + 量增价跌 = 趋势可能结束
 │ └─ 下降趋势 + 量缩价跌 = 下跌正常延续
 └─ 震荡市中：
 ├─ 量缩价平 = 洗盘蓄势（上升通道中）/ 出货（高位）
 └─ 量平价平 = 多空不明，观望

步骤3：识别量价背离
 ├─ 价格创新高 + 成交量/换手率递减 = 顶背离
 ├─ 价格创新低 + 成交量/换手率递增 = 底背离
 ├─ OBV 与价格背离 = 量能方向信号
 └─ MACD 柱状图与价格背离 = 动能衰减信号

步骤4：换手率辅助确认
 ├─ 换手率处于历史低位 + 量价背离 = 底部概率高
 ├─ 换手率处于历史高位 + 量价背离 = 顶部概率高
 └─ 异动换手率/融资换手率提供更高精度

步骤5：资金流向验证（需谨慎使用）
 ├─ 连续多日净流入 + 低位 + 放量 = 建仓信号
 ├─ 单日暴增净流入 = 噪音，忽略
 └─ 板块级别资金流向 > 个股级别资金流向

步骤6：综合评分
 ├─ 多维度信号一致性越高，操作信心越强
 └─ 至少 3 个独立维度给出一致信号才考虑行动
```

## 八、量价分析的常见陷阱

### 8.1 "放量必涨"的迷信

放量并不一定意味着上涨。量增价跌是下降趋势中最常见的形态之一。放量只是说明多空分歧加大，至于是多方还是空方获胜，需要看价格方向。将"放量"等同于"利好"是初学者最常见的错误。

### 8.2 忽视量价背离的滞后性

量价背离是一个**渐变过程**，而非瞬时事件。顶部区域可能持续数周甚至数月的"价格创新高但量能递减"状态。如果在背离出现的第一个信号就反向操作，可能会承受巨大的时间成本和心理压力。正确做法是：**识别背离 → 提高警惕 → 等待确认信号 → 再行动**。

### 8.3 资金流向数据的过度依赖

如第五节所述，传统资金流向数据在计算逻辑上存在根本缺陷。如果完全依赖"主力净流入"数据做交易决策，长期来看大概率亏损。资金流向数据只能作为辅助参考，不能作为独立决策依据。

### 8.4 换手率的绝对值陷阱

不同市值、不同行业的股票，换手率的"正常水平"差异巨大。小盘股的日均换手率可能高达 10% 以上，而大盘蓝筹可能不到 1%。不能跨股票简单比较换手率的绝对值，应该与该股票自身的历史换手率水平进行比较（即换手率的分位数水平）。

### 8.5 对倒交易的误导

主力可以通过"对倒"（左手倒右手）人为制造成交量。对倒的目的是制造"放量"的假象，吸引跟风盘。对倒的特征通常是：成交量突然放大但价格变动不大，且后续走势与"放量"的方向不符。识别对倒需要结合 Level-2 数据和逐笔成交分析。

## 工具使用指导

使用 股价表现（ifind-ds-stock-mcp）获取量价分析所需的数据。

**九种量价形态判断**：
- query: "贵州茅台最近30日的收盘价、涨跌幅、成交量、成交额"
- LLM 根据涨跌幅方向 + 成交量变化方向，判断属于九种量价形态中的哪一种

**量价背离识别**：
- query: "宁德时代最近60日的收盘价、最高价、成交量"
- LLM 比较价格新高/新低与成交量变化趋势：
 - 价格创新高 + 成交量递减 = 顶背离
 - 价格创新低 + 成交量递增 = 底背离

**换手率分析**：
- query: "比亚迪最近60日的换手率"
- LLM 判断换手率绝对水平（<1%低迷 / 3-7%正常 / >15%极度活跃）及相对历史分位

**OBV/MFI 量价指标**：
- query: "中科曙光最近60日的OBV和MFI"
- OBV 与价格背离 = 量能方向信号
- MFI > 80 超买 / < 20 超卖

**资金流向（需谨慎使用，参见第五节缺陷说明）**：
- query: "贵州茅台最近10日的主力资金净流入净流出"
- 返回数据仅作辅助参考，必须说明资金流向的计算缺陷

**典型调用场景**：
```
用户问："宁德时代最近有没有量价背离？"
→ 数据需求："宁德时代最近60日的收盘价、最高价、成交量、OBV"
→ LLM 分析：价格是否创新高但成交量递减？OBV 是否与价格走势背离？
→ 结合换手率水平和位置判断，给出量价关系评估
```
