# 各大类资产分析框架

## 股票

股票是资产配置中收益弹性最大的资产类别，其长期回报来源于经济增长和企业盈利扩张。股票分析的核心维度包括盈利周期、估值水平、流动性和风险偏好。

盈利周期是股票定价的分子端驱动。盈利周期的观测指标包括工业企业利润增速、PMI新订单、上市公司业绩预告和财报。中国的盈利周期与库存周期高度相关，一轮完整的库存周期约3-4年，对应盈利的上升期和下行期各1-2年。盈利上行期股票通常表现较好，但估值变化可能放大或缩小盈利的贡献。

估值水平是分母端的核心变量。A股常用估值指标包括PE-TTM（滚动市盈率）、PB（市净率）、PS（市销率）及其历史分位数。不同行业适用不同估值指标：金融地产看PB，消费医药看PE，科技成长看PS或PEG。估值分位数的回看窗口一般取5-10年，过长的回看窗口可能包含不可比的结构性变化。

流动性和风险偏好是估值扩张或收缩的催化剂。国内流动性指标包括M2增速、社融增速、DR007、shibor；海外流动性指标包括美联储利率、美元指数、北向资金流向。风险偏好指标包括融资余额、新增开户数、换手率、偏股基金发行规模。当流动性充裕且风险偏好上行时，估值扩张推动股价上涨；当流动性收紧或风险偏好下降时，估值收缩可能抵消盈利增长。

## 债券

债券是资产配置中的「压舱石」，提供相对稳定的票息收益和较低波动率。债券分析按品种可分为利率债和信用债两大类。

利率债（国债、政策性金融债）的定价核心是实际利率和通胀预期。名义收益率 = 实际利率 + 通胀预期 + 期限溢价。10Y国债收益率是国内利率债定价的锚，其走势受货币政策（降准降息/加息收紧）、经济基本面（PMI、通胀）、资金面（超储率、DR007）、供需关系（国债发行节奏、银行配置需求）等因素驱动。利率债在衰退期的表现最佳，是资产配置中的对冲工具。

信用债在利率债基础上叠加了信用利差，信用利差反映违约风险补偿和流动性补偿。信用利差的走势受信用环境（社融、违约事件）、行业景气度、发行人资质等因素影响。城投债、产业债、地产债的信用利差走势分化较大，需要逐一分析。信用债的配置价值在于票息增厚，但信用风险事件可能导致利差骤然走阔，需要严格控制个券集中度。

债券的久期管理是利率风险管理的关键工具。久期衡量债券价格对利率变动的敏感度——久期5年的债券，利率上行10bp价格下跌约0.5%。在利率下行周期拉长久期增厚收益，在利率上行周期缩短久期控制回撤。

## 商品

商品是资产配置中与股债相关性较低的资产类别，具有抗通胀属性。商品分析的核心维度包括供需基本面、库存周期和金融属性。

供需基本面是商品定价的基础。原油受OPEC+产量政策、全球需求、地缘政治影响；铜受新能源需求和全球制造业景气驱动；铁矿石受中国房地产和基建投资影响；农产品受天气和种植面积影响。商品价格的波动率显著高于股债，不适合作为核心持仓，适合作为卫星配置。

库存周期是商品价格的重要驱动。一轮完整的库存周期分为被动去库存（价格低位反弹）、主动补库存（价格加速上涨）、被动补库存（价格见顶回落）、主动去库存（价格持续下跌）四个阶段。当前国内正处在从被动补库存向主动去库存过渡的阶段，商品整体承压。

商品的金融属性体现在与美元的负相关关系和与通胀的正相关关系。美元走强时以美元计价的商品价格承压，美元走弱时商品受益。通胀上行时商品作为实物资产具有天然对冲属性。CTA（商品交易顾问）策略通过做多和做空商品期货获取趋势收益，与股债的相关性较低，是机构投资者的常用另类配置工具。

## 黄金

华创宏观张瑜「金非昔比」和广发宏观「黄金定价框架和展望」两篇报告系统阐述了黄金的配置逻辑。黄金同时具备三大金融属性：抗通胀（与实际利率负相关）、避险（地缘冲突和金融危机时需求上升）、资产配置（与股债相关性低，分散化价值突出）。

黄金的定价框架可简化为三个变量：实际利率（持有黄金的机会成本，用10Y TIPS收益率近似）、美元指数（黄金以美元计价，美元走强压制金价）、避险情绪（VIX、地缘冲突指标）。实际利率是黄金定价最重要的单一变量——实际利率下行1%，金价通常上涨约5-8%。不过近年来黄金的走势与实际利率出现阶段性背离，这反映了央行购金（尤其是新兴市场央行）对黄金需求的支撑。

黄金在资产配置中的角色取决于投资目标。作为通胀对冲工具，黄金在滞胀环境下的表现最佳。作为避险资产，黄金在全球金融危机或地缘冲突期间提供保护。作为分散化工具，黄金与股债的低相关性使其成为组合中有效的多元化补充。配置比例通常建议5%-15%，过高会拖累长期收益（黄金不产生现金流，长期回报依赖价格升值）。

## 另类资产

另类资产包括私募股权、房地产、基础设施、对冲基金等，其共同特征是流动性较低但预期收益较高。耶鲁模式将另类资产配置比例提升至60%以上，核心逻辑是通过流动性溢价获取超额收益。

私募股权在投资组合中的价值在于获取企业成长溢价。一级市场的估值通常低于二级市场，成功退出时获得溢价回报。但私募股权的流动性差（投资期通常7-10年）、回报分布偏态（少数成功案例贡献大部分收益）、估值不透明等问题需要投资者具备专业判断能力。

基础设施投资（收费公路、港口、电力设施等）的特点是现金流稳定、通胀挂钩、垄断属性强，适合追求长期稳定收益的投资者。

### CTA策略
CTA（Commodity Trading Advisor）策略通过做多和做空商品期货获取趋势收益，与股债的相关性较低，是机构投资者常用的分散化工具。CTA策略的核心逻辑是商品价格的动量效应——趋势一旦形成，往往会持续数月。CTA策略在2016年商品牛市、2020年疫情后商品反弹中表现突出，但在震荡市中可能因频繁止损而产生回撤。

CTA策略在资产配置中的角色是「危机阿尔法」。历史数据显示，CTA策略在股债双杀时期（如2008年、2020年3月、2022年）往往能取得正收益或至少保持稳健，因为商品市场的趋势在宏观冲击中通常更加明确。配置比例建议5%-15%，过高会显著增加组合的波动率和复杂性。

### REITs
REITs（不动产投资信托基金）提供房地产市场的流动性入口，兼具股性和债性——股性体现在租金增长带来的资本利得，债性体现在稳定的股息分配。国内公募REITs自2021年上市以来，底层资产从产业园、高速公路扩展到仓储物流、保障性租赁住房等领域，流动性逐步改善。

REITs在资产配置中的价值在于提供通胀保护（租金通常与通胀挂钩）和分散化（与股债的相关性中等偏低）。配置比例建议5%-10%，重点关注底层资产的现金分红能力和租约稳定性。REITs的风险包括利率敏感性（利率上行压制估值）、集中度风险（单一项目占比过高）和流动性风险（二级市场成交尚不活跃）。
