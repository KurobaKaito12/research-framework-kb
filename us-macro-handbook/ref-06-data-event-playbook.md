# 数据事件点评操作手册（Data Event Playbook）

> CPI、非农和GDP数据发布后的标准化点评流程与模板。

---

## CPI数据点评——7步流程

前置：读取 [ref-03](ref-03-inflation.md) + [ref-fw-04](ref-fw-04-tariff-and-supply-shocks.md) + [ref-fw-05](ref-fw-05-market-pricing-framework.md)

风格要点：①标题=一句话定性 ②三维度对比（实际vs预期vs自预测） ③分项有数据有逻辑 ④量化阈值推演 ⑤"往前看"场景分叉 ⑥配置含义

```
# X月CPI点评：[一句话定性]

## 一、定性+市场反应
一句话概括数据性质（如"高了但没那么高""虚惊一场""不在高而在持续多久""缓解鹰派压力"）
+ 各类资产即时反应（美债/美元/美股/黄金变化方向和幅度）
+ **2Y vs 10Y方向分化**：若2Y跌10Y涨→曲线趋平→风险溢价重定价；若同向→方向性交易主导

## 二、数据概览（三维度对比）
| 指标 | 实际 | 一致预期 | 自预测 | 前值 |
|------|------|---------|-------|------|
| CPI环比 | | | | |
| CPI同比 | | | | |
| 核心CPI环比 | | | | |
| 核心CPI同比 | | | | |
→ 偏差来源：整体vs核心谁偏离预期？偏离方向？

## 三、分项拆解（能源→食品→核心商品→核心服务）
逐项环比+同比+逻辑解释（每个分项1-2句话）

**分项框架采用五分类法**（按价格形成机制分组，替代传统六分类）：
| 分类 | 权重 | 驱动逻辑 | 关注点 |
|------|------|---------|--------|
| 食品 | ~14% | 供应链/天气 | 短期扰动 |
| 竞争性商品 | ~20% | 关税+全球化竞争 | **关税传导斜率**是否递减 |
| 竞争性服务 | ~17% | 需求+工资 | 除房租外核心服务环比 vs 前3月均值 |
| 房租 | ~36% | 滞后市场租金6-12月 | OER样本轮换效应 |
| 政府管控类 | ~13% | 政策决定 | 医疗/教育等 |

逐项展开：
- 能源：油价传导阶段？零售汽油vs批发？电力是否跟随？**油价→CPI传导弹性：油价每涨10%→能源CPI+2.4%→总体CPI+0.15pp**（比早期估算的+0.2-0.3pp更精确）
- 食品：供应链/天气影响？
- 核心商品→竞争性商品：
  - **关税传导斜率**（关键）：家电/服装/体育用品环比是否在减速→制造商无法完全转嫁成本→传导在减弱而非增强→与"关税必然推高通胀"的线性思维矛盾
  - 二手车vs Manheim？机票从极端值回归？
- 核心服务→房租+竞争性服务：
  - 房租OER环比（vs前值是否异常→**6个月样本轮换效应**→某批次采样时租金涨幅弱→对应月份OER补偿性偏强→下月技术性反转）→**必须在分项中标注"样本轮换效应"及预计反转方向**
  - 除房租外核心服务环比 vs 前3月均值→需求趋弱信号
  - **超核心CPI**（非住房核心服务，权重31.5%）→粘性通胀关键→必须单独跟踪环比趋势。**注意1月调价效应**：1月超级核心跳升是年复一年的规律（商家年初集体涨价），属季节性而非趋势性，不应过度解读
  - 运输/机票（能源关联）
- **季调因子检查**：1月数据需对比非季调vs季调环比，若季调环比偏离远大于非季调→季调因子是主因
- 特殊关注：与自预测的偏差来源
- **CPI→PCE映射**：Cleveland Fed实时估算PCE环比/同比→必须报告（居住/医疗权重差异导致PCE通常低于CPI）

## 四、供给冲击影响评估
- 关税对核心商品→竞争性商品：传导处于哪个阶段？是否已反映在服饰/汽车？**传导斜率是在增强还是减弱？**
- 油价对headline：是否已完全反映？二轮效应是否开始显现（扣掉能源后核心商品/服务是否有异动）？
- 前期冲击消退进度

## 五、趋势判断+量化推演
- 基数效应+环比趋势 → 未来3个月同比路径
- **关键量化阈值**：
  - "油价每上涨10%推高整体CPI约0.15pp"（更精确估算）
  - "油价中枢$80→CPI高点3.1-3.2%；$100→3.5%与基准利率持平→Fed难降息"
  - 核心PCE映射（CPI→PCE调整：居住/医疗权重差异）
- 粘性vs弹性拆分：哪个在驱动？
- **Trimmed Mean CPI + 粘性CPI交叉验证**：报告克利夫兰联储Trimmed Mean CPI（剔除8%-92%极端值，若仍在3%+→通胀广度未真正缓解）+ 亚特兰大联储粘性CPI（回落→持久性在减弱）→两指标方向是否一致？与核心CPI方向是否一致？
- 通胀预期（1Y/5Y BEI，密歇根预期）
- **展望路径**：CPI同比Q2见峰→能源冲顶+OER一次性技术效应+关税高基数消退→后续回落节奏

## 六、Fed含义
- 降息条件量化：基准利率 vs CPI水平→空间存在但被什么堵住？
- 降息是"延后"还是"逆转"？→区分两种情景（核心区分）
- 降息时间线推演：需要什么条件打开？（油价回落？地缘缓和？）
- Fed"看穿"（look through）短期扰动的条件
- **Warsh因素**：新任主席可能更依赖就业趋势（中枢）而非单月数据→中枢下移=增长缺口扩大=降息必要性提升→与"延后非逆转"逻辑一致但更量化
- **油价→Fed决策门槛**：油价成为Fed决策关键变量的门槛很高→与"$100分水岭"逻辑一致

## 七、前瞻+场景分叉
- 下月CPI前瞻（基数+领先指标+冲击评估）
- **场景分叉**：
  - 情景1：油价在这一位置震荡→Fed可以"看穿"→降息延后非逆转→利率敏感品种可左侧布局
  - 情景2：油价再度冲高后回落→货币政策实质扰动不大→但可能给金融资产带来瞬时冲击→美元独强→避险资产也承压
  - 关键监测指标：美元走势（流动性压力指标）
- 配置含义：利率敏感 vs 确定性景气 vs 防守
```

## 非农数据点评——7步流程

前置：读取 [ref-02](ref-02-labor-market.md) + [ref-fw-03](ref-fw-03-monetary-fiscal-cycle-transmission.md) + [ref-fw-06](ref-fw-06-ai-capex-and-consumer-kshape.md)

风格要点：①标题=一句话定性 ②表面vs底层 ③噪音因素识别（罢工/天气/基数） ④多个月均值平滑波动 ⑤AI就业替代单独点明 ⑥"降息是延后非逆转" ⑦$100油价分水岭

```
# X月非农点评：[一句话定性]

## 一、定性+市场反应
一句话概括数据性质（如"中规中矩""明弱实强""也没看起来的那么强""全面超预期""爆冷"）
+ 资产即时反应（美债/美元/美股方向+幅度）

## 二、数据概览
| 指标 | 实际 | 预期 | 前值 | 方向 |
|------|------|------|------|------|
| 新增非农 | | | | |
| 失业率 | | | | | **保留两位小数**（如4.26%→4.33%四舍五入后都是4.3%但方向是上升→方向比整数更重要）
| 劳动参与率 | | | | |
| 平均时薪环比 | | | | |
| 平均时薪同比 | | | | |
| 平均工时 | | | | |
+ 基准变动/前值修正方向和幅度

## 三、表面vs底层
**表面**（标题数字）：非农超预期/不及预期 → 市场"应激反应"
**底层**（扒开表面）：
- 前2个月修正方向和幅度→是上修还是下修趋势？
- 参与率+总就业人口趋势
- 薪资增速vs预期
- **超预期/不及预期的来源是否过于集中？**（如单靠医疗保健一个行业贡献大部分→数据强劲程度大打折扣）
- 政府 vs 私人就业拆分
- **噪音因素识别**：罢工恢复？天气/气温？基数效应？
- **企业端vs居民端背离检查**：新增非农（企业调查）偏强但就业者减少+参与率下降（居民调查）→信号混杂→**居民端更准确反映劳动力市场疲软**→点评中应同时报告两端
→ 表面和底层是否指向一致？

## 四、就业结构拆解
- 拉动行业 vs 拖累行业
- **行业集中度指标**：教育&医保在非农中占比→占比回落=结构更健康，占比偏高=数据含金量打折
- **罢工/天气恢复**：教育健康/建筑/休闲酒店→恢复性增长属正常
- **AI影响行业**：信息/金融是否继续萎缩？（6个月累计数据）
- 家计调查vs企业调查方向是否一致？
- **多个月均值平滑**：将最近3-4个月平均→消除"过山车"波动→真实趋势是多少？
- **劳动力供给不可逆收缩**：55岁以上参与率逼近疫情低点+非法移民禁入→双重冲击→难以逆转→结构性压低潜在增长

## 五、供需缺口+工资-通胀链条
- 职位空缺/失业人数比（JOLTS最新）
- "低雇低辞"均衡是否持续？
- 初请确认+萨姆规则距离
- 时薪趋势（3M年化 vs 6M年化）→是否在回落？
- AI对工资的压制效应是否可观测？
- 工资→核心服务通胀传导阶段
- **"盈亏平衡"非农中枢**（Fed官方测算）：25Q4=5.7万→26Q1=3.6万→26Q4=0.5万→零增长即均衡→**新增就业中枢持续下移→中枢下移>Fed降息信号**
- **核心通胀三分法**（与CPI五分类对应）：核心商品（24.2%，看关税与地缘）+ 住房（44.3%，继续降温）+ 超核心（31.5%，粘性关键）→就业数据→工资→超核心传导是关键链条

## 六、Fed含义
- **核心判断**：就业数据是"回归正常"还是"趋势性转变"？
- 双目标拉扯：就业温和增长 vs 通胀约束→Fed困境
- **降息是"延后"还是"逆转"？**→核心区分
- 降息"堵点"在哪？（油价？Fed内部分歧？换届？政治因素？）
- 从实际利率vs自然利率角度看：是否仍需降息？（如"实际利率仍高于自然利率约50bp→仍需2-3次降息"）
- **$100油价分水岭**：油价维持$100以上到年底→CPI>3.5%→Fed年内无法降息；否则降息延后非逆转
- **Warsh因素**：新任主席可能更依赖就业趋势中枢而非单月数据→中枢下移=增长缺口扩大=降息必要性提升→与"延后非逆转"逻辑一致但更量化
- 政治约束：中期选举→Trump需要"降本"→最终方向偏宽松

## 七、前瞻+场景分叉
- 2Y/10Y/美元/美股/黄金→市场反应是否过度/不足？
- **场景分叉**：
  - 情景1：地缘缓解+油价回落→降息预期回归→利率敏感品种可左侧布局（美债/黄金/恒科/创新药）
  - 情景2：局势恶化+油价维持$100+→降息无望→计入悲观预期不足的权益市场承压→聚焦确定性景气或防守
- 关键变量：油价/地缘→降息预期→资产方向
- 下月非农前瞻+下一个关键数据
```

## GDP数据点评——7步流程

前置：读取 [ref-01](ref-01-gdp-and-growth.md) + [ref-fw-01](ref-fw-01-cycle-positioning.md) + [ref-fw-02](ref-fw-02-transmission-chains.md)

风格要点：①标题=一句话定性 ②表面vs驱动结构 ③季节/天气/基数等噪音识别 ④"滚动式放缓"框架 ⑤区分"放缓"vs"衰退" ⑥反身性逻辑 ⑦配置含义

```
# X季度GDP点评：[一句话定性]

## 一、定性+市场反应
一句话概括数据性质（如"大超预期但市场反应平淡""衰退休矣？降息休矣？""继续放缓但程度不深"）
+ 资产即时反应（美债/美元/美股方向+幅度）
+ **市场反应是否与数据强度匹配？**（如GDP大超预期但市场平淡→预期已计入/更关注前瞻/数据是过去时）

## 二、数据概览（三维度对比）
| 指标 | 实际 | 一致预期 | 前值(修正后) | 方向 |
|------|------|---------|-------------|------|
| 实际GDP环比折年 | | | | |
| GDP同比 | | | | |
| GDP平减指数 | | | | |
+ 前值修正方向和幅度（如一季度从-2.9%上修至-2.1%）
→ 偏差来源：超预期/不及预期的主因是什么分项？

## 三、分项贡献拆解（消费+投资+库存+净出口+政府）
逐项贡献度（ppt）+环比变化+逻辑解释：

**标准拆解框架**：
| 分项 | 贡献(ppt) | vs上季 | 驱动逻辑 |
|------|----------|--------|----------|
| 个人消费 | | | 服务vs商品拆分；耐用品vs非耐用品 |
| 住宅投资 | | | 抵押贷款利率压制 vs 成屋低库存补库 |
| 非住宅投资 | | | 制造业建筑（财政刺激）vs 设备/知识产权 |
| 库存变动 | | | 主动去库 vs 被动去库 vs 提前"抢跑"进口补货 |
| 净出口 | | | 出口vs进口谁主导？进口抢跑关税？ |
| 政府支出 | | | 国防/非国防/州地方 |
| **核心GDP(PDFP)** | | | 剔除库存+净出口+政府后的内生需求 |

逐项展开：
- **消费**：服务消费（医疗保健为主要贡献）vs 商品消费（机动车/娱乐设备等耐用品）→消费韧性来源是什么？超额储蓄耗尽进度？→**核心马达切换**：从低收入人群的"超额储蓄"→高收入人群的"超额财富"（股房财富效应）→如果美股下跌将冲击这一防线
- **住宅投资**：是否受降息后成本下降推动？（9月降息→4季度住宅改善的传导）→但利率再度走高后能否持续？成屋低库存导致新屋开工虚强？
- **非住宅投资**：制造业建筑支出占非住宅投资比例~5%，属结构性（产业政策刺激）非趋势性→不能以此判断投资周期重启→**制造业从建厂期→设备购置期**：厂房投资回落+信息设备/工业设备增长→AI驱动设备投资是新动能
- **库存**：大幅去化是暂时的（假期因素）还是主动去库存？进口抢跑关税前置需求？→**生产商/批发商 vs 零售商分层**：生产批发去库但零售仍补库→若需求端无法消化零售库存→后续补库力度有限
- **净出口**：进口拖累扩大→关税前"抢跑"补货→需求被前置而非消失→**Q1抢进口+Q2完全反转是"完美镜像"**→需在Q2点评中标注
- **政府支出**：国防支出波动→新政府到位后政策兑现节奏→**CBO财政预算更新**→财政空间可能被放大
- **核心GDP（PDFP）**：私人国内最终购买（Private Domestic Final Purchases）= 消费+固定投资→剔除高波动的库存+净出口+政府→**PDFP连续回落=内生增长动能在走弱**，即使headline GDP走强→"外强中干"

## 四、噪音/暂时性因素识别
- **季节/天气效应**：一季度寒冷天气拖累→二季度反弹是天气恢复而非趋势加速（反复强调的"暂时性因素"）
- **基数效应**：前值大幅下修→对比基数变化
- **GDPNow vs 最终值**：亚特兰大联储GDPNow模型平均绝对误差0.8ppt→当前预测非最终值→越接近披露时间越准
- **"滚动式放缓"**（核心框架）：本轮周期最大特点→各环节呈正弦波式交替下行→不同环节时间错位→对冲抵消→加总看起来没衰退→但大方向仍是放缓
- **抢跑/前置效应**：大选/关税前进口和库存前置→短期推高二季度但透支未来
- **噪音剔除法**：将净出口+库存变动+政府支出三大噪音项剔除→计算"核心GDP环比折年率"→与headline对比→若核心>headline→数据比看起来好；若核心<headline→"外强中干"
- **"技术性衰退"vs"危机性衰退"**（核心区分）：
  - 技术性衰退：GDP环比折年率单季转负，但消费/投资内需项未崩塌→由净出口/库存拖累→属于库存周期小波动
  - 危机性衰退：消费+固定投资同时转负→NBER定义衰退→这才是真正的衰退
  - **判断标准**：消费+投资内需是否崩塌→而非headline是否连续两季负增

## 五、趋势判断+"放缓vs衰退"核心区分
- **核心判断**：不需要动辄担心深度衰退，也不用亢奋判断再加速→更可能是"软着陆"中间状态
- **切换"新动能"还需时间**：从消费驱动→投资+地产驱动需要降息传导，当前高利率反身性仍压制
```
