## 核心判断逻辑

**就业数据是美联储政策的直接锚。** 非农和失业率是FOMC最关注的数据之一，就业强弱直接影响降息/加息概率→2Y利率→整条曲线。

**供需缺口>失业率。** 疫情后供给冲击（超额退休+超额致死）使失业率的衰退信号变弱，职位空缺/失业人数比更能反映劳动力市场松紧。缺口→时薪增速→核心服务通胀的传导链条是核心。

**初请失业金是最及时的衰退预警。** 滞后仅5天，初请>260K持续数周→衰退信号。萨姆规则触发意味着衰退已开始，不是即将开始。

**非农频繁下修≠政治操纵。** 近期CES首次回复率下降→下修频次增加，但历史规律未显示连续下修与经济周期间有显著相关性。

**ADP不是非农的前瞻指标。** 两者数据源和口径不同，各有优劣，不能以ADP预测非农方向。

## 五、劳务市场研究框架

**三套就业统计数据对比**：

| 指标 | 来源 | 优势 | 劣势 |
|------|------|------|------|
| ADP(小非农) | 私人行政/工资数据 | 周频更新，真实交易数据 | 选择性偏差（仅ADP客户） |
| CES(大非农) | 企业问卷调查 | 官方指标，最权威 | 存在修正问题；首次回复率下降→下修频次增加 |
| CPS(家计调查) | 家庭问卷调查 | 用于计算失业率 | 与CES口径不同（含自雇/农业等） |

**注意**：ADP不是CES的前瞻指标，各有优劣。近期非农频繁下修≠政治操纵，历史规律未显示连续下修与经济周期间有显著相关性。

**供给-需求-缺口框架**：

| 维度 | 定义 | 含义 |
|------|------|------|
| 劳务供给 | 在职者+失业者 | 本国劳动力缺口vs外国补充；疫情超额致死+超量退休→难以完全修复；移民限制进一步减少供给 |
| 劳务需求 | 在职者+职位空缺 | 已基本修复至疫情前，增量空间有限；关税不确定性压制招聘 |
| 供需缺口 | 需求-供给（需求主导） | 缺口→时薪增速；1965年至今供需缺口与工资增速走势趋同 |

**两条策略启示**：
1. **供给难以完全修复→供需缺口难以闭合→工资通胀中枢抬升**→软着陆情形下通胀难回2%
2. **失业率不再仅由需求驱动→萨姆规则衰退判断力变弱**：疫情供给冲击打破原有模式→萨姆规则阈值或抬升；但一旦触发仍会引发衰退交易

## 六B、"Low Hire / Low Fire" 均衡（新增）

**MS核心概念**：移民限制→劳动供给↓ + 关税/不确定性→劳动需求↓ → 供需同步萎缩

```
劳动力供给↓（移民大幅减少+超额退休缓退）
劳动力需求↓（关税不确定性+企业延迟招聘）
        ↓
   "低雇低辞"均衡
        ↓
失业率变化不大，但就业市场活力显著下降
```

**特征**：
- 招聘率低→求职者找工难
- 解雇率低→在职者安全感强
- 职位空缺下降→跳槽减少→工资议价力减弱
- 月均就业增幅从200k+降至50-70k

**对宏观的含义**：
- 失业率不会大幅上升→萨姆规则难触发→传统衰退信号弱化
- 但就业增长持续低迷→实际劳动收入增长受限→消费增长温和
- 工资增速缓慢回落→不是通胀驱动因素，但也不快速降温
- **劳动力市场降温主要通过"招聘减少"而非"裁员增加"**→更温和但更持久

**移民对潜在增长的影响**：
- MS估计：移民减少拖累潜在GDP增长约0.5pp
- 总量GDP增长放缓，但人均可能改善（取决于移民技能结构）
- 详见 [ref-fw-06](ref-fw-06-ai-capex-and-consumer-kshape.md#七移民与潜在增长)

## 六C、AI对就业的影响框架（新增）

**核心原则：替代任务而非替代职业**

- 全球24%工作岗位（~8.4亿）暴露于AI→高收入国家33.5%
- 但暴露≠替代→历史表明技术创造的新岗位>消灭的
- 美国当前60%的职业在1940年不存在

**替代效应 vs 复位效应**：
- 替代：AI接管特定任务→相关岗位减少
- 复位：新任务/新职业出现→人类保持比较优势
- 生产率效应：收入↑→需求↑→新需求创造新就业
- **历史上复位+生产率效应>替代效应**

**当前宏观影响**：
- AI对失业率的上行压力<0.1pp→宏观可忽略
- 52%股权分析师预计AI小幅减少员工→42%预计无影响
- 青年失业率上升主要反映疫后正常化+结构因素→非AI直接替代

**更大的风险：资本vs劳动不平等**：
- AI生产率收益流向资本>劳动→劳动收入份额↓
- 职业内工资不平等加剧→资历高受益，新手受压
- 若无财政再分配→K型分化加剧

**WF洞察（4月）**：AI驱动的效率提升对工资增长施加持续下行压力→非农就业增长已停滞→实际收入（扣转移支付）增长放缓→油价冲击可能使实际收入转为负增长→K型分化中低收入群体进一步受压

**新形态**：Agentic AI→OPC（一人公司）→降低创业门槛→净创造就业→但重组传统组织

## 六、就业：市场定价

就业数据对美债的传导核心路径：

```
非农强 → 降息预期↓ → 2Y↑ → 10Y↑（政策驱动）
初请持续>260K → 衰退预期↑ → 2Y↓ → 曲线陡化
时薪↑ → 通胀预期↑ → BEI↑ → 10Y↑（工资-通胀螺旋）
职位空缺/失业<1 → 缺口闭合 → 降息条件接近
```

## 快速判断清单

- [ ] 新增非农方向及3个月均值趋势
- [ ] 失业率+劳动参与率组合：参与率下降导致的失业率走低≠就业改善
- [ ] 职位空缺/失业人数比是否接近1.0（平衡点）
- [ ] 初请失业金是否持续>260K（衰退信号）
- [ ] 萨姆规则是否已触发（3个月均失业率较12个月低点↑0.5pp）
- [ ] 时薪环比是否>0.3%（通胀压力信号）
- [ ] ECI季度数据是否显示工资增速拐点
