# 增长（Economic Growth）

> 层次：实际产出 → 消费与收入 → 投资与地产 → 工业与库存 → NFIB小企业 → 市场定价

---

## 核心判断逻辑

**消费是增长的基本盘，投资是波动的放大器。** 消费占GDP 70%，决定增长中枢；投资占~18%但波动最大，决定增长方向。分析增长，先看消费稳不稳，再看投资变不变。

**消费正在K型分化。** 低收入群体受政府削减+移民限制+关税冲击，购买力最弱；中收入受益于薪资增长，增长最强；高收入受益于财富效应。总量稳健可能掩盖结构脆弱性。

**油价冲击对消费的影响不对称。** WF分析：服务占消费>50%且多为非可选→整体消费对油价敏感度随时间下降；但低收入群体能源支出占比更高→K型分化加剧。中度油价冲击减缓但不逆转消费增长；只有大规模持续冲击才可能引发衰退级收缩。

**AI投资是结构性的增长引擎，但净贡献远低于毛贡献。** AI Capex（计算机/软件/数据中心/电力）保持强劲，但大量设备依赖进口→扣除进口后对GDP净贡献缩水60-80%。增长结构从消费驱动转向capex驱动。详见 [ref-fw-06](ref-fw-06-ai-capex-and-consumer-kshape.md)。

**地产是美债利率最直接的实体传导渠道。** 10Y利率→房贷利率→地产销售→住宅投资→房价→房租CPI（滞后15-18M），链条清晰且时滞可量化。地产回暖反而强化美联储紧缩决心（通过房租CPI传导）。

**PMI提供方向而非幅度。** ISM制造业PMI更多提供收缩/扩张的方向性判断，预期成分大会放大真实波动。客户库存→新订单→整体PMI的内部传导链条是中期核心。

**库存周期是短周期的锚。** 库存周期~4年，是经济波动最短的周期驱动。PMI客户库存高位→未来新订单回升潜力大，(新订单-自有库存)缺口领先整体PMI约3-6个月。

**GDP与GDI均值比单值更可靠。** 两者理论上应等，实际有统计误差；大幅偏离时需关注均值信号。

**GDP解读方法论**：
- **美国GDP用环比折年率**（假设全年每季同样增速），非同比——与国内习惯不同
- **拆解四分法**：私人消费 + 私人投资(含库存) + 净出口 + 政府支出，分别看拉动率
- **消费"商品弱服务强"**：疫后常态，服务消费韧性>商品，跟踪重点在服务消费
- **私人投资三大块**：建筑/设备/知识产权(非住投资) + 住宅投资 + 库存变动，库存投资波动大常拖累GDP
- **衰退判定**：纽约联储衰退概率模型 + GDP环比连两季为负（技术性衰退，但NBER看更多指标）
- **GDP实时预测**：亚特兰大联储GDPNow，随数据发布持续更新
- **GDP vs GDI**：理论上应等，实际有统计误差；均值更可靠，大幅偏离时需关注

**关键时滞关系**：
- 10Y美债利率↔30Y房贷利率：几乎同步
- 美债利率变动→地产销售增速：反向关系，领先1-3个月
- 新屋销售→新屋开工：滞后约5个月
- 成屋销售→成屋改造：滞后4-6个月
- 成屋销售→中介佣金：基本同步
- 10Y美债利率环比变动→住宅投资GDP：领先约2个季度
- 房价→房租CPI：领先约15-18个月

**住宅投资拆分**：

| 分项 | 占住宅投资比 | 驱动 | 时滞 |
|------|------------|------|------|
| 新房建设 | 46% | 新屋销售 | 滞后5个月 |
| 成屋改造 | 33% | 成屋销售 | 滞后4-6个月 |
| 中介佣金 | 16% | 成屋销售 | 同步 |

**重要结论**：成屋销售对住宅投资的影响>新屋销售（49% vs 46%），因美国成屋占地产销售90%+，人均居住面积~70平米已饱和→置换需求>增量需求

**"惜售"效应**：前期低利率再融资→成屋业主不愿卖（换贷成本高）→成屋库存低位→推高房价→新房销售相对受益

**地产对通胀影响**：①建筑业就业/薪资韧性→核心非房租服务通胀↑ ②房价→房租CPI（滞后18M）→年内地产回暖反而强化美联储紧缩决心

**地产后周期消费**：2000年前地产销售领先后周期耐用品消费6个月，近20年关系弱化→耐用品消费进入自身置换周期

**ISM制造业PMI内部传导链条**：

```
客户库存(逆相关)→新订单(1M)→产出(2M)→就业(5M)→自有库存→(6M-1Y)→客户库存(闭环)

```

**PMI解读要点**：
- PMI更多提供**方向性判断**（收缩/扩张），而非幅度——预期成分大，会放大真实波动
- **中期指标**：客户库存→驱动新订单→驱动整体PMI。客户库存高位→未来新订单回升潜力大
- **短期指标**：(新订单-自有库存)缺口领先整体PMI约3-6个月
- **外部环境**：金融条件放松(美联储转鸽)→有利于PMI反弹
- ISM vs Markit PMI：统计口径不同但长期不分化，短期分歧不改变趋势
- ISM制造业PMI领先美国实际GDP同比约3个月
- **价格指数**：PMI价格指数≈PPI→企业盈利→设备投资→经济韧性"蝴蝶效应"
- **PMI与市场**：ISM制造业PMI与标普500盈利增速、铜金比高度相关

## 快速判断清单

- [ ] GDP环比折年率方向及四分法贡献（消费/投资/净出口/政府）
- [ ] 消费：个人支出环比 + 储蓄率趋势 + 信用卡拖欠率是否恶化
- [ ] 地产：30Y房贷利率→销售→开工传导是否顺畅，NAHB领先信号
- [ ] PMI：ISM制造业是否扩张，客户库存→新订单→产出内部链条
- [ ] 库存：库销比趋势，(新订单-自有库存)缺口方向
- [ ] 地产传导至通胀：房价→房租CPI的15-18M滞后效应是否已计入
- [ ] 经济意外指数是否偏强/偏弱，增长因子对10Y的贡献方向
