# 央地财政关系与地方财力

## 3.1 央地财税关系沿革

| 阶段 | 特征 |
|------|------|
| 统收统支（1949-1978） | 高度集中"一灶吃饭" |
| 分灶吃饭（1978-1994） | 改革开放放权让利；中央财政"两个比重"急剧下滑 |
| **分税制（1994至今）** | 国发[1993]85号；划分中央税、地方税、共享税；建立中央对地方转移支付制度 |

**分税制的成果与遗留问题**：
- 中央税收占比从1993年21%大幅提升至1994年55%，此后稳定50%左右
- 地方支出比重却不降反升（1994年70% → 2020年86%）
- "事权与支出责任不匹配"是地方融资平台和"土地财政"的制度根源

| 维度 | 内容 |

- **中央事权**：国防、外交、出入境管理、国防公路等
- **地方事权**：社会治安、市政交通、农村公路、城乡社区事务
- **共同承担**：义务教育、高等教育、科技研发、基本养老保险、基本医疗等

## 3.3 转移支付：中央对地方的纵向调节

中央对地方转移支付占地方一般公共预算收入约50%，是地方财政重要血液。

### 三类
| 类型 | 用途 | 特征 |
|------|------|------|
| 一般性转移支付 | 平衡地区间财力差距 | 地方政府可统筹使用 |
| 共同财政事权转移支付 | 履行共同事权 | 2019年新设 |
| 专项转移支付 | 指定用途 | 不可挪用 |

> 2019年决算报告将"税收返还"科目直接纳入"一般性转移支付"统计。

### 当前规模与趋势
- 2025年中央对地方转移支付超10万亿（同口径增8.4%）
- 2024年起强化"财力下沉"——更多向困难地区、市县基层倾斜
- 2026年继续强调兜牢"三保"（保基本民生、保工资、保运转）

## 3.4 地方财力的概念辨析

### 几个相近的概念

| 概念 | 定义 | 用途 |
|------|------|------|
| 地方一般公共预算收入 | 税收+非税（狭义概念） | 统计年鉴口径 |
| 地方财政总收入 | 地方一般预算收入+上划中央收入 | 反映本地税收创造能力 |
| 一般公共预算收入总计 | 地方一般预算收入+转移性收入+债务收入 | 反映可安排资金 |
| 地方财政收入 | 各地表述不一 | 看具体地方文件 |

**关键勾稽**：
```
地方一般公共预算收入 = 地方本级收入 + 中央对地方转移支付
地方本级收入 = 税收收入 + 狭义非税收入
```

### 地方财力两种官方计算

**方法1：分预算收支表计算**（数据完备性要求低）

| 科目 | 公式 |
|------|------|
| 一般公共财力 | 地方本级一般预算收入+上级补助+调入资金+上年结转-下级上解 |
| 基金财力 | 基金收入+上级补助+上年结转-下级上解 |
| 国资财力 | 国资收入+中央补助+上年结余 |
| **地方综合财力** | 三者之和 |

**方法2：财政部官方公式**（财预[2017]35号）

```
某地区政府财力 = 一般公共预算财力 + 政府性基金预算财力
某地区一般公共预算财力 = 本级一般预算收入 + 中央（上级）补助 - 上解支出
某地区政府性基金预算财力 = 本级基金收入 + 中央（上级）基金补助 - 基金上解
```

> 方法1能展示完整图景，方法2更准确反映可支配财力。

## 3.5 财政自给率：地方财政自我保障能力

```
财政自给率 = 一般公共预算收入 / 一般公共预算支出
```

**省级三梯队**：
- 第一梯队（>50%）：沪、京、粤、津、苏、浙、闽、辽（约8省市）
- 第二梯队（35-50%）
- 第三梯队（<35%）：欠发达地区

**地市层面**：
- 多数省份内部自给率最高的是省会城市
- 江浙地区苏杭自给率超100%
- 同时也有7个地级市低于50%

## 3.6 非税占比：观察地方财政质量

非税占一般公共预算收入比重各省差异大：
- **>30%**：贵州、新疆、宁夏、黑龙江等（财政质量较弱）
- **<20%**：浙江、北京、上海、江苏（财政质量较高）

**判断逻辑**：非税占比高 → 地方财政"挤水分"信号、依赖性强；非税占比低 → 税基扎实。

> 2025年前11月**非税收入累计同比下降-14.7%**，是2026年观察地方"挤水分"动态的重要切入点。

## 3.7 地方政府债务率与红橙黄绿分档

### 演变三阶段

| 阶段 | 时期 | 特征 |
|------|------|------|
| 阶段1 | 2011年起 | 4个分析指标：债务率、偿债率、逾期债务率、借新还旧偿债率 |
| 阶段2 | 2014年43号文后 | 一般/专项债务率、综合债务率（加权） |
| 阶段3 | 2020年起 | **"红橙黄绿"分档** |

### 红橙黄绿分档（核心）

| 档位 | 债务率区间 |
|------|-----------|
| 红 | ≥300% |
| 橙 | 200% ≤ 债务率 < 300% |
| 黄 | 120% ≤ 债务率 < 200% |
| 绿 | < 120% |

```
债务率 = (一般债余额 + 专项债余额) / (一般公共预算财力 + 政府性基金预算财力)
```

### 当前情况

- 2020年末全国地方政府债务率约97%，近年突破100%
- **化债推进后债务率边际改善**——12万亿置换降低利息成本2.5个百分点+
- 借新还旧偿债率上升（2020年达63%）反映高度依赖滚续

## 3.8 园区财政

园区（开发区/高新区）有"一级财政"和"非一级财政"两种：
- **一级财政**：开发区设立金库、单独编报预算
- **非一级财政**："两块牌子、一套人员"运行

### 园区财政分析的四个指标

| 指标 | 含义 |
|------|------|
| 财政自给率 | 自我保障能力 |
| 税收占比 | 财政质量 |
| 补助依赖度 | 上级补助/一般预算收入 |
| 土地财政依赖度 | 国有土地出让金/一般预算收入 |

**对比示例**：
- 广州开发区：财政自给率高、税收占比高、对补助依赖低（独立性强）
- 部分中西部园区：补助依赖度高、土地财政依赖度高

## 3.9 看地方财力的"五个维度"

1. **看自给率**：高(>50%)/中/低(<35%)三档
2. **看税收占比**：财政质量
3. **看补助依赖**：经济越弱越依赖中央转移支付
4. **看土地依赖**：地产周期下行时风险敞口
5. **看债务率**：红橙黄绿分档

## 3.10 当前央地关系新动向（2025-2026）

- **"财力下沉"成主线**：转移支付强化向市县倾斜
- **"三保"兜底压力**：困难地区财政腾挪空间收窄
- **化债释放地方财力**：12万亿框架降低地方利息支出，部分释放为"投资型"专项债额度
- **专项债"自审自发"试点**：2025年起在部分省份扩大试点，下放项目审批权
- **38号文土地资源转型**：从"增量扩张"到"存量盘活+省级统筹"，影响地方土地财政模式
