# 实战指引：八步排查 + 主要矛盾抓取 + 月度点评写作范式

> **本文档是skill的执行核心。** 写财政分析（尤其是月度点评+宏观主题展望）时，重点参考本文档。

## 8.0 输出产品形态：三类题型，三种写法

财政分析问题的输出深度应与题型匹配。**拿到问题先判断属于A/B/C哪一类，再用对应模板**。

| 类型 | 名称 | 驱动 | 字数 | 触发关键词 | 使用模板 |
|------|------|------|------|-----------|---------|
| **A类** | 月度/季度数据点评 | 数据驱动 | 1500-2500字 | "X月财政点评"、"X月数据怎么看"、用户提供excel | §8.3 三段式 |
| **B类** | 深度展望/年度策略 | 逻辑驱动 | 3000-5000字 | "展望"、"下半年"、"年度策略"、"深度分析"、"财政空间" | §8.7 五段式 |
| **C类** | 预算报告/政策解读 | 事件驱动 | 1500-2500字 | "预算报告怎么看"、"两会财政"、"ECW信号" | [ref-07](ref-07-budget-and-tone.md) |

> A类与B类的核心区别：A类回答"数据发生了什么"（what），B类回答"这意味着什么以及后续会怎样"（so what + what's next）。不确定时默认走B类深度。

## 8.1 主要矛盾抓取法（最重要）

### 为什么重要？

财政是个"百宝箱"——四本账、收支两端、十几个税种、地方债、化债、特别国债、转移支付、政策性工具……每个维度都有大量信息。**用户问的题如果偏宏观（如"X季度财政展望"），最容易出现的失败模式就是把每个维度都过一遍，每段两三句话**——看似全面，实则没有重点，读完没记住任何东西。

**正确的做法**：

1. 先从所有维度中**识别一两个最关键的主要矛盾**
2. 围绕主要矛盾**深入展开论述**——配数据、配政策、配传导链
3. 次要维度**一笔带过或不提**——有时不提反而显得聚焦

### 主要矛盾识别清单（按优先级）

#### 信号1：政策定调变化（最强信号）

- **看政府工作报告/预算报告/中央经济工作会议**
- 哪一句修饰语变了？哪一句是新增？哪一句被删除？
- **变了的部分就是主要矛盾。**
- 例：2026年定调"更加积极有为、提高精准度和有效性"——"精准度+有效性"是新增重心，反映从"加码"转向"加码+提效"，这是2026年主要矛盾之一

#### 信号2：数据异常项

- **看用户提供的excel/或最新月度财政数据**
- 哪个指标偏离趋势/季节性最大？
- 哪个数据明显超预期或不及预期？
- **异常即主要矛盾切入点。**
- 例：2025年11月非税收入同比-10.8%（前值+22.2%），是当月最大边际变化——背后是"前期截留资金陆续形成支出"+基数效应

#### 信号3：市场分歧点

- **看卖方报告共识度**
- 当前财政积极程度，市场是否存在分歧？分歧在哪？
- **分歧即主要矛盾。**
- 例：2025年市场对"财政发力是否足够"分裂——一派看广义赤字率10%已极高、一派看准财政撬动效率不足

#### 信号4：决策层关注焦点

- **看政治局会议、财政部长讲话、中央经济工作会议**
- 决策层最近反复强调什么？
- **决策层关注的就是主要矛盾。**
- 例：2025年下半年决策层频提"投资于人"+"提振消费"——民生支出向"投资于人"倾斜成为支出端主要矛盾

#### 信号5：传导链断点

- 财政→经济→市场链条中，最近哪个环节出了问题？
- **断点即主要矛盾。**
- 例：2024年专项债发行进度快但实物工作量改善有限——传导链在"项目落地+杠杆撬动"环节断了，准财政工具补位成为主要矛盾

### 异常识别经验法则

> 写月度点评时，以下经验阈值可辅助快速判断"哪些数据值得重点展开"：

| 指标类型 | 关注阈值 | 说明 |
| ------------------------ | -------------------------- | ------------------------ |
| 税收/支出单月同比 | 较前值变动 > 3个百分点 | 通常值得作为"看点"展开 |
| 累计同比 vs 全年预算目标 | 偏离 > 5个百分点 | 进度明显偏快/偏慢 |
| 非税收入单月同比 | 波动 > 10个百分点 | 非税波动天然大，阈值放宽 |
| 土地出让收入单月同比 | 较前值变动 > 5个百分点 | 地产周期敏感指标 |
| 专项债发行进度 | 较去年同期偏离 > 5个百分点 | 反映发行节奏前置/后置 |

> 这些是经验参考而非硬规则。真正重要的异常是"能被政策逻辑解释的异常"——单看数字跳升不如看背后是基数效应、政策意图还是结构变化。

### 信号3扩展：市场分歧的获取与对比方法

**为什么重要**：分歧本身就是信息——它告诉你市场对某件事的定价尚未收敛，存在预期差交易机会。

**操作方法**：

1. **搜索多家卖方同题点评**：搜索"X月财政数据点评"，对比 3-5 家卖方（中金/中信/兴业/申万等）的标题和核心判断
2. **识别分歧维度**：财政分歧通常集中在——力度够不够（广义赤字率已高 vs 准财政撬动不足）、节奏前置还是后置、化债对稳增长的间接效应有多大
3. **判断分歧性质**：是"程度分歧"（大家都看多但程度不同）还是"方向分歧"（有人看多有人看空）——后者比前者更值得展开
4. **在报告中呈现分歧**：用一句话点明分歧即可——"当前市场对X存在分歧：部分观点认为...；另一部分则认为..."——不要长篇综述，把分歧作为自己判断的对照

### 反面教材：不要这样写

❌ "X季度财政展望主要包括五个方面：第一是收入端...第二是支出端...第三是政府债...第四是化债...第五是政策性工具..."

✅ "X季度财政展望的核心矛盾在于**[主要矛盾A]**和**[主要矛盾B]**。前者主要因为...，后者反映...。具体来看，[A的展开论述]...；[B的展开论述]...。其他维度方面，收入端基本符合预期，专项债发行节奏与市场预期一致，不再赘述。"

## 8.2 财政分析八步排查流程（用于综合分析）

> 这八步**不是写作大纲**，是**判断流程**。判断完后再用"主要矛盾抓取法"组织输出。

### Step 1：确认财政政策当前定调（30秒）

- 当年定调措辞？修饰语变化？
- 当年赤字率？新增专项债？超长期特别国债？

### Step 2：评估收入端（2分钟）

| 维度 | 关键指标 | 判断标准 |
| -------------- | -------------------------------- | ---------------------------- |
| 税收增速 | 一般预算税收同比 | 与名义GDP比较；与PPI同比比较 |
| 主要税种 | 增值税、企业所得税、个税、消费税 | 哪个拖累/推动 |
| 非税收入 | 一般预算非税同比 | 异常上升 → 地方"挤水分"信号 |
| 政府性基金收入 | 国有土地出让收入同比 | 看地产周期 |

### Step 3：评估支出端（2分钟）

| 维度 | 关键指标 |
| ------------------ | ---------------------------- |
| 一般预算支出进度 | 累计支出/全年预算 |
| 政府性基金支出进度 | 累计支出/全年预算 |
| 民生vs基建 | 民生三项 vs 基建四项当月同比 |
| 债务付息支出占比 | 反映利息负担 |

### Step 4：评估广义财政空间（1分钟）

| 工具 | 当前进度 |
| -------------------------- | ------------- |
| 国债+地方债+特别国债净融资 | 累计/月度 |
| 超长期特别国债发行进度 | 累计/全年额度 |
| 特殊再融资债 | 累计/化债额度 |
| 新型政策性金融工具 | 落地节奏 |

### Step 5：评估财政对流动性影响（1分钟）

- 是否缴税大月？政府债供给压力？财政存款变化方向？央行是否配合？

### Step 6：评估对债市股市影响（2分钟）

参考 SKILL.md 速查表中的"财政与债市/股市"两节。

### Step 7：考虑央地关系与地方财政（1分钟）

- 转移支付节奏？地方"三保"压力？化债执行情况？土地出让收入？

### Step 8：综合判断与展望（2分钟）

**关键**：抓主要矛盾输出，不要每步都来一句。

## 8.3 月度财政点评写作范式（核心模板）

### 写作流程

1. **拿到excel数据**（用户提供，每月更新，如"财政数据 2026年3月.xlsx"）
2. **读"头表"sheet**，确认本月概览：
 - 一般公共财政收入/支出当月同比+较前值
 - 税收/非税同比
 - 基建类/民生类支出同比
 - 政府性基金收入/支出同比
 - 地方土地出让收入同比
3. **读其他相关sheet**确认细节（四大税种、各支出方向、专项债进度、实际赤字、政府存款等）
4. **判断本月主要看点**：哪个数据异常？哪个体现政策意图？
5. **按下文模板写正文**

### 标准结构（三段式）

#### 要点总结段（5行，放在标题下方、正文最前面）

> 对标卖方报告的开篇摘要，让读者30秒内抓住本月财政全貌。格式：
>
> ```
> > **要点总结**：
> > - 收入端：{{一句话+核心数字，如"一般预算收入同比X%，税收受PPI拖累边际走弱"}}
> > - 支出端：{{一句话+核心数字，如"支出同比X%，民生三项强于基建四项，彰显'投资于人'基调"}}
> > - 核心矛盾：{{一句话，如"税收修复偏慢 vs 支出前置发力，第一本账平衡压力上升"}}
> > - 市场含义：{{一句话（可选），如"广义赤字进度偏快，Q2政府债供给压力对资金面形成阶段性扰动"}}
> > ```

#### 开头（lead paragraph）

- 一句话概括本月/本季度财政画像
- "两本账"分化或同向状态
- 第一本账特征 + 第二本账特征
- 收尾以"具体来看："过渡

**模板**：

> "X月/X季度财政整体呈现[两本账分化/同向]的特征，第一本账[特征描述]，第二本账[特征描述]。具体来看："

#### 第（1）段：一般预算收入

**结构**：

1. 总览：单月同比 + 较前值变化 + 累计同比 + 全年预算目标 + 完成预算X%（与历史对比快/慢）
2. 拆"税收 vs 非税"：分别单月+累计+较前值
3. **税收结构上几个核心看点**（编号1、2、3、4），通常包含：
 - **国内增值税** → PPI/名义GDP/工业增加值的支撑
 - **企业所得税** → 工业利润/输入性通胀
 - **个人所得税** → 节奏/基数/监管
 - **国内消费税** → 以旧换新/烟油车酒
 - **进口环节税收** → 外贸韧性
 - **地产相关税** → 地产周期
 - **印花税** → 股市成交
4. （可选）**中央 vs 地方本级收入分化**——结尾段加这一句往往很有信息量

#### 第（2）段：一般预算支出

**结构**：

1. 总览：单月同比 + 较前值 + 累计 + 预算目标 + 完成预算X%
2. **民生三项 vs 基建四项**对比（彰显"投资于人"基调）
3. 各分项细化——社保就业、卫生、教育（民生）；城乡社区、农林水、交运、节能环保（基建）
4. 资金拨付节奏分析（财政存款指标变化、政府债发行进度）

#### 第（3）段：政府性基金收支

**结构**：

1. **收入端**：单月+累计+预算目标+完成预算X%（与过去两年同期比较）
2. **土地出让收入**累计+同比
3. （重要）政策视角：38号文转型、地产周期、收储/城市更新等
4. **支出端**：单月+累计+完成预算
5. 专项债发行进度+对支出的拉动效应

#### 综合段（结尾，最重要）

**结构**：

1. 综合两本账：识别本月最大亮点/最大问题
2. **实际赤字+广义赤字数字**（"X月实际赤字完成X万亿元，广义赤字完成X万亿元"）
3. **往后看**（前瞻）：
 - 财政增量工具节奏（特别国债发行、政策性金融工具落地、地方自审自发新增项目）
 - 影响因素（基数效应、政策意图、土地财政掣肘等）
4. **关注点列出**（3-5项）：税收修复持续性、特别国债、准财政工具、项目落地效率、化债节奏等

#### 风险提示

三句话：通常包含"债券资金使用节奏低于预期"+"土地出让收入超预期下滑"+"地产修复不及预期"等。

## 8.4 写点评的常用语言（直接套用）

### 描述变化方向

- "明显抬升/明显放缓"
- "中规中矩"（变化不大）
- "亮眼"
- "略有放缓/略有回落/小幅回落"
- "深度负区间"
- "明显修复/边际修复/延续修复势头"
- "由+X%进一步回落至-X%"
- "较前值有所收窄/扩大"

### 解释逻辑

- "不宜线性外推"（节奏扰动）
- "持续性还需观察"
- "对...形成一定挤压"
- "彰显...的基调"
- "对内生动能改善有一定指引意义，但基数效应的影响也不能忽略"
- "整体仍偏强/偏弱"
- "...的资金效应提振"
- "短期内难逆转"
- "已形成补充作用/形成一定支撑"

### 政策表述

- "投资于人"vs"投资于物"
- "提质增效"
- "做优增量、盘活存量"
- "关注...持续性"
- "财政从此前的[X]逐渐向[Y]切换"

### 8.4.1 文字规范——禁用词汇与替代词汇（强制）

> 财政分析是政策文本，保持专业、客观、中性。**禁止使用夸张渲染和极端唱衰的戏剧化词汇**。普通方向性描述词（疲软、回落、加深、偏弱、降幅扩大、承压、走弱、下行）均为中性语言，正常使用。

**判断标准**：禁用词是那些带有"视觉冲击感"或"灾难化叙事"的词汇（塌方、断崖、崩溃、崩盘、双杀、冰点等），不是普通的方向+幅度描述。

| 禁用词汇（❌） | 替代词汇（✅） |
| -------------------------- | ------------------------ |
| 塌方、坍塌 | 明显回落、较快下行 |
| 冰点 | 偏弱、有待改善 |
| 衰退、衰退式 | 走弱、承压 |
| 双杀 | 两端承压、双重压力 |
| 断崖式下降 | 明显下降、较快回落 |
| 恶化 | 走弱、压力偏大、有待改善 |
| 崩盘、崩溃 | 调整压力偏大 |
| 亏空 | 缺口 |
| 极度、极端（修饰负面指标） | 明显、偏大、较深 |
| 惨淡、低迷（过度情绪化） | 偏弱、尚不活跃 |
| 冰火两重天（过度戏剧化） | 分化、结构性差异 |

**以下为正常中性词汇，无需避讳**（仅列举常见项）：
疲软、回落、加深、偏弱、降幅扩大、承压、走弱、下行、拖累、收缩、放缓、不振。

> 核心区分：**"降幅扩大"是数据描述，"断崖式下降"是情绪渲染**——前者客观，后者禁用。

## 8.5 完整月度点评示例（套用2026年3月报告模式）

```markdown
# [核心亮点]——XX年X月财政数据点评

[开头段]X季度/X月财政整体呈现[两本账分化/同向]的特征，第一本账[特征]，第二本账[特征]。具体来看：

## (1) 一般预算收入[变化关键词]

X月全国一般公共预算收入同比[X%]，较前值[Y%][变化]。X季度/累计同比录得[X%]，全年预算目标[Y%]，完成年初预算约[X%]，[与历史对比]。

其中，非税收入[评价]，X月及累计同比分别录得[X%]、[Y%]，[较前值变化]。税收单月同比[X%]，前值[Y%]，[特征描述]。累计同比[X%]，[与目标比较]。结构上的几个核心看点如下：

1、国内增值税单月同比[X%]，[逻辑分析与PPI/名义GDP的关系]。

2、X月个税同比[X%]，[节奏/基数/监管解释]。

3、国内消费税同比[X%]，[以旧换新/烟油车酒解释]。

4、地产相关税种[评价]，X月五大地产相关税合计同比[X%]，[与一二手房分化的关系]。

[可选]另一个值得关注的变化是，X月中央、地方本级财政收入同比分别为[X%]和[Y%]，[切换/分化的政策含义]。

## (2) 一般预算支出[变化关键词]

X月一般公共预算支出单月同比[X%]，较前值[Y%][变化]，[基数解释]。综合X季度/累计看，累计同比增长[X%]，全年预算目标[Y%]，完成预算约[X%]，[与历史对比]。

结构上，X月单月民生三项支出合计同比约[X%]，[与总支出对比]。其中，社保就业、卫生、教育单月同比分别为[X%]、[Y%]和[Z%]，对应累计同比[X%]、[Y%]和[Z%]，[彰显"投资于人"基调等]。相比之下，X月单月基建四项支出合计同比约[X%]，较前值[Y%][变化]。可能与[财政资金拨付/政府债节奏]有关。
```

## 8.7 B类：深度展望/年度策略报告写作框架

> 触发条件：用户问"展望/下半年/年度策略/深度分析/财政空间"等逻辑驱动型问题。对标中金/中信/兴业及海外投行深度策略报告质量。**3000-5000字**。

### B类核心原则

1. **逻辑驱动，非数据驱动**——数据为逻辑服务，不为展示而罗列
2. **主要矛盾优先**——整个报告围绕1-2个核心矛盾展开，次要维度一笔带过
3. **每段首句亮判断**——不铺垫、不迂回，第一句给出结论，后续用数据论证
4. **预期差是alpha来源**——没有与市场不同的判断，这一节不值得写

---

### 报告结构（五段式）

#### 【开头】要点总结（200-300字，5句话）

```
1. 政策取向：当前财政定调为[X]，边际变化在[Y]
2. 收支格局：收入端受[Z]驱动[改善/承压]，支出端[前置发力/节奏偏慢]
3. 核心矛盾：[A]与[B]是当前财政面临的主要张力
4. 政策工具：后续重点关注[C]、[D]的落地节奏与规模
5. 市场含义：对经济/流动性/资产配置的核心指向是[E]
```

> 要点总结是全篇的"电梯演讲"——读者只读这一段也能抓住核心判断。每个句号是一个独立判断，句与句之间递进而非并列。

---

#### 一、宏观环境与政策取向（800-1000字）

##### 1.1 为什么此时需要财政发力/保持/收缩？

**量化缺口测算**（必写）：
- 列出当前经济面临的核心缺口（产出缺口、消费缺口、房地产投资缺口、外需不确定性等）
- 给出缺口规模估算（如"房地产投资较2021年高点累计下降约X%，对应每年X万亿的投资缺口"）
- 说明为什么货币政策/产业政策补不了这个缺口，必须靠财政
- 这是全篇的"why"——回答"财政为什么要这么做"

**写作要点**：
- 使用实际数据而非定性描述（如"工业产能利用率X%，低于合意水平Y%"）
- 明确"只能靠财政"的逻辑链（货币传导受阻、居民企业加杠杆意愿弱、外需不确定性上升）

##### 1.2 政策取向解读

融入现有 [ref-07 §7.2](ref-07-budget-and-tone.md) 措辞演变框架：
- 当前定调措辞 vs 历史同类措辞的力度对标
- 修饰语变化揭示的政策意图边际方向
- 信号源权威性排序：中央经济工作会议 > 政治局会议 > 政府工作报告/预算报告 > 财政部新闻发布会 > 部长署名文章 > 金融时报专栏

**写作要点**：
- 重点分析"变了什么"而非"是什么"——措辞的边际变化比绝对水平更重要
- 新出现的表述与被删除的表述同等重要
- 结合数字验证措辞（措辞说"更加积极"但赤字率仅微调 = 力度不及措辞暗示）

#### 二、从收支两端看财政（600-800字）

> 关键原则：**只讲拖累最大的1-2项，不逐个税种罗列。** 这一节是背景铺垫，不是全篇重点。控制在800字以内。

##### 2.1 收入端：谁在拖累？谁在支撑？

融入现有 [ref-02](ref-02-tax-system.md) 税收分析、[ref-01 §1.2](ref-01-core-framework.md) 土地出让框架：
- 只展开对收入变化贡献最大的1-2个税种/收入项
- 不做"增值税X%、企业所得税Y%、个税Z%、消费税W%"的并列罗列
- 写法示例："X月一般预算收入同比X%，主要受增值税（贡献X个百分点）和土地出让收入（拖累X个百分点）驱动。其中增值税受益于PPI降幅收窄……"
- 非税收入异常时单独分析（是"挤水分"还是"国资上缴"？）

##### 2.2 支出端：钱花在了哪里？

融入现有 [ref-01 §1.2](ref-01-core-framework.md) 民生vs基建对比维度：
- "民生三项 vs 基建四项"的增速对比
- 支出进度 vs 历史同期（快/慢了多少？）
- 一句点明支出结构性特征（"投资于人"vs"投资于物"）

##### 2.3 发债进度

融入现有 [ref-04](ref-04-local-bonds.md) 地方债框架：
- 专项债发行进度 vs 去年同期
- 超长期特别国债发行节奏
- 化债置换专项债 vs 传统新增专项债的并行节奏（两者是平行关系，不是占用关系）

##### 2.4 收支缺口与平衡方式

融入现有 [ref-05](ref-05-deficit-and-tools.md) 三层次赤字框架：
- 当前使用的是什么赤字口径？实际赤字/广义赤字分别完成多少？
- 调入资金+动用结转结余的规模（第一本账平衡手段）
- 专项债+特别国债对第二本账的填补效应

#### 三、核心矛盾（全篇灵魂，500-800字）

> 这一节是整个报告最重要的部分。用 [§8.1](#81-主要矛盾抓取法最重要) 的主要矛盾抓取法，**识别1-2个核心矛盾并深入展开**。这一节写好了，整篇报告就立住了。

##### 3.1 矛盾识别

使用五大识别信号（详见 [§8.1](#81-主要矛盾抓取法最重要)）：
1. 政策定调变化（措辞变即矛盾）
2. 数据异常项（偏离趋势/季节性最大）
3. 市场分歧点（卖方分裂处）
4. 决策层关注焦点（政治局会议/部长讲话）
5. 传导链断点（财政→经济→市场哪个环节出问题）

##### 3.2 矛盾展开（每个矛盾1-2段）

对每个核心矛盾：
- 第1段：**矛盾是什么**——描述现象，配数据
- 第2段：**为什么会这样**——政策意图、经济环境、制度约束三层归因
- （可选）第3段：**这意味着什么**——对市场判断的含义

##### 3.3 常见矛盾形态参考

| 矛盾类型 | 典型表现 | 常见于 |
|---------|---------|--------|
| 定调vs落地 | 政策措辞积极但实际发力节奏偏慢 | 年初/两会后 |
| 预算内vs预算外 | 广义赤字率高但准财政撬动不足 | 稳增长关键期 |
| 中央vs地方 | 中央发力积极但地方受制于化债/土地财政 | 化债推进期 |
| 规模vs效率 | 资金到位但项目储备/实物工作量转化慢 | 专项债发行高峰后 |
| 收入vs支出 | 收入改善但支出未同步跟进（或反之） | 月度数据点评 |

##### 4.3 与市场预期的差异

**债市**：

- 化债效应：高息隐债→低息显债→信用利差收窄

### B类写作原则（强制约束）

> 以下原则贯穿B类报告写作全过程，**每一段写完后应自检是否违反**。

1. **禁止数据罗列**。不要说"增值税X%、企业所得税Y%、个税Z%、消费税W%"，要说"增值税受PPI驱动是收入端最大拉动力，贡献了X个百分点的增量"。
2. **禁止平铺直叙**。每段首句亮判断，后续用数据论证。不要铺垫三段才给结论。
3. **结构优先级**。核心矛盾（第三节）> 政策工具研判（第四节）> 市场含义（第五节）> 收支拆解（第二节）。写的时候精力按此分配，核心矛盾至少占全篇25%。
4. **预期差导向**。如果第四节4.3段"与市场预期的差异"只能写"与市场共识一致"，则整段缩为一句话。报告的价值不在于"正确"，在于"与共识不同的正确"。
5. **避免过度拆解**。次要税种/次要支出方向一笔带过，不以"全面"牺牲"锐度"。读者看完记不住5个税种的数字，但会记住1个核心判断。
6. **每段3-5句话**。一个论点 + 一个数据 + 一个逻辑 = 一段。超过5句说明论点不够聚焦。
7. **写完先过 §8.10 三道门再发送**。逐数溯源 → 交叉验证 → 时效检查。任何一个数字没有来源 → 删掉或重写。这是铁律，不是建议。

## 8.8 五个常见误区（避免！）

1. **误区**："狭义赤字率没破3%就不积极"
 **正解**：实际赤字率+广义财政空间才是衡量关键
2. **误区**："非税收入增速高 = 财政状况好"
 **正解**：非税高增可能是地方"挤水分"信号，财政质量恶化
3. **误区**："土地出让收入下降 = 政府性基金支出必然下降"
 **正解**：地方专项债发行可对冲收入下行
4. **误区**："专项债发行慢 = 财政发力不足"
 **正解**：可能是项目储备问题或资金已通过其他渠道（特别国债、政策性金融工具）补位
5. **误区**："化债 = 新一轮放水"
 **正解**：化债是债务结构调整（高息→低息），不直接增加广义债务总量；通过降低利息负担间接释放财政空间

## 8.10 数据校验机制（铁律——发送前强制执行）

> ⚠️ 这是产出质量的最后一道防线。**报告写完后的第一件事不是发给用户，是逐项过这一节的三道门。** 违反任何一门 → 必须修正后再发。

### 第一门：逐数溯源

**报告中出现的每一个具体数字**（增速、绝对值、百分比、金额、时间点），必须能回答"这个数字从哪里来"。

| 检查项 | 标准 | 违规示例 |
|--------|------|---------|
| GDP增速 | 来自国家统计局/同花顺iFinD，非凭印象 | ❌ "一季度GDP增速大概率在5.2%-5.3%"（实际5.0%，完全错误） |
| 财政收支数据 | 来自财政部官网/用户excel/卖方点评援引 | ❌ "一般预算收入约X万亿"（凭感觉给的区间） |
| 地方债/专项债 | 来自财政部/企业预警通/Wind | ❌ "发行进度大约X%"（没有实际数字支撑） |
| 市场利率/股指 | 来自iFind EDB/行情终端，标日期 | ❌ "10Y国债收益率在X%附近"（凭近期印象，未查最新） |
| 政策表述 | 来自会议公报/讲话原文，非转述 | ❌ "政治局会议强调继续加码"（没有原文验证，实际是"精准有效"） |

**铁律**：无来源的数字 → 删除，改写为定性表述。区间数字（如"约X%-Y%"）→ 必须来自权威预测或实际数据，禁止凭印象估算。

### 第二门：交叉验证

同一关键数字至少两个独立来源印证。对不上时按权威性排序取信：

```
官方统计（统计局/财政部/央行） > 官方媒体（新华社/人民日报） > 专业财经（财新/一财） > 卖方研报 > 自媒体
```

不满足交叉验证的数字 → 标注单一来源（如"据财政部发布会"），让读者自行判断可信度。

### 第三门：时效检查

- 每个数字对应的时点是否最新？有没有更新的月度/季度数据已公布？
- 政策表述是否来自最近一次会议？（比如4月底政治局会议已开，就不能用3月两会定调代替）
- 引用的卖方报告是否在一个月以内？

### 判例：本次Q2展望GDP错误的教训

| 维度 | 详情 |
|------|------|
| 错误写法 | "一季度GDP增速大概率在5.2%-5.3%" |
| 实际数字 | 5.0%（国家统计局2026年4月16日公布） |
| 错误原因 | 写报告时凭"Q1开局好于预期"的定性印象，脑补了一个"高于目标0.2-0.3个百分点"的区间数字 |
| 正确做法 | 写之前搜"2026年Q1 GDP增速" → 找到国家统计局5.0% → 直接引用。如果想表达"超预期"，应引用彭博一致预期（如4.8%）与5.0%对比，而非自行编一个区间 |
| 规则违反 | 违反SKILL.md 原则2"禁止凭印象给数字或区间"、违反第一门"无来源的数字 → 删除" |
