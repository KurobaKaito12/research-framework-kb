# 税收体系分析框架

## 2.1 我国税制基本情况

我国采用复合税制，**18个税种**分为五大税类：

| 税类 | 主要税种 | 税收占比顺位 |
|------|---------|------------|
| 商品和劳务税类（流转税） | 增值税、消费税、关税 | 占税收一半以上 |
| 所得税类 | 企业所得税、个人所得税 | 第二大类 |
| 财产和行为税类 | 房产税、车船税、印花税、契税 | 较小 |
| 资源税类 | 资源税、环境保护税、土地增值税、城镇土地使用税 | 较小 |
| 特定目的税类 | 城市维护建设税、车辆购置税、耕地占用税、船舶吨税、烟叶税 | 较小 |

### 主要税种格局（结构性，量级长期相对稳定）

四大主税种 = 增值税 + 消费税 + 企业所得税 + 个人所得税 ≈ 占税收 60-70%

| 税种 | 占税收量级 | 备注 |
|------|---------|------|
| 国内增值税 | 第一大税种 | 与PPI、名义GDP高度相关 |
| 企业所得税 | 第二大 | 跟随工业企业利润 |
| 国内消费税 | 中等 | 烟、油、车、酒贡献近99% |
| 个人所得税 | 中等 | 节奏受春节等扰动 |
| 进口环节税收（关税+进口增值税+进口消费税） | 中等 | 与进口金额同步 |
| 地产相关5税（契税+土增+房产+城镇土地+耕地占用） | 合计约10-12% | 与地产销售/投资周期同步 |
| 印花税（含证券交易印花税） | 较小 | 与股市成交活跃度同步 |

> **量级会随税基波动而变化，写最新点评时直接读excel底稿/iFind数据，不依赖此处历史占比。** 增值税+企业所得税长期占税收一半以上，是分析税收变化的主战场。

## 2.2 我国税收的关键特点

| 特点 | 含义 | 启示 |
|------|------|------|
| 间接税为主 | 流转税占主体 | 对**价格水平（PPI）敏感性高** |
| 第三产业税收占比上升 | 第二产业占比下降、第三产业上升 | 服务业是税基新增长点 |
| 企业是主要纳税人 | 自然人缴税占很小一部分 | 企业经营状况决定税收主线 |
| 宏观税负低于发达经济体 | 狭义宏观税负15%左右，广义约25% | 减税降费空间在收窄 |

## 2.3 中央与地方税收划分（核心）

1994年分税制改革后建立"中央税、地方税、共享税"三类体系。

### 中央固定收入
关税、进口环节增值税/消费税、国内消费税、车辆购置税、船舶吨税

### 地方固定收入
房产税、城镇土地使用税、土地增值税、契税、车船税、耕地占用税、烟叶税、环境保护税

### 中央地方共享（核心三大税）

| 税种 | 中央 | 地方 |
|------|-----|-----|
| 增值税（非进口） | 50% | 50% |
| 企业所得税 | 60% | 40% |
| 个人所得税 | 60% | 40% |

### 历次重大调整

- 2002年：所得税从地方固定改为央地6:4共享
- 2016年：增值税央地分成由75:25改为50:50（营改增完成）
- 2016年：证券交易印花税改为中央100%
- 2018年：环境保护税开征，全部归地方

### 地方内部分成

- 各省内部各级（省/市/区县）分成比例**因地而异**
- 重庆、山东、江西等省份对增值税、所得税的省/市分成比例显著不同
- 园区财政享有特殊分成机制（基期留存+增量分成）

## 2.4 税收数据与宏观经济指标的联系（**核心传导**）

### 税收 vs PPI（最重要传导）

**现价计税使PPI对税收影响大**，通胀（紧缩）时即使其他条件不变税收增速也会加快（放慢）。

```
PPI上行 → 增值税基扩大 → 增值税同比上行 → 总税收同比上行
```

> **写税收点评时，PPI是首要解释变量。** 例：2026年3月增值税单月同比+5.5%，PPI转正与名义增长边际改善是核心支撑。

### 税收 vs GDP（不能简单线性）

不一致的原因：
- 价格依据不同（税收按现价、GDP按不变价）
- 核算方法不同（出口退税是减项 vs 进口环节税收是增项）
- 税收制度特性（累进税制使部分税增速快于税基）

### 主要税种的解释变量

| 税种 | 核心驱动 | 写点评时关注 |
|------|---------|------------|
| 国内增值税 | PPI、名义GDP增速、工业增加值 | 名义增长、平减指数 |
| 企业所得税 | 工业企业利润 | 利润累计同比；输入性通胀对利润分配 |
| 个人所得税 | 工资性收入、监管力度 | 节奏（春节奖金扰动）、基数、监管强化 |
| 国内消费税 | 烟、油、车、酒（贡献近99%） | 以旧换新、油价、烟酒消费 |
| 进口环节税收 | 进口金额（一般贸易为主） | 外需韧性、关税战 |
| **地产5税**（契税+土增+房产+城镇土地+耕地占用） | 商品房交易+地产投资 | 一二手房分化、新房成交、投资增速 |
| 印花税 | 证券交易+经济活跃度 | 股市成交额变化（核心驱动） |

### "四大主税种"（写点评时常用合并指标）

增值税 + 消费税 + 企业所得税 + 个人所得税 = 占税收60-70%，是分析税收主线的核心抓手。

## 2.5 税收变化的几个常见解释模板（写点评直接套用）

### 模板1：PPI修复 → 税收转好

> "国内增值税单月同比增长X%，延续修复势头，主要受到PPI转正和名义增长边际改善的支撑。本季度名义GDP增速修复至X%，平减指数回到零值附近。"

### 模板2：输入性通胀挤压利润

> "相比之下，企业所得税单月同比下降X%，反应输入性通胀对成本和利润分配可能有扰动，对下游利润形成一定挤压。"

### 模板3：节奏与基数扰动

> "X月个税同比大增X%，但节奏和基数扰动居多，不宜线性外推。某年春节相对靠前，企事业单位集中发放的职工年终奖金应缴个税在2月份入库较多，今年或更多体现在3月。"

### 模板4：以旧换新支撑消费税

> "国内消费税同比增长X%，主要受'以旧换新'外的通讯器材、石油制品、金银珠宝（价格上涨逻辑）提振。"

### 模板5：地产相关税偏弱

> "X月地产相关税种依然偏弱，五大地产相关税合计同比约-X%。一线城市二手房市场热度延续，但对新房和投资端的传导有限。"

### 模板6：进口环节强证外需韧性

> "与外需相关的进口环节增值税和消费税、关税X月单月同比分别增长X%和X%，整体仍偏强，与年初以来外贸韧性相印证。"

### 模板7：央地税基修复重心切换

> "X月中央、地方本级财政收入同比分别为X%和X%，**中央本级收入累计同比为去年X月以来首次转正，反应税基修复的重心逐渐从此前的地方转向中央层面。**"

## 2.6 税制改革方向

按"十四五"规划纲要，税制改革主线："**减间接、增直接**"

### 核心方向

1. **健全地方税体系**：消费税征收环节后移并下划地方（2019年定方向，但烟酒油车四大税目尚未实质改革）
2. **房地产税立法**：上海/重庆已试点，2022年因经济下行暂缓，待时机成熟推进
3. **健全直接税体系**：完善个税综合所得改革

### 税收法定原则推进
- 18税种中13个已立法
- 房产税、城镇土地使用税仍以暂行条例形式

## 2.7 看税收的"四个落脚点"

1. **看主税种**：增值税+企业所得税占一半，分析税收先看这两个
2. **看价格因素**：PPI是现价税收的首要解释变量
3. **看央地分成**：分析地方财力时要看本省内部分成比例
4. **看异常项**：哪个税种偏离趋势/季节性最大，那就是主要矛盾点
