# 财政分析核心框架：四本账 + 三层次赤字

## 1.1 财政vs货币：两类政策的本质区别

| 维度 | 财政政策 | 货币政策 |
|------|---------|---------|
| 主体 | 财政部及各级政府 | 央行 |
| 工具 | 税收、政府支出、举债、转移支付 | 利率、准备金、OMO、结构性工具 |
| 作用机制 | 直接（"真金白银"流入实体） | 间接（通过金融体系传导） |
| 受益主体 | 可定向到企业、居民、特定行业 | 普惠性强（银行、广义流动性） |
| 起效速度 | 较慢（预算+项目落地） | 较快（利率即时传导） |

**当前阶段背景**：货币宽松空间和作用愈发受限，财政更能反映"真金白银"，财政与内需相关度明显提升——这是研究财政时必须把握的大背景。

## 1.2 四本账：财政分析的根基

我国预算体系由四本账构成：

| 账本 | 规模顺序 | 主要收入来源 | 主要功能 | 是否计赤字 |
|------|---------|------------|---------|-----------|
| **一般公共预算**（第一本账） | 最大 | 税收（80%+） | 民生+运转+宏观调控 | ✓ |
| **政府性基金预算**（第二本账） | 第二大 | 国有土地出让金（占~80-90%）+地方专项债 | 专款专用，基建为主 | ✗（基金不列赤字） |
| 国有资本经营预算（第三本账） | 最小 | 国企利润上缴 | 国企改革+补社保 | ✗ |
| 社会保险基金预算（第四本账） | 较大 | 保险费+财政补贴 | 养老/医疗等专款 | ✗（独立运行） |

**实践中重点看前两本账**——四本账分析的关键。

### 收支两条统计口径

- **"收支"**：实际收支
- **"收支总量"**：实际收支 + 调入资金 + 结转结余动用

理解这一点是搞清"狭义赤字 vs 实际赤字"的关键。

### 四本账之间的勾稽

```
一般公共预算 ←调入→ 政府性基金 ←调出→ 国资经营
 ↓ 财政补贴
 社会保险基金（专款专用，不能反向补贴一般预算）
```

**关键勾稽**：
- 第二、三本账盈余 → "调出资金"补一般公共预算（解释官方vs实际赤字差异的核心）
- 一般公共预算 → 可补贴社保基金（2024年补贴超3万亿）
- 社保基金不能反向补贴一般公共预算

### 第一本账支出结构（占比靠前的方向）

| 大类 | 支出项 | 政策意图 |
|------|-------|---------|
| **民生类** | 社会保障和就业、卫生健康、教育 | 刚性占比最大；近年彰显"投资于人"基调 |
| **基建类** | 城乡社区事务、农林水、交通运输、节能环保 | 顺经济周期，受财政发力节奏影响大 |
| **其他** | 一般公共服务、公共安全、国防、科技、债务付息 | 相对稳定 |

> 在写点评时，"民生三项"（社保就业+卫生+教育）vs "基建四项"是常用的对比维度，前者反映"投资于人"，后者反映"投资于物"。

### 第二本账核心：土地出让金

- 国有土地出让金长期占政府性基金收入80-90%
- 土地财政深度绑定地方财政命脉
- **2024-2025年地产周期下行**，土地出让收入持续走弱，倒逼第二本账结构变化
- **2025年38号文**："推动土地资源从增量扩张到存量盘活+省级统筹"——纠偏土地财政模式，第二本账中长期路径正在重塑

## 1.3 三层次财政赤字（核心新框架）

> 这是2024-2025年起市场普遍采用的财政力度评估框架，**比单看"狭义赤字率3%"更能刻画真实财政立场**。

### 三个层次定义

| 层次 | 名称 | 定义 | 性质 |
|------|------|------|------|
| **第一层** | 狭义财政赤字 | 一般公共预算收支差额（第一本账） | "官方赤字率" + 实际赤字（市场口径） |
| **第二层** | **广义财政赤字（两本账赤字）** | 一般公共 + 政府性基金 收支差额 | 市场常用，含特别国债 |
| **第三层** | **准财政赤字** | 广义+城投融资+政策性金融工具+铁道债+基建贷款 | **最贴近实物工作量** |

### 第一层：狭义赤字（一本账）的两种口径

| 概念 | 定义 | 用途 |
|------|------|------|
| **官方赤字** | 一般国债 + 一般地方债（按债务工具定义） | 年初赤字目标，预算约束 |
| **实际赤字** | 一般公共预算支出 - 一般公共预算收入（含调入资金、动用结转等真金白银） | 月度点评常用 |

```
实际赤字 ≈ 官方赤字 + 调入资金 + 动用结转结余
```

**关键判断**：实际赤字率往往略高于官方赤字率（多出来的部分 = 第二、三本账调入+蓄水池动用，是"真金白银"的一部分）。

详细赤字框架见 [ref-05-deficit-and-tools.md §5.2-§5.3](ref-05-deficit-and-tools.md)。

### 第二层：广义赤字（两本账，市场最常用）

```
口径一（简单粗暴）：广义赤字 = 两本账支出之和 - 两本账收入之和
 = 第一本账实际赤字 + 第二本账实际赤字（月度点评常用）
口径二（工具加总）：= 一般国债 + 一般地方债 + 地方专项债 + 特别国债 + 注资特别国债 + 置换债 + ...
```

> 当前阶段（2025-2026）广义赤字率已达**10%左右**，远超狭义赤字率，是市场判断财政力度的核心指标。

**特点**：
- 政府性基金"开门"后，专项债+特别国债逐渐主导广义赤字增量
- **注资特别国债+置换债不具直接"真金白银"效应**——前者补银行资本金、后者改债务结构，但通过改善现金流间接传导。实践中常需"全口径"和"剔除非真金白银口径"分别看
- 与狭义赤字往往同向变动，但近年专项债+特别国债弹性更大

### 第三层：准财政赤字（贴近实物工作量）

```
准财政赤字 = 广义赤字 + 城投融资 + 政策性金融工具 + 铁道债 + 基建贷款（不含已纳入预算的）
```

**特点**：
- 不纳入预算管理，但属于政府类项目主要资金来源
- **更贴近实物工作量**——是预算资金的"配套资金"
- 2022年的政策性开发性金融工具（PSL支持，7400亿）、2025年新型政策性金融工具（5000亿，2026年扩至8000亿）是关键边际变量

### 三层次的传导次序

```
两本账赤字（广义） → 预算外赤字（准财政） → 居民和企业宽信用 → 经济增长
 ↑领先 ↑贴近实物工作量
 政策立场为主 滞后于两本账
```

**关键经验规律**（来自历史复盘）：
1. **各层次赤字率对边际增长的拉动效率呈现降低趋势**——以基建贷款拉动的基建投资衡量，单位赤字撬动效率走弱
2. **两本账赤字（广义赤字）更代表政策立场，往往更领先**——逆周期性更强
3. **预算外赤字（准财政）受激励机制和项目进度影响**，更贴近实物工作量
4. **企业和居民端的宽信用是准财政到经济增长的核心环节**

## 1.4 当前财政分析的核心议题（2025-2026）

### 议题1：预算弹性已彻底打开

- 狭义赤字率"3%红线"2024年起被打破，2025-2026年保持4%
- 超长期特别国债（2024起每年1万亿+，2025-2026年1.3万亿）成常态工具
- 5000亿大行注资特别国债（2025）+ 3000亿（2026）—— 工具箱继续扩展
- 财政空间从"赤字+地方债"扩展为"赤字+地方债+特别国债+特殊再融资+新型政策性金融工具"多元结构

### 议题2：化债主线进入"主动+常态化"阶段

- 2024年11月12万亿化债框架（6+4+2）：6万亿专项债置换隐债（3年）+ 4万亿地方债额度（5年）+ 2万亿2029年前到期棚改隐债
- 2025年首批2万亿化债专项债已全部发行完毕
- 化债思路从"应急式"转向"主动+常态化管理"
- **化债深刻重塑了地方政府债务管理与城投生态**——平均利率成本下降2.5个百分点以上

### 议题3：土地财政转型与第二本账结构调整

- 土地出让收入持续走弱（2024-2025同比深度负区间）
- 2025年38号文推动土地资源从"增量扩张"到"存量盘活+省级统筹"
- 第二本账中长期路径正在重塑——专项债、特别国债部分填补
- 房地产税立法仍处推进阶段

### 议题4：财政货币协同新机制

- 央行二级市场买卖国债（2024年正式启动）
- 政府债发行节奏与央行流动性投放协同度提升
- 准财政工具（政策性金融工具）成为"财政+货币"共同发力的新载体
- "新型政策性金融工具"（2025年5000亿+2026年8000亿）成为撬动杠杆的关键

## 1.5 看财政的"五句话"

1. **看四本账，重点看前两本** — 第一本账反映民生与运转，第二本账反映基建与项目
2. **看三层次赤字** — 狭义看立场、广义看力度、准财政看实物工作量
3. **支出端比收入端更重要** — 当前阶段财政发力关键看支出节奏，而非收入超收
4. **抓措辞变化** — 政策定调（稳健→积极→更加给力→超常规）的边际变化是判断方向的核心信号
5. **抓主要矛盾** — 不要每个维度都泛泛而谈，找一两个最关键的传导链深入展开
