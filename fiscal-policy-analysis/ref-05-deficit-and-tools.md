# 三层次赤字、特别国债与准财政工具

## 5.1 三层次赤字框架（核心）

> 这是2024年起市场普遍采用的财政力度评估框架。**单看"狭义赤字率3%"已无法准确刻画财政立场**。

### 三层次定义

```
 准财政赤字（预算外）
 ╔════════════════════════╗
 ║ 城投融资+政策性金融工具+ ║
 ║ 铁道债+基建贷款等 ║
 ╚════════════════════════╝
 ↑包含
 ┌────────────────────────┐
 │ 广义赤字（两本账赤字） │
 │ ┌──────────────────┐ │
 │ │ 一般公共预算赤字 │ │
 │ │ ↓ 第一本账 │ │
 │ │ 实际赤字 vs 预算赤字│ │
 │ └──────────────────┘ │
 │ ┌──────────────────┐ │
 │ │政府性基金收支差额 │ │
 │ │ ↓ 第二本账 │ │
 │ │ 含特别国债 │ │
 │ └──────────────────┘ │
 └────────────────────────┘
```

### 各层次的政策意义

| 层次 | 名称 | 性质 | 关键特征 |
|------|------|------|---------|
| 第一层 | 狭义赤字 | "官方赤字率" | 反映**政府的稳增长意愿** |
| 第二层 | **广义赤字（两本账）** | 市场常用 | 反映**预算内财政强度** |
| 第三层 | **准财政赤字** | 不在预算 | **最贴近实物工作量** |

### 传导次序

```
两本账赤字（广义） → 预算外赤字（准财政） → 居民/企业宽信用 → 经济增长
 领先（政策立场） 贴近实物工作量 撬动杠杆 最终效果
```

**经验规律**：
1. **各层次赤字率对边际增长的拉动效率呈现降低趋势**——单位赤字撬动效率走弱，可能与投资边际报酬递减、债务以新换旧滚续、城投融资受限等有关
2. **广义赤字往往领先**——逆周期意图先体现在两本账，再传导到准财政
3. **准财政赤字滞后但更贴近实物**——城投融资+政策性金融工具是"配套资金"，需要项目落地才形成实物工作量
4. **企业和居民端的宽信用是准财政到经济增长的核心环节**——若融资需求疲弱，准财政发力难以转化为经济增长

## 5.2 第一层：狭义赤字的两个口径

> 狭义赤字只看第一本账（一般公共预算）。**有两种刻画方式**——一种从债务工具入手（官方），一种从收支差入手（市场）。

### 口径一：官方赤字（按债务工具定义）

```
官方赤字 = 一般国债 + 一般地方债（即用于填补一般预算的债务工具净融资）
```

- 这是政府工作报告/预算报告每年公布的"赤字目标"
- 每年提前确定，具有约束力（如2024-2026年赤字率4%）
- **不含专项债**（专项债算政府性基金口径）
- **不含特别国债**（不计入赤字）
- 数值参考：2025年5.66万亿 → 2026年5.89万亿

### 口径二：实际赤字（按收支差定义）

```
实际赤字 = 一般公共预算支出 - 一般公共预算收入
```

- 用支出端实际数减收入端实际数得出
- **包含了调入资金、动用结转结余等"真金白银"**——因为这部分钱也实实在在用于支出，应该体现财政力度增强
- 实际赤字往往大于官方赤字，差额 ≈ 当年从其他账本调入资金 + 动用预算稳定调节基金/结转结余
- 是月度点评中"X月/X季度实际赤字完成XX万亿元"的口径

### 二者勾稽

```
实际赤字 = 官方赤字 + 调入资金 + 动用结转结余 等真金白银项
```

> **写点评时记住"实际赤字"的简单算法 = 第一本账支出 - 第一本账收入**，不需要拆调入项。

## 5.3 第二层：广义赤字（市场最常用，对应"两本账"）

> 广义赤字 = 第一本账+第二本账综合。**同样有两种刻画方式**：一种简单粗暴（收支差），一种工具加总。

### 口径一：简单粗暴算法（市场点评常用）

```
广义赤字 = 一般公共预算支出 + 政府性基金支出 - 一般公共预算收入 - 政府性基金收入
 = 第一本账实际赤字 + 第二本账实际赤字
```

- 与"实际赤字"算法一致，简单清晰
- **写月度财政点评时使用此口径**——即"X月广义赤字完成XX万亿元"
- 例：2026年一季度实际赤字完成1.31万亿，广义赤字完成2.57万亿

### 口径二：按债务工具加总（更细致的视角）

```
广义赤字（工具口径） = 一般国债 + 一般地方债 + 地方专项债（传统口径，主要投资型）
 + 普通超长期特别国债 + 注资特别国债（2025起大行/金融机构注资）
 + 化债置换专项债（6万亿框架年度额度，单列）
 + 其他特殊再融资债 + ...（其他政府债务工具）
```

**关键区分**：上述工具中，**部分不具有"真金白银"效应**——

| 工具 | 是否真金白银 | 说明 |
|------|------------|------|
| 一般国债 | ✓ | 用于填补一般预算赤字，形成支出 |
| 一般地方债 | ✓ | 同上 |
| **传统新增专项债**（如2026年4.4万亿） | ✓（投资型） | **绝大多数用于投资项目建设**；少数也可能用于化债，但需明确说明用途 |
| 普通超长期特别国债 | ✓ | 用于"两重两新"实体支出 |
| **注资特别国债** | **✗** | **注资银行→改善资本金→间接传导**，不直接形成实体支出 |
| **化债置换专项债**（6万亿框架，年度2万亿，**与传统新增专项债是单独的两笔**） | **✗** | **隐债→显债的结构调整**，不增加需求；通过降息和缓解现金流间接传导 |
| 特殊再融资债 / 普通置换债 | ✗ | 同上 |

#### 传统新增专项债 vs 化债置换专项债（**关键澄清**）

> ⚠️ 这是skill使用过程中容易出错的点：

- **2026年新增专项债额度4.4万亿元** = **传统口径**，**绝大多数用于投资项目**（基建、保障房、收储、设备更新等），**不包含化债置换**
- **6万亿化债置换专项债**（2024-2026年每年2万亿） = **单独的化债工具**，**与4.4万亿是平行关系，不是占用关系**
- 两者合计：2026年专项债"全口径"发行总规模约**4.4万亿（传统） + 2万亿（化债置换） ≈ 6.4万亿**
- 极少数情况下，传统新增专项债中部分会注明"用于化债"，但**绝大多数仍是投资型**——不要默认假设"4.4万亿里有2万亿是化债"

#### "全口径" vs "剔除非真金白银口径"

实践中常需要两种计算分别看：
- **全口径**：反映债务总规模（含注资、置换等）
- **剔除非真金白银口径**：反映对实体经济的实际支出拉动力（剔除注资特别国债、化债置换专项债、特殊再融资债等结构调整工具）

### 当前水平参考（2025-2026）

- 狭义赤字率（官方）：4%
- 实际赤字率：略高于4%（含调入项）
- **广义赤字率：约10%**（两本账收支差/GDP）
- 历年广义赤字率呈上升趋势

## 5.3.4 不同赤字口径的使用场景（**重要**）

> 不同赤字口径**对应不同分析阶段**，混用会导致逻辑错乱。

### 场景一：年初评估当年财政力度（前瞻视角）

- **使用工具加总口径**：一般国债 + 一般地方债 + 地方专项债 + 特别国债 + ...
- 因为当年实际收支尚未发生，无法用"支出-收入"算实际赤字
- 通常做法：将本年各类债务工具**与往年同口径对比**，判断财政力度是边际加码还是退坡
- 典型场景：两会预算报告解读、年度财政展望、"X+1年财政空间还有多大"
- 注意要保持口径一致性——比如要不要把"注资特别国债""化债置换专项债"算进来，应在多年比较中保持一致

### 场景二：实际发生后回溯评估（实操视角）

- **使用收支差口径**：实际赤字（一本账支出-收入）+ 广义赤字（两本账支出-两本账收入）
- 数据来源是已发生的财政部月度收支数据
- 典型场景：月度/季度财政点评、半年度/年度财政回顾、判断"已完成多少预算进度"
- 这是skill中"X月实际赤字完成X万亿、广义赤字完成X万亿"的标准句式来源

### 简记

| 视角 | 时间窗口 | 推荐口径 | 数据可得性 |
|------|---------|---------|----------|
| 年初评估 | 当年尚未发生 | 工具加总（多年同口径对比） | 预算数 |
| 月度/季度回顾 | 已发生 | 收支差（实际赤字/广义赤字） | 财政部月度数据 |
| 全年决算 | 全年完成 | 两者皆可，相互验证 | 决算数 |

## 5.5 特别国债的演变

### 历次重大特别国债

| 年份 | 规模 | 用途 |
|------|-----|------|
| 1998 | 2700亿 | 注资四大国有银行 |
| 2007 | 1.55万亿 | 设立中投公司 |
| 2017 | 6964亿 | 续作1998年到期 |
| 2020 | 1万亿 | 抗疫特别国债 |
| 2022 | 7500亿 | 中央汇金注资续作 |
| **2024起** | **1万亿** | **超长期特别国债**（首次常态化） |
| 2025 | 1.3万亿 + 5000亿 | 超长期特别国债 + 大行注资特别国债 |
| 2026 | 1.3万亿 + 3000亿 | 超长期特别国债续发 + 中央金融机构注资特别国债 |

### 超长期特别国债的政策含义

- 期限超长（30Y/50Y），资金成本低
- **不计入赤字**——突破"狭义赤字3%红线"的关键工具
- 投向"两重两新"：国家重大战略实施和重点领域安全能力建设 + 设备更新 + 消费品以旧换新
- **常态化发行**：从2024年开始连续多年发行，相当于打开了财政空间的新维度

### 大行注资特别国债（2025起）

- 用于注资国有大型商业银行（补充资本充足率）
- 帮助银行扩大信贷投放空间，支持实体经济
- 与货币政策协同的新形式

|------|-----|------|

| 2025 | 5000亿 | 新型政策性金融工具（首批） |
| 2026 | 8000亿 | 新型政策性金融工具（扩量） |

- 主要补充项目资本金
- 是预算外广义财政的重要补充——撬动地方杠杆的关键工具

## 5.7 财政"工具箱"全景

### 收入端工具
1. 税收政策：减税降费 vs 加征
2. 国资收益上缴：国资经营预算→一般预算
3. 央行结存利润上缴（如2022年1.1万亿）

### 支出端工具
1. 支出节奏：前置发力 vs 后置发力
2. 结构调整：基建/民生/科技/化债
3. 转移支付：兜牢"三保"

### 债务工具
1. 国债（中央）：含**超长期特别国债**+**大行注资/金融机构注资特别国债**

3. 地方专项债（政府性基金，不计赤字）
4. 特殊再融资债/特殊置换债（化债专用）

### 准财政工具
1. **政策性金融工具**（新型2025起）
2. 政策性银行专项贷款
3. PSL
4. 城投融资（化债下整体收缩）

## 5.9 财政可持续性边界

### 国际警戒线
- 政府债务/GDP < 60%（欧盟马约）
- 赤字率 < 3%
- 偿债率 < 20%

### 我国实际情况

- 2024年末地方债余额超50万亿，国债余额超34万亿
- 中央+地方法定债务/GDP约60-65%（不含隐债）
- 加上隐性债务，市场估算政府广义债务/GDP更高
- 与美、日等发达经济体相比仍处可控区间

### 可持续性"三看"

1. **看利息支出占财政支出比重**：2024-2025年债务付息支出累计同比13%-22%（远超总支出增速），是潜在挤出效应来源
2. **看政府债总余额/GDP增速**：超过名义GDP增速时债务/GDP上升
3. **看融资成本与名义GDP增速差**：国债收益率长期低于名义GDP增速时债务可滚动

## 5.10 看赤字的"五句话"

1. **狭义赤字3%已被打破**——4%在2024年起常态化
2. **广义赤字率约10%才是真实力度**——三本账综合判断
3. **特别国债是新工具维度**——常态化发行打开财政空间新窗口
4. **化债不是新增刺激**——是债务结构优化（高息→低息），间接释放财政空间
5. **准财政工具是杠杆撬动核心**——新型政策性金融工具8000亿+特别国债是2026年关键边际

## 5.11 当前主要矛盾参考（2025-2026）

> **写"财政空间还有多大"或"X季度展望"类问题时，重点围绕主要矛盾展开**：

- **预算内积极但准财政撬动有待强化**——预算内资金积极前置，但杠杆撬动效果还需观察
- **化债与传统专项债是平行关系，但化债的间接影响仍是关键**——化债置换专项债（年度2万亿）与传统新增专项债（年度4.4万亿）单独下达，不互相挤占。但化债通过降低地方利息支出、缓解城投现金流、改变隐债显性化节奏等，**间接影响稳增长效果**
- **土地财政掣肘第二本账**——38号文转型短期难逆转
- **新型政策性金融工具的实际效果是关键变量**——决定准财政能否真正撬动企业宽信用
- **二季度增量工具能否跟上**——特别国债发行进度+政策性金融工具落地+地方自审自发新增项目
