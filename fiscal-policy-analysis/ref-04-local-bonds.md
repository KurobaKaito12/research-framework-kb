# 地方政府债与化债

## 4.1 地方债发行模式演变

| 阶段 | 时期 | 特征 |
|------|------|------|
| 1995-2008 | 禁令期 | 1995年新预算法明令禁止地方政府发债，靠融资平台+国债转贷 |
| 代发代还 | 2009-2010 | 应对金融危机，财政部代发代还 |
| 试点自发代还 | 2011-2013 | 6省市试点 |
| 试点自发自还 | 2014 | 10省市试点 |
| **全面自发自还** | 2015至今 | 所有省份均可自发自还 |

**当前框架**：43号文（国发[2014]43号）+ 新预算法（2015）后，地方政府举债**只能通过发行政府债券**。

## 4.2 地方债的三种分类

### 维度1：按项目是否有收益

| 类别 | 用途 | 列入哪本账 |
|------|------|-----------|
| **一般债** | 公益性项目（无收益） | 一般公共预算 |
| **专项债** | 公益性项目（有一定收益） | 政府性基金预算（不增加赤字） |

### 维度2：按资金用途

| 类别 | 用途 |
|------|------|
| **新增债** | 用于新项目建设；额度由财政部下达 |
| **置换债** | 2015-2018年发行，将非债券形式存量债务（贷款等）置换为政府债券；不增加债务余额 |
| **再融资债** | 2018年5月正式提出，偿还到期地方政府债券本金 |
| **特殊再融资债** | 2020年12月起，用于偿还纳入预算管理的存量债务 |
| **特殊置换债** | 2024年12万亿框架启动后，用于置换隐性债务 |

### 维度3：按发行方式
- **公开发行**：竞价
- **定向发行**：定向承销，主要用于置换或特殊再融资

## 4.3 地方债限额管理

### 总量原则

地方债实行限额管理制度，新增地方政府债券限额遵循**"正向激励"原则**——按"地方财力"和"重大项目支出"两个维度量化分配，并兼顾"限额空间"调节。

### 限额调配的三种类型

| 调配类型 | 描述 | 频率 |
|---------|------|------|
| 一般限额↔专项限额调配 | 2016年首次大规模；2019及之后罕见 | 罕见 |
| 债务限额跨地区调配 | 国家通过限额回收再分配 | 历史性 |
| **债务限额跨年度调配** | 用于置换债的特殊再融资债+特殊置换债 | **化债关键工具** |

### 限额空间

- 限额空间 = 地方政府债务限额 - 债务余额（理论剩余举债空间）
- 2024年起12万亿化债框架使用大量限额空间
- **2025年5000亿地方债务结存限额下达**（充分利用历史结存的限额）

## 4.4 地方债发行节奏

### 历史规律

- **2019年之前**：3月之后开始发行
- **2019-2024年**：提前批发放→Q1前置发行
- **2025-2026年**：发行节奏继续前置，提前批占下年总额度的60%
- **2026年Q1**：新增专项债累计发行约1.16万亿，发行进度26.4%，明显快于2025年同期21.8%和2024年同期16.3%

### 投向变化

| 时期 | 主要投向 |
|------|---------|
| 2017-2018 | 土地储备、收费公路、棚改 |
| 2019-2020 | 七大重点领域 + 两新一重 + 城镇老旧小区改造 + 公共卫生 |
| 2024起 | **允许用于土储**（首次开放）、**收购存量商品房**、化债 |
| 2025-2026 | 化债+稳增长两条线；自审自发试点扩大 |

### 当前发行结构（2025-2026）

**关键澄清**：2026年专项债"全口径"发行规模拆为两部分（**平行关系，不是占用**）：

| 工具 | 规模 | 用途 |
|------|------|------|
| **传统新增专项债**（年初额度4.4万亿，2025-2026持平） | 4.4万亿 | **绝大多数用于投资项目**（基建+保障房+收储+设备更新+自审自发试点等）；少数也可能用于化债，但需明确说明用途 |
| **化债置换专项债**（6万亿框架年度额度） | 2万亿 | **专门用于隐债置换**，单独下达，与4.4万亿不重复 |
| 合计 | 约6.4万亿 | — |

## 4.5 地方债的偿还

### 一般债 vs 专项债偿还方式对比

| 维度 | 一般债 | 专项债 |
|------|--------|--------|
| 偿债资金来源 | 一般公共预算（税收） | 项目收入；不足时基金预算补偿 |
| 列报科目 | 一般公共预算支出（债务还本支出） | 政府性基金预算支出 |
| 续作机制 | 借新还旧（再融资债） | 借新还旧（再融资专项债） |

### 接续率

```
接续率 = 当年用于偿还到期债券本金的再融资债发行规模 / 当年地方债到期量
```

**接续率必须≤100%**。2019-2021年接续率呈下降趋势（财政纪律加强），但近年化债推进下接续率维持高位。

## 4.6 化债：12万亿框架（核心）

### 化债节点回溯

| 时间 | 事件 |
|------|------|
| 2014年43号文 | 政府性债务管理制度正式确立 |
| 2015-2018年 | 12.2万亿置换债（基本完成） |
| 2019年起 | 部分地区通过再融资债偿还存量债务（隐含隐债置换） |
| 2020.12 | 首批"特殊再融资债"发行（建制县区试点） |
| 2021.10 | 广东、北京全域无隐性债务试点 |
| 2023.10 | 化债重启，1.5万亿特殊再融资债 |
| **2024.11** | **12万亿化债大招（6+4+2框架）** |
| 2025 | 首批2万亿置换债全部发行完毕，平均利息成本降低2.5个百分点+ |
| 2026 | 化债常态化推进；强调"严防虚假化债、违规化债" |

### 12万亿化债框架（2024年11月推出）

```
6万亿专项债置换隐债（3年，2024-2026每年2万亿）
 +
4万亿地方政府债务限额（5年，每年8000亿，2024-2028）
 +
2万亿（2029年前到期的棚改隐债，原合同偿还）
 = 12万亿
```

**意义**：
- 隐性债务平均利率从约6%降至约2%
- 减轻地方政府利息支出约6000亿元（5年累计）
- "解放"地方财政更多资源用于稳增长
- 化债思路从"严控+被动消化"转向"主动置换+财政纪律"双管齐下

### 城投生态变化

- 2017-2021：政策严控+部分非标违约
- 2022-2023：35号文后退平台政策推进
- 2023.10起：化债重启，城投估值收益率快速下行
- 2024.11起：12万亿大招，城投信仰阶段性强化、估值进一步压缩
- 2025-2026：化债"常态化"，城投存量化解节奏加快、平台主体逐步退出政府融资职能

## 4.7 自审自发改革（2025-2026新动向）

**背景**：专项债额度大但项目储备和审批低效是长期瓶颈。

**改革要点**：
- 部分省份扩大"自审自发"试点
- 项目审批权下放，地方自审自发的新增项目
- 6月以后是关键节点（2025年）—— 关注地方自审自发项目启动情况
- 关注专项债资金用途分配（偿还拖欠款 / 城市更新 / 收储 / 补充项目资本金）

## 4.8 投资交易要点

### 发行场所与投资者
- 全国银行间债券市场（主导）
- 银行是地方债最主要持有者

### 利差
2020年4月窗口指导后，地方债与国债利差稳定在**15-30BP区间**（招标定价应高于国债收益率10BP以上、低于25BP的弹性区间）。

### 期限结构
- 2015年：以1Y、3Y、5Y、7Y、10Y为主
- 2018年起期限拉长（加入15Y、20Y、30Y）
- 2020-2025年平均发行期限延长至14年+
