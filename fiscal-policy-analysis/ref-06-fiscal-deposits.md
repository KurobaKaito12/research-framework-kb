# 财政存款与流动性传导

## 6.1 财政存款的两个口径

| 口径 | 数据源 | 特征 |
|------|-------|------|
| 货币当局政府存款 | 央行资产负债表负债端 | 中央+地方国库存款 |
| 金融机构财政性存款 | 金融机构人民币信贷收支表 | 财政性存款+机关团体存款 |

**两者差额主要来自国库定存**（央行投放货币的工具之一）。

> **机关团体存款"名为政府存款，实为一般存款"**：1998年央行通知将其从财政性存款剥离，按一般存款比例缴准，对流动性几乎无影响。**研究流动性时主要讨论狭义财政性存款（不含机关团体存款）**。

## 6.2 财政存款变化的驱动

**理论公式**：
```
Δ财政存款 = 税收收入 + 政府性基金收入 + 非税收入 + 政府债净融资 - 财政支出
```

实际拆分为三个分项基本能解释月度波动（拟合度90%+）：
- 公共预算收支差额
- 政府性基金预算收支差额
- 政府债净融资（国债+地方债）

## 6.3 财政存款的季节性规律

| 月份 | 性质 | 主因 |
|------|-----|------|
| 1、4、5、7、10月 | **典型增加月** | 缴税大月（增值税申报+企业所得税预缴）+季初无支出 |
| 3、6、9、12月 | **典型减少月** | 季末支出冲量 |
| 2、8、11月 | 规律不明显 | 春节因素扰动等 |

### 缴税大月强度排序

| 月份 | 强度 | 主因 |
|------|------|------|
| 5月 | ★★★★★ | 企业所得税年度汇算清缴 |
| 10月 | ★★★★★ | 增值税申报+企业所得税Q3预缴 |
| 4月、7月 | ★★★★ | 增值税+企业所得税预缴 |
| 1月 | ★★★ | 春节前缴税前移+个税年度汇缴 |

> **个税不集中纳税，对资金面冲击较小**；增值税分散性强；**所得税是真正的"季节性扰动制造者"**——分季预缴+5月汇算清缴。

## 6.4 财政存款对流动性的影响

### 路径1：影响央行储备货币

```
Δ储备货币 = Δ外汇占款 + Δ对其他存款型公司债权 - Δ政府存款 + Δ其它杂项
```

**机制**：缴税使企业一般存款（按比例缴准）转变为财政存款（全额上缴央行、不计提准备金），银行超额准备金下降，央行储备货币减少。

**反向关系**：政府存款上升 ↔ 储备货币下降（银行间流动性收紧）；反之亦然。

### 路径2：影响广义货币M2

```
ΔM2 = Δ各项贷款 + Δ外汇占款 - Δ财政存款 + Δ其它杂项
```

**机制**：财政存款不计入M2，缴税使企业/居民存款（计入M2）转变为财政存款（不计入），M2减少；财政支出反向。

> **M2与政府存款季节性"反相位"是常态**，分析M2变化时需剔除财政因素。

## 6.5 主要税种纳税期限

| 税种 | 纳税期限 |
|------|---------|
| 企业所得税 | 月度或季度预缴（次月/次季15日内）；年度终了后5个月汇算清缴 |
| 个人所得税 | 次月15日内缴纳 |
| 国内增值税 | 1日、3日、5日、10日、15日、1个月或1个季度（次月/次季15日内申报） |
| 进口增值税 | 海关填发缴款书之日起15日内 |
| 国内消费税 | 与增值税相同 |

## 6.6 看财政存款的"三个抓手"

1. **看节奏**：缴税大月（1/4/5/7/10）vs 支出大月（3/6/9/12）的资金面规律
2. **看驱动**：拆分公共预算、基金预算、政府债净融资三项是否符合季节性
3. **看协同**：政府债大月发行 + 财政存款上升 → 银行间资金面承压；央行是否配合（降准/加大OMO投放）是关键
