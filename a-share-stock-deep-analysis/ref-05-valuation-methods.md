# 估值方法论与定价

估值是科学与艺术的结合——精确的错误不如模糊的正确。

## 一、估值方法分类

### 相对估值法
| 方法 | 适用场景 | 局限性 |
|------|----------|--------|
| PE | 盈利稳定的成熟企业 | 亏损企业不适用；周期股PE陷阱 |
| PB | 重资产行业 | 轻资产企业PB失真 |
| PS | 高增长亏损企业 | 不考虑盈利能力 |
| PEG | 成长股 | 增速预测不准则PEG也不准 |
| EV/EBITDA | 资本密集行业 | 忽略资本支出差异 |

### 绝对估值法
| 方法 | 适用场景 |
|------|----------|
| DCF | 现金流稳定可预测的企业 |
| DDM | 稳定高分红企业 |
| NAV | 资源类/地产类企业 |

## 二、周期股PE陷阱

- 周期股PE最低时往往是盈利顶峰 = 卖出信号
- 周期股PE最高时往往是盈利底部 = 买入信号
- 周期股应使用PB或EV/EBITDA估值

## 三、PEG应用

```
PEG = PE / 未来3年预期年化利润增速(%)
PEG < 1：可能被低估
PEG = 1：合理估值
PEG > 1.5：可能被高估
```

## 四、不同类型公司的估值方法

| 公司类型 | 首选方法 | 辅助方法 |
|----------|---------|---------|
| 消费龙头 | PE + DCF | PEG |
| 科技成长 | PS + PEG | DCF（远期） |
| 金融（银行） | PB | DDM |
| 周期股 | PB + EV/EBITDA | — |
| 地产 | NAV | PB |
