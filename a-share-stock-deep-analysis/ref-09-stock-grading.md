# 个股综合评级体系

将多维度分析汇总为结构化的个股评级。

## 一、评级维度与权重

### 六维评分体系
| 维度 | 权重 | 核心指标 | 评分范围 |
|------|------|---------|----------|
| 商业模式 | 15% | 盈利模式清晰度、产业链定位、定价权 | 1-10分 |
| 财务质量 | 20% | ROE趋势、FCFR、三张表匹配度 | 1-10分 |
| 护城河 | 20% | 竞争优势来源、深度、可持续性 | 1-10分 |
| 估值 | 20% | 安全边际、估值分位、横向比较 | 1-10分 |
| 催化剂 | 15% | 预期差方向、催化剂确定性、时间窗口 | 1-10分 |
| 风险 | 10% | 致命风险排查、重大风险评估 | 1-10分（逆向） |

### 综合评级
| 综合得分 | 评级 | 含义 |
|----------|------|------|
| 8.0-10.0 | S级（强烈推荐） | 商业模式优秀+财务健康+低估+明确催化 |
| 6.5-7.9 | A级（推荐） | 多数维度良好，有一两个突出优势 |
| 5.0-6.4 | B级（中性） | 各维度一般，缺乏明显的超额收益来源 |
| 3.5-4.9 | C级（谨慎） | 存在明显短板或风险 |
| <3.5 | D级（回避） | 存在致命风险或多个重大风险 |

## 二、各维度评分细则

### 商业模式评分
| 分值 | 标准 |
|------|------|
| 8-10 | 一句话说清商业模式，有强定价权，现金流优秀 |
| 6-7 | 模式清晰，有一定定价权，现金流良好 |
| 4-5 | 模式一般，定价权弱，现金流中等 |
| 1-3 | 模式复杂/不清晰，无定价权，现金流差 |

### 财务质量评分
| 分值 | 标准 |
|------|------|
| 8-10 | ROE>15%且趋势向上，FCFR>0.8，三表完美匹配 |
| 6-7 | ROE>10%且稳定，FCFR>0.5，三表基本匹配 |
| 4-5 | ROE波动大或趋势平，FCFR不稳定 |
| 1-3 | ROE下行，FCFR为负，三表存在疑点 |

### 护城河评分
| 分值 | 标准 |
|------|------|
| 8-10 | 多重壁垒叠加，竞争优势5年以上无虞 |
| 6-7 | 有明确壁垒，但可能被逐步侵蚀 |
| 4-5 | 壁垒较弱，领先优势2-3年 |
| 1-3 | 几乎无壁垒，完全竞争 |

### 估值评分
| 分值 | 标准 |
|------|------|
| 8-10 | 低于内在价值30%以上，历史分位<20% |
| 6-7 | 低于内在价值10-30%，历史分位20-40% |
| 4-5 | 接近内在价值，历史分位40-70% |
| 1-3 | 高于内在价值，历史分位>70% |

### 催化剂评分
| 分值 | 标准 |
|------|------|
| 8-10 | 有高确定性催化剂，预期差明确指向正面 |
| 6-7 | 有中确定性催化剂，预期差可能正面 |
| 4-5 | 催化剂不明确，预期差方向不清 |
| 1-3 | 缺乏催化剂，或预期差指向负面 |

### 风险评分（逆向：分数越高=风险越低）
| 分值 | 标准 |
|------|------|
| 8-10 | 无致命风险，重大风险可控 |
| 6-7 | 无致命风险，有1-2个需要关注的重大风险 |
| 4-5 | 存在不确定的重大风险 |
| 1-3 | 存在致命风险或多个高概率重大风险 |

## 三、特殊调整因子

### 一票否决项
以下情况直接降为D级：
- 确认财务造假
- 退市风险
- 实控人涉刑事风险
- 资不抵债

### 加分项
| 因素 | 加分 | 说明 |
|------|------|------|
| 产业资本净增持 | +0.5 | 内部人真金白银看好 |
| 机构持仓持续增加 | +0.3 | 聪明钱认可 |
| 处于行业高景气周期 | +0.5 | 顺风而行 |
| 管理层优秀（有长期记录） | +0.3 | 一流人才做三流生意可以做成一流 |

### 减分项
| 因素 | 减分 | 说明 |
|------|------|------|
| 大股东减持/高比例质押 | -0.5 | 内部人行为背离 |
| 行业处于下行周期 | -0.5 | 逆风前行 |
| 公司治理存在瑕疵 | -0.3 | 利益输送风险 |
| 商誉/净资产>30% | -0.3 | 减值风险 |

## 数据工具指南

| 评级维度 | 推荐工具 | 用法说明 |
|----------|---------|---------|
| 商业模式 | 股票信息 + 财务数据 | 获取主营构成、行业定位及收入结构数据 |
| 财务质量 | 财务数据 | 获取ROE、FCFR、三表核心指标进行质量评分 |
| 护城河 | 股票检索 + 财务数据 | 筛选同行并对比ROE/毛利率，验证竞争优势持续性 |
| 估值 | 财务数据 + 指标搜索/数据需求 | 获取估值指标与无风险利率，进行绝对/相对估值 |
| 催化剂 | 资讯检索 + 公告检索 + 公司事件 | 扫描新闻/公告/事件，识别预期差与催化剂 |
| 风险 | 风险指标 + 股东数据 + 公司事件 | 量化风险指标+大股东行为+风险事件综合排查 |
| 行情概览 | 股票概要 + 数据需求 | 获取最新行情快照与资金流向作为辅助参考 |
| ESG评估 | ESG数据 | 获取ESG评分，纳入风险维度的补充评估 |
