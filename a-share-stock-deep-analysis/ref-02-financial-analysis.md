# 财务分析与杜邦拆解

## 一、杜邦分析：ROE三因素拆解

```
ROE = 净利率 × 资产周转率 × 权益乘数
```

| 驱动模式 | 典型行业 | 投资含义 |
|----------|----------|----------|
| 高净利率型 | 白酒、医药、软件 | 护城河强，估值可给更高 |
| 高周转率型 | 零售、家电、快消 | 运营效率是核心竞争力 |
| 高杠杆型 | 银行、地产 | 杠杆是双刃剑，关注风险 |

## 二、自由现金流分析

```
FCFF = 经营活动现金流净额 - 资本性支出
```

FCFR（自由现金流/净利润比率）：
- FCFR > 1：现金流质量优秀
- FCFR 0.5-1：正常范围
- FCFR < 0.5：利润质量堪忧

## 三、三张表交叉验证

### 关键警示指标
- 利润增长但经营现金流下降 → 利润质量存疑
- 营收增长但应收账款增长更快 → 赊销推动
- 利润高但不分红且频繁融资 → 利润可能不真实
- 在建工程长期不转固 → 可能虚增资产
