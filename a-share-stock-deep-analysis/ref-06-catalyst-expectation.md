# 催化剂识别与预期差分析

股价的驱动力来自预期差，而非绝对好坏。

## 一、预期差分析框架

### 核心公式
```
股价变动 = f(现实 - 预期)
```
- 利好事件但已被充分定价 → 股价不涨反跌（"见光死"）
- 利空事件但比预期好 → 股价反弹
- 分析师一致预期的集中修正方向 = 预期差的方向

### 预期差来源
| 来源 | 机制 | 可操作性 |
|------|------|----------|
| 盈利超预期 | 季报/年报业绩大超分析师一致预期 | 高——跟踪高频数据可前瞻 |
| 政策超预期 | 政策力度或方向超出市场预期 | 中——政策信号可追踪但难精确 |
| 行业拐点 | 行业景气出现未被市场定价的拐点 | 高——中观数据可验证 |
| 技术突破 | 新技术/新产品进度超预期 | 低——信息不对称大 |
| 竞争格局变化 | 龙头份额加速集中或新进入者颠覆 | 中——需要产业链调研 |

### 预期差分析步骤
1. **确定市场一致预期**：分析师一致盈利预测、市场隐含增速
2. **收集领先信号**：高频数据（月度销量、价格、订单）、产业链反馈
3. **判断预期差方向**：现实是否会好于/差于一致预期
4. **评估定价程度**：股价是否已反映预期差

## 二、催化剂分类与分级

### 按时间维度分级
| 级别 | 持续性 | 操作策略 | 典型案例 |
|------|--------|---------|----------|
| 宏观级催化 | 半年以上，周期性 | 可以右侧参与 | 降准降息、产业政策大周期 |
| 行业级催化 | 1-3个月，短平快 | 不建议右侧，左侧布局 | 行业旺季、供需缺口 |
| 个股级催化 | 取决于利好程度 | 事件驱动，快进快出 | 业绩暴增、重组、大单 |

### 按确定性分级
| 确定性 | 特征 | 策略 |
|--------|------|------|
| 高确定性 | 政策已发布、订单已签、产能已投 | 可以加仓位 |
| 中确定性 | 产业趋势明确但节奏不确定 | 标准仓位 |
| 低确定性 | 预期/主题驱动，尚无基本面验证 | 小仓位试错 |

## 三、盈利预期差跟踪

### 季报预期差分析
- **事前**：利用高频数据和中观指标预判业绩
- **事后**：比较实际业绩与一致预期的偏差
- **定价**：观察业绩公布后股价反应
 - 超预期但股价不涨 → 市场已提前定价或认为不可持续
 - 不及预期但股价不跌 → 市场已预期到利空或认为是短期扰动

### "预期共振"行业轮动
- 淡化个股预期变化的绝对水平
- 聚焦行业内个股分析师预期调整的**共振方向**
- 大多数个股预期同方向修正 → 行业景气趋势信号强

### 滚动更新
- 每季度基于预期差分析结果校准盈利预测模型
- 寻找"预期惯性"或"认知盲区"：市场是否一贯高估或低估某行业
- 利用连续的预期差跟踪捕捉Alpha机会

## 五、个股催化剂清单

分析个股时，系统检查以下潜在催化剂：

| 维度 | 具体催化剂 |
|------|-----------|
| 业绩 | 业绩超预期、订单加速、提价成功、降本增效 |
| 产品 | 新产品发布、产品通过认证、大客户导入 |
| 产能 | 新产能投产、产能利用率提升 |
| 政策 | 行业扶持政策、税收优惠、补贴 |
| 资本 | 股票回购、大股东增持、股权激励 |
| 治理 | 管理层更换、资产注入、分拆上市 |
| 行业 | 供给出清、竞争对手退出、需求拐点 |
