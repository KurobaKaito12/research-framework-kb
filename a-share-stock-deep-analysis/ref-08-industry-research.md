# 行业研究方法论

行业研究 = 理解供需规律 + 跟踪景气变化 + 判断竞争格局。

## 一、行业研究起步三件事

### 1. 明确定义与分类
- 行业 = 提供同类产品/服务的企业集合（供给概念）
- 产业 = 产品/服务有协作关系的多个行业集合
- 行业特征归结为两点：**特定产品** + **企业群体**

### 2. 了解行业发展史
行业发展史的三大价值：
- **起点蕴含根本价值**：产品最初解决什么需求？
- **发展揭示分化方向**：企业战略、盈利模式如何分化？
- **历史信息构筑全貌**：产品、技术演变，企业成长更替

### 3. 核心问题导向
行业研究要回答三个递进问题：
- **是什么**：行业规模、增速、结构、参与者
- **为什么**：驱动增长的因素、竞争格局形成的原因
- **怎么办**：投资哪个环节、选择哪些公司

## 二、行业分析框架

### 波特五力模型
| 力量 | 分析要点 | 对行业利润的影响 |
|------|---------|----------------|
| 行业内竞争 | 集中度、差异化程度、退出壁垒 | 竞争激烈→利润压缩 |
| 潜在进入者 | 进入壁垒高低、资本需求 | 壁垒低→长期利润受压 |
| 替代品威胁 | 替代品性价比、转换成本 | 替代品强→定价权受限 |
| 供应商议价力 | 供应商集中度、原材料替代性 | 议价力强→成本端受压 |
| 客户议价力 | 客户集中度、转换成本 | 议价力强→价格端受压 |

### 产业链分析
```
上游（原材料/设备）→ 中游（制造/加工）→ 下游（品牌/渠道/终端）
```
- 利润在产业链中的分配取决于各环节的**供需关系**和**竞争格局**
- 产业链上最稀缺的环节获取最大利润
- 上游看资源，中游看技术和规模，下游看品牌和渠道

## 三、行业景气度跟踪

### 景气度的本质
景气度 = 行业供需关系的状态，反映行业的盈利趋势。

### 分行业跟踪方法
| 行业类型 | 核心跟踪指标 | 数据频率 |
|----------|-------------|---------|
| 消费品 | 终端销售数据、渠道库存、提价幅度 | 月度/周度 |
| 周期品 | 产品价格、开工率、库存 | 日度/周度 |
| 科技制造 | 订单、产能利用率、渗透率 | 月度/季度 |
| 金融 | 信贷数据、利差、资产质量 | 月度 |
| 地产 | 销售面积、土地成交、新开工 | 月度 |

### 景气度拐点识别
- **量的拐点**：订单/销量增速见底回升
- **价的拐点**：产品价格触底反弹
- **利润的拐点**：毛利率/净利率开始改善
- 通常顺序：价格先行 → 量跟随 → 利润最后确认

## 四、竞争格局分析

### 集中度与格局类型
| 格局类型 | 特征 | 投资含义 |
|----------|------|----------|
| 完全竞争 | CR3<10%，大量小企业 | 难以找到持续优势的公司 |
| 分散竞争 | CR3=10-30%，有区域龙头 | 关注份额提升逻辑 |
| 寡头竞争 | CR3=30-70%，少数大企业 | 龙头溢价合理，关注价格战风险 |
| 双寡头/垄断 | CR3>70% | 护城河深，定价权强，估值可给更高 |

### 竞争格局的演变方向
- **集中度提升**（正面）：行业出清、龙头份额扩大 → 利好龙头
- **集中度下降**（负面）：新进入者增加、技术降低壁垒 → 利润分散

## 五、新兴行业分析特殊框架

### 渗透率S曲线
新兴行业投资的核心是判断渗透率位置：
- **0-10%**：概念导入期，高风险高赔率
- **10-30%**：快速渗透期，最佳投资窗口
- **30-50%**：加速到减速的拐点，增速见顶
- **>50%**：成熟期，增速放缓，估值收缩

### 新兴行业的关键变量
1. 技术成熟度（是否跨过了商业化门槛）
2. 成本曲线（是否达到经济性拐点）
3. 政策支持力度（补贴、标准、准入）
4. 产能建设节奏（供给过剩风险）
5. 终端需求真实性（是否靠补贴拉动）

## 数据工具指南

### 年报中的行业竞争格局信息

分析行业竞争格局和产能变化时，上市公司年报/半年报中的"行业格局与趋势"章节是重要的一手信源。通过 公告检索 搜索行业内多家公司的年报，交叉比对可获得市场份额、技术路线、产能扩张计划、上下游关系等信息。

| 分析步骤 | 推荐工具 | 用法说明 |
|----------|---------|---------|
| 行业景气指标获取 | 指标搜索 + 数据需求 | 先搜索行业PMI/产量/价格等指标ID，再获取时序数据 |
| 行业内公司筛选 | 股票检索 | 按行业分类筛选上市公司，分析竞争格局和集中度 |
| 行业政策与动态 | 资讯检索 + 公告检索 | 搜索行业政策文件、产业规划及行业新闻 |
| 行业资金流向 | 指标搜索 + 数据需求 | 搜索行业资金流向相关指标，获取行业板块资金流入流出数据，判断资金偏好 |
| 行业公司财务对比 | 财务数据 | 批量获取行业内公司的营收增速、毛利率等对比指标 |
| 行业竞争格局与产能 | 公告检索 | 搜索行业内多家公司年报，交叉比对"行业格局与趋势"章节和产能数据 |
