# 财务造假识别与排雷

## 一、五步排雷流程

1. **判断行业风险**：资产难以清点/收入确认灵活/关联交易密集/现金交易为主
2. **分析公司治理和关联交易**：实控人、供应商客户是否关联方
3. **分析融资活动**：财务健康却频繁增发→异常
4. **关注可疑资本支出和并购**：高溢价收购后续大额商誉减值
5. **三张表交叉验证**：最有效的检测手段

## 二、四个匹配原则

| 匹配 | 检查要点 |
|------|---------|
| 实际vs报表 | 产品滞销但报表收入好→异常 |
| 同行业对比 | 行业低迷但一家逆势高增长→需验证 |
| 当期vs历史 | 会计政策突然变更→盈余管理嫌疑 |
| 报表项目间 | 利润大涨但经营现金流为负→利润不真实 |
