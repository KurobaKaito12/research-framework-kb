# 国债期货定价与期现指标

## 1. 定价起点

国债期货是以名义标准券为标的、以一篮子可交割国债进行实物交割的场内合约。分析顺序：

1. **可交割券篮子**：确认合约对应的可交割国债范围，必须用中金所最新通知复核。
2. **转换因子 CF**：把实际国债折算为票面利率 3% 的名义标准券。
3. **CTD**：空头会选择交割成本最低的券，常用最大 IRR 或最小净基差识别。
4. **理论价格**：由 CTD、carry、交割期权共同决定。
5. **期现指标**：IRR、基差、净基差、期货隐含收益率、跨期价差本质上都在刻画期现偏离。

---

## 2. 转换因子（CF）

CF 把实际国债折算为票面利率 3% 的名义标准券，等于以 3% 贴现率计算的债券价格。

**方向规律（方向写错是常见硬伤）：**

- 票面利率 > 3% → CF > 1（债券比标准券"贵"）
- 票面利率 < 3% → CF < 1（债券比标准券"便宜"）
- 票面利率 = 3% → CF ≈ 1，CF ≈ 该券净价（当 YTM = 3% 时）

**CTD 识别方向：**

当市场 YTM > 3%，高久期券的交割成本最低 → CTD 偏向长久期高券龄券；
当市场 YTM < 3%，低久期券的交割成本最低 → CTD 偏向短久期低券龄券；
同久期中，YTM 较高的券更可能成为 CTD（CF 相对更高，折算后卖给期货更有利）。

CTD 在利率波动较大或品种跨越 3% 分界时容易切换，切换会引起套保比率、DV01 和基差的跳变，分析中必须追踪。

---

## 3. 交割期权

**三类交割期权，重要程度不同：**

| 期权类型 | 内容 | 实务重要性 |
| --- | --- | --- |
| 转换期权（质量期权）| 空头可在可交割券中选择最便宜的券交割 | 最重要，净基差约等于其价值 |
| 月末期权 | 最后交易日后、交割月底前还可交割，利用价格波动 | 中金所逐日结算机制下可忽略 |
| 时机期权 | 在交割月内选择最优交割时机 | 国内合约设计下可忽略 |

净基差（BNOC）≈ 转换期权价值。交割临近时转换期权价值趋于耗尽，净基差趋向 0。

## 4. IRR 与正常范围

**定义：** IRR = 买入 CTD 现券 + 卖出期货、持有到交割的年化收益率。

```
IRR = (期货全价 × CF − CTD全价) / CTD全价 × 365 / (T − t)
```

**正常范围：** 正常市场下 IRR 在资金成本附近浮动，大致 1%–3%。

- IRR > 资金成本：正套空间打开，正套盘压制期货，基差趋于低位。
- IRR < 资金成本（甚至负值）：正套不经济，期货相对现券偏弱，基差偏高。
- IRR 长期偏低但不为负：交割期权价值较高，净基差偏宽。

**历史极端情形（帮助校验当前水位）：**

- IRR > 4%：历史上主要出现在 2017–2018 年（最高约 5.18%，2018/12/28），2019 年以来未再出现。若当前 IRR 接近或超过 4%，需额外核实并说明。
- IRR 深度为负：2016 年底至 2017 年初曾出现，当时大量机构通过空期货对冲信用债→空头集中→期货被压低→IRR 深度负值。这是反套逻辑成立的历史窗口，极为罕见。

## 5. 基差与净基差

```
基差 = CTD 现券净价 − 期货价格 × CF
净基差 = 基差 − 持有收益（carry）≈ 转换期权价值
```

**分析四层（不能只看绝对高低）：**

1. **哪个券的基差**：CTD、活跃券、新老券的基差可能差异很大，对应操作含义不同。
2. **合约生命周期哪一段**：临近交割基差受收敛约束更强，远月基差更受预期和资金影响。
3. **谁在驱动**：多头情绪、套保空头、正套盘、反套盘或移仓盘，驱动不同则应对逻辑不同。
4. **能否执行**：现券流动性、融券可得性、交易成本、保证金和资金成本决定真实收益。

## 6. 方向锚定恒等式（写任何因果链前必查）

利率衍生品分析最常见的硬伤是因果链里某一步符号写反。下面的恒等式是方向自检的唯一标准，凡写"A 变化导致 B 变化"，先对照此表逐步验证符号。

| 恒等式 | 推出的方向关系 |
| --- | --- |
| 基差 = 现券净价 − 期货价格 × CF | 期货涨→基差缩小；现券涨→基差走扩 |
| 期货 ≈ 现券 − carry，carry = 持有期票息 − 融资成本 | 融资成本↑→carry↓→期货折价缩小（期货相对现券变贵）；carry > 0 时期货贴水现券 |
| IRR 与基差通常反向 | IRR 高 ⟺ 期货（经 CF 调整）相对现券偏贵 ⟺ 基差低甚至负；IRR 低 ⟺ 基差高 |
| 净基差 = 基差 − carry ≈ 转换期权价值 | 净基差低 = 期权价值低，临近交割时自然趋零 |
| 跨期价差 = 远月 − 近月，中枢偏负 | 远月 carry 累积更多→折价更深；融资成本↑→carry↓→远月折价缩小→跨期价差↑（与"成本升价格跌"的直觉相反） |
| 移仓方向 | 多头移仓（卖近买远）→近月↓远月↑→跨期价差↑；空头移仓（买近卖远）→跨期价差↓ |
| 临近交割 | 基差向 0 附近收敛；净基差向 0 收敛；远月约束更弱 |

**自检动作：** 写完含因果方向的段落，挑出每处"↑/↓ 导致 ↑/↓"，逐一对照上表验证。特别警惕：

- "融资成本升→期货折价加深"（错，应是折价缩小）
- "多头移仓→跨期价差折价加深"（错，多头卖近买远→近月降远月升→价差扩大/折价减少）
- "IRR 高→期货偏弱"（错，IRR 高 ⟺ 期货相对现券偏贵）

## 7. 期货隐含 YTM

计算时先问用途：

1. **CTD 券法**：最精确。将 `期货价格 × CF` 视为 CTD 远期价格，结合交割日现金流反推收益率。用于套保、期现比较和精细套利。
2. **标准券法**：中长期趋势、品种间粗比较，降低计算复杂度，不能用于精细套利。
3. **简易法**：`期债YTM ≈ 名义票息 + (100 − 期货价格) / 大致久期`。盘中快速翻译价格变动，输出时必须提示是粗估。

注意：期债 YTM 忽略基差、CTD 切换和交割期权时精度下降。比较期货与现券 YTM 须确保同一合约、同一 CTD、同一日期。

## 8. 期现关系的四层判断

1. **理论层**：期货价格由现券价格、资金成本、票息收入和交割期权共同决定。
2. **套利层**：IRR > 资金成本时正套盘压低期货；IRR 过低时空头失去交割意愿，期货相对偏弱。
3. **交易层**：期货可能先反映消息，日间偏离会被基差和交割逻辑约束。
4. **制度层**：可交割券范围、CTD 切换、最后交易日、交割月保证金和交割流程影响可交易性。

## 9. 价格序列与回测

量化回测时须处理合约非连续性：

- 只用主力连续价格会忽略移仓收益/损失，扭曲空头和跨期策略。
- 建仓信号来自近月合约，移仓后应重新判断远月 IRR、基差和流动性，不能简单平移。
- 引用回测结论必须说明：价格序列处理方式、移仓日选择、交易成本、是否重新生成信号。

## 10. 当前数据检查清单

写任何当前国债期货分析前，至少检查：

- **合约**：主力/次主力、到期月、是否临近交割、可交割券范围。
- **定价**：CTD（品种、久期、YTM）、CF、IRR（vs. 资金成本）、基差、净基差（vs. 历史分位）、期债YTM。
- **市场**：价格涨跌、成交量、持仓量、成交持仓比、前二十会员净持仓。
- **现券**：对应活跃券收益率、期限利差、活跃券流动性和新老券利差。
- **资金**：R/DR、FR007、存单、回购融资和跨季/跨年因素。
- **执行**：保证金、现券融资/融券可得性、交割意愿、移仓进度。
