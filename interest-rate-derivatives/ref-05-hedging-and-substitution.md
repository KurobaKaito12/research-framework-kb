# 套保、多头替代与负久期

## 1. 先定义问题

套保类问题不要先问"用期货还是 IRS"，先定义组合风险：

1. **被套保资产是什么**：国债、政金债、信用债、组合还是未来买券需求。
2. **风险来源**：利率上行、曲线变形、赎回压力、供给冲击、信用利差还是流动性。
3. **套保期限**：日内/几天、几周、跨月、跨季还是长期。
4. **目标**：降低回撤、锁定收益、临时替代现券、做负久期还是提高资金效率。
5. **约束**：工具权限、保证金、授信、会计、现券能否卖出、IRS 能否冲销。

## 2. 国债期货套保

### 套保比例公式

**BPV/DV01 法（首选）：**

```
套保手数 = BPVP × CF / BPVCTD
```

其中 BPVP 为组合基点价值，BPVCTD 为 CTD 券基点价值，CF 为转换因子。

等价表达：`套保手数 = 组合DV01 / 单手期货DV01`，单手期货 DV01 ≈ CTD 券 DV01 / CF。

**修正久期法（缺乏精细 DV01 时）：**

```
套保手数 = P × MDP / (F × MDCTD)
```

其中 P 为组合市值，MDP 为组合修正久期，F 为期货价格，MDCTD 为 CTD 修正久期。隐含收益率平行移动假设，适合粗估。

**β 系数调整（被套保资产与 CTD 不完全匹配时）：**

```
调整后手数 = 理论手数 × β
```

历史回归 β 约为 1.3–1.7（被套保国债收益率对 CTD 收益率的敏感程度通常高于 1:1）。β 来自滚动回归，必须定期更新，尤其在利率快速波动时。

**跨久期交叉套保的 β 参考（被套保资产与 CTD 期限明显不同时）：**

| 被套保 vs CTD | 典型 β 范围 | 主要残差来源 | 适用场景 |
| --- | --- | --- | --- |
| 30Y vs 10Y CTD | 0.65–0.85 | 30Y-10Y 利差变动 | TL 工具受限时用 T 替代 |
| 10Y vs 5Y CTD | 0.80–0.95 | 10Y-5Y 利差变动 | T 工具受限时用 TF 替代 |
| 30Y vs 5Y CTD | 0.50–0.70 | 30Y-5Y 利差大幅波动 | 不推荐，残差过大 |
| 10Y 信用债 vs T CTD | 0.30–0.60 | 信用利差主导 | 仅对冲利率部分，信用部分裸奔 |

β 越低，套保残差越大。β < 0.7 时建议优先用期限匹配的合约，或组合多合约按久期缺口配比。

**套保效果参考排序：** 10Y 国债 > 10Y 地方债 > 10Y 国开债 > 信用债。信用债含信用利差风险，国债期货只对冲利率部分，残差较大。

### 标准流程

1. 明确被套保资产的期限、DV01、流动性和目标对冲比例。
2. 选择合约：期限匹配、流动性充足、与主力切换时间配合、基差/净基差水位合理。
3. 计算套保比例（见上方公式）。
4. 动态调整：CTD 切换、主力合约切换、久期自然缩短、基差变化都可能改变比例。
5. 退出/移仓：短期优先期货；长期须预估移仓成本。

### 成本与风险

- **基差风险**：卖出套保 ≈ 多现券 + 空期货，类似做多基差，基差收敛可能削弱套保收益。
- **移仓成本**：长期空头套保需反复移仓；远月−近月价差为负时，空头移仓有损耗。
- **CTD 切换**：被套保券与 CTD 的久期、票息、流动性不同，会造成比例跳变，需重新计算。
- **保证金压力**：现券浮亏和期货保证金占用可能叠加。
- **信用债套保残差**：国债期货只能对冲利率风险，信用利差走阔无法覆盖。

## 3. IRS 套保

IRS 更适合中长期久期对冲，尤其当投资者不希望卖出现券或期货移仓成本较高时。

**核心公式：**

```
多债券 + 支付固定端 IRS = Bond/Swap Basis + (FR007 − 实际融资利率)
```

Basis 和资金利差相对稳定时，套保效果较好；非银融资利率大幅高于 FR007、现券与 IRS 走势背离或冲销成本上升时，套保会失效。

**标准流程：**

1. 计算现券/组合 DV01。
2. 选择互换期限和标的（FR007、Shibor3M 等）。
3. 用 IRS DV01 计算名义本金和套保比例。
4. 检查 carry、roll、买卖价差和冲销机制。
5. 设定动态调整规则：收益率波动、组合久期变化、相关性变化、资金利差变化。

## 4. 国债期货 vs IRS

| 维度 | 国债期货 | IRS |
| --- | --- | --- |
| 交易场所 | 场内标准化 | 银行间/场外为主 |
| 退出 | 平仓便利 | 反向交易或冲销，流程更复杂 |
| 期限 | 季月合约，需移仓 | 可覆盖更长期限 |
| 成本 | 基差、移仓、保证金 | carry、basis、冲销、买卖价差 |
| 短期套保 | 更便利 | 可用但未必最优 |
| 长期套保 | 移仓成本高 | 相对更合适 |
| 主要风险 | CTD 切换、基差、流动性 | 资金利差、负 carry、冲销、期限错配 |

一般逻辑：短期快速对冲/止损/赎回压力 → 优先期货；长期持有/不能卖券/移仓成本高 → 优先 IRS；信用债/非标 → 先评估利率风险占比和相关性，再决定。

## 5. 多头替代

多头替代是用期货替代现券久期暴露：少量保证金买入期货，剩余资金投资低风险资产或保留流动性。

**简单替代：** 期货 + 存单替代现券。收益来源：期货涨价的久期收益 + 存单/货币基金利息收益 + 再投资收益。

**增强替代（博取净基差收敛超额收益）：** 当现券净基差处于历史高位时，卖出现券 + 买入期货，等待净基差向 0 收敛获取额外收益。

**净基差开仓参考阈值（主力合约历史 80% 分位）：**

| 品种 | 主力合约 80% 分位 |
| --- | --- |
| TS | 0.12 元 |
| TF | 0.34 元 |
| T | 0.20 元 |
| TL | 0.34 元 |

**全季月合约历史分位参考（更宽松，因非主力阶段净基差通常更高）：**

| 品种 | 80% 分位 | 90% 分位 |
| --- | --- | --- |
| TS | 0.16 元 | 0.26 元 |
| TF | 0.44 元 | 0.69 元 |
| T | 0.61 元 | 0.97 元 |
| TL | 0.32 元 | 0.46 元 |

净基差高于上述阈值时，增强替代的胜率较高；净基差偏低或临近交割时，交割期权价值趋零，增强空间有限。

**多头替代的五大技术风险：**

1. **CTD 切换风险**：切换后持有的现券不再是 CTD，基差可能不收敛。
2. **非 CTD 券基差不收敛**：持有非 CTD 券的净基差收敛不稳定。
3. **非主力阶段流动性差**：期货非主力阶段建仓和移仓成本上升。
4. **移仓换月成本**：若在多手跨期移仓中买远月付出溢价，侵蚀替代收益。
5. **保证金追加压力**：期货价格下跌时，现券账面盈亏与期货保证金追加可能错配。

**主要收益风险：**

- 期货没有票息；若现券 carry 很强，替代效果下降。
- 基差走扩伤害多头替代；净基差从低位走扩（期权价值提升）同样伤害替代头寸。
- 移仓可能带来正负收益，不能忽略。

## 6. 负久期策略（见 ref-08 详解）

负久期策略不是简单"看空债"，而是控制组合回撤、赎回风险或阶段性降低利率暴露。详见 ref-08。

简要工具选择：

- **空国债期货**：适合短期、流动性好、退出快；有基差和移仓成本。
- **支付固定端 IRS**：适合中长期；有负 carry、basis 和冲销成本。
- **组合式**：短期用期货止血，中期用 IRS 稳定对冲。

## 7. 套保方案模板

输出一份套保方案时按以下结构：

1. **一句话方案**：短期/长期、期货/IRS、套保比例和期限。
2. **组合风险画像**：资产期限、DV01、流动性、信用利差暴露、回撤容忍度。
3. **工具选择**：期货 vs IRS 的成本、期限和退出机制。
4. **套保比例**：BPV 法、修正久期法或回归法，说明 β 和再平衡规则。
5. **成本估算**：期货（基差/移仓/保证金）；IRS（carry/roll/basis/冲销）。
6. **动态调整**：CTD 切换、主力合约切换、资金收紧、basis 变动、组合久期变化。
7. **失效条件**：相关性下降、信用利差走阔、融资失败、流动性恶化。
8. **头寸限额与流动性**：确认套保手数不超过中金所持仓限额；核查近月/远月日均成交量能否在计划建仓期内平稳容纳手数；预留现货端和期货端同时不利时的保证金追加空间。
