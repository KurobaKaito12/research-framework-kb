# 输出范式与数据机制

模板给的是骨架，不是填空题。每个范式都服从一条更高的规则：**按主要矛盾决定详略，没有判断的小节不写。** 先读第 9-10 节的文风范例和反面清单，再回来用模板。

## 1. 通用写作原则

所有输出都要像卖方研究，但落点是买方操作：

- 开头先给核心判断，不先堆数据。
- **文字要有层次感，不要连续堆段落。** 每个一级标题下用**粗体短标签**（如 `**跟踪口径：**`、`**核心信号：**`、`**三种异常情形：**`）拉出子级结构；并列的情形、要点用 bullet list，每条粗体短语起头后接解释；大节之间用 `---` 分隔。读者应能 5 秒内扫到关键结论所在位置——扫不到就说明层次不够。
- 原因按主次排序：直接触发 -> 结构矛盾 -> 放大机制 -> 后续观察。每条都要是具体的事，不是抽象的"维度"。
- 数据进入原因链时要有边际含义：弱于前值、弱于预期、弱于季节性、环比转弱、结构项拖累或政策含义变化。正文只保留最关键的一两处比较，不要把内部数据核查过程写成段落。
- **跨品种/跨期限比较优先用可比口径。** 比较 TS/TF/T/TL、不同期限 IRS 或不同期限现券时，优先使用涨跌幅、bp变化、利差变化、分位数等可横向比较的指标；绝对价格变动、元/点数变化用于补充交易体感和关键点位。不要只用绝对涨跌来得出期限强弱结论。
- **核心结论要形成"事实 + 定价含义 + 策略落点"。** 好的摘要不是主题升华，而是先交代关键数据发生了什么，再说明当前定价处在什么位置，最后落到方向、工具、节奏、风险或触发条件之一。若一句结论只能概括主题，不能带来操作或风险含义，就压缩或删除。
- 高频事件是否展开取决于本次是否有边际信息，不取决于事件类别本身。央行公开市场操作、日常到期续作、例行公告等，如果在规模、期限、价格、净投放或政策信号上偏离常态，并改变资金预期或交易约束，可以是主线；如果没有边际变化，就不要进入正文，也不要为了说明"它不是核心"而专门提它。不要把某次点评的取舍泛化成所有场景的规则。
- 策略建议必须包含触发条件、观察锚（具体点位/区间）、风险点。
- **不做无增量推断。** 事实足够说明问题时，不要再补一句泛化判断；尤其少写"这说明市场不是交易 A，而是交易 B""期现同步说明不是单纯情绪"这类对操作没有新增贡献的句子。
- **避免章节重复。** 点评中"定价位置"和"后续操作"常常是一件事，若两节都会落到追涨赔率、回调买入和失效点位，就合并为"策略含义"。
- 当前市场任务必须写明数据截止时间；没有取到最新数据时明确说明，不用来路不明的数字填空。
- **典型判断处用历史案例落地。** 讲策略的机会窗口、失效条件、极端情形时，举一个可溯源的历史真实案例（背景、触发、当时指标水平、结果），比抽象论述更有交易思维和说服力。案例细节记不准就检索补全或只做定性描述，不编点位。不是每段都配，目的是落地不是凑字数。
- **表格精简直观，不替代文字。** 论述主体是文字；表格只把核心对照浓缩成一眼可读的快照，要干净直观。**该要的表格就要，不该要的不要**——判断标准是"这张表去掉，读者会损失什么"；答不上就删。不要刻意压表格数量，也不要每节都挂表把文字抽空。关键阈值、机制方向、操作含义必须在文字里说清，表格只放浓缩后的并列对照。
- 模板的小节是"可选项清单"，不是"必填项清单"。当下不构成矛盾、又没有操作含义的小节，压缩成一句话或并入相邻段落。
- 报告范式服务阅读体验，不要把内部检查清单、判断流程原样写进正文。用户要求的"要想清楚"通常是写作前的动作，不等于要把每一步都输出。
- **不写元话语。** 正文只是分析师对客户说的话。本 skill 里的检索纪律、数据纪律、期限/流动性提示——"长端报价稀薄不作为主表达""引用需谨慎""不用历史均值简单套""需以数据库复核""结论以定性为主"——是写给模型自己的执行指令，不进正文。缺数据时用自然的定性判断表达，不暴露内部流程。面向读者的披露（数据截止日、资料来源、口径说明）可以写；面向自己的执行备忘不写。

## 2. 事件/热点/点评类

适用：某日国债期货大涨大跌、TL 跌破/站上关键均线、IRS 异动、主力切换、持仓量异常、供给冲击、资金面冲击。

### 点评类的核心任务

点评不是把当天上涨/下跌的所有可能原因排一遍，而是回答三个问题：

1. **市场在交易什么**：基本面趋势变化、政策窗口打开/关闭、机构行为冲击、风险偏好切换、供给压力释放，还是技术位和移仓造成的阶段性波动。
2. **这个驱动能持续多久**：区分一次性交易、阶段性修复、趋势重定价和行情尾声。直接触发剂不一定是主因，必须说明它为什么能在当日放大，或为什么不能演变成趋势。
3. **后续怎么表达**：给出主推工具、节奏和失效条件。国债期货点评中，方向、跨品种、跨期、基差最多展开一到两个真正有交易含义的维度；先看本质矛盾，不能因为本次用了跨期，下次就机械套跨期。

推荐结构：

1. **现象和一句话判断**：价格、收益率、成交持仓、受冲击品种，带具体数字；随后直接给出"如何理解"的结论。
2. **真问题**：把表面事件翻译成市场真正关心的问题。例如弱数据点评要问"是否足以打开降息/宽松窗口"，关税/地缘点评要问"是交易性避险还是趋势冲击"，技术位点评要问"突破/跌破是否获得量仓和基本逻辑确认"。
3. **原因拆解**：按"直接触发剂 -> 核心矛盾 -> 放大机制 -> 反向约束"排序。每点都要是具体事实，不写"基本面因素""技术面因素"这种空筐。
4. **策略含义**：把定价程度和操作建议放在一起写，说明当前点位是否已经交易了相当预期、追涨/回调/止盈哪种节奏更合适。不要把单边、基差、跨期、跨品种、IRS 全部排一遍——多数时候只有一两个维度有机会，其余顶多一句话。
5. **执行细节**：若处在移仓、供给、政策窗口等特殊时点，即便它不是行情主线，也要补足会影响交易执行的指标。例如移仓窗口至少检查近远月成交持仓占比、跨期价差、近月 IRR/基差和合约选择。
6. **观察锚与失效条件**：关键点位、资金利率、成交量、持仓转移、IRR、基差、供给时点、政策窗口，尽量给具体数值；风险提示覆盖与结论相反的触发因素。

写作要点：

- 开头直接说"如何理解本轮调整/上涨"，然后第一、第二、第三给原因。
- 原因第一条通常写直接触发剂（具体事件、数据、政策、技术位），但必须随后写"为什么这个触发剂在此时有效"。例如弱数据不是自动利多债市，还要看数据是否改变政策预期、是否被资金面/机构行为放大、当前点位是否已提前定价。
- 写宏观数据时，至少交代一个"比较基准"：前值、市场预期、季节性、环比、结构分项或政策阈值。没有比较基准的数字不能独立支撑"增长斜率变化""政策预期变化"这类结论；但正文不要把所有比较基准都列出来。
- 写机构行为时要落到资产负债表或产品行为：债基赎回、理财/债基净申购、保险/银行配置、券商自营平券、套保盘止盈止损。不要只写"交易情绪变化"。
- 技术分析点评明确标注"纯技术视角"还是"技术+基本面综合视角"。
- 当主力切换或移仓节奏会改变行情解释时，要展开移仓比例、近远月价差、近月 IRR、基差和多空主导方。若移仓不是行情主线，但报告讨论的是移仓窗口内的期债策略，也要用一小段或表格给出上述最小检查，服务合约选择和风险提示。
- 给操作建议时，至少说清方向、节奏、工具和关键点位。正文要像交易建议，不要写成"方向/节奏/工具/点位"四项检查表；除非用户明确要求表格化。

### 点评类常用判断句式

- **交易而非趋势**：事件冲击明确，但利率区间、政策约束或风险资产表现尚未被打破，适合快进快出，不追涨杀跌。
- **修复而非反转**：技术位被收复/跌破，但中期均线、供给、通胀或配置承接尚未确认，原趋势只被部分修正。
- **趋势进入后半段**：核心逻辑仍在，但关键利差/点位已压缩到目标区间，后续更依赖新催化，操作从追随转为保护收益。
- **机构行为主导**：基本面消息不强，行情却对利好/利空钝化，需优先分析赎回、净申购、止盈止损、套保和配置盘承接。
- **移仓放大波动**：近月持仓仍高、远月承接加快或近远月价差偏离，价格变化可能混合了方向交易和换月交易，策略应切到远月或跨期表达。

## 3. 深度/专题类

适用：某一策略研究、年度/季度展望、科普、回测、工具比较、套保方案。

推荐结构：

1. **核心摘要/核心观点**：3-5 条，先给结论和适用场景，每条都含明确判断。
2. **问题本质**：该策略赚什么钱、为什么现在值得讨论。一两段说清，不铺陈定义。
3. **机制框架**：只保留得出结论所必需的逻辑链条，公式从简。
4. **历史复盘或情景测算**：用于验证框架，不把历史点位外推为当前阈值。
5. **实战细节**：建仓、配比、移仓、止盈止损、成本、流动性——这部分要具体，是专题的价值所在。
6. **当前策略建议**：结合最新数据给可操作表达。
7. **风险和失效条件**：CTD、基差、资金、供给、政策、冲销等。

专题最容易犯的两个错：变成概念百科，或只复述历史报告。每节自检"这节对当前或未来操作有什么用"，答不出就重写。

## 4. 周度/月度回顾与展望

适用：本周国债期货和 IRS 市场回顾、月报策略部分、双周报策略。

### 推荐总结构

1. **核心观点**：国债期货和 IRS 各 1-2 句，每句尽量同时包含关键事实、定价位置和策略落点；不要只写抽象主线。
2. **市场回顾**：先国债期货，再 IRS；按品种和驱动写，不写流水账。
3. **国债期货交易策略**：见下方说明。
4. **IRS 交易策略**：见下方说明。
5. **风险提示**：供给、资金、政策、基本面、海外、流动性。

### 国债期货市场回顾

- 主力合约价格、涨跌幅、收益率、成交量、持仓量和主力切换，带数据；跨品种强弱比较优先用涨跌幅，绝对涨跌只作辅助。
- 按时间线梳理行情，每段点出驱动判断，不写流水账。
- 点出哪个品种最强/最弱，背后是资金、供给、期限利差、技术位还是套保盘。
- CTD、IRR、基差、净基差、期债 YTM 的变化按需补充——有明显变化才写，没变化不必硬提；写出来就要落到正套/反套、多头替代、套保配比或入场节奏，不单独做指标概括。

### 国债期货交易策略——按主要矛盾详略

下面五个维度是**可选清单**。判断顺序：先确定本期主要矛盾是哪一两个，那一两个写透（含具体点位和触发条件），其余维度若无变化、无机会，一句话带过甚至不单列。

1. **方向策略**：现券方向 + 期债技术和量仓，给多空/观望条件和点位。
2. **期现/基差策略**：只在 IRR、基差、净基差出现可交易偏离，或临近交割、移仓时才展开。平时没有偏离，就写一句"期现指标处于常态，暂无明显套利空间"，不要为这个小节编出一段分析。
3. **跨品种策略**：曲线斜率/曲率有明确判断时才写，重点 TS-TF-T-TL。
4. **跨期策略**：临近移仓换月时写，含移仓进度、近远月价差、近月 IRR 和多空主导方；不在移仓窗口则可不写。
5. **套保/多头替代**：市场波动或供给风险较大时补充，否则不必硬写。

判断标准：如果一个小节删掉，读者不会损失任何当前信息，就该删或并掉。**用户反馈里"期现/基差策略像有用的废话"，根源就是把无矛盾的小节硬写成段落。**

### IRS 交易策略——按主要矛盾详略

同样是可选清单：方向、期差、Shibor/FR007 basis、养券回购/套保。本期 IRS 没有独立机会时，可以只写方向一段，明确说明期差/basis 当前无催化即可，不必每个都铺开。

## 5. 回顾展望类（半年度/年度等跨期回顾 + 前瞻）

适用："2026 年以来衍生品市场回顾及下半年展望""国债期货年度回顾与展望"等。这类报告 = 扎实的回顾 + 有判断的展望，两部分都不能虚。

### 回顾部分的硬要求

- **分阶段，带时间线。** 把回顾区间拆成 2-4 个阶段，每个阶段给：时间段、关键点位变化、驱动事件、市场表现。例如"1 月-2 月中：资金面转松带动期债修复，TL 主力从 X 涨到 Y，驱动是 …"。
- **国债期货和 IRS 都要回顾，不能偏科。** 如果任务标题是"衍生品市场回顾"，国债期货的阶段性行情、主力品种表现、移仓交割特征必须有独立篇幅；只写 IRS 或只写期货都算跑题。
- **回顾以行情复盘为主，不给行情乱起名字。** 优先回答"哪段时间、哪个品种、涨跌多少、由什么驱动、留下什么矛盾"。少写"进入某某行情""从 A 扩展为 B""市场属性发生变化"这类抽象标签，除非后文能用数据和策略含义支撑。
- **回顾要有真实细节。** 关键点位、关键事件必须能溯源到行情数据或公开报道。检索不到具体数据时，用定性的阶段性描述（"一季度期债震荡偏强""二季度长端波动加大"），不要用"市场呈现复杂特征"这类空话占位，也不要编造点位。
- 回顾不只是叙事，每个阶段末尾要有一句"这个阶段教会我们什么 / 遗留什么矛盾到下半年"，但这句话必须是具体约束或策略含义，不写抽象升华。

### 展望部分

- 先给下半年/下一年的**核心判断**（方向、曲线、主推策略），再展开。
- 展望要承接回顾：回顾里识别出的遗留矛盾，展望里要回应。
- 策略建议落到具体表达和触发条件，明确基准情景下主推什么，不要把所有情景平行铺开。
- 情景分析可保留（基准/乐观/调整），但要点明哪个是基准、概率倾向，以及各情景下的具体应对。

## 6. 套保方案输出

适用：客户问"用国债期货还是 IRS 套保""怎么对冲组合久期""负久期策略怎么做"。

推荐结构：

1. **一句话方案**：短期/长期、期货/IRS、套保比例和期限。
2. **组合风险画像**：资产期限、DV01、流动性、信用利差暴露、回撤容忍度。
3. **工具选择**：国债期货 vs IRS 的成本、期限和退出机制——结合本组合的具体情况选，不要把通用对比表抄一遍。
4. **套保比例**：DV01法、修正久期法，或滚动相关性/波动率法。
5. **成本估算**：期货基差/移仓/保证金；IRS carry/roll/basis/冲销。
6. **动态调整**：CTD切换、主力合约切换、资金收紧、basis变动、组合久期变化。
7. **失效条件**：相关性下降、信用利差走阔、资金融资失败、流动性恶化。

## 7. 科普/概念解释

**仅在用户明确要求科普时使用本范式。** 常规市场报告、策略报告、点评里不要插入概念科普段落——面向专业读者，概念点到为止。

用户确实要科普时：

1. 一句话定义。
2. 放到完整定价链条中解释它解决什么问题。
3. 给一个简化示例或直觉，不使用过期历史券作为当前事实。
4. 说明常见误区。
5. 回到交易含义。

## 8. 输出自检

发送前逐项检查：

- [ ] 是否先说明了数据截止时间。
- [ ] 每个具体数字是否有来源和日期；有没有写下来路不明的精确数字。
- [ ] 宏观或行情数字是否写明了比较基准和边际含义，而不是只罗列数字。
- [ ] 跨品种/跨期限比较是否使用了可比口径，绝对涨跌是否只作为补充。

## 9. 文风范例（对标报告实际写法）

以下是固收点评/策略的真实写法特征，照着写：

**范例 A——点评开头与原因拆解（直接、具体、有触发剂）：**

> 昨日国债期货市场出现明显调整，尤以 TL 跌幅最大……如何理解本轮 TL 大幅调整？
> 第一，技术面看 TL 本身处在关键阻力位上。……遇到去年 12 月末前高、60 日均线、日线 BOLL 上轨等阻力压制……
> 第二，昨日上海楼市新政是直接触发剂。2 月 25 日午间，上海住建委等五部门发布《关于进一步优化调整本市房地产政策的通知》……
> 第三，移仓换月节奏放大波动。本轮移仓换月（2603→2606）进度整体偏慢，近月合约持仓量偏高，存在集中平仓需求……

要点：原因第一条往往是直接触发的**具体事件**（一项政策、一次发行），不是"市场情绪变化"这种抽象表述；每条原因都带具体细节（日期、文件名、合约对、点位）。

**范例 B——策略落点（具体到点位和信号）：**

> 对于国债期货，前期在技术关口不追涨，目前 TL 短期单边追空性价比也不高，做多时机需要等待更多积极信号：1）TL 在 111.7~112 附近能否企稳，对应日线 BOLL 中下轨的位置；2）成交量是否趋于萎缩，指向抛压减轻；3）MACD 等底背离信号。在此之前更多关注做窄基差、跨品种等机会。

要点：观察锚是**具体点位区间**和**具体技术信号**，不是"关注资金面变化"这类空话；策略建议明确"做什么、不做什么"。

**范例 C——市场逻辑论述（判断先行，论据跟进，不堆方法论）：**

> 当前债市核心逻辑清晰，资金面维持宽松格局，叠加理财-债基资金涌入，市场呈现出典型的"缺资产"状态……
> 首先，资金面持续且极度宽松是本轮行情的核心支撑……
> 其次，交易盘是行情重要推力。近日理财-债基持续获得净申购……基金交易盘成为市场主要买入力量，形成资金流入—收益率下行—申购进一步增加的正向循环。

要点：每段首句是判断，后面是支撑该判断的具体事实和机制；不写"需要从多个维度分析""判断顺序是"。

### 完整范例（点评/热点类——展示从核心观点到风险提示的全流程）

下面两篇是**结构与文风的范例**，按本 skill 的格式规则（核心判断先行、粗体短标签拉子级、并列项分条、`---` 分节）组织。文中数据为示意，仅用于展示写法，不作为当前事实引用。读的时候看两点：一是**怎么用结构把判断和证据组织得一眼可扫**，二是**怎么把"缺资产""共振修复非反转"这类有判断力的表达写进正文而不堆方法论**。

**范例 D——现券点评（曲线压平 + 缺资产行情）：**

> # 债市突破关键点位，进入新阶段
>
> **核心判断：** 做多动能持续释放，10Y 国债下破 1.75% 关键点位，超长端补涨是本轮核心特征。当下是资金极宽 + 理财-债基涌入下的典型"缺资产"行情，债市对基本面、通胀回升钝化——"一力降十会"。短期仍处友好环境、利差压缩有望延续，但"易操作阶段"或已近尾声，空间收窄、中期风险累积。
>
> ---
>
> **行情怎么走的。** 近三周显著偏强，4 月 21 日机构集中压平曲线，10Y 破 1.75%；20 年、50 年超长端尤为亮眼，补涨成主线。
>
> **支撑行情的四条线索（按主次）：**
>
> - **资金面极宽且持续——核心支撑。** 稳增长稳预期下流动性适度宽松；年初央行大额投放叠加 2、3 月财政存款分别净减 6165 亿、8547 亿，超储充裕；3 月起信贷动能放缓、资金淤积；银行负债端降息 + 结汇回升压低资金利率，DR001 在 1.2% 附近。
> - **交易盘是主要推力。** 理财-债基持续净申购，基金交易盘形成"资金流入—收益率下行—申购增加"正循环；配置盘偏谨慎，银行低位兑现、保险配置偏弱。
> - **供给不确定性出清。** 超长期特别国债发行计划落地，规模/节奏/期限的压制因素解除，为超长端打开下行空间。
> - **票据超季节性下行印证信贷偏弱。** 10 月期国股转贴现降至 0.79% 年内新低，票-国债、票-存单利差分别至 -37BP、-62BP，指向 4 月信贷投放一般。
>
> 基本面与通胀强于预期为何被忽视：前者未在融资需求上兑现，后者是输入性的，关键是都未改变货币宽松的现实——市场乘机把握机会。利率与期债突破关键阻力位，又反过来强化做多热情。
>
> ---
>
> **策略含义。** 市场惯性仍在，未来 1-2 周风险整体可控；但最顺畅阶段或近尾声，开始关注加速探底后的阶段性拐点：
>
> - **空间已不大。** 10Y 已破前低、继续下行空间有限；30-10Y 利差压至 45BP 以下空间或基本到位；30Y 在 2.2% 下方阻力加大。
> - **更细颗粒度挖利差。** 长端 30-10Y、20-10Y 期限利差及政金-国债税收利差；中短端 3-5Y 税收利差与期限利差，优先布局高流动性个券。
> - **组合用哑铃型。** 短久期锁收益、长久期博曲线平坦，保持长端流动性；可适度配 DR 浮息债，资金低位时具防御属性、收紧时票息跟随上调，提供安全垫。
>
> 把握剩余机会的同时为后续波动做两手准备。今年年初市场普遍偏谨慎，实际却是资金宽松、赔率友好的"easy 模式"，是典型看难行易的年份。
>
> **风险提示：** 资金面超预期收紧；地方债供给超预期。

> 要点：核心判断一段说清"现象 + 定价位置 + 操作倾向"；原因分条、每条粗体起头带具体数字；策略落到具体利差品种、点位阈值（45BP、2.2%）和组合结构，不停在"可关注"；"缺资产""一力降十会""easy 模式"等有判断力的表达保留，但不复述方法论。

**范例 E——国债期货点评（技术位 + 共振修复判断）：**

> # TL 能否有效站稳 20 日均线？
>
> **核心判断：** 昨日债市罕见"大涨"，TL 主力收复 20 日均线、盘中最高触 111.58，但尾盘交易盘获利了结留下上影线。本质是资金宽松 + 交易盘空平驱动的**共振修复，而非趋势反转**。前期"逢高试空"逻辑部分仍成立但需动态调整——短期关键看 TL 能否有效站稳 20 日均线。
>
> ---
>
> **本轮上涨的四个驱动：**
>
> - **跨季资金面超预期宽松。** 央行连续大额投放，R、DR 系列平稳甚至下行。
> - **配置盘与交易盘形成合力。** 券商自营跨季集中平券、借贷集中度高；公募季末冲量偏好中短端，叠加同业自律强化，非银流动性充沛。
> - **避险情绪阶段回归。** 亚太股市集体低开，债市防御属性回归，但对"胀"的担忧未解除。
> - **技术性反弹。** 前期期债拥挤度高、空头集中，具备空头回补特征。
>
> ---
>
> **前期逢高试空逻辑是否还成立——回到核心矛盾和技术位：**
>
> - **核心矛盾未根本变化。** 货币偏支持 + 资金宽松使短端平稳；但中东局势的输入性通胀担忧仍在（3 月问卷显示 PPI 转正是主要担忧），长端下行信心不牢；二季度政府债发行计划公布在即、超长债迎发行高峰，银行/分红险承接力待考。降息预期等催化出现前，资金 + 情绪难支撑 TL 单边，**TS/TF 确定性更强**。
> - **技术形态尚未真正修复。** 20 日线是短期多空分水岭，60 日线定调中期牛熊。TL 虽收复 20 日线，但 60 日及更长均线仍下压；若不能进一步站稳 60 日线，多头趋势难确立。
>
> ---
>
> **策略含义——短期看 TL 能否站稳 20 日均线，分两种情形：**
>
> - **情形一：站稳。** 未来 1-3 个交易日 TL 续运行于 20 日线上方，且量、仓配合，说明反弹不只是空头回补。此时空头宜先止损或降杠杆，新仓不宜追高；若回踩 20 日线不破，可轻仓试多。
> - **情形二：跌回。** 站上后很快跌回、续呈冲高回落，说明上方抛压仍重，昨日更接近阶段性修复；"逢高做空"仍可作主线，节奏关注政府债供给。
>
> 操作上：多头在 20 日线附近适度减仓护浮盈；空头不急于追空，等反弹后再定价——TL 连续数日冲高回落或基差修复至合理区间，可轻仓试空。跨季后资金无虞、短端更稳，**做多 TS/TF + 做空 TL 的跨品种组合短期仍具操作空间。**
>
> **风险提示：** 地缘冲突超预期；通胀超预期回升；政府债供给节奏超预期。

> 要点：点评不排列所有涨跌原因，先定性"共振修复非反转"再展开；情形分析点明两条路径各自的触发信号（量仓配合 / 冲高回落）和对应操作，不平铺让读者自选；落到可执行的跨品种组合而非"可关注"。

## 10. 反面清单（自检时逐条对照）

发现以下任何一条，重写：

- **"不是 A，而是 B" 反复出现。** 全文超过一两次就是口头禅。改成直接陈述。
- **方法论复述进了正文。** 出现"可以分三类""判断顺序是""需结合 X、Y、Z 综合考虑""本质上是在刻画…"——删掉，直接给结论。
- **无增量判断过多。** 出现大量"这说明/这意味着/本质上"但后面没有新增操作、风险或约束，只是在重复事实——删掉或改成具体结论。
- **漂亮但无用的二次概括。** "核心变化是……""增量不只来自……""呈现清晰分化""重新转向……""进入某某行情"这类句子看起来像结论，但如果没有新增数据、定价位置、操作含义或风险约束，本质仍是包装事实。能改成"可比数据 + 定价含义 + 策略落点"就改，改不出来就删。
- **因果方向凭直觉跳步。** 出现"成本上升→价格下跌""套保盘减少→利好基差""IRR 高→期货偏弱"这类未对照恒等式的方向判断——回到 ref-02 第 3 节逐步验证符号。方向写反会顺着论证链连带后面整段失真，是最伤报告的硬伤。
- **正确的废话。** 一句话拿到任何报告、任何时点都成立、不含当前判断（"基差交易要看可执行收益""不能机械按分位数操作""理论 IRR 不等于真实收益"）——补当前判断或删除。
- **章节之间重复。** "定价位置""后续操作""结论"三处反复表达同一件事，读者只得到重复口径而非新增信息——合并章节或让每节承担不同功能。
- **凑结构的空段落。** 某小节通篇是通用原则、没有一个当前市场的具体判断或数字——删掉或并入相邻段落。
- **正文里科普概念。** 常规报告整段解释 CTD/IRR/基差/carry"是什么"——删掉，专业读者不需要。注意区分：用 1-2 句点透某个机制（如"跨期价差为何中枢偏负""交割期权为何归空头"）是论证的一环，当它对当前结论是关键时应当保留，这不算科普。
- **来路不明的精确数字。** 出现没有来源的小数点后两三位的利率/价格——换成定性描述或标注需复核。
- **情景平铺。** 三四个"若…则…"平行排列、不给基准和倾向——点明基准情景和主推路径。
- **回顾跑题或偏科。** 标题含某品种但正文几乎没回顾它；回顾没有时间线、没有阶段——补齐。
- **结论不可执行。** 策略落在"可关注""需观察""择机参与"而没有品种、方向、点位、触发条件——具体化。
- **元话语泄漏。** 正文出现"需以数据库复核""引用需谨慎""不作为主表达""结论以定性为主"等给模型自己的执行指令——删掉，改成自然的分析表述。
- **表格替代了文字。** 表格里塞满本应写成段落的论述（含义列动辄一两句话），正文反而只剩两三句过渡——把内容写回正文，表格只留浓缩对照。判断标准：把所有表删掉后，正文是否依然论述完整；如果文字立刻撑不起论述，说明之前是表格在撑、文字被掏空了。
- **格式扁平堆积。** 一级标题下全是连续段落、无粗体标签、无分条——读者找不到关键词落脚。遇到并列情形必须分条，每条粗体起头；跟踪口径、核心信号、实操含义等子级内容用粗体短标签拉出层次，不要连续塞进长段。

## 11. 数据检索动作

### 当前市场分析的最小动作

全网检索必须**主动发起**，不是等其他渠道都没有数据才去搜。它同时服务两个目的：①验证数据时效；②搜索近期政策动态、市场事件和卖方分歧，防止遗漏对分析有实质影响的近期信息。

- 查最新合约行情、主力合约、成交持仓、CTD、IRR、基差和净基差。
- 查对应现券收益率、资金利率和关键期限利差。
- 查最新官方交易所通知，确认可交割券和主力合约切换节奏。
- 对 IRS，查最新 CFETS/中国货币网曲线、FR007/Shibor/NCD 和买卖价差。
- **全网检索（所有当前市场任务均适用，不限于政策/宏观）**：搜索近期相关政策动态、市场异动事件、机构行为信号；检索头部卖方（国泰海通等）对同一议题的最新观点，判断共识与分歧。
