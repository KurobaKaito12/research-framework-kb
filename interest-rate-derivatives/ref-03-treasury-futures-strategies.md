# 国债期货策略框架

## 1. 策略地图

国债期货策略从逻辑上分为六类：

1. **方向策略**：表达对现券收益率方向的判断，同时利用期货杠杆、流动性和技术位。
2. **期现/基差策略**：交易期现偏离、IRR、基差/净基差和交割收敛。
3. **跨期策略**：交易近远月相对价格，核心是 carry、净基差差和移仓主导方。
4. **跨品种/蝶式策略**：交易收益率曲线斜率和曲率，核心是配比、基差风险和策略窗口。
5. **套保/多头替代/负久期**：组合风险管理和资产配置效率（见 ref-05、ref-08）。
6. **技术指标和量仓辅助**：服务节奏、止损和拥挤度识别，不单独决定方向。

## 2. 方向策略

**标准拆解（分析逻辑，正文不要写成清单）：**

1. **现券方向锚**：增长、通胀、融资、政策、供给、资金面、风险偏好和配置力量。
2. **期债特有信号**：基差/IRR 水位、成交持仓、主力合约切换、技术位、套保盘、CTA 行为。
3. **品种选择**：TS 偏资金与短端政策；TF 兼具短中端属性；T 是长端核心；TL 对超长端供给、保险/基金久期偏好和技术交易更敏感。
4. **操作表达**：多/空主力，或用跨品种替代单边，以降低水平风险。

**判断顺序（内部工具，不写进正文）：**

- 先判断现券收益率中枢是否有方向。
- 再判断期货是否已比现券多定价或少定价（基差/IRR 水位）。
- 最后判断交易节奏：技术位、量仓、基差和移仓是否支持现在入场。

**关键点位写法：** 回调买、反弹空须给一个可交易点位，依据可以是 5/10/20/60 日均线、前高前低、BOLL 中轨/上下轨、跳空缺口、整数关口或成交密集区。正文用一两句自然呈现，不罗列所有指标。

典型写法：`现券方向仍偏多，但期债低基差已透支赔率，单边不宜追；更优表达是等待回调后做多 T，或用跨品种降低追高风险。`

## 3. 期现套利和基差策略

### 正套

**头寸：** 买入 CTD 或可交割券 + 卖出期货。

**赚取：** IRR > 资金成本/存单替代收益，或期现偏离向合理水平收敛。

**适用条件：** IRR 明显高于资金成本；CTD 流动性可满足建仓；资金利率后续大幅上行风险低；保证金和融资安排稳定。

**主要风险：** 期货继续上涨的保证金压力；CTD 切换；交易成本侵蚀；IRR 高不代表马上收敛，持有期可能被拉长。

### 反套

**头寸：** 卖空现券 + 买入期货。

可操作性通常弱于正套。现券借贷、融券成本、最终交割收到券不受多头控制，以及二次买卖摩擦，使反套门槛高。只有 IRR 明显低于合理水平、融券成本可控且有执行能力时才适合讨论。

**历史参照：** 2016 年底至 2017 年初 IRR 深度负值期间，反套逻辑成立，但彼时是因为空头集中对冲信用债形成的极端情形，而非常规机会。

### 基差策略（方向对照表，写前必查）

| 策略 | 头寸 | 赚什么钱 | 适用场景 | 主要约束 |
| --- | --- | --- | --- | --- |
| 做多基差 | 多现券 + 空期货 | 基差**走扩** | 基差处于低位、距交割尚远 | 与临近交割的自然收敛天然对抗 |
| 做空基差 | 空现券 + 多期货 | 基差**收窄** | 基差较高且临近交割 | 受融券可得性制约，与反套同源 |

关键对应：基差偏高、预期收敛到 0，对应的是**做空基差**（空现券+多期货），不是做多基差。"持有现券等待基差收敛"不是做多基差，做多基差赚的是基差继续走扩的钱。

## 4. 跨期策略

跨期价差 = 远月 − 近月。它不是均值回归，判断顺序是：

1. **理论定价**：持有收益差（carry 差）、资金利率、票息、CF 差异。
2. **净基差差异**：远月和近月交割期权价值不同。
3. **移仓主导方**：多头主导移仓抬升价差；空头主导移仓压低价差。
4. **近月 IRR 信号**：见移仓机制恒等式。

### 跨期价差中枢与天然为负的原因

跨期价差中枢天然偏负（约 −0.3 至 −0.4 元）。原因：现券持有通常有正 carry（票息收入 > 融资成本），正 carry 把期货压低于现券，交割越晚、累积 carry 越多，因此远月比近月更低，差值为负。

**由此推出资金面与价差的方向关系（容易写错）：**

- 资金面收紧、融资成本上行 → carry 收窄 → 远月折价缩小 → 跨期价差上行（向零靠近）
- 资金面宽松、carry 走阔 → 远月折价加深 → 跨期价差下行（更负）

与"持有成本上升压低价格"的朴素直觉相反，必须特别留意。

### 移仓机制恒等式（CRITICAL，写移仓分析时不能跳过）

| 场景 | 操作 | 价差影响 | 判断线索 |
| --- | --- | --- | --- |
| 多头主导移仓 | 卖近买远 | 近月↓远月↑ → 价差**上行**（折价减少） | IRR 偏高，空头持有至交割意愿强，多头被迫主动移仓 |
| 空头主导移仓 | 买近卖远 | 近月↑远月↓ → 价差**下行**（折价加深） | IRR 偏低，空头不愿交割，空头主导移仓 |
| IRR 正常 | 两类移仓均有 | 价差在中枢附近 | 无法单凭 IRR 判断主导方，需看持仓结构 |

**快速判断口诀：** IRR 高 → 空头留守近月 → 多头主动换月 → 价差上行；IRR 低 → 空头逃离近月 → 空头主导换月 → 价差下行。

### 移仓窗口时间节点

| 节点 | 流动性 | 建议 |
| --- | --- | --- |
| T−20（到期前 20 个交易日）| 近远月流动性均好 | 最优移仓窗口 |
| T−15 | 近月流动性开始下降 | 一般移仓窗口 |
| T−10 | 近月流动性明显下降 | 尽量完成移仓，避免用近月承载大仓位 |

### 跨期策略的历史胜率

- **做多跨期价差**（买远月+卖近月）：胜率低。要求融资成本高于票息收入，现实中极罕见；IRR 高时还受正套盘压制。
- **做空跨期价差**（卖远月+买近月）：胜率高但机会少。通常在 IRR 低、基差高时出现，且受限于借贷成本和流动性。

跨期价差更适合作为**合约选择工具**（指导用近月还是远月表达观点），而非独立的主策略。推荐作为主策略的前提：价差明显偏离理论中枢、有独立催化剂、驱动与单边方向不冲突。

### 跨期分析正文落点

只有当移仓会改变行情解释、执行合约选择或价差本身有交易价值时，才展开跨期分析。移仓窗口中的最小检查：

1. **移仓进度**：近月/远月持仓量和成交量变化，远月占近远月合计比例。近月减仓+远月增仓先按换月承接处理，不等同于方向资金撤退。
2. **价差方向**：远月−近月是扩大还是收窄，结合 IRR/基差、资金利率交叉验证。
3. **近月交割吸引力**：近月 IRR 高且基差低 → 正套意愿强 → 多头更可能主动移仓；IRR 低或基差高 → 空头交割意愿弱 → 空头可能主导移仓。
4. **操作选择**：观点若跨越移仓窗口，优先用远月表达；价差本身有交易机会时，用跨期价差单独表达。

## 5. 跨品种与蝶式

跨品种策略交易收益率曲线形态，不是利率水平本身。

### 做陡/做平配比

**DV01 中性配比（标准方法）：**

```
N_A × DA × P_A × M_A = N_B × DB × P_B × M_B
期货DV01 ≈ CTD券DV01 / CF
```

其中 M 为合约乘数：TS = 20,000；TF / T / TL = 10,000。

**简化配比（低频策略近似参考，需定期校验）：**

- TF 与 T：约 2:1（两手 TF 对一手 T）
- T 与 TL：约 3:1（三手 T 对一手 TL）

CTD 切换、利率快速波动或移仓阶段须重算。

**曲线方向变量：**

- 短端：资金面、政策利率决定（TS 最敏感）
- 长端：基本面预期、财政供给、配置需求（T 为核心）
- 超长端：特别国债/地方债供给、保险和基金久期偏好（TL 最敏感）

### 历史回测参考

来自固收研究（2026/4）：

| 策略 | 胜率 | 期间 |
| --- | --- | --- |
| TF 做陡策略 | 64.56%（所有品种中最高）| 历史全区间 |
| TL 做陡策略 | 累计 +2.45 元 | 2025/9–12 月 |

**含义：** 做陡策略整体胜率优于做平，TF 做陡和 TL 做陡在特定窗口最有效。选品种时优先看曲线驱动因素，而非机械用历史胜率。

### 三个执行风险

1. **基差风险**：期货曲线和现券曲线可能背离，TS/TL 基差和流动性变化会放大误差。
2. **统计套利风险**：利差分位数高低不是交易理由，必须先有收益率曲线方向判断。历史分位只回答赔率，不回答催化剂。
3. **近远月选择风险**：策略窗口若可能跨移仓期，不能在主力合约上建仓；需估计持有期并选择合适月份。

### 蝶式

交易曲率。做多蝶式通常是做多两端、做空中端；做空蝶式相反。优点是降低水平和斜率暴露，缺点是三腿执行、调仓、移仓和交易成本更复杂。只有在曲率空间、流动性和执行成本同时合适时才推荐。常见配置：T + TS − 2TF。

## 6. 技术指标（深化版）

技术指标回答节奏和止损，不单独决定中期方向。必须结合基本面方向和量仓。

### 均线系统

| 均线 | 主要用途 |
| --- | --- |
| MA60 | 牛熊分界线，判断中期多空趋势 |
| MA20 | BOLL 中轨，入场时机和反弹/回调幅度参考 |
| MA5 / MA10 | 短线交易节奏，趋势强时用于顺势加仓 |

**TL 均线策略回测（2023 年 4 月起，多空合并）：** 夏普比率 2.17，胜率约 80%。说明均线策略在趋势性行情中有效，震荡行情需降权。

### MACD

**零轴位置最重要：** DIF 和 DEA 均在零轴上方，偏多趋势；均在下方，偏空趋势。不要只看 MACD 柱线的扩张和收缩。

**背离使用原则（容易误用）：**

- 顶背离：价格创新高但 MACD 不创新高 → **提示追涨风险，不宜直接作为空单依据**。多头趋势中顶背离频繁出现但行情仍可延续，机械反向易亏损。
- 底背离：价格创新低但 MACD 不创新低 → **不宜在空头趋势中直接布多单**。需确认趋势有转向迹象才可跟随。

背离是警示信号，不是交易信号。

### BOLL

- 通道开口扩大 → 趋势延续。
- 价格贴上轨运行 → 多头强势，不宜机械做空。
- 价格贴下轨运行 → 空头强势，不宜机械做多。
- 机械碰轨做反向（日线）的历史胜率不足 40%，慎用。

### 量价配合

| 模式 | 含义 |
| --- | --- |
| 量价齐升 | 多头强势信号 |
| 量升价跌 | 空头增仓，趋势向下 |
| 量跌价升 | 弱反弹，上涨动能不足 |
| 量价齐跌 | 跌势衰减，可能阶段性企稳 |

技术突破必须结合成交量放大；缩量突破容易是假突破。

### RSI / KDJ

- RSI > 70 超买、< 30 超卖，在趋势行情中容易长期停留在超买/超卖区，不宜机械逆向。
- KDJ 在 J 线快速走强/走弱时提示短线动量，需结合均线判断趋势背景。

## 7. 持仓量和成交量

持仓量上升不等于多头强。常见原因：

1. 跨品种策略建仓。
2. 期现套利或套保盘进入。
3. 多空分歧加剧，博弈加深。
4. 市场扩容带来的自然增长。

**四种量仓组合的含义：**

| 价格 | 持仓 | 解读 |
| --- | --- | --- |
| 上涨 | 增加 | 多头主导，趋势强 |
| 上涨 | 减少 | 空头止损平仓，动能可能不足 |
| 下跌 | 增加 | 空头主导，趋势强 |
| 下跌 | 减少 | 多头止损平仓，跌势可能衰减 |

分析持仓必须结合价格、成交量、成交持仓比、前二十会员净持仓、基差/IRR 和移仓进度。

## 8. 常见误区

- **"期货领先现券"** 不等于期货可预测现券，领先往往是流动性差异和信息反映节奏不同。
- **IRR 为负不必然是反套机会**，可能是空头对冲集中、交割期权被让渡，历史上成立的条件极为苛刻。
- **基差高不必然做多基差**，临近交割自然收敛会使做多基差逆风。
- **跨品种不能只看利差分位**，结构性需求变化（如保险久期调整）会改变利差中枢。
- **技术背离是警示信号，不是交易信号**；顶背离不宜直接做空，底背离不宜在下跌趋势中做多。
- **移仓窗口内近月减仓不等于方向资金撤退**，先按换月承接处理。
