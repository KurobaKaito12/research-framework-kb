# 框架沉淀与维护说明

## 1. 使用定位

本文件不是原始参考材料索引。skill 对外分发时可以只包含 `interest-rate-derivatives/` 文件夹本身，不需要附带原始 PDF、PPT 或提取文本。

本文件的作用是说明：已有参考材料最终沉淀成了哪些可直接使用的框架、哪些内容被有意剔除、后续维护时应该更新什么。使用者不需要回查原始材料，也能理解这套 skill 的知识边界和维护方式。

## 2. 沉淀原则

资料学习被压缩成三类可复用资产：

1. **主线框架**：用完整分析链条组织国债期货和 IRS，而不是按材料多少决定权重。
2. **实战规则**：把期现、跨期、跨品种、套保、多头替代、负久期、技术指标、量仓等专题变成可调用的判断规则。
3. **输出范式**：把点评、专题、周报/月报、套保方案的写作方式沉淀成固定结构。

未保留为知识资产的内容：

- 历史合约、历史 CTD、历史点位和历史利差区间。
- 当时的策略结论和目标点位。
- 已过时的品种范围、制度口径和数据截图。
- 仅适用于某一篇报告当时市场环境的叙事。

核心原则：先有完整框架，再把细节放到对应节点；不因为某一类材料更多，就让该模块在 skill 中过度膨胀。

## 3. 已沉淀的国债期货主线

完整主线为：

`定价机制 -> 期现指标 -> 方向判断 -> 期现/基差策略 -> 跨期 -> 跨品种/蝶式 -> 套保/替代 -> 量仓技术辅助 -> 输出范式`

### 定价机制

国债期货分析起点是可交割券、CTD、转换因子、IRR、基差、净基差和交割期权。期货价格不是孤立价格，而是现券、融资成本、票息收入、交割选择权和交易盘共同作用的结果。

沉淀位置：

- `ref-01`：总框架和主要矛盾。
- `ref-02`：定价、期现指标、YTM 和价格序列。

### 方向判断

方向判断不能脱离现券收益率，但也不能只是现券观点的复制。必须加入期债特有信号：基差/IRR、成交持仓、主力切换、技术位、套保盘和交易盘行为。

沉淀位置：

- `ref-03`：方向策略、技术指标、量仓解释。
- `ref-06`：点评和月报中如何表达方向观点。

### 期现与基差

正套、反套和基差策略的头寸可能相似，但收益来源和窗口期不同。套利看 IRR 与资金/融券成本，基差策略看收敛、走扩、交割月和执行条件。

沉淀位置：

- `ref-02`：IRR、基差、净基差定义和数据检查。
- `ref-03`：期现策略、基差策略和实战细节。

### 跨期

跨期价差不是简单均值回归，核心是远近月 carry、净基差差异、近月 IRR 和移仓主导方。做空跨期价差通常比做多跨期价差条件更自然，但机会频次和窗口期都有限。

沉淀位置：

- `ref-03`：跨期策略判断顺序和常见误区。
- `ref-06`：主力切换点评和月报跨期小节。

### 跨品种与蝶式

跨品种和蝶式交易的是曲线斜率/曲率，而不是单纯利率水平。分位数只回答赔率，不回答方向；建仓必须同时考虑基差风险、DV01配比、策略窗口期和近远月选择。

沉淀位置：

- `ref-03`：做陡/做平、曲线交易三个坑、配比和蝶式。

### 技术指标与量仓

技术指标和持仓量只服务节奏、止损、拥挤度和放大机制，不替代基本逻辑。持仓量上升可能来自跨品种、期现套利、套保、多空分歧或市场扩容，不能直接解释为多头强。

沉淀位置：

- `ref-03`：技术指标和持仓量解释。
- `ref-06`：技术点评的输出边界。

## 4. 已沉淀的 IRS 主线

完整主线为：

`浮动端基准 -> 资金/政策预期 -> 互换曲线 -> carry/roll -> 方向/期差/基差 -> bond/swap basis -> 套保和冲销`

### 产品和定价

FR007 IRS 更贴近回购资金和政策预期，长端兼具债券属性；Shibor 3M IRS 要额外看 NCD、银行负债和报价粘性；LPR、FDR 等品种必须以官方最新手册为准。

沉淀位置：

- `ref-01`：IRS 在总框架中的位置。
- `ref-04`：产品理解、定价直觉和当前制度复核要求。

### 策略

IRS 策略分为方向、期差、Shibor/FR007 基差、bond/swap basis 和养券回购。所有策略都必须检查 carry、roll、买卖价差和冲销可行性。

沉淀位置：

- `ref-04`：IRS 各类策略框架。
- `ref-06`：IRS 周度/月度策略输出结构。

### 套保

IRS 更适合中长期久期对冲，但要接受负 carry、basis 不稳定、期限错配和冲销成本。不能把 IRS 套保写成无成本或完美对冲。

沉淀位置：

- `ref-04`：IRS basis 与养券回购。
- `ref-05`：IRS 套保和工具比较。

## 5. 已沉淀的套保与组合管理主线

完整主线为：

`组合风险画像 -> 工具选择 -> 套保比例 -> 成本估算 -> 动态调整 -> 失效条件`

### 工具选择

国债期货通常更适合短期、快速、标准化对冲；IRS 通常更适合中长期、不希望卖券或不想反复移仓的对冲。二者没有绝对优劣，取决于期限、基差、carry、冲销、工具权限和退出需求。

沉淀位置：

- `ref-05`：国债期货 vs IRS 工具比较。
- `ref-06`：套保方案输出模板。

### 多头替代

多头替代是用期货替代现券久期暴露，收益来自期货方向、剩余资金现金管理和可能的基差变化；风险来自没有票息、基差走扩、移仓和保证金波动。

沉淀位置：

- `ref-05`：多头替代。

### 负久期

负久期不是单纯看空债，而是组合回撤管理。输出时必须给出对冲比例、触发条件、退出条件和失效条件。

沉淀位置：

- `ref-05`：负久期策略。

## 6. 已沉淀的输出范式

完整主线为：

`任务识别 -> 时效取证 -> 主要矛盾 -> 选择范式 -> 交易表达 -> 风险/失效条件`

### 事件点评

用于市场异动、主力切换、技术破位、IRS 异动等。结构是：现象一句话、核心结论、原因拆解、策略含义、观察锚、风险提示。

### 深度专题

用于策略研究、年度/季度展望、科普、回测、工具比较。结构是：核心摘要、问题本质、机制框架、历史复盘或情景测算、实战细节、当前建议、失效条件。

### 周度/月度回顾

用于月报策略部分或双周报策略。国债期货和 IRS 的策略小节是"可选清单"，按本期主要矛盾决定详略，无矛盾的小节压缩或合并，不为凑结构硬写。

### 回顾展望

用于半年度/年度跨期回顾加前瞻。回顾须分阶段、带时间线，覆盖标题涵盖的所有品种（不能只写 IRS 或只写期货）；展望要承接回顾遗留的矛盾，给明确主推路径。

沉淀位置：

- `ref-06`：全部输出范式和自检清单。

## 7. 需要未来持续维护的点

以下内容有时效性，不能只依赖 skill 当前文本：

- 中金所国债期货合约规则、可交割券范围、转换因子、保证金和交割细则。

维护时优先更新利率互换工具快照（若有本地缓存）和相关 reference 中的制度口径；若是分析框架升级，再同步调整 `ref-01` 到 `ref-06`。

## 8. 使用者无需原始材料时的工作方式

若只拿到 skill 文件夹，按以下方式使用即可：

1. 先读 `SKILL.md` 判断任务类型和应加载的 reference。
2. 当前市场任务先查最新数据和官方规则。
3. 按 `ref-01` 抓主要矛盾。
4. 按产品和策略加载 `ref-02` 到 `ref-05`。
5. 按 `ref-06` 输出成点评、专题、月报策略或套保方案。
6. 若需要理解这套框架为何这样组织，再读本文件。
