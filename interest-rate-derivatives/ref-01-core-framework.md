# 利率衍生品总框架

## 1. 研究对象

利率衍生品研究不只是"看多看空债市"，而是回答三类问题：

1. **用什么工具表达观点**：现券、国债期货、IRS、回购、债券借贷各自成本、流动性、杠杆、期限和退出机制不同。
2. **价格为什么偏离**：国债期货看期现关系、交割选择权、基差、移仓和保证金；IRS 看浮动端基准、曲线预期、carry/roll、客盘对冲、basis 和冲销。
3. **偏离能否交易**：交易机会来自方向判断、相对价值、期限结构、基差收敛、套保需求、资金成本和拥挤度变化。

## 2. 分析母框架

### 国债期货：联动与割裂并存

国债期货与现券联动，源于一篮子可交割券、CTD、转换因子和交割收敛；国债期货与现券割裂，源于场内杠杆、投机/套保盘、交易时段、流动性、保证金和交割期权。解释任何期债异动时，先判断是"现券带动期货"、"期货价格发现带动现券"，还是"期货微观结构独立冲击"。

价格发现功能不等于可预测性。期货在日内可能领先现券，但日间收益率预测仍会受基差、CTD 切换、移仓和交易盘平仓影响。不要把"期货先动"直接写成"现券必然跟随"。

### IRS：资金预期与债券属性并存

短端 IRS 更像资金利率预期，长端 IRS 更像无本金债券工具。FR007 IRS 反映对未来回购定盘利率的预期，也受货币政策、资金面尾部风险、客盘套保和流动性影响；Shibor 3M IRS 还要看 NCD、Shibor 报价粘性和银行负债成本。

### 策略：先问暴露，再问收益

每个策略先拆暴露：

| 策略 | 核心暴露 | 主要收益来源 | 主要风险 |
| --- | --- | --- | --- |
| 方向 | 利率水平/期货价格 | 现券方向 + 期债杠杆 + 技术位 | 基差、止损、拥挤交易 |
| 期现/基差 | 期现偏离 | IRR、基差/净基差收敛 | 融资、融券、CTD切换、保证金 |
| 跨期 | 近远月相对价格 | 持有收益差、净基差差、移仓主导方 | CTD不一致、资金利率、移仓节奏 |
| 跨品种 | 曲线斜率 | 不同期限收益率相对变化 | 配比误差、DV01跳变、流动性 |
| 蝶式 | 曲线曲率 | 中端相对两端变化 | 三腿执行、调仓和成本 |
| IRS方向 | 互换曲线水平 | 固定端变动 + carry/roll | 浮动端、客盘、冲销 |
| IRS期差 | 互换曲线斜率 | 长短端相对变化 | DV01配比、曲线非平行 |
| IRS基差 | Shibor vs FR007 | 两条互换曲线相对变化 | Shibor粘性、NCD和资金分化 |
| 债券/互换基差 | 债券收益率 vs IRS | basis收敛/走扩 | 资金利差、现券流动性、套保失效 |
| 套保 | 降低组合利率风险 | 控制回撤 | 不完全对冲、负carry、移仓/冲销 |

## 3. 八个主要矛盾识别器

1. **现券方向**：收益率是否由资金、基本面、政策、供给、风险偏好或配置力量驱动。
2. **期现关系**：IRR、基差、净基差是否偏离资金成本或当前分位。
3. **曲线形态**：短端受资金/政策，长端受基本面/供给/配置，超长端还受机构久期偏好。
4. **移仓交割**：近月 IRR、基差、持仓下降节奏、多空交割意愿决定跨期价差。
5. **套保盘**：现券流动性差、赎回、利率快速上行或供给冲击可能触发期货空头/IRS支付固定端集中。
6. **资金面**：DR/R、FR007、存单、回购融资成本同时影响期现套利、IRS浮动端和短端品种。
7. **技术位与量仓**：均线、MACD、KDJ、RSI、成交持仓只用于辅助定节奏，不替代基本逻辑。
8. **拥挤度与预期差**：持仓量、成交持仓比、卖方共识、基差极值和曲线分位共同决定追涨追空性价比。

## 4. 数据最小包

### 国债期货任务

- TS/TF/T/TL 主力及次主力价格、涨跌、成交量、持仓量、成交持仓比。
- 各合约 CTD、转换因子、IRR、基差、净基差、期货隐含收益率或期债 YTM。
- 对应现券收益率、活跃券、国债期限利差、国债-政金债/税收利差。
- R001/R007、DR001/DR007、FR007、同业存单、回购融资成本。
- 主力切换进度、近远月价差、多空前二十会员净持仓。

### IRS任务

- FR007 IRS、Shibor 3M IRS、LPR IRS（如相关）各期限定盘/收盘/行情曲线。
- FR007、Shibor 3M、R/DR、NCD发行利率、NCD二级收益率。
- IRS期差（如 5Y-1Y、10Y-1Y）、Shibor/FR007 basis、债券/互换 basis。
- carry、roll、DV01、买卖价差、成交活跃期限、冲销可行性。
- 现券收益率、融资成本和组合久期。

## 5. 时效与制度信息

产品规则可能更新。涉及合约条款、可交割券范围、IRS曲线品种、发布频率、清算规则时，必须优先用官方源复核：

- 中金所国债期货产品页、交易所通知、合约交割细则。
- 中国外汇交易中心/中国货币网发布的利率互换曲线和估值手册。
- 上清所和交易中心关于标准利率互换交易清算服务的通知。

**数据降级规则（优先源不可用时）：** iFind 无结果 → 中国货币网/中金所官方源 → 头部卖方研报（/国泰海通优先）中的近期数据 → 公开行情软件的近似值（须标注"估算，非精确值"）。关键参数（CTD/IRR/DV01）若来自估算而非终端，必须在正文说明误差量级和影响。

截至 2026-05-19 的制度口径如下，仅作起点，不替代最新检索。当前可确认的官方口径包括：中国货币网 2026-01-21 发布的《中国外汇交易中心利率互换估值手册V1.7》，以及中国货币网基准曲线服务中列示的 Shibor3M、FR007、FDR001、FDR007、Shibor O/N、LPR1Y、LPR5Y 等互换曲线。国债期货可交割券和转换因子会随新券加入持续更新，不能沿用历史报告中的券表。
