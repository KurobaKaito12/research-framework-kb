# 量化大类资产配置：三层次逻辑

> 来源：金工研究《全球大类资产配置的三层次逻辑及对宏观基本面量化的思考》（2024-11-29，林晓明/徐特/陈烨/何康等）。
> 使用本方法论产出分析时，请声明数据来源（Wind / Bloomberg / 研究团队 等）。

## 0. 核心思想

**"投资逻辑分散"和"大类资产分散"同样重要。** 任何单一配置逻辑（"圣杯"）都会阶段性失效，但三种逻辑彼此低相关，融合后能"西方不亮东方亮"，改善组合的风险收益特征。本框架以**层次风险平价**为基准，叠加三层次逻辑对各资产的**风险预算比例**做乘法调整：

| 层次 | 角色 | 时间跨度 | 解决的问题 | 信息来源 |
|------|------|----------|------------|----------|
| 第一层：经济周期模型 | 战略配置 SAA | 年 | 进攻还是防守 | 全球市场因子周期 |
| 第二层：宏观因子模型 | 战术配置 TAA | 月 | 细分资产超配/低配（基本面） | 中美增长-流动性 |
| 第三层：趋势追踪模型 | 战术配置 TAA | 月 | 细分资产超配/低配（技术面） | 时序+截面动量 |

样本回测（2010-12-31 至 2024-10-31，双边 2‰费用，月度调仓）：融合策略年化 6.1%、夏普 2.3，较基准提升 2.5pct/0.66；最长新高天数从基准 265 天降至 102 天。

## 1. 基准：层次风险平价（HRP）

**资产池（18 个）= 9 中国 + 9 美国**，覆盖股、债、商品、类货币四大类。典型成分：
- 进攻-股：沪深300、中证500、红利低波、恒生指数 / 标普500、纳指、道指
- 进攻-商品：南华金属/能化/农产品 / 彭博工业品/农产品/能源/贵金属
- 防守-债：7-10年中债、10年美债期货
- 防守-类货币：SGE黄金、美元指数ETF

**层次风险预算结构**（自上而下逐层等分）：
1. 进攻资产 : 防守资产 = 风险平价（各 50%）
2. 每一类内：中国资产 : 美国资产 = 风险平价
3. 每一国内：生息资产（股、债）: 非生息资产（商品、类货币）= **2 : 1**

**风险预算优化**（求权重 w，使各资产风险贡献率 RC 匹配目标比例 r）：

$$\arg\min_{w}\sum_{i,j}\left(\frac{RC(w_i)}{r_i}-\frac{RC(w_j)}{r_j}\right)^2,\quad \text{s.t. }\sum w_i=1,\ 0\le w_i\le 1$$

其中组合风险 $\sigma_w=\sqrt{w'\Sigma w}$，边际风险 $MRC(w_i)=[\Sigma w]_i/\sigma_w$，风险贡献率 $RC(w_i)=w_i[\Sigma w]_i/\sigma_w^2$。

## 2. 调仓规则总表（核心落地）

三层次信号在基准风险预算之上以**乘法**调整，调整系数本身带主观性（经济周期/时序动量定为 5，宏观因子/截面动量定为 2，体现"周期是根本力量"的判断）：

| 层次 | 调整规则 |
|------|----------|
| 经济周期 | 预测市场因子**上行** → 全体进攻资产风险预算 ×5；**下行** → 全体防守资产 ×5；**拐点** → 维持风险平价 |
| 宏观因子 | 按宏观观点对各资产打分，风险预算 × `pow(2, 宏观因子得分)` |
| 趋势-时序动量 | 触发**破位**信号的资产风险预算 ÷5 |
| 趋势-截面动量 | KST 前 1/3 资产 ×2；后 1/3 资产 ÷2 |

最终风险预算 = 基准比例 × 各层调整系数连乘 → 代入风险预算优化求权重。

## 3. 第一层：经济周期模型（SAA）

**全球统一市场因子**：全球主要经济体股、商、利率、汇四大类资产走势具统一性，共同受 42 月基钦 / 100 月朱格拉 / 200 月库兹涅茨三周期驱动。

构建步骤：
1. 选取覆盖发达/新兴、欧美/亚太的全球代表性股票、商品、外汇（计算月末同比收益率）和利率（同比差分）。
2. 对四大类各做 PCA，取第一主成分；**利率、外汇的第一主成分 ×(-1)** 使方向与股、商一致。
3. 四个第一主成分 zscore 标准化后等权相加 → **全球市场因子**。
4. 对市场因子做**三周期拟合**（傅里叶变换 → 高斯滤波 → 逆傅里叶变换），全局拟合优度约 R²=47%。

**滚动外推给观点（避免未来信息）**：综合 50/60/70/80/90/100 个月多窗口，各窗口内重建市场因子、三周期拟合、外推 3 个月：续升 +1 / 续降 -1 / 拐点 0。加总：总分 ≥3 判上行（进攻 ×5）；≤-3 判下行（防守 ×5）；否则维持基准。

**适用边界**：经济周期模型只能用于 SAA（判进攻/防守），超额收益缓慢波动向上，**难以确定细分资产机会**。

## 4. 第二层：宏观因子模型（TAA·基本面）

以**增长-流动性**为核心的中美宏观因子体系（不含通胀因子，因通胀对资产非一阶逻辑、且本质是商品动量已在第三层体现）：

- 中国：增长、信用、货币
- 美国：增长、流动性

**映射打分**：依据"宏观因子-资产"一阶逻辑映射表（如：中国增长景气利好沪深300/中证500/南华商品；中国货币宽松利好红利低波/利空美元；美国流动性宽松利好美股/黄金/利空美元），观点利好 +1、利空 -1、无观点 0，风险预算 × `pow(2, 得分)`。注意：当因子观点与映射表表头相反时，利好利空也取反。

**中国因子构建**：从海量宏观指标按相关性/领先滞后性筛选代理指标（增长：发电量、铝材、汽车产量、新开工、税收等；信用：M1-PPI、M1-M2、社融存量、贷款余额等；货币：DR007、R007、SHIBOR、国债收益率等）→ 口径统一/季调预处理 → **OECD 法**（类 PCA，适合中国制造业为核心、指标高相关）合成。**本文不再做 HP 滤波**（保留趋势项；HP 只留周期项易过拟合、且与第一层周期信号重合）。观点用**因子动量法**：连续两期上行→景气/扩张/宽松；连续两期下行→承压/收缩/收紧；否则无观点。（不再用相位判断法，避免与第一层重合。）

**美国因子构建**：代理指标（增长：ISM 制造/非制造 PMI、工业产出、耐用品订单、新房销售、BDI、期限利差等；流动性：美欧日央行总资产、通胀预期、FOMC 利率概率/预测、FRA-OIS、2年期美债等）→ **扩散指数法**（打分法：各指标 ±1 取均值，荣枯线 0；因美国服务业为核心、指标低相关，不宜用类 PCA）。得分 >+0.1 景气/宽松，<-0.1 承压/收紧，中间无观点。

**适用边界（重要）**：近两年宏观因子模型超额走平甚至回撤——可能因**宏观预期、高阶逻辑对资产价格的影响大于宏观现实、一阶逻辑**。这是宏观基本面量化的新难题。

## 5. 第三层：趋势追踪模型（TAA·技术面）

应对基本面量化"刻画不了的拐点事件"与"非理性超涨超跌"。无论基本面模型样本内多优秀，**都建议加一层趋势追踪作为保护**。

### 5.1 时序动量（规避技术面风险）
用**月线**（优于日/周线），识别**破位**优于识别突破（与处置效应/锚定效应导致的空头趋势延续有关）。三指标任一提示破位即风险预算 ÷5：
- **双均线**：3 月均线连续"死叉"6/9/12/15/18/21 月均线 → 破位
- **MACD**（Wind 默认参数）：处于绿柱且绿柱扩大 → 破位
- **布林带**（Wind 默认参数）：月线从上向下穿越中轨 → 破位；注意月线突破下轨是**反转信号**，此时不再看空

### 5.2 截面动量（比较强弱）
用**确然指标 KST**：取同一动量定义下 4 个窗长（过去 21/63/125/250 交易日的**夏普比率**），按 10%:20%:30%:40% 加权求和。18 资产按 KST 排序：前 1/3 ×2，后 1/3 ÷2。

**适用边界**：趋势追踪近两年最强（羊群效应→动量效应，强者恒强）；动量偶有崩溃（momentum collapse），但只要存在非理性投资者就值得长期信任。

## 6. 融合与反思

- 三层次低相关，融合即"投资逻辑分散"，显著缩短最长新高天数（基准 265 → 102 天，意味着即使前高建仓不到半年也能回本创新高）。
- **解读交易信息（技术面）是量化的比较优势场景，解读基本面信息则不是**——故务必保留趋势追踪保护层。
- 宏观预期/高阶逻辑是新难题，线性解法：Factor Mimicking、用分析师预测值、Nowcasting；非线性方向：大语言模型。

## 7. 应用本 skill 时

1. **先定基准**：明确资产池与层次风险预算结构（进攻/防守 50:50，中美平价，生息:非生息 2:1）。
2. **逐层取信号**：经济周期（进攻/防守）→ 宏观因子（中美增长-流动性打分）→ 趋势追踪（破位/KST 排序）。缺数据时明确指出需要哪些输入，不要编造信号。
3. **按调仓总表连乘调整风险预算**，再做风险预算优化得权重。
4. **给结论时标注适用边界**：经济周期仅判 SAA；宏观因子在"预期主导"行情中可能失效；趋势追踪是必备保护层。
5. 区分**战略**（年度进攻/防守）与**战术**（月度细分资产超低配）两个层面表述。
