## 二、超储率与货币乘数测算框架

### 基础货币构成
```
基础货币 = 储备货币 + 不计入储备货币的金融性公司存款 + 其他负债中属于基础货币部分
储备货币 = 货币发行 + 其他存款性公司存款 + 非金融机构存款
```

### 超储率测算
```
超额准备金 = 其他存款性公司存款 - 法定准备金
超储率 = 超额准备金 / 一般存款余额
```

| 超储率水平 | 流动性含义 |
|-----------|----------|
| < 1% | 流动性紧张，资金利率可能快速上行 |
| 1.5%-2.5% | 正常区间 |
| > 3% | 流动性过剩，资金利率可能下行 |

### 货币乘数
```
货币乘数 = M2 / 基础货币 = (1 + c) / (r + e + c)
```
核心关系：降准→货币乘数扩大

## 四、流动性分析实用框架

四因素分析框架：
```
Δ基础货币 = 外汇占款变动 + 央行向银行投放 + 财政存款变动 + 现金投放变动
```

## 五、报表变动分析的常见误区

1. 扩表≠宽松，缩表≠收紧（中国央行与美联储机制不同）
2. 单一科目大幅变动≠政策转向
3. 忽视季节性因素
4. 对其他金融性公司债权异动≠金融救助
5. 政府存款变动≠财政政策
