## 第二步：数据校验

获取数据后**必须逐一校验**，不通过则重新搜索或标注"⚠数据待核实"：

**校验一：资产=负债**
* 总资产 = 总负债（含自有资金）
* 差值 > 1亿元 → 数据获取有误或遗漏自有资金

**校验二：储备货币=三个子项之和**
* 储备货币 = 货币发行 + 其他存款性公司存款 + 非金融机构存款
* 不等时检查是否遗漏非金融机构存款

## 第四步：联动验证

### 5个核心联动

| 联动 | 看到什么 | 意味着什么 |
| ---------- | ----------- | ------------------------------------------ |
| 对银行债权↔储备货币 | 债权↑+储备货币↑ | 央行主动扩表投放流动性 |
| | 债权↓+储备货币↓ | 央行缩表回笼 |
| 政府存款↔储备货币 | 政府存款↑+储备货币↓ | 缴税/发债回笼流动性，央行可能需对冲 |
| | 政府存款↓+储备货币↑ | 财政支出投放流动性 |
| 对银行债权↔政府存款 | 两者同时增加 | 央行投放和财政回笼同时发生，**看谁主导** |
| 对政府债权↔政府存款 | 对政府债权变动 | 体现国债买卖净买入及存续国债到期情况 |
| 其他资产↔其他负债 | 同时异常波动 | 可能有未公开的特殊操作 |

## 第五步：综合判断

### 5.1 政策立场判断矩阵

| 维度 | 宽松 | 中性 | 紧缩 |
| ------------------- | ------------------------------ | -------- | ------------------------------ |
| 量：资产负债表增速 | >5% | 2-5% | <2%或负 |
| 价：政策利率方向 | 下调 | 不动 | 上调 |
| 结构：工具组合 | 降准+MLF增量+结构性工具扩容 | MLF等量续做 | MLF缩量+正回购 |
| 超储率 | >2.0% | 1.5-2.0% | <1.5% |

5维度中3个以上同方向→确认政策立场；维度间矛盾→分析矛盾来源

## 第六步：前瞻与风险

* 关键观察节点：季末MPA考核、主要税期、政府债发行高峰
* 风险场景：MLF大量到期缩量 | 汇率破位贬值 | 地方债务风险暴露 | 财政大幅发力

## 季节性调整速查

| 月份 | 科目 | 方向 | 原因 | 提醒 |
| ----------- | ------ | ---- | ------------ | ----------------------- |
| 1-2月 | 货币发行↑↓ | 先增后减 | 春节前提现/节后回笼 | **#1误读来源**：不可将M0暴增解读为宽松 |
| 1/4/5/7/10月 | 政府存款↑ | 增加 | 季度缴税/企业所得税汇算 | 非政策紧缩 |
| 3/6/9/12月 | 政府存款↓ | 减少 | 季末/年末财政支出 | 非政策宽松 |
| 5-10月 | 政府存款↑ | 阶段增加 | 政府债发行高峰 | 央行通常对冲 |
