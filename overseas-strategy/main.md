# 港股与海外权益策略研判框架

本skill封装的是一套海外权益策略研判方法论，源自海外策略框架（2025版）。**港股为核心研判对象**（更复杂、变量更多），**美股为辅**（独立回答 + 作为研判港股时的外部输入）。

## 何时启用本skill

只要用户的问题涉及港股、美股、或者中国权益的海外资金面变量，就应当启用：

**港股直接相关**：
- "港股现在怎么看 / 恒生指数怎么看 / 恒生科技怎么样"
- "中资股能买吗 / 港股通该不该加 / 南向资金怎么看"
- "AH溢价怎么看 / 港股相对A股优势在哪"
- "现在港股配多少合适"
- "港股某行业（如互联网/新消费/创新药/红利）怎么看"
- 涉及 HIBOR、联系汇率、沽空占比、港股回购、香港本地股等概念

**美股直接相关**：
- "美股能不能买 / 美股到顶了吗 / 美股估值贵不贵"
- "标普500、纳斯达克怎么看"
- "美国会衰退吗 / 美股熊市怎么应对"
- 涉及 SPX EPS、美股 ERP、美国实际利率、AAII看空比例等

**外部输入类**（也启用，因为这些变量是港股研判的关键）：
- "美元走强港股能涨吗"
- "美债利率下行对港股影响"
- "全球流动性宽松对A/H的影响"
- "EPFR外资流向最新状况"

如果用户问题同时涉及A股，可联动调用 `a-share-strategy` skill（如果已安装）。

## 核心心法（先记住三句话）

> **市场属性**：港股是中国基本面 + 海外资金面的离岸市场，对美元高度敏感。
> **港股研判**：美元和国内基本面定方向，南向定弹性，估值定赔率。
> **美股研判**：长期EPS驱动，估值不一定均值回归，警惕滞涨>深度衰退>轻度衰退>短期冲击。

这三句话是整个框架的压缩包。回答前先在这个层级里定位用户问的是哪一层。

### 第二步：按框架拆解

**回答"港股大势"类问题时**，按以下骨架：
1. 基本面（中国经济尤其是地产和消费）方向
2. 全球流动性（M2汇总）状态
3. 美元周期当前位置（核心变量）
4. 资金面三层结构（外资/南向/本地）
5. 情绪指标（沽空/RSI/回购）

**回答"港股相对A股"类问题时**：
- AH溢价当前位置 + 美元方向 + 港股PE → AH溢价走向
- 港股估值低、波动大、弹性强；A股工业占比高、散户主导

**回答"美股"类问题时**：
1. 当前在长牛中的位置（EPS增速、估值中枢）
2. 利率与估值关系（增长推动 vs 通胀推动）
3. 是否有衰退/滞涨风险（决定熊市深度）
4. 短期情绪（RSI、AAII看空比例）

### 第三步：标注证据等级和盲点

每个结论后面，明确：
- **支持指标**：依据的具体指标和当前读数
- **反向风险**：什么情况下结论被推翻
- **指标边界**：哪些指标在当前范式下可能失效

### 第四步：避免几个常见陷阱

1. **不要把港股当A股看**。
2. **不要把美股当港股看**。
3. **不要忽略离岸市场的脆弱性**。
4. **不要孤立看美元指数**。
5. **不要按 P/E 简单做美股估值判断**。

## 关于数据

本skill**不负责取数**。当框架需要某个指标时：
1. 用户已提供数据 → 直接套框架
2. 用户未提供 → 明确告知需要的指标名 + 数据源
3. 如果环境有取数能力，可建议调用
