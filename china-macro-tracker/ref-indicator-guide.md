## 高频重点指标

### 需求端
- **全球制造业PMI**：>50=外需扩张，<50=外需收缩
- **韩国前10日/20日出口**：领先中国出口约2周
- **SCFI/CCFI**：SCFI对出口景气度领先1-2个月
- **乘联会乘用车零售**：最可靠的消费高频指标
- **专项债/特别国债发行进度**：Q1偏慢→Q2-Q3加速→Q4冲刺

### 价格
- **南华工业品指数**：对PPI有1-2个月领先性
- **铜价**：全球制造业+新能源交叉指标
- **原油**：PPI输入成本核心驱动
- **猪肉/蔬菜价格**：猪价能繁母猪存栏领先约10个月

### 旧动能/地产
- **二手房成交面积/套数**：地产需求的前瞻锚
- **二手房挂牌价环比**：企稳信号：价格收敛至0
- **30城商品房成交面积**：已从核心指标降级为辅助指标
- **百城土地成交溢价率**：开发商拿地意愿

### 新动能产业
- **DRAM/NAND价格**：全球半导体周期的价格锚
- **AI算力租赁价格**：AI供需紧张程度的核心高频指标
- **碳酸锂价格**：新能源车+锂电池核心成本指标
- **硅料/组件价格**：光伏产能去化进度
- **新能源车上险量**：消费端新动能周度代理
- **储能系统中标价格/招标量**：储能产业前瞻指标

## 低频重点指标

| 指标 | 要点 |
|------|------|
| 官方制造业PMI | 50荣枯线，PMI是环比概念 |
| 工业增加值同比 | 生产端确认，注意服务业占比上升 |
| 固定资产投资累计同比 | 三大支柱：制造业/基建/房地产 |
| 社零同比 | 消费端确认，不含服务 |
| 出口/进口同比（美元） | 出口拆三因素：外需×份额×价格 |
| CPI/PPI | CPI先拆波动来源，PPI先拆新旧动能 |
| 新增社融及结构 | 核心信贷比总量更重要 |
| M2/M1同比 | M1-M2剪刀差反映经济活力 |

## 数据解读注意事项

1. 先确认口径再看数据
2. 季节性和基数效应必须排除
3. 单一指标不可靠，需交叉验证
4. 价格vs数量需区分
5. 传导链条要验证通畅度
6. PMI是环比概念
