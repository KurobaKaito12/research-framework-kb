# 中国宏观经济追踪（China Macro Tracker）

**所有中国宏观经济研究的基础skill。** 任何涉及中国经济的研究、分析、报告、点评、数据解读任务，都必须先调用本skill。

## 触发条件

凡是涉及以下主题的任务，必须调用本skill：
- 中国经济数据（GDP、PMI、社融、CPI、PPI、工业、投资、消费、进出口等）
- 中国宏观政策（货币、财政、房地产、产业政策等）
- 中国大类资产配置（股、债、商、汇的基本面分析）
- 中国经济转型、新旧动能、产业趋势
- 对中国经济有影响的海外事件

用户同时提及中美宏观时，可参考库内 `us-macro-handbook` 框架获取美国背景。

## 步骤一：第一原则——框架定骨架，搜索定内容

**分析骨架看框架，市场实情看搜索。** 两者分工明确，不可混淆：

1. **框架定骨架**：根据研究主题，在references中查找对应的分析框架（framework）。有 → 先读框架建立分析结构（看什么、怎么拆、关注哪些维度）
2. **搜索定内容**：具体的市场信息、当前主流讨论、最新数据、预期差信息 → 必须通过网络搜索获取。框架中的静态判断和数字可能过时，不可直接引用，每次分析都应以最新搜索结果为准
3. **交叉验证**：搜索得到的市场观点与框架的分析逻辑交叉验证。框架提供"应该怎么想"，搜索提供"现在发生了什么"。不一致时以数据和逻辑为准

## 步骤三：输出格式规范

### 分析大原则

1. **强制最新数据**：所有结论必须以最新可得数据为锚，搜索不是可选项是前置条件。输出必须标注"数据截止时间"
2. **提炼特征而非罗列数据**：根据数据总结特征、提炼背后反映了什么，不要堆砌数字
3. **整体连贯有故事性**：有框架的连贯论述，逻辑流畅推进，用"第一/第二/第三"增加条理
4. **每段首句必须是总结性判断**：不用铺垫，直接亮观点
5. **PPI/CPI上行情景必须区分拉动类型**："PPI转正"本身不构成判断——需求拉动型（量价齐升，全面利好）、成本推动型（挤压中下游利润，上游受益中下游受损）、供给收缩型（去产能行业受益，结构性利好）、外需输入型（出口链+上游受益，不是内需改善信号）、猪周期噪音（对投资决策无意义）。五种类型对应五种完全不同的资产含义，直接说"PPI转正利好"而不区分类型是不可接受的无效分析。完整框架见 `ref-framework_nominal_price.md`
6. **每个判断必须有数据或逻辑支撑**：禁止无锚定观点
7. **传导链条必须完整**：不只说结论，要有中间环节
8. **落到操作**：胜率赔率意识、交易思维，分析最终落到"该怎么操作"上
9. **关注预期差**：市场已定价了什么？还有什么未被定价？
10. **区分总量与结构**：总量平稳不等于结构健康，区分内生动能vs外生拉动
11. **传导在新旧动能切换期更长更弱**：不能简单套用历史链条
12. **拥挤度意识**：共识越高，追涨性价比越低
13. **所有数据标注**：具体数值 + 日期 + 来源
14. **使用 → 表达逻辑链**：用箭头串联因果，不堆砌孤立判断

**基本面决定中期走势，所有分析最终服务于投资决策。** 股市和债市关注的基本面信息不同，同一数据对不同市场含义不同。以下模块围绕股债两条主线组织，每个大标题首行标注该板块的核心判断维度。

### 一、总量：经济周期定位与名义增长锚

> 周期定位（反复/修复/企稳） / 名义增速方向 / 增长引擎识别 / 量价组合 / 融资条件

#### 经济定位（每次报告的起点）

**每次分析的第一步是对当前经济做周期定位，而非直接看数据。** 定位分两个维度，给出综合判断即可，不需要逐项罗列数据：

**短期周期定位**：综合增长（GDP/工增/PMI）、通胀（CPI/PPI/平减指数）、融资（社融/M1-M2）、盈利（工业企业利润）等维度，用转型期四阶段（承压期/反复期/修复期/企稳期）定性。阶段判断方法和信号详见 `ref-framework_classic_cycle.md`

**长期阶段定位**（新旧动能转换四阶段）：

| 阶段 | 特征 | 核心矛盾 | 政策基调 |
|------|------|---------|---------|
| I 旧下新无 | 旧动能加速下行，新动能尚未形成规模 | 失速风险、预期全面转弱 | 强刺激托底 |
| II 旧下新萌芽 | 旧动能继续收缩，新动能出现结构性高增长，总量仍偏弱但分化加剧 | 结构阵痛、总量承压 | 托底+培育并重 |
| III 旧稳新崛起 | 旧动能触底企稳，新动能加速扩张，体量和盈利贡献显著提升 | 分化加剧、旧动能反复 | 精准滴灌 |
| IV 旧小周期新壮大 | 新动能成为主体引擎，旧动能进入弱周期性波动 | 新的周期规律 | 常规化 |

短期+长期两个维度结合，决定分析的侧重点和股债方向判断。详见 `ref-framework_transition.md`

**增长引擎识别**：每次定位后必须明确回答——当前经济增长的主要驱动力是什么？从以下引擎中选取1-3个主导引擎（只列当期实际在起作用的）：出口 / 消费 / 地产 / 基建 / 制造业投资（含新动能）/ 库存周期 / 政策刺激。明确引擎 = 明确分析焦点。

#### 核心锚点：名义GDP

**名义GDP是中期资产定价的核心锚。** 不是实际GDP，而是名义GDP（实际GDP+平减指数）决定企业盈利、利率中枢和资产价格方向。

- CPI和PPI比实际GDP更重要。内需驱动的CPI和PPI上行（核心CPI回升+PPI转正）是真正的需求改善信号，比猪周期波动或外需驱动的通胀更有意义
- 名义GDP的驱动来源比绝对水平更重要——方向和边际变化是核心，搜索确认最新读数
- 名义GDP修复 = 实际增速稳 + 平减指数收敛 → 详见 `ref-framework_nominal_price.md`

### 二、供需：分化格局、驱动力与市场含义

> 三度判断 / 供需缺口 / 股债驱动力 / 盈利分化方向 / 股债联动状态

#### 三度框架

**三度不判断经济好坏，只判断趋势清晰度和市场状态。**

**能见度**：地缘环境（冲突走向是否明朗）+ 增长引擎（主要驱动力是否清晰可辨）+ 政策友好度（方向是否稳定可预期）。能见度与经济好坏无关——数据可以很好但能见度低（如关税政策反复），也可以数据疲弱但能见度高（如政策路径明确）。能见度低 → 降仓位、提安全边际；能见度高 → 趋势交易有效性提升。

**共识度**：市场对宏观方向的看法是否一致。高共识 = 方向对但赔率差（拥挤），需找二阶变量；低共识 = 赔率好但胜率不确定，需判共识收敛方向。

**分化度**：旧经济（地产/消费/传统制造）与新经济（AI/新能源/高端装备）走势是否同步。分化度高 → 总量指标解释力下降，结构性策略占优；分化度低 → 传统周期框架适用性回升，总量策略占优。

| 维度 | 高 | 低 |
|------|-----|-----|
| 能见度 | 趋势交易，方向性仓位 | 降仓位，提安全边际 |
| 共识度 | 警惕拥挤，找二阶变量 | 赔率好，判收敛方向 |
| 分化度 | 结构性策略，轻视总量 | 总量策略，传统框架适用 |

#### 债市看什么：旧经济+融资需求+内生动能+广谱价格

债市的核心是判断利率方向。利率由旧经济基本面和融资需求共同驱动。

1. **融资需求**：信贷规模是否超过季节性回升，贷款利率是否同步上行。如果社融放量+贷款利率上行，对债市明确负面。详见 `ref-framework_financing.md`
2. **旧经济（房地产）**：债市与旧经济相关度最高。房价、成交量、房地产投资增速好转 → 利率上行压力大。地产是利率的"锚"。详见 `ref-framework_transition.md`旧动能部分
3. **内生动能**：M1-M2剪刀差收敛、居民消费倾向回升 = 经济活力恢复 → 利率上行。内生动能不足 → 利率下行空间打开
4. **广谱价格动能**：PPI方向和核心CPI方向比headline CPI更重要。广谱价格上行（非猪周期驱动）→ 利率上行压力。详见 `ref-framework_nominal_price.md`

详细分析框架 → `ref-framework_market_focus.md`

#### 股市看什么：新经济（产业逻辑）+ 盈利分化

股市的核心是判断盈利方向和结构。在新旧动能切换期，结构比总量更重要。

1. **新经济（产业逻辑）**：股市看新经济，新动能的景气度和盈利能力决定股市方向。AI、新能源车、半导体等产业的景气周期和盈利兑现是股市最核心的基本面驱动。详见 `ref-framework_new_momentum.md`
2. **盈利分化**：新旧动能盈利增速差决定风格轮动。新动能盈利>旧动能 → 成长+科技占优；旧动能阶段性改善 → 周期+价值反弹。详见 `ref-framework_transition.md`
3. **名义GDP→企业盈利传导**：名义GDP回升 → 工业企业利润改善 → 上市公司盈利修复。这是股市最核心的盈利周期逻辑
4. **估值锚**：ERP（股权风险溢价）、中美利差（外资流向）、北向资金（增量资金）

详细分析框架 → `ref-framework_market_focus.md`

#### 股债联动

- "看着股票做债券"：股市强 → 风险偏好↑ → 债市承压
- 但不是机械负相关：流动性驱动时股债同涨，风险事件驱动时股跌债涨
- 温差期（基本面与微观感受有差距）可能股债同向看政策，温差收敛期才回归各自基本面
- **关键区别**：债市跟着旧经济走，股市跟着新经济走。旧经济企稳 → 债市压力；新经济景气 → 股市机会。两者可以同时发生

### 三、价格：通胀拉动类型与名义GDP修复路径

> PPI拉动类型 / 核心CPI方向 / 平减指数收敛速度 / 广谱性 / 通缩or再通胀

**强制前置步骤——PPI拉动类型判断**：每次涉及价格数据的分析，必须先用 `ref-framework_nominal_price.md` 中"快速判断表"定位当前PPI上行最接近哪种拉动类型，再据此推导资产含义。五种类型及其核心资产差异：

| 拉动类型 | PPI | 核心CPI | 产出 | 股市含义 | 债市含义 |
|---------|-----|---------|------|---------|---------|
| 需求拉动型 | ↑ | ↑ | ↑ | 全面利好 | 利率上行压力 |
| 成本推动型 | ↑ | ↓/持平 | 持平 | 中下游利空，上游受益 | 中性偏空 |
| 供给收缩型 | ↑ | 持平 | ↓ | 结构性利好去产能行业 | 视传导而定 |
| 外需输入型 | ↑ | 持平 | 持平 | 出口链+上游受益 | 冲击有限 |
| 猪周期噪音 | — | 持平 | — | 无意义 | 不改变方向 |

完整的CPI/PPI分项跟踪、翘尾新涨价拆解、高频价格指标 → `ref-framework_nominal_price.md` 和 `ref-handbook_prices.md`

### 四、经济结构与产业逻辑

> 新旧增速差 / AI链景气 / 新能源去化进度 / 出口份额变化 / 双速经济

**产业逻辑是股市最核心的基本面驱动，也是新旧动能转换的微观基础。** 每次报告必须包含产业结构段落，从新旧经济权重和增速差切入，再展开核心产业链。

#### 经济结构总览
新经济占GDP比重/贡献率 + 新旧经济利润增速差 + 投资增速差 → 量化表达"双速经济"特征。这段是宏观总量与产业细节之间的桥梁。

#### 旧经济：地产链与城投-基建链
地产链（房建+建材+家装+家电）GDP权重+拖累幅度 + 化债约束下城投-基建的收缩弹性 → 旧经济的"底"在哪里，收缩速度是否在放缓。

#### 新经济：三条核心产业链
- **AI/半导体链**（最主线）：全球半导体销售额增速、Hyperscaler Capex→中国中间品出口、国产替代进度、训练→推理过渡
- **新能源链**：NEV渗透率→盈利质量转变、光伏产能去化进度（硅料→组件价格链）、碳酸锂价格锚
- **高端装备**：工业机器人+国产化率、C919交付、商业航天产业化

#### 出口竞争力
从产业链视角看出口——哪些品类在持续获取全球份额（船舶、汽车、工程机械、机电中间品）。

详细行业框架与跟踪节奏（含高频/低频指标清单）→ `ref-framework_new_momentum.md`
